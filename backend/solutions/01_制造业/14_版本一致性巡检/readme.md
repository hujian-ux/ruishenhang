# 场景使用说明 · 版本一致性巡检（m3-4）

> 角色：研发 PE ｜ 行业：离散制造 ｜ 场景定位：每周定时扫描系统 vs 现场版本差异，生成分部门通知稿，每次巡检自动留痕应对 ISO 审核

## 场景一句话
P-IPC-01 智能控制柜，每周日 08:00 定时触发一次巡检，扫描 8 份受控文件。这一周发现 2 项不一致，AI 主动读懂台账里工艺/品质留的备注（"打印稿还没发下去""电子版还没打印"），把两项归口到执行侧延迟，生成的通知稿直接 @ 两位当事人。

## 文件清单
| 文件 | 角色 | 说明 |
|---|---|---|
| `03_技能包/版本一致性巡检/SKILL.md` | Skill 定义 | 4 步法与提示词 |
| `主提示词.md` | 主提示词 | 学员实际发送的训练提示词 |
| `系统受控清单.csv` | 原始输入 | 系统侧 8 份受控文件及版本 |
| `现场发放台账.csv` | 原始输入 | 现场侧 8 份发放版本及备注 |
| `版本一致性巡检表.csv` | **预期交付物** | 文件类型 × 系统版本 × 现场版本 × 一致性结论（含归口与待办） |

## 交付物验证记录
- `版本一致性巡检表.csv`：668 bytes，8 数据行（6 一致 / 2 不一致，与素材数字对齐）
- 两份源台账均已生成（各 8 行）
- 验证脚本：`gen_assets.py`（断言 size>0 且 行数>0，并校验 6/2 一致性分布）
- 关键数字对齐：8 份全量比对；2 项不一致 = 装配图纸 系统V2.1/现场V2.0、PLC程序 系统V3.0/现场V2.9；现场备注归口执行侧延迟。

## 使用步骤
1. 在 WorkBuddy 导入并启用本场景 Skill 包
2. 导出系统受控清单与现场发放台账（各 8 份受控文件）
3. 复制 `主提示词.md` 内容，粘贴两份台账并发送（或配置每周日 08:00 定时任务）
4. 查看逐项 diff 的一致性清单（6 一致 / 2 不一致）
5. 确认 AI 已将现场备注归口到执行侧延迟、分清研发/执行责任
6. 按分部门通知稿（工艺回收 / 品质校验 / 生产换 SOP）推送并追整改，巡检自动留痕
