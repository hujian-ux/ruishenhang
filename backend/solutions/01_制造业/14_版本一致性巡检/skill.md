# 版本一致性巡检 Skill

## 适用时机
- 研发 PE 每周抽查系统 vs 现场版本一致性（SOP / 图纸 / 规格书 / 作业指导）
- 痛点："系统里改了，现场还在用老版"是 ISO 审核与客户抽检抓的重点
- 目标：定时任务或一句话触发，10 秒完成全量 diff + 分部门通知稿 + 自动留痕

## 输入
- 系统侧受控版本清单（PLM/EDM 导出的当前受控版本）
- 现场侧发放台账（各工位实际在用版本 + 工艺/品质留的备注）

## 工作流（4 步）
1. **读两份清单** — 系统侧受控版本 + 现场侧发放台账
2. **逐项 diff** — 按料号 / 文件号对齐，生成 一致 / 不一致 清单
3. **读懂现场备注** — 工艺/品质在台账上留的"打印稿没发下去""电子版没打印"，自动归口到执行侧延迟原因
4. **生成通知稿** — 按岗位分段（工艺回收 / 品质校验 / 生产换 SOP），一键推 IM

## 输出
- 差异清单：一致 / 不一致 逐项结论
- 分部门待办通知稿（@ 相关当事人，责任面清楚）
- 每次巡检自动留痕，审核直接调取

## 关键规则 / 提示词
- 全量比对，不再抽查：人工只能挑几份、查哪几份靠习惯；这里 8 份受控文件逐项 diff 全跑
- 读懂现场备注：把"打印稿没发下去""电子版没打印"这类备注归口到执行侧延迟（不是研发发布问题），帮 PE 分清是研发还是执行的问题
- 状态表达用中性词 一致 / 不一致（对应行业红/绿，但不依赖颜色传达）
- 每次巡检结果写入台账，确保 ISO 审核可追溯
