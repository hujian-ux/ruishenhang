现状与痛点

这个场景的难点从来不是"检出不良"，而是检出之后那半天里，没人愿意签字。

拍板的人不是品质，材料要品质准备

这批发不发最终是老板或业务负责人拍的。品质工程师的真实角色是把判断依据凑齐、把后果说清楚。可现实是：异常照片往群里一发，生产说"不影响"、业务说"客户等着"、老板问"到底能不能发"——最后变成谁嗓门大听谁的。

耗时

最关键的那份判据，在别的部门手里

这批能不能让步，答案不在品质部，在销售保管的《客户质量协议》附件里。同一镀层发花缺陷，A 客户写明可让步，B 客户第 6.3 条写零缺陷。这道商务门槛比技术门槛硬，但品质部平时压根不持有这份文件。

高风险

抽样档位用错，把该放的批拦了下来

外观类次要缺陷本按 AQL2.5 判，功能类主要缺陷按 AQL1.0 判。现场检验员一把尺子量到底，把只影响外观的缺陷按主要缺陷接收数判不合格，本可放行的批被扣在仓库、拉去开会、走一遍特采。

成本浪费

"返工来得及吗"没人算得清

判返工的前提是返工真能在交期前干完：单件工时、能投几人、返工后是否全检、外协来回几天、修磨过量会不会超差。这些分散在班组长和外协厂口头承诺里，品质现场算不出，只能凭感觉说"应该赶得上"。

高风险

一个会在该停的地方停下来、并告诉你怎么解的助手，比一个永远给得出答案的助手可信。

传统做法

异常照片发群 → 生产说不影响、业务说客户等着 → 老板问"能不能发" → 凭"上次好像这么发过"拍一个 → 事后补一张特采单签字。客户协议没人查、先例没人查、返工来不来得及没人算，三样全靠猜。

WorkBuddy 做法

五份材料一次读齐 → 先过三条硬拦截红线（安全特性 / 合同零缺陷 / 影响无法评估）→ 按缺陷等级用正确 AQL 档位复核 → 三个批次给出三种不同结论（放行 / 返工后复检 / 暂缓放行），每条带证据出处、风险、代价 → 另附待确认事项清单 + 自动写进先例台账。

三个核心价值
01先拦红线，再谈取舍

三条红线一票否决：安全 / 特殊特性超差、合同写明零缺陷、影响无法评估。命中即禁止让步，不给模型任何裁量空间。中通汽零那批就是这么被拦下来的。
02把商务门槛摆到桌面上

让步能不能走，先查客户协议怎么写的。技术全过，协议锁死照样出局；反过来外观类缺陷有明文可让、还有先例可引的，就该痛快放行。判据带条款编号和版本号。
03不确定的明说，不硬写

拿不到的数据单独列一节：要向销售确认哪条款、向技术确认哪个图纸版本、要客户书面回函的哪一项，并附建议话术。敢说"这个我拿不到"，比什么都敢判更可信。

方案定位

不是替品质"定"结论，而是把判断依据凑齐、把后果说清楚，让能签字的人签。一个会在该停的地方停下来、并告诉你怎么解的助手，比一个永远给得出答案的助手可信。

解决方案的工作流程

从五份材料到一份能签字的决策单，5 步走完，每步可追溯到证据出处。

01读齐五份材料

检验记录 / 订单交期 / 客户协议 / 返工产能 / 先例台账，一次读齐。

02过红线拦截

安全特性 · 合同零缺陷 · 影响无法评估，命中即禁止让步。

03按档位复核判定

缺陷分 CR / MA / MI，对应 AQL 1.0 / 2.5 重算接收数。

04五档结论 + 代价

放行 / 返工 / 暂缓 / 让步 / 拒收，两边代价都摆出来。

05待确认 + 沉淀

要问谁什么 + 本次处置写进先例台账。

案例基本介绍

脱敏案例，展示从三张"不合格"单到三种不同处置结论的全过程。品质工程师不是判官，而是把依据凑齐让老板签的人。

脱敏案例：华锐机电 · 2026-08-08 下午

三个批次明后天陆续要发，全部检出异常。品质工程师王敏手上三张 OQC 不合格单：恒达重工的液压阀体（密封面加工痕）、中通汽零的制动支架（孔位偏移）、华东电气的电磁阀壳体（镀层发花），交货日分别 08-09、08-10、08-11。三张单在系统里长得一样——都是"不合格"。但把客户协议、返工产能、成品库存、先例台账拉进来一起看，三批的出路完全不同。

提示词
TRAINING PROMPT · 复制即用
请基于以下四份素材，为脱敏案例「华锐机电 · 2026-08-08」的三个待发批次出具一份能签字的交付风险评估决策单，严格按 5 步输出。

【输入 1 · 检验记录（OQC 不合格单）】（节选自 检验记录_OQC不合格单.csv）
- B-0809 恒达重工 液压阀体 320 件 密封面加工痕 交货 08-09
- B-0810 中通汽零 制动支架 600 件 孔位偏移 交货 08-10
- B-0811 华东电气 电磁阀壳体 480 件 镀层发花 交货 08-11
- 系统判定：三批全部「不合格」，但正确结论应各不相同

【输入 2 · 客户质量协议条款】（节选自 客户质量协议条款.csv）
- 恒达重工 V3.2：一般外观/尺寸，双方确认后可让步
- 中通汽零 V2.0 第 6.3 条：零缺陷交付，供方不得让步接收不合格品
- 华东电气 V1.8：外观类次要缺陷，双方确认后可让步（有先例）

【输入 3 · 返工产能】（节选自 返工产能.csv）
- B-0809 修磨 5.0 工时/件，可投 2 人，返工后复检；先发库存 200 件保上线，缺口 120 件返工后补
- B-0810 孔位偏移不可返修，挑选后剩 564 件，补产需 6 天
- B-0811 无需返工

【输入 4 · 先例台账】（节选自 先例台账.csv）
- 华东电气 2025-11 镀层发花 → 放行（AQL2.5 + 协议可让）
- 恒达重工 2025-06 密封面加工痕 → 返工后复检
- 中通汽零 2024-09 尺寸超差 → 拒收隔离（命中零缺陷）

【输出要求】
1. 先过三条硬拦截红线（安全/特殊特性超差 · 合同零缺陷 · 影响无法评估），命中即禁让步
2. 按缺陷等级用正确 AQL 档位复核：MI 用 AQL2.5（抽 32 件 Ac=2），MA 用 AQL1.0（抽 32 件 Ac=1）
3. 三个批次各给一档结论（放行 / 返工后复检 / 暂缓放行 / 让步接收 / 拒收隔离），每条带证据出处、风险与代价
4. 待确认事项清单：要向销售确认哪条款、向技术确认哪个图纸版本、要客户书面回函哪一项
5. 把本次处置写进先例台账

关键数字：三批共 1,400 件；华东电气镀层发花 MI、AQL2.5 抽 32 件 Ac=2 实测 2 件本就合格；中通汽零补产需 6 天而交期剩 3 天。
生成后自检：红线是否先判？AQL 档位是否用对？五档是否都带证据与代价？确认无误再输出决策单。
