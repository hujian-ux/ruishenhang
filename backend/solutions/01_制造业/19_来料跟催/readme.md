# M6-2 来料跟催 · 场景资产说明

> 行业：离散制造 ｜ 岗位：采购 ｜ 脱敏案例：恒信精密机械 ｜ 分析基准日：2026-08-04

"按逾期天数拍脑袋催料"会漏掉真正要催的命单、又会去催一堆根本不急的。本场景用
**供应商履约画像 → 预测到货日 → 断料日 → 缺口天数 → 四色分级 → 跟催话术**，
把 18 张在途单精准排成 🔴3 / 🟡4 / 🟢6 / ⚪5，真紧急只有 3 张（其中 2 张还没到承诺期）。

## 二、案例设定

### 18 张在途采购单（6 家供应商 / 13 项物料）

下游 18 张工单于 2026-08-06 ~ 2026-09-08 陆续上线，关键物料覆盖主控板 / 连接器 / 面漆 /
轴承 / 软管 / 螺栓 / 齿轮 / 冷轧板 / 密封条等。基准日 2026-08-04 早上，8 张已逾期、10 张未逾期。

合计 18 张 / 6 家 / 13 项物料；真紧急仅 3 张，其中 2 张尚未到承诺期。

### 关键反差：逾期 ≠ 紧急

- **PO-2607-8836 冷轧板 SPCC 2.0mm**：承诺 2026-07-30，已逾期 **5 天**，但下游 WO-2609-005
  2026-09-08 才上线、库存可撑 18.7 天 → 断料日 2026-09-26、缺口 **−47 天** → **⚪ 逾期但不急**
  （传统按逾期排第 2，但本周完全不用催）。
- **PO-2607-8858 主控板 A 版**：承诺 2026-08-06，**未逾期**，但供应商 S-021 准时率仅 61.5%、按历史
  推算 2026-08-11 到货；下游 WO-2608-024 2026-08-08 上线、库存仅够 1.0 天 → 断料日 2026-08-09、
  缺口 **+2 天** → **🔴 紧急催**（传统排序根本排不到它，却是最该今天催的命单）。

### 跟催话术（7 条，四要素齐全）

对 3 张 🔴 + 4 张 🟡 各生成一条话术，均含「履约数据 + 预测结果 + 后果 + 具体请求」。
例（PO-2607-8858）：捷元电子科技近 6 月 13 单准时 8 单、准时率 61.5%、平均晚 4.2 天、波动 0.84；
预计 2026-08-11 到；WO-2608-024（主机厂A）08-08 上线、库存只够 1.0 天、08-09 断料、PPAP Level 3
锁定不能替；请求 08-08 12:00 前先分批空运 60 pcs、今日 18:00 前回运单号。

## 四、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」入口点击「添加技能 → 上传技能」，
   导入本场景 Skill 包（`03_技能包/来料跟催/SKILL.md` 所在文件夹），并在「已安装」列表中启用。
2. 从 ERP 导出 `01_在途采购单.csv`、`03_下游工单上线计划.csv`、`04_物料库存与日均用量.csv`，
   确认在途单含**承诺到货日**、工单含**上线日**、库存含**日均用量**（缺列则断料日算不准）。
3. 补齐 `02_供应商逐单履约记录.csv`：近 6 个月每张单的承诺/实际到货，用于反算履约画像；
   缺这份则预测退化为承诺日，须显式标注。
4. 复制 `主提示词.md` 中的主提示词整段发送，注意基准日与企业名按实际替换。
5. 核对：排序是否按缺口天数、预测是否叠历史延误、断料日是否向下取整、🔴 是否当日升级。
6. 把 🔴/🟡 话术与责任人时点派发；⚪ 只登记纳入月度考核；准时率<70% 的供应商列为重点辅导。
