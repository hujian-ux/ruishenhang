# 主提示词 · 对账与开票核对

> 把下面提示词直接复制发给 WorkBuddy（已启用「对账与开票核对」技能），并将 4 份 CSV 一并上传。

```
请基于以下 4 份素材，为「恒信精密机械 · 某主机厂 2026-07 对账」完成一份对账差异核对，严格按 5 段输出。

【输入素材】
1. 客户对账单.csv：客户侧，含 對賬單编号 / 客戶零件號 / 含稅單價 / 数量 / 金額(含税)，共 39 行
2. 我方出货明细.csv：我方侧，含 送货单号 / 客户零件号 / 本厂料号 / 未税单价 / 数量 / 金额(未税)，共 42 行
3. 价格表.csv：客戶零件號 ↔ 本厂料号、含税 ↔ 未税 映射换算依据
4. 回执台账.csv：送货单号 → 回执单号 / 状态（已签 / 缺失）

【输出要求】
1. 字段映射：客戶零件號→本厂料号、含税↔未税按税率换算、繁→简，自动识别对应关系，不用手工建表。
2. 单号归一：039A→039、简写→完整，建立客户行↔我方行对应。
3. 逐行匹配：以「日期+料号+数量」三维匹配，区分双边行与单边行。
4. 五类差异归口：数量差/单价差/税率差/期间归属/回执缺失，每类附归口判定
   （数量以签收为准、期间保留出货月、税率需协商、回执缺失请补录、单价以报价+价格表为准）。
5. 对账开票核对表 + 对客回函稿：差异清单列「差异单号/本厂料号/差异类型/我方口径/客户口径/差额/归口判定/处置建议」，
   合计差额单独成行；回函逐条对应差异明细，财务复核关键项后即可发出。

生成后自检：客户少记与双方口径差是否分开列示？回执缺失项是否标了"请客户补录"？最大单笔差异是否点名？
```

## 说明
- 本提示词对齐案例：客户 39 行对账单 vs 我方 42 行出货明细，双方 48,880 元差额 5 分钟归口。
- 期望产出：`对账开票核对表.csv`（7 笔差异 + 合计 48,880 元）+ 对客回函稿。
- 归口判定为规则驱动（数量以签收为准、期间保留出货月、回执缺失需补录），避免财务与销售拍脑袋吵架。
