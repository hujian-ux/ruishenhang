现状与痛点

财务月末对账 —— 每月准时准点撕逼，财务和销售一起煎熬。一份对账单捏在手里 3 天也理不清。

客户格式和我方对不上

客户发来"對賬單编号 / 客戶零件號 / 含稅單價"繁体+客户零件号+含税单价；我方用"送货单号 / 本厂料号 / 未税单价"，光字段映射就要半天。

高频
单号不一致最费神

客户回执写"DN-20260729-039A"我方只有"DN-20260729-039"；或客户把"DN-20260705-0A"简写。财务一个个手工归一，挂错单是常态。

耗时
差异来源五花八门

数量差 / 单价差 / 税率差 / 期间归属 / 回执缺失，5 类差异要分门别类归口，一份对账单 3 天理不清。

高风险
回函写起来更痛苦

每笔差异都要写清"谁的口径 / 我方结论 / 处置建议"，财务一天写不完，客户等着回款、开票排队、老板每天问一遍。

成本浪费

把对账做成'字段映射 + 单号归一 + 五类差异归口 + 自动回函'——规则透明可复核，不再是财务和销售拍脑袋吵。

WorkBuddy 的解决与价值

WorkBuddy 把对账做成一条标准生产线：财务只提供客户对账单 + 我方出货 + 价格表 + 回执台账，AI 自动完成字段映射、单号归一、逐行匹配、五类差异归口，并生成可发出去的对客回函。

传统做法

财务手工映射字段 → 逐行匹配 → 归类差异 → 写回函，3 天起步，客户等着回款；大对账单能对到吵架，谁都不愿先认账。

WorkBuddy 做法

拖入 4 份文件 → 一句触发 → 5 分钟拿到 7 笔差异清单 + 差额分解 + 对客回函稿，财务只需复核关键项就能发出。

三个核心价值
01字段映射自动

繁→简、客户零件号→本厂料号、含税↔未税，AI 自动识别对应关系，财务不用手工建映射表。

02五类差异归口

数量差 / 单价差 / 税率差 / 期间归属 / 回执缺失，每类附归口判定（客户少记 / 双方口径差），结论可追溯。

03对客回函自动

差异清单直接生成回函文字，格式规范、逐条对应差异明细，财务复核后一键发出，不再逐条手写。

方案定位

不是替财务写对账，而是把"映射 + 归一 + 归口 + 回函"做成可复跑的生产线，把 3 天的对账压缩到 5 分钟。

解决方案的工作流程

整个流程完全自动，财务只在最后做关键项复核，共 5 步。

01字段映射

繁→简 + 含税↔未税换算，客戶零件號→本厂料号，AI 自动识别对应关系。

02单号归一

039A→039、简写→完整，建立客户行↔我方行对应，不再手工挂单。

03逐行匹配

以日期 + 料号 + 数量三维匹配，区分双边行与单边行。

04差异分类

五类差异 + 归口判定：数量以签收为准、期间保留出货月、回执缺失需补录。

05生成回函

输出差异清单 + 我方结论 + 处置建议，财务复核关键项后即可发出。

案例基本介绍

脱敏案例，展示从 4 份表到完整对账差异核对与回函的全过程。对账是财务和销售每月都要面对的"撕逼现场"。

脱敏案例：恒信精密机械 · 某主机厂 2026-07 对账

每月月末，客户 39 行对账单与我方 42 行出货明细对不上，双方差 48,880 元。WorkBuddy 一次读齐 4 份文件，5 分钟把差异归口到 7 笔：4 笔归客户少记（回执缺失 + 期间归属）、3 笔归双方口径差（单价 / 税率 / 数量）。其中最大单笔 33,900 元是客户对账单遗漏的 DN-028 回执缺失项，附上回执扫描件客户可立即认账——对账从"吵架"变成"核对"。

【输入素材】
1. 客户对账单.csv：客户侧，39 行，含 對賬單编号 / 客戶零件號 / 含稅單價 / 数量 / 金額(含税)

3. 价格表.csv：客戶零件號 ↔ 本厂料号、含税 ↔ 未税 映射换算依据
4. 回执台账.csv：送货单号 → 回执单号 / 状态（已签 / 缺失）

【输出要求】
1. 字段映射：客戶零件號→本厂料号、含税↔未税按税率换算、繁→简，自动识别对应关系
2. 单号归一：039A→039、简写→完整，建立客户行↔我方行对应
3. 逐行匹配：以「日期+料号+数量」三维匹配，区分双边行与单边行
4. 五类差异归口：数量差/单价差/税率差/期间归属/回执缺失，每类附归口判定
 （数量以签收为准、期间保留出货月、税率需协商、回执缺失请补录、单价以报价+价格表为准）
5. 对账开票核对表 + 对客回函稿：差异清单列「差异单号/本厂料号/差异类型/我方口径/客户口径/差额/归口判定/处置建议」，合计差额单独成行
