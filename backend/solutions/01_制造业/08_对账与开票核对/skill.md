# 对账与开票核对 · SKILL

## 适用时机
- 月末/季度末与客户对账，双方金额对不上、谁都不愿先认账。
- 客户用繁体+客户零件号+含税单价，我方用送货单号+本厂料号+未税单价，字段对不上。
- 单号带后缀（如 `DN-20260729-039A`）或简写（如 `DN-20260705-0A`），手工归一耗时。
- 需要一份"差异清单 + 归口判定 + 处置建议"的对客回函，而不是一堆待解问题。

## 输入（4 份）
1. `客户对账单.csv`：客户侧，含 對賬單编号 / 客戶零件號 / 含稅單價 / 数量 / 金額(含税)
2. `我方出货明细.csv`：我方侧，含 送货单号 / 客户零件号 / 本厂料号 / 未税单价 / 数量 / 金额(未税)
3. `价格表.csv`：客戶零件號 ↔ 本厂料号、含税 ↔ 未税 的映射换算依据
4. `回执台账.csv`：送货单号 → 回执单号 / 状态（已签 / 缺失），用于判别回执缺失类差异

## workflow
1. **字段映射**：把客户字段翻译成本厂口径——客戶零件號→本厂料号（查价格表），含税↔未税按税率换算，繁→简。
2. **单号归一**：去掉客户单号后缀/简写，统一成我方系统单号（如 `039A→039`、`0A→`完整号），建立 客户行 ↔ 我方行 的对应。
3. **逐行匹配**：以「日期 + 料号 + 数量」三维匹配，找出两边都有的行与仅单边有的行。
4. **差异分类（五类）**：数量差 / 单价差 / 税率差 / 期间归属 / 回执缺失；每类给**归口判定**：
   - 数量差：以签收单为准
   - 期间归属：保留出货月
   - 税率差：需协商统一口径
   - 回执缺失：需客户补录回执
   - 单价差：以我方报价单价 + 价格表为准
5. **生成回函**：输出「差异清单 + 我方结论 + 处置建议」文字稿，财务复核关键项后即可发出。

## 输出
- `对账开票核对表.csv`：差异单号 / 本厂料号 / 差异类型 / 我方口径 / 客户口径 / 差额 / 归口判定 / 处置建议，最后一行为合计。
- 对客回函稿（Markdown）：逐条对应差异明细，格式规范、可复核。

## 关键规则 / 提示词要点
- 归口判定是**规则驱动**，不是主观拍脑袋：数量以签收为准、期间保留出货月、回执缺失请客户补录。
- 把"客户少记"与"双方口径差"分开列示，便于客户快速认账（回执缺失类客户可立即认账）。
- 估算与确定项分开标注；回函只对确定的差异下结论，存疑项标"待协商"。

## 案例基准（恒信精密机械 · 某主机厂 2026-07 对账）
- 我方 42 行（未税）合计 1,551,432 元；客户 39 行（含税）合计 1,502,552 元。
- 7 笔差异归口，净差额 48,880 元：4 笔归客户少记（回执缺失 + 期间归属），3 笔归双方口径差（单价/税率/数量）。
- 最大单笔 33,900 元（DN-028 回执缺失），附回执扫描件客户可立即认账。
