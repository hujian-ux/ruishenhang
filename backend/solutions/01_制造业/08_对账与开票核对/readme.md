# 对账与开票核对 · 场景资产说明与验证记录

## 场景概述
离散制造财务岗位场景。把客户对账单 + 我方出货明细 + 价格表 + 回执台账一次读齐，自动完成字段映射、单号归一、逐行匹配、五类差异归口，并生成可发出去的对客回函。
