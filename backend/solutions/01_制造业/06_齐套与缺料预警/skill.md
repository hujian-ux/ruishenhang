# 齐套与缺料预警 · 六条化解路径

## 一、适用时机

命中以下任一表述即启用本技能：

- 「这几张工单能不能开工」「齐套率算一下」「缺料预警」
- 「MRP 报缺了，怎么办」「缺口怎么化解」
- 「能不能用替代料」「库里有没有类似料能顶」
- 「要不要走紧急采购」「要不要跟客户改交期」
- 「呆滞料能不能用掉」

**不适用**：单纯查库存余额、单纯算 MRP 净需求、供应商询价比价（走「来料跟催」或「询价比价」技能）。

## 二、核心原则（违反即结论不可信）

### 原则 1 · 可用库存四项扣减，禁止用总库存算齐套

```
可用库存 = 总库存 − 安全库存 − 已分配他单 − IQC 待检
```

必须**双口径并列输出**：总库存口径齐套率 vs 可用库存口径齐套率。
两者差距越大，说明原有报表的"假齐套"越严重。总库存口径 100% 而可用口径只有 16.7%，
就是"开线当天才发现料动不了"的根因。

### 原则 2 · 先剔伪缺口，再谈化解

```
若（该物料在途数量 ≥ 毛缺口）且（在途承诺到货日 ≤ 该物料所在工序的需料日）
   → 伪缺口，真缺口 = 0，不进入路径判定
否则 → 真缺口 = 毛缺口
```

**工序需料日 = 工单需料日 + BOM 中该物料所属工序的偏移天数**。
后序工序的物料不能拿工单开工日去比，否则会把在途能覆盖的缺口误判成真缺口，
为伪缺口付现货溢价。

### 原则 3 · 六条路径有先后，不是并列

漏斗顺序固定，**必须逐条自上而下判定，上一条不可用才看下一条**：

| 顺序 | 路径 | 消耗现金 | 动客户 | 说明 |
|---|---|---|---|---|
| 01 | 替代料 | 否（仅差价） | 视 PPAP | 用已有资源 |
| 02 | 呆滞料反查 | 否 | 视 PPAP | 用已有资源，还能消化库存 |
| 03 | 分批投产 | 否 | 否 | 只换口径，用时间腾挪 |
| 04 | 紧急采购 | **是** | 否 | 开始花钱 |
| 05 | 调整交期 | 否 | **是** | 代价最高 |
| 06 | 拆单 | 否 | **是** | 单件成本上升 |

顺序错了就会为伪缺口付溢价、为能用的呆滞料花现货钱。

### 原则 4 · 替代料四道校验，缺一道即不可用

1. **客户认可** —— 硬门槛，第一道。客户 PPAP 锁定料号或原材料规格 → 直接出局，技术全过也没用。
2. **技术等效** —— 图纸公差是否覆盖实测值、是否 Pin-to-Pin、老化与 EMC 复测结论。
3. **是否需重新首件** —— 需 FAI 则写入前置条件并计工期。
4. **成本差异** —— 单位差价 × 投用量，计入代价栏。

呆滞料反查沿用同样四道校验，只是第二道换成「实测值 vs 图纸公差区间」。

### 原则 5 · 同一批料在不同工单上结论可以相反

判定必须**按「工单 × 物料」逐条做，不能按物料一刀切**。
同产品、同图纸、同一批呆滞料，客户 A 按图纸验收可用，客户 B 有 PPAP 锁定就被否决。
输出中必须把这种反差显式写出来，这是本技能最有说服力的部分。

### 原则 6 · 缺口必须收敛验算到 0

```
真缺口合计 − Σ各路径化解量 = 剩余未化解缺口
```

剩余 > 0 的必须单独列⚪档并写明升级对象。不允许"大概能搞定"。

## 三、输入（七份数据）

| 序号 | 文件 | 关键字段 |
|---|---|---|
| 01 | 待开工工单.csv | 工单号、产品编码、客户、计划台数、工单需料日、客户交货日 |
| 02 | BOM用量表.csv | 产品编码、物料编码、单台用量、单位、所属工序、工序需料日偏移(天) |
| 03 | 库存可用量表.csv | 总库存、安全库存、已分配他单、IQC待检、标准单价 |
| 04 | 在途采购单.csv | 采购单号、物料、在途数量、承诺到货日 |
| 05 | 替代料清单.csv | 原料号、替代料号、技术验证结论、客户认可口径、是否需重新首件、成本差异、替代料可用库存 |
| 06 | 呆滞料库龄与实测.csv | 批次号、数量、库龄、标称厚度、实测厚度、实测报告号、已计提跌价比例 |
| 07 | 图纸公差与PPAP约束.md | 图纸公差区间、客户 PPAP 等级、原材料规格是否锁定、变更周期、现货报价 |

缺任一份都要**显式提示缺哪份、会导致哪条路径判不了**，不得静默跳过。

## 四、工作流程（5 步）

### STEP 1 · 导入七份数据并对齐口径
读全 7 份，核对物料编码/产品编码/工单号能否交叉对上；对不上的行单独列出，不猜。

### STEP 2 · 算准可用库存（双口径并列）
逐物料算 `可用库存 = 总库存 − 安全 − 已分配 − 待检`；
同时给出总库存口径与可用库存口径的齐套率对照表。

### STEP 3 · 定位真缺口（按工序需料日重判）
1. 展开 `工单 × BOM` 得到每行需求量 = 单台用量 × 计划台数；
2. 计算每行的工序需料日 = 工单需料日 + 工序偏移；
3. 同一物料按**工序需料日先后**逐单锁定可用库存，得每行 `本单可用分配` 与 `毛缺口`；
4. 按原则 2 判 `伪缺口 / 真缺口`。

### STEP 4 · 六条路径漏斗逐条判定
对每条真缺口，**六条路径全部给结论**（可用 / 不可用 / 不启用 + 理由），
命中的那条额外给四栏：**可行性、代价（带金额或工期数字）、风险、前置条件**。

### STEP 5 · 三色结论 + 收敛验算 + 成本净影响
- 工单级三色：🟢 可按计划开工 / 🟡 有条件开工 / 🔴 需升级决策；取该工单**最差档**；
- 每张工单写清：缺什么、走哪条路、**谁**在**什么时点**做完**什么**；
- ⚪ 剩余未化解缺口做收敛验算；
- 材料成本净影响 = 紧急采购溢价 + 替代料成本差异 − 呆滞损失避免。

## 五、输出（齐套缺料预警表）

主表逐行 = `工单 × 物料`，列序固定：

```
工单号 / 产品编码 / 产品名称 / 客户 / 计划台数 / 工单需料日 / 所属工序 / 工序需料日 /
物料编码 / 物料名称 / 单台用量 / 单位 / 需求量 /
总库存 / 安全库存 / 已分配他单 / IQC待检 / 可用库存 / 本单可用分配 / 毛缺口 /
在途单号 / 在途数量 / 在途到货日 / 缺口性质 / 真缺口量 /
命中化解路径 / 化解量 / 代价 / 风险 / 前置条件 / 剩余缺口 /
工单预警结论 / 责任人 / 完成时点
```

主表之后附 6 张汇总：
1. 双口径齐套率对照
2. 缺口性质判定（剔伪缺口）
3. 六条路径逐条判定明细
4. 三色开工结论
5. 缺口收敛验算
6. 材料成本净影响

## 六、输出前自检清单

- [ ] 可用库存是否用了四项扣减，没有直接拿总库存？
- [ ] 双口径齐套率是否并列给出？
- [ ] 每条毛缺口是否都按**工序需料日**（不是工单需料日）与在途到货日比过？
- [ ] 六条路径是否**逐条**给了结论，而不是只写命中的那条？
- [ ] 替代料/呆滞料判定是否第一道先过「客户认可」？
- [ ] 是否存在同一批料在不同工单结论相反的情况，是否已显式写出？
- [ ] 三色结论每张工单是否都有责任人 + 完成时点？
- [ ] 缺口收敛验算是否为 0？不为 0 是否列了⚪档与升级对象？
- [ ] 代价栏是否都是可核对的数字（金额/天数），没有"较高""略贵"这类模糊词？

## 七、禁止事项

- 禁止用总库存算齐套率而不标注口径。
- 禁止跳过某条路径不给结论（哪怕是"不启用"也要写）。
- 禁止在客户认可未确认的情况下把替代料判为"可用"。
- 禁止给出没有责任人和时点的结论。
- 禁止在缺口未收敛为 0 时输出"全部化解"。
- 禁止把后序工序物料的在途到货日与工单开工日比较。
