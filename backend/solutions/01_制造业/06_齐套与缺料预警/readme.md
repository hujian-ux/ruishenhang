# M6-1 齐套与缺料预警 · 场景资产说明

> 行业：离散制造 ｜ 岗位：采购 ｜ 脱敏案例：恒信精密机械 ｜ 分析基准日：2026-08-04

MRP 只告诉你缺多少，本场景回答**缺口怎么化解**：替代料 → 呆滞料反查 → 分批投产 →
紧急采购 → 调整交期 → 拆单，六条路径逐条判定可行性、代价、风险、前置条件，
最后给三色开工结论与责任人时点。

### 关键洞察：同一批呆滞料，两张工单结论相反

呆滞批 **B-2412-07**（库龄 248 天，320 kg，实测厚度 **1.92 mm**，报告 QR-2412-0731）：

- **WO-2608-001（P-BRK-03 / 华东电气）** → 图纸 GT-BRK-03-C 公差 2.0±0.10（1.90~2.10）覆盖 1.92，
  客户按图纸验收、无 PPAP 锁定 → **可用，全额投用 320 kg**
- **WO-2608-002（P-BRK-03 / 主机厂A）** → 同产品、同图纸、同一批料，公差同样覆盖，
  但原材料规格已随 PPAP Level 3 获批，厚度 1.92 属材料变更点须客户书面批复、PSW 重签 4-6 周 → **否决**
- **WO-2608-005/006（P-ENC-07）** → 图纸 GT-ENC-07-B 公差 2.0±0.05（1.95~2.05），
  1.92 低于下限 → **技术上即不可用**

区别只在「有没有 PPAP」和「图纸公差差 0.05」——这两个字段 ERP 里都没有。

## 四、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」入口点击「添加技能 → 上传技能」，
   导入本场景 Skill 包（`03_技能包/齐套与缺料预警/SKILL.md` 所在文件夹），并在「已安装」列表中启用。
2. 从 ERP 导出 `01_待开工工单.csv`、`02_BOM用量表.csv`、`03_库存可用量表.csv`、`04_在途采购单.csv`，
   确认库存表含**安全库存 / 已分配 / IQC待检**三列（缺列则可用库存算不准）。
3. 补齐 ERP 之外的三份：`05_替代料清单.csv`、`06_呆滞料库龄与实测.csv`、`07_图纸公差与PPAP约束.md`。
4. 复制 `主提示词.md` 中的主提示词整段发送。
5. 核对：双口径齐套率是否并列、伪缺口是否被剔掉、六条路径是否逐条给结论、缺口是否收敛为 0。
6. 把三色结论按责任人与完成时点派发；🔴 档当日升级。
