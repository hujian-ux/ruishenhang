现状与痛点

MRP 跑完给出一串缺口数字，然后就停了。真正决定「这单能不能开」的判断，全在人的脑子里——而它依赖的四类信息，一样都不在 ERP 的计算范围内。

MRP 算得出缺口，答不出怎么办

系统报「M-SPCC-20 缺 532 kg、M-PCB-001 缺 60 pcs」就结束了。接下来能不能用替代料、库里那批呆滞板材规格接近能不能顶、要不要花钱买现货，全靠人问一圈。

高频
库存看着够，开工才发现动不了

M-PCB-001 总库存 320 pcs，MRP 里显示不缺。扣掉安全库存 80、被在制工单已分配 100、IQC 未放行待检 20，真正可用只有 120 pcs。用总库存算出的「齐套」是假齐套。

高风险
技术上能替，客户不认也白搭

M-PCB-002 与 M-PCB-001 Pin-to-Pin 兼容、过了 1000h 老化与 EMC 复测。但主机厂A 的 PPAP 已锁定料号，要换就得重走 PPAP Level 3 含 PSW 重签，周期 4-6 周。

高风险
为伪缺口付了现货溢价

4 项报缺里有 2 项挂在后序工序，在途到货早于工序需料日，根本不缺。拿工单开工日去比就会误判成真缺口，白付 18% 现货溢价。

成本浪费

「判断要靠图纸公差、客户 PPAP 约束、呆滞料实测值、供应商 MOQ 四类信息，它们分散在图纸、PPAP 文件、库龄表、供应商邮件里——一样都不在 ERP 里。」

WorkBuddy 的解决与价值

先把口径算准，再按漏斗顺序过六条路径，每条给可行性 + 代价 + 风险 + 前置条件，最后落到三色结论和责任人时点。

传统做法

MRP 出缺口清单 → 采购凭经验想办法 → 问工艺能不能替、问仓库有没有类似料、问供应商能不能催 → 各方口头答复散在微信里 → 最后拍一个方案。替代料被客户否决、呆滞料能用却没想到、为伪缺口付了溢价，都是常见结果。

WorkBuddy 做法

七份数据一次读完 → 可用库存按四项扣减算准（双口径并列）→ 剔掉 2 项伪缺口 → 六条路径按漏斗顺序逐条判定（先用已有资源、再用时间腾挪、最后才花钱或动客户）→ 532 kg 与 60 pcs 全部化解、收敛验算为 0 → 6 张工单三色结论，每张写清缺什么、走哪条路、谁在什么时点做完什么。

三个核心价值
01路径有先后，不是并列

替代料 / 呆滞料反查不花钱不延期，必须先试；分批投产只换口径不消耗物料；紧急采购开始花钱；调整交期动客户代价最高。顺序错了就会为伪缺口付溢价，为能用的呆滞料掏现货钱。

02替代料四道校验，缺一道即不可用

客户认可 / 技术等效 / 是否需重新首件 / 成本差异。第一道是硬门槛——技术全过、PPAP 锁料号照样出局。同一颗替代料，华东电气可以用、主机厂A 不能用。

03结论落到人和时点，可被审计

六条路径每条都给结论（含「不启用」及理由），形成可向上解释的决策链；三色结论每张工单带责任人与完成时点，🔴 档当日升级。缺口收敛验算必须为 0。

方案定位

不是替采购做决定，而是把「口径算准 → 伪缺口剔除 → 六条路径漏斗 → 三色结论」做成可复跑、可复算、可审计的决策链，让每一笔溢价支出都是最后手段。

解决方案的工作流程

从七份数据到三色开工结论，共 5 步，每一步都可验算。

01导入七份数据

工单 / BOM / 库存可用量 / 在途单 / 替代料 / 呆滞料实测 / 图纸公差与 PPAP，缺哪份显式提示。

02算准可用库存

总库存 − 安全 − 已分配 − 待检；总库存口径与可用口径双口径并列，暴露假齐套。

03定位真缺口

按工序需料日（工单需料日 + 工序偏移）重判，在途早于需料日的剔为伪缺口。

04六条路径漏斗

逐条判可行性 / 代价 / 风险 / 前置条件，替代料与呆滞料先过客户认可硬门槛。

05三色结论与验算

工单级三色结论 + 责任人 + 时点，缺口收敛验算归零，出材料成本净影响。

案例基本介绍

脱敏案例，展示从七份数据到三色开工结论的全过程。分析基准日 2026-08-04，恒信精密机械 8 月上旬 6 张待开工工单。

脱敏案例：恒信精密机械 · 6 张工单 630 台

6 张已下达待开工工单，涉及三个产品（制动支架总成 / 电控主控模块 / 编码器机箱）、两个客户（华东电气 / 主机厂A）。MRP 跑出四项物料报缺，但其中两项是伪缺口——密封条挂 OP40 总装、轴承挂 OP30 压装，在途到货都早于工序需料日。真缺口只有 M-SPCC-20 冷轧板 532 kg 和 M-PCB-001 主控板 60 pcs。难点在于：主板的替代料对华东电气能用、对主机厂A 被 PPAP 否决；同一批呆滞板材对制动支架落在图纸公差内可用、对编码器机箱超出下限。同一批料、同一份图纸，换个客户结论就反了。

提示词
TRAINING PROMPT · 复制即用
请以离散制造采购岗位的身份，基于我上传的 7 份数据做「齐套与缺料预警」，分析基准日 2026-08-04，企业：恒信精密机械。

【输入】
1. 01_待开工工单.csv：工单号、产品编码、客户、计划台数、工单需料日、客户交货日
2. 02_BOM用量表.csv：产品编码、物料编码、单台用量、单位、所属工序、工序需料日偏移(天)
3. 03_库存可用量表.csv：总库存、安全库存、已分配他单、IQC待检、标准单价
4. 04_在途采购单.csv：采购单号、物料、在途数量、承诺到货日
5. 05_替代料清单.csv：技术验证结论、客户认可口径、是否需重新首件、成本差异、可用库存
6. 06_呆滞料库龄与实测.csv：批次号、数量、库龄、标称厚度、实测厚度、已计提跌价比例
7. 07_图纸公差与PPAP约束.md：图纸公差区间、两客户 PPAP 等级与原材料规格是否锁定、现货报价

【硬性计算口径】
1. 可用库存 = 总库存 − 安全库存 − 已分配他单 − IQC待检。禁止用总库存算齐套。
2. 工序需料日 = 工单需料日 + BOM 中该物料的工序偏移天数。
3. 需求量 = 单台用量 × 计划台数；同一物料按工序需料日先后逐单锁定可用库存。
4. 伪缺口判定：在途数量 ≥ 毛缺口 且 在途到货日 ≤ 工序需料日 → 伪缺口，真缺口记 0。
5. 六条路径按漏斗顺序逐条判定，顺序不可颠倒：
 01 替代料 → 02 呆滞料反查 → 03 分批投产 → 04 紧急采购 → 05 调整交期 → 06 拆单
6. 替代料/呆滞料四道校验：客户认可（硬门槛，第一道）→ 技术等效 → 是否需重新首件 → 成本差异，缺一道即不可用。
7. 判定按「工单 × 物料」逐条做。同一批料在不同客户的工单上结论可以相反，请显式写出反差。

【输出要求】
1. 双口径齐套率对照表：总库存口径 vs 可用库存口径，并说明"假齐套"从何而来
2. 缺口性质判定表：毛缺口 / 在途 / 到货日 / 最晚工序需料日 / 性质 / 真缺口量，指明哪几项是伪缺口
3. 六条路径逐条判定矩阵：行=每条真缺口，列=六条路径，每格给结论+带数字的理由；命中的那条补可行性/代价/风险/前置条件
4. 齐套缺料预警表主表：逐行 = 工单 × 物料，含可用库存明细、缺口性质、命中路径、剩余缺口、工单结论、责任人、完成时点
5. 三色开工结论：🟢可按计划开工 / 🟡有条件开工 / 🔴需升级决策 / ⚪剩余未化解缺口，取该工单最差档
6. 缺口收敛验算（必须为 0）+ 材料成本净影响 = 紧急采购溢价 + 替代料成本差异 − 呆滞损失避免

【输出前自检】
可用库存是否四项扣减？双口径是否并列？每条毛缺口是否用「工序需料日」而非「工单需料日」比过在途？六条路径是否每条都给了结论（含"不启用"）？替代料是否第一道先过客户认可（PPAP）？是否写出同一批呆滞料在两张工单结论相反的对比？三色结论是否都有责任人与时点？缺口收敛验算是否为 0？

确认无误再输出，并把主表另存为「齐套缺料预警表.csv」。
