# 利润风险提示 · SKILL

## 适用时机
- 不想等到月底结账才发现某单亏了；想在交货前就对毛利异常亮红灯。
- 财务想做"事中盯单毛利"，但厂里只算得准料、算不准工、几乎算不到费。
- 加急运费挂在"管理费用-运输费"总账、不指定订单号，导致账面毛利虚高。
- 需要一份"哪张单出问题了、偏了多少、钱花在哪四项、该找谁"的预警，而不是期末总账。

## 输入（5 份）
1. `报价测算.csv`：各在制订单的 材料/人工/外协/其他 四项成本结构与报价毛利额、报价毛利率
2. `领料单.csv`：实际领用 vs BOM 标准用量，算超领材料（准）
3. `外协对账.csv`：实际外协费 vs 报价外协费，算外协增量（准，但滞后约 1 个月，需含未入账部分）
4. `物流账单.csv`：加急运费，常挂管理费用总账、关联订单=未指定
5. `返工单.csv`：返工件数 × 标准工时，算返工成本（只能估算）

## workflow
1. **取报价基线**：从报价测算取材料/工/外协/其他四项结构与报价毛利率。
2. **归集三项实发**：超领材料、外协增量（含未入账）、加急运费。
3. **反查未挂订单费用**：按收货客户 + 发货日，把"关联订单=未指定"的加急运费挂回对应订单。
4. **估算返工并标注**：返工件数 × 标准工时 × 费率，标为估算值并算估算占比。
5. **阈值判定 + 建议**：预计毛利率 vs 报价毛利率，跌破 5 个点即提示，附增量拆解、责任归口方向、建议动作。

## 输出
- `利润风险提示表.csv`：订单号 / 产品 / 合同额 / 报价毛利率 / 预计毛利率 / 跌幅 / 增量成本合计 / 风险项·归口 / 触发 / 建议动作。

## 关键规则 / 提示词要点
- **做信号，不做精确核算**：承认算不准工，反而让场景在中小厂真正跑起来；目标是"这张单要出问题了"。
- **把没挂订单的钱找回来**：加急运费按收货客户 + 发货日反查回订单——这一项在案例里是 1 万元，占该单增量的 22.2%，不反查就少算五分之一以上，很可能不触发提示。
- **估算的部分明说是估算**：返工工时只能用件数 × 标准工时估，所有由此推出的金额单独标为估算值并给估算占比，让人自己判断结论稳不稳。
- 四项增量成本数据可得性不同，处理方式就不同：超领(准) / 外协(准但滞后) / 运费(要反查) / 返工(只能估)。

## 案例基准（明远精密 · 2026-08-09 · 4 张在制订单）
- 4 张单合同额合计 74.94 万；3 张正常，1 张（SO-20260705-031 中信重装 调节阀体）出事。
- 该单报价毛利 27.5%，摊回四项增量后预计只剩 11.8%，跌 15.7 个百分点；79,200 元报价毛利被吃掉 45,088 元，剩 34,112 元。
- 四项增量：超领材料 18,870 / 外协增量 15,120 / 加急运费 10,000（反查得来）/ 返工工时 1,098（估算）；估算部分占比 2.4%，所以"跌到 11.8%"结论站得住。
- 顺带发现同客户第二张单 SO-049 同产品同工艺仍在制，建议提前介入精车与热处理。
