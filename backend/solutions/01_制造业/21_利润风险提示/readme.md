# 利润风险提示 · 场景资产说明与验证记录

## 场景概述
离散制造财务岗位"事中盯单"场景。把报价测算 + 领料单 + 外协对账 + 物流账单 + 返工单一次读齐，把四项可归集的增量成本摊回单张在制订单，与报价测算比偏差，毛利跌破阈值即提示。本场景做"偏差信号"而非精确核算，估算部分明确标出。

- 4 张在制订单合同额合计 74.94 万 ✔
- SO-20260705-031 报价毛利 27.5% → 预计 11.8%（跌 15.7pt）✔
- 四项增量：超领 18,870 + 外协 15,120 + 运费 10,000 + 返工 1,098 = 45,088 ✔
- 79,200 元报价毛利被吃掉 45,088 元，剩 34,112 元 ✔
