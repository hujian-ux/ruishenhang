# 工程变更管理 ECN 全流程管控 Skill

## 适用时机
- 研发 PE 作为工程输入接口岗，承接变更雷区（换供应商 / 材料替换 / 参数调整等）
- 需要把"拍脑袋分级、靠人记 FMEA"变成规则化、可追溯的标准生产线
- 目标：一句话触发，2 分钟拿到分级 + 6 维影响评估 + 验证计划 + 审批流转 + FMEA/CP/PPAP 联动

## 输入
- 变更申请信息：变更描述、变更类型（新零件/设计参数/工艺参数/材料/供应商变更）
- 可选：BOM / 订单 / 工单三份表（用于自动展开影响面）
- 引用标准：IATF 16949:2016 §8.5.6、ISO 9001:2015 §8.5.6、AIAG FMEA/SPC/PPAP 手册

## 工作流（6 步）
1. **变更发起** — 信息录入，按 4 维度（影响范围/可逆性/验证周期/成本影响）分级判定，生成 ECN 编号
2. **影响评估** — 设计/工艺/质量/生产/采购/客户 6 维评估，FMEA 联动，风险汇总
3. **验证计划** — 按级别匹配验证项，责任到人，设里程碑
4. **审批流程** — L1-L6 权限审批，时限管控，加签规则（Red 含客户+总经理）
5. **实施跟踪** — 进度看板，问题闭环，文件更新追踪
6. **效果确认** — Cpk / 良率 / 客诉，闭环判定，PDM 归档

## 三级变更分级（决定所有后续动作）
- **Red 重大变更**：影响客户/安全/法规，验证≥4 周，成本≥10 万，不可逆，需客户批准，6 级审批，PPAP 等级 3
- **Yellow 一般变更**：影响内部工艺/质量，验证 1-4 周，成本 1-10 万，可逆需重新验证，3 级审批，PFMEA+CP 更新
- **Blue 临时变更**：单件/短期试验，验证≤1 周，成本<1 万，可随时撤回，2 级审批，首件+过程监控
- **判定原则**：取最高等级作为最终分级；任一维度触发 Red 条件 → 判 Red（避免拆分变更规避审批）

## 输出
- 分级判定（Red/Yellow/Blue）+ 判定依据
- 6 维影响评估矩阵（每维 高/中/低 + 风险点 + 验证内容 + 责任人 + 完成日期）
- 完整验证计划 + 审批流转清单 + FMEA/CP/PPAP 联动清单 + 分部门通知稿 + 实施节点看板 + 效果闭环检查清单

## 关键规则 / 提示词
- 分级有依据：按 4 维度自动判，不凭感觉
- FMEA 更新红线：RPN≥60 必须改进；严重度≥8 必须立即整改；新失效模式必须补充
- 每次变更、评估、审批、验证全部自动留痕，审核员一问即可调出 ECN 编号全流程记录
