# 开工条件核查 Skill

## 适用时机
- 试产 / 量产开线前，需给出"可开 / 需补 / 不可开"综合结论
- 传统做法：跨 5 个部门问，2-3 小时起步，答案凑齐了状态又变了
- 目标：一句话触发，1 分钟拿到五项红黄绿 + 补齐建议 + 责任岗位

## 输入
- 5 份跨部门状态报表（按产品 ID 交叉过滤）：
  1. BOM 基线（研发 / 工艺）
  2. 齐套报表（PMC / 仓库）
  3. SOP 台账（工艺）
  4. 产能负荷表（PMC / 生产）
  5. 工装状态表（设备 / 生产）
- 可选：人（人员资质）、环（现场温湿度 / ESD）补充检查项

## 工作流（4 步）
1. **并行读 5 份文件** — 同时读 BOM 基线 / 齐套报表 / SOP 台账 / 产能负荷表 / 工装状态表
2. **按产品 ID 交叉** — 每份文件按产品 ID（如 P-IPC-01）过滤，得到该产品在五个维度的状态
3. **五项红黄绿** — BOM 版本 / 物料齐套 / 工艺 SOP / 产能位 / 工装治具，逐一给结论
4. **出综合结论 + 建议** — 可开 / 需补 / 不可开三档；每项卡点配具体补齐动作 + 责任岗位

## 输出
- 五项红黄绿结论（用 通过 / 需补 / 不足 表达，避免纯色依赖）
- 综合结论：可开工 / 需补后开工 / 不可开工
- 每项卡点的补齐建议（具体动作）+ 责任岗位标签

## 关键规则 / 提示词
- 不只打颜色，还给方案：主控板缺 60 → "用替代料 M-PCB-002 补齐"；喷涂满载 → "300 台分 3 批过喷涂"
- 结论不是二元"能开 / 不能开"，而是给出黄灯 + 具体补齐动作
- 每项卡点必须带责任岗位，PE 不再是"发现问题→自己想办法→亲自协调"的独角戏
- 状态表达统一为中性词：通过 / 需补 / 不足（对应行业红黄绿三色，但不依赖颜色传达）
