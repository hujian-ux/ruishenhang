# 场景使用说明 · 开工条件核查（m3-2）

> 角色：研发 PE ｜ 行业：离散制造 ｜ 场景定位：试产/量产开线前，一句话触发五项检查

## 场景一句话
P-IPC-01 智能控制柜试产 300 台，传统跨 5 个部门问要 2-3 小时。用 WorkBuddy 一句话触发，1 分钟出五项结论（通过/需补/不足）+ 综合结论（需补后开工）+ 每项卡点补齐建议 + 责任岗位，把"带病开工"拦在开线前。

## 交付物验证记录
- `开工条件核查清单.csv`：578 bytes，7 数据行（覆盖 人/机/料/法/环 五类，5 项核心 + 人/环 补充）
- 5 份源报表均已生成（BOM 1 行 / 齐套 4 行 / SOP 2 行 / 产能 2 行 / 工装 2 行）
- 验证脚本：`gen_assets.py`（断言 size>0 且 行数>0，全部通过）
- 关键数字对齐：P-IPC-01 试产 300 台；主控板 M-PCB-001 缺口 60 件 → 替代料 M-PCB-002 补齐；喷涂满载 → 300 台分 3 批。综合结论 = 需补后开工（黄灯，2 项需补）。

## 使用步骤
1. 在 WorkBuddy 导入并启用本场景 Skill 包
2. 导出 5 份报表（BOM基线 / 齐套 / SOP台账 / 产能负荷 / 工装状态），按产品 ID 过滤
3. 复制 `主提示词.md` 内容，粘贴 5 份报表并发送
4. 查看五项结论与综合结论（可开 / 需补 / 不可开）
5. 按卡点补齐建议（含责任岗位）协调补齐
6. 达成补齐动作后，给出最终开工许可
