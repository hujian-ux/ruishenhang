现状与痛点

BOM 这一步做错，后面采购、齐套、成本、报价全部跟着错 —— 而且往往要等到停线或客户退货才发现。

人肉对 Excel 漏行

没上 PLM 的企业靠并排肉眼看、靠 VLOOKUP 拼公式。行数一多就漏行，料号字符相近更是看错高发区（M-PCB-001 和 M-PCB-002）。

高频
一物多码是通病

同一颗料，采购一个编码、仓库一个编码、车间又一个编码。行业里"一物多码率一成七"并不夸张，三个库存账导致紧急采购与呆滞并存。

高风险
格式五花八门

客户给 PDF、研发发 Excel、供应商甩张截图、有人把表格贴进邮件正文。动手比对前，先得把这些手工敲成统一格式，耗掉大半程。

耗时

BOM 出错，行业共识是'两成技术问题、八成管理问题'——这套东西不承诺上了 AI 就不乱，它做的是把该查的全查一遍、把每条判断的依据留下来。

WorkBuddy 的解决与价值

这件事的价值不在"导得快"，在"把雷找出来，并且算清每颗雷值多少钱"。把两份 BOM 直接扔进去，拿回来的不是"导入成功"，而是按类型分组的差异清单、脏数据体检报告、每条变更牵动的在途订单与库存金额，以及 AI 自己也不确定的那几项。

传统做法

先把各种格式手工敲成统一表 → 两个 Excel 并排肉眼比、拼 VLOOKUP 公式 → 标差异 → 挨个部门问影响谁 → 写变更说明报审批。整理与核对占掉大半时间，漏一行等到停线才知道。

WorkBuddy 做法

两份 BOM 直接丢进去（Excel/PDF/截图/邮件正文混着来都行）→ 一次对话给出差异清单 + 脏数据体检 + 影响面金额 + 待确认项。判断权还在人手里，但该看的东西一条都不会漏。

四个核心价值
01格式不再是门槛

Excel、CSV、PDF、扫描件、截图、邮件正文里的表格，都能读成统一结构再比对，不用先做数据治理。

02差异按类型分组

新增 / 删除 / 替换 / 用量变化 / 信息修订，分类说清楚。这是行业本来就在用的语言，比"两边不一样标黄"有用得多。

03导入前先体检

疑似重复料、单位混用、用量为空、层级孤儿件、替代料未标、版本号缺失 —— 先捞出来给你看，命中一条就省一次事。

04把改动翻译成钱

一条变更牵动哪些未完工工单、哪些在途采购、旧料还剩多少库存值多少钱。这是唯一能让老板也听懂的那一层。

方案定位

不追求"全自动写进 ERP"。行业里 AI 读图纸认表格的准确率上限在九成上下，硬要做到全自动，代价是把错误也一起自动化。这套东西的定位是：把该查的全查一遍，把拿不准的老实说出来，判断留给人。

解决方案的工作流程

一次对话走完，中间任何一步都能追问"这条为什么这么判"，共 6 步。

01读两份 BOM

多格式解析，自动认哪份是基线、哪份是新版。

02脏数据体检

比对前先扫可疑项：重复料 / 单位 / 空值 / 孤儿件。

03对齐与匹配

料号对齐，字符相近的标置信度，拿不准的列出。

04差异分类

新增 / 删除 / 替换 / 用量变化 / 信息修订，附依据。

05影响面展开

牵动的工单、在途采购、旧料库存金额逐条算清。

06澄清与留痕

不确定项列清，每条判断附依据，供人复核。

脱敏案例：某工控产品制造商，一份看着简单的换版 BOM，里面埋了三种不同性质的问题。

脱敏案例：某工控产品制造商 · 换版 BOM 里的三种问题

研发发来的是一份 Excel、一份 PDF，外加一封邮件，三份内容还不完全一致。PE 要做的是跟 ERP 里导出的现行基线对齐，找出所有改动再走变更审批。难点不在"哪几行不一样"，而在"有几处不一样是它本来就不该那样"。AI 找出来的最有价值的一条，不是"哪几行改了"，而是那颗关键料的替代关系被悄悄清空了，同时研发在邮件正文里写着"这颗料供货紧张，请评估"——把这两件事联起来，才知道这不是漏填，是研发在等 PE 接话。

维度	案例设定	业务解读
输入形态	Excel + PDF + 邮件	三份来源，内容不完全一致
比对对象	现行基线 vs 新版	与 ERP 受控 BOM 对齐，找全部改动
后续动作	走变更审批 + 录入基线	AI 一次对话给出差异 / 体检 / 影响面
关键洞察	替代料清空 + 邮件"供货紧张请评估"	非漏填，是研发等 PE 接话，须先评估再审批

TRAINING PROMPT · 复制即用
请基于以下两份素材，为「某工控产品制造商 · 智能控制柜」做 BOM 导入前的工程基线核对，严格按 6 段输出。

【输入 1 · 现行基线】（节选自 基线BOM.csv，ERP 导出）
- 字段：料号 / 描述 / 用量 / 单位 / 替代料 / 版本
- 示例：M-PCB-001 主控板，用量1，单位PCS，替代料M-PCB-002，版本V1.2

【输入 2 · 新版 BOM】（节选自 新版BOM.csv / PDF / 邮件）
- 研发发来 Excel + PDF + 邮件三份，内容不完全一致
- 重点：M-PCB-001 替代关系被清空、邮件正文写"该料供货紧张，请评估"

【输出要求】
1. 脏数据体检：疑似重复料、单位混用、用量空值、替代料未标、版本缺失
2. 差异清单（按类型分组）：新增 / 删除 / 替换 / 用量变化 / 信息修订，每条含旧值新值依据
3. 关键风险：替代料清空是否关联交易方备注，说明研发在等 PE 接话而非漏填
4. 影响面展开：在途采购 + 旧料库存金额（如 M-PCB-002 在库 60 件 ≈ ¥4,200）
5. 待确认清单：AI 明确"拿不准"的项单列，附依据
6. 核对结论：是否可走变更审批及建议动作
