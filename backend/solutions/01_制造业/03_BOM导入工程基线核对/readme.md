# 场景使用说明 · BOM 导入 · 工程基线核对（m3-1）

> 角色：研发 PE ｜ 行业：离散制造 ｜ 场景定位：新版 BOM 导入前，先把雷找出来

## 场景一句话
研发发来 Excel + PDF + 邮件三份不一致的新版 BOM，PE 用 WorkBuddy 一次对话完成「多格式解析 → 脏数据体检 → 差异分类 → 影响面展开 → 澄清留痕」，输出可追溯的核对清单，再走变更审批。

## 交付物验证记录
- `BOM基线核对表.csv`：1,514 bytes，15 数据行（含 新增/删除/替换/用量变化/信息修订/疑似重复料/一致 全部分类）
- `基线BOM.csv`：474 bytes，12 数据行
- `新版BOM.csv`：441 bytes，11 数据行
- 验证脚本：`gen_assets.py`（断言 size>0 且 行数>0，全部通过）
- 关键数字对齐：M-PCB-001 替代料清空 + 邮件"供货紧张请评估"；旧替代料 M-PCB-002 在库 60 件（≈¥4,200）；风扇删除旧料 15 件（≈¥1,350）；新增 M-SEN-040 触发 PO-77 在途 60 件。

## 使用步骤
1. 在 WorkBuddy 导入并启用本场景 Skill 包
2. 准备 `基线BOM.csv`（ERP 导出）与 `新版BOM.csv`（研发发来）
3. 复制 `主提示词.md` 内容，粘贴两份 BOM 正文并发送
4. 核对差异清单中"替代料被清空"项是否关联交易方备注（关键风险）
5. 查看影响面金额（在途采购 + 旧料库存残值）
6. 依待确认清单逐项人工复核后，走变更审批
