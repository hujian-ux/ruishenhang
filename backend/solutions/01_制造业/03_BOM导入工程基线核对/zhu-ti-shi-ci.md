# 主提示词 · BOM 导入 · 工程基线核对

> 复制以下内容，把两份 BOM 原文粘贴到【输入】位置，发送给 WorkBuddy（已启用「BOM导入·工程基线核对」Skill）。

---

请基于以下两份素材，为「某工控产品制造商 · 智能控制柜」做 BOM 导入前的工程基线核对，严格按 6 段输出。

【输入 1 · 现行基线】（节选自 基线BOM.csv，ERP 导出当前受控 BOM）
- 字段：料号 / 描述 / 用量 / 单位 / 替代料 / 版本
- 示例：M-PCB-001 主控板，用量1，单位PCS，替代料M-PCB-002，版本V1.2

【输入 2 · 新版 BOM】（节选自 新版BOM.csv / PDF / 邮件正文，研发发来）
- 研发这次发来 Excel + PDF + 邮件三份，内容不完全一致
- 重点：某关键料替代关系被清空、邮件正文写"该料供货紧张，请评估"

【输出要求】
1. 脏数据体检报告：疑似重复料、单位混用、用量空值、替代料未标、版本缺失，逐条列出
2. 差异清单（按类型分组）：新增 / 删除 / 替换 / 用量变化 / 信息修订，每条含旧值、新值、判断依据
3. 关键风险项：重点核对"替代料被清空"是否关联交易方备注（邮件"供货紧张，请评估"），说明这代表研发在等 PE 接话，而非漏填
4. 影响面展开：每条变更牵动的未完工工单、已下采购订单/在途、旧料剩余库存金额
5. 待确认清单：AI 明确"拿不准"的项单列，每条附依据
6. 核对结论：是否可走变更审批，建议动作

生成后自检：料号字符相近项（如 M-PCB-001 / M-PCB-002）是否都标了置信度？替代料清空项是否查了邮件备注？确认无误再输出。
