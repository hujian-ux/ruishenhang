# 主提示词 · 订单接单评审 / 急单可行性

> 适用场景：销售甩来一张急单，老板要你在 1-2 小时内回答「能不能按时交、卡在哪、怎么调」。
> 把下面 4 份报表内容贴进提示词对应位置，发送给已启用本 Skill 的 WorkBuddy。

---

请基于以下 4 份报表，对目标急单做接单评审，严格按三色体系输出。

【输入 1 · 订单明细】（节选自 订单明细.csv）
- SO-20260708-001 · 华东能源集团（战略）· P-IPC-01 智能控制柜 · 300 台 · 交期 2026-08-06（距今天 10 天）
- 字段：订单编号 / 客户 / 客户等级 / 产品 / 数量 / 交期 / 距今天数

【输入 2 · 物料齐套】（节选自 物料齐套.csv）
- 主控板 M-CTRL-001：需求 300 · 已备 240 · 缺口 60 · 替代料 M-PCB-002 可补 60（正好补齐）
- 字段：物料编号 / 需求数 / 已备数 / 缺口 / 替代料 / 替代可补

【输入 3 · 产能负荷】（节选自 产能负荷.csv）
- 喷涂：本周产能 300 · 已排 300 · 负荷率 100% · 瓶颈标记「满载」
- 装配一线：负荷率 95% · 本周余 16 台
- 字段：产线/工序 / 本周产能 / 已排 / 负荷率 / 瓶颈标记

【输入 4 · 在制冲突】（节选自 在制冲突.csv）
- WO-20260701-031 喷涂在制 200，占满喷涂本周余量
- 字段：工单号 / 工序 / 在制数 / 与急单冲突 / 说明

【输出要求】
1. 三色接单结论：🟢可接 / 🟡谨慎 / 🔴不建议（对 SO-20260708-001 给出一档）
2. 卡点清单：逐项列 物料齐套 / 产能瓶颈 / 在制冲突 的具体数字
3. 建议动作：每项卡点配「具体动作 + 责任岗位（PE/采购/PMC/生产）+ 完成时限」
4. 形成一张「接单评审表」：订单 × 物料齐套可行性 / 产能可行性 / 在制冲突 / 交期可行性 × 综合结论

自检：黄灯是否给出「协调后可接」清单？每项建议是否都有责任岗位和时限？确认后输出。
