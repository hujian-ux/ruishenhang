# 订单接单评审 · 急单可行性

## 适用时机
- 销售把急单甩过来，需要在 1-2 小时内答复客户「能不能按期交」
- 需要综合评估「齐套 + 产能 + 在制冲突 + 客户等级」四维，而非拍脑袋答应
- 接到单后发现主控板缺料、喷涂满载等卡点，需要给出可执行的协调清单

## 输入（inputs）
- 订单明细表：订单编号、客户、客户等级、产品、数量、交期、距今天数
- 物料齐套表：物料编号、需求数、已备数、缺口、替代料、替代可补
- 产能负荷表：产线/工序、本周产能、已排、负荷率、瓶颈标记
- 在制冲突表：在制工单、工序、与急单冲突、说明

## 工作流程（workflow）
1. **收数据**：读取订单/工单/齐套/产能 4 份报表
2. **按订单交叉**：以目标订单+产品过滤，建立 5 维评估基线（齐套/产能/在制/客户等级/交期）
3. **跑综合评估**：齐套缺口能否补、产能瓶颈是否超载、在制冲突是否抢占、客户等级权重
4. **三色结论**：
   - 🟢 可接单：物料 100% 齐套 + 产能有位 + 无瓶颈超载 → 销售直接回客户、PMC 排入序列
   - 🟡 谨慎接单：有齐套缺口但替代料可补 / 或产能紧但可调整 → 给「协调后可接」清单（**黄灯是最有用的一档**）
   - 🔴 不建议接：严重齐套不足且无替代 / 产能严重超载 → 给最早可交日期 + 赶工/外协/改期取舍
5. **出建议**：每项卡点配具体动作 + 责任岗位 + 完成时限，结论沿链路可追溯

## 输出（outputs）
- 接单评审表：订单 × 物料齐套 / 产能 / 在制冲突 / 交期可行性 × 综合结论
- 每条建议带：动作描述 + 责任岗位（PE/采购/PMC/生产）+ 完成时限

## 关键规则
- 结论不是「能/不能」二元，**黄灯（谨慎接单）是最重要的一档**——让 PMC 从「拍板背锅」变成「给协调清单」，销售拿清单回客户，责任面清清楚楚
- 不只打颜色，要给方案：缺料→给替代料编号与可补数量；满载→给分批方案
- 评估顺序：先看齐套可补性 → 再看产能瓶颈 → 最后看客户等级，不可颠倒
- 数据时点声明：若报表超 24h 未更新，滞后类判断标注「不可信」

## 提示词（参考 主提示词.md）
「请基于订单/齐套/产能/在制 4 份报表，对目标急单跑综合评估，输出三色接单结论（🟢/🟡/🔴）+ 每项卡点的具体动作 + 责任岗位 + 完成时限。」
