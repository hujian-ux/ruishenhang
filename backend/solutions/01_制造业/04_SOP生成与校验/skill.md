# Skill · SOP生成与校验（离散制造 · 工艺岗）

## 适用时机
- 图纸或工艺卡升版后，怀疑现场作业指导书（SOP / WI）没跟上。
- 体系审核（客户审、三方审）前，需要自查"文件对文件、参数对参数"。
- 同一类不良反复出现，想确认是否因为指导书没回写真实异常。
- 准备修订指导书，需要把"为什么改、按哪份文件改、改完影响谁"整理成变更包。

## 不适用 / 红线
- **不承诺**从图纸自动生成一份可直接发布的指导书：参数取值牵涉安全与责任，最终取值与签字必须人来定。
- 本技能只负责"把该核的全核一遍、把拿不准的标出来、把改动理由与证据备齐"，让工程师签得下去。

## 输入（inputs）
1. `现行作业指导书.md` —— 现场工位上挂的那一版（含版本号、编制/审核/批准、变更履历）。
2. `工艺卡与图纸技术要求.csv` —— 上游已升版的控制计划 / 工艺路线卡 / 图纸技术条款（含引用的图纸版本）。
3. `历史异常记录.csv` —— 近半年返修、客诉、内部异常，需含"关联工序/参数"字段。

## 输出（outputs）
1. **校验报告**：每条问题定位到「文件 + 条目 + 各文件参数并排值 + 判定依据 + 严重度」。
2. **新版指导书**：按标准栏位排好，预留编制/审核/批准签字栏与变更履历，可打印挂工位。
3. **变更影响清单**：哪些文件要跟着改、哪些岗位要重培训、旧版如何回收（附发放登记）。

## workflow（一次对话走完，每条结论可追问"这是按哪份文件判的"）
1. **读几份文件**：指导书 + 工艺卡 + 图纸技术要求 + 异常记录，统一抽取"同一参数"在不同文件中的表述。
2. **依据版本核对**：指导书引用的图纸版本 vs 当前生效图纸版本；跨大版本 → 触发重大升版判据。
3. **参数逐条并排比**：同一参数（如焊接电流、扭矩、涂胶量）在指导书 / 工艺卡 / 图纸中的取值并列，标出差值与"以谁为准"。
4. **完整性 + 异常扫描**：扫描模糊表述（"适当""少许""按经验"）、缺公差、缺检验频次、空异常处理；并回查历史异常记录，把"该参数已引发过 N 次返修"标在旁边。
5. **出升版包**：给出改动项 + 依据 + 责任岗位 + 变更说明 + 升版级别（见下）。

## 升版判级规则（不靠感觉）
- 引用的依据文件**跨了大版本**，或**关键参数对不上超过三处** → 判为**重大升版**：必须走完整文控流程 + 车间培训。
- 其余为普通升版，走常规变更。

## 关键规则 / 提示词要点
- 每条偏差都必须给出「文件 + 条目号 + 各文件的值 + 判定依据」，不允许只说"不一致"。
- 模糊表述一律列出原句 + 建议改写（带公差 / 频次 / 异常处理动作）。
- 历史异常必须回写：标注"该参数已引发 2 次返修 + 1 次客诉（四月虚焊 / 五月虚焊 / 六月客诉）"。
- 严重度分级用中性词（重大 / 一般 / 提示），**禁止**用红绿橙状态色表达。
- 最终交付物 = `SOP生成校验表.xlsx`（工艺要求 → 可执行SOP步骤 × 校验项）。
