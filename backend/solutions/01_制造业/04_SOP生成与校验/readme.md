## 交付物数字对齐（与素材 /tmp/mfg_4.1.txt 一致）
- 焊接电流：图纸/工艺卡 220 A，现行指导书 200 A，**差 20 A** → 超差。
- 历史异常：四月虚焊返修、五月虚焊返修、六月客户抽检投诉，**2 次返修 + 1 次客诉**，三次指向同一焊接参数。
- 升版判级：引用图纸跨大版本（Rev.B→Rev.D）+ 关键参数对不上 6 处（>3）→ **重大升版**（完整文控 + 车间培训）。

## 使用方式
1. 在 WorkBuddy 左侧「专家·技能·连接器」入口点「添加技能 → 上传技能」，导入 `03_技能包/SOP生成与校验/` 文件夹，并在「已安装」启用。
2. 准备三份输入素材（现行指导书 / 工艺卡与图纸 / 历史异常记录）。
3. 复制 `主提示词.md` 中的提示词，粘贴素材内容发送。
4. 核对校验报告：每条偏差是否给了"以谁为准"，模糊表述是否列了改写建议，历史异常是否回写到参数旁。
5. 下载 `SOP生成校验表.xlsx` 作为送审升版包的工艺对照底稿。
