### 关键数字对照（与素材口径一致）
- 直接成本小计 = 540(材料)+120(外购)+297.5(CNC)+90(钳工)+180(表面)+65(包装) = **1292.50 元**
- 管理费(12%) = 1292.50 × 0.12 = **155.10 元**
- 单件成本合计 = 1292.50 + 155.10 = **1447.60 元**
- 本批 200 件成本 = 1447.60 × 200 = **289,520.00 元**
- 常规单价 = 1447.60 × 1.23 ≈ **1780.55 元**
- 加急单价 = 1447.60 × 1.37 ≈ **1983.21 元**（较常规 +202.66）
- 批量单价 = 1447.60 × 1.12 ≈ **1621.31 元**（较常规 −159.24）

> 说明：WorkBuddy（Excel/LibreOffice）打开 xlsx 时公式会自动计算；以上为预期值，用于核对口径。素材核心对齐点"不用先排队等技术"——本交付物证明销售可独立产出初稿，仅把待确认清单中影响大的项交技术复核。
