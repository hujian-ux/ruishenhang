# 合同条款确认（销售 · 离散制造）

## 适用时机
- 客户发来自己的采购模板 / 中标后正式合同，销售准备签字或转老板/财务看一眼之前。
- 企业**没有内部标准合同模板**也能用：本技能用「外部通用红线 + 自己历史合同」拼出比对基线。
- 一句话触发：「帮我把这份合同按风险等级过一遍，给可替换的修改文本」。

## 核心前提与设计
中小制造企业普遍没有内部标准合同模板，所以"与内部标准模板逐条比对"这个常规做法前提不成立。本技能拆成两个基线分别回答：
- **基线① 通用条款红线清单**：回答"这条在行业里算不算坑"（外部经验，替代内部标准模板）。
- **基线② 自己历史已签合同**：回答"这条相对我们平时签的是松还是紧"，并能翻出同一客户的旧账（内部经验，替代我们的标准条件）。

## 输入（inputs）
1. 本次合同原文 / 条款摘录（建议按「条款号 + 类别 + 原条款摘要」整理成 CSV）。
2. `通用条款红线清单.csv`：13 条通用红线（验收/技术规格/付款/违约金/质保金/管辖/送达 七类）。
3. `历史已签合同基线.csv`：近 2 年已签合同的真实条款 + 履约情况备注（含同一客户旧账）。

## 输出（outputs）
1. **合同条款差异比对表.csv**：每条 = 条款号 / 类别 / 原条款摘要 / 风险等级 / 风险点 / 红线对照 / 建议修改文本 / 旧账关联。
2. **三条致命项摘要.md**：给老板一页纸——三条最致命项 + 谈判优先级 + 同一客户旧账提醒。
3. 反馈邮件可直接复制的修改条款原文。

## workflow（5 步）
1. **读条款并归类**：逐条归入七类（验收/技术规格/付款/违约金/质保金/管辖/送达/其他），标记模糊表述。
2. **比红线清单（基线①）**：逐条对照 13 条红线，判定"在行业里算不算坑"，给风险类别。
3. **比历史合同（基线②）**：判定"相对平时签的是松还是紧"，并检索同一客户历史履约（旧账）。
4. **定等级 + 出文本**：高 / 中 / 低 三级，每条给可直接替换的条款原文（不是"建议关注"）。
5. **三条致命项摘要**：把最致命的 3 条单独摘出，附谈判优先级与旧账提醒，给老板看。

## 关键规则 / 提示
- **只做条款提示，不出法律意见**：任何输出末尾标注「本页内容为条款风险提示，不构成法律意见」。
- **模糊表述优先标高风险**：如"符合甲方使用要求""可随时提出异议"这类无期限、无标准、无上限的表述，是逐条看最容易漏的坑。
- **违约金看两个量**：比例是否超日万分之五（通常水平），基数是否用"合同总价"而非"逾期未交付部分"。两者都异常即为高。
- **精密/机加件必查技术规格**：合同只写产品名称、未附图纸与技术协议，杀伤力比违约金还大——卖方无书面标准可反驳。
- **"订金"必须纠正**：写"订金"丧失定金罚则保护，应改"定金"或注明可退。
- **交付条款要配对质量期限**："签收即完成交付"须与质量异议期限配套看，单看像好事、合起来是坑。
- **旧账必查**：同一客户上一份合同的质保金/尾款若超期未清，新合同相同条款要单列提醒。
