# 场景使用说明 · 经营复盘（离散制造 · 管理层）

## 一、场景定位
把订单 / 交付 / 库存 / 质量 / 成本五条线一次性读入，判定健康度 → 指出好看指标背后的代价（矛盾检测）→ 恶化项四层下钻到具体订单与客户 → 输出带责任人和时限的三个必须关注问题。

案例：恒信精密机械 2026 年 6 月经营复盘。

## 二、文件清单与作用
| 文件 | 角色 | 在场景中的作用 |
| --- | --- | --- |
| `03_技能包/经营复盘/SKILL.md` | Skill 定义 | 五条线判定 + 矛盾检测 + 四层归因 + 简报生成的规则与提示词 |
| `主提示词.md` | 提示词 | 学员实际发送给 WorkBuddy 的主提示词（已含案例数字） |
| `五条线部门报表.csv` | 原始输入 | 5 部门 × 主指标 + 支撑指标，5 行样本 |
| `毛利归因订单明细.csv` | 原始输入 | 毛利缺口四层归因到订单层，3 张单 20.3 万敞口 |
| `经营复盘看板.md` | 预期交付物 | 一页式经营简报：健康度表 + 矛盾 + 归因 + 三问题 |

## 三、交付物验证记录（Python 生成）
- `五条线部门报表.csv`：生成成功，size 1016 字节，5 行数据（>0）。
- `毛利归因订单明细.csv`：生成成功，size 610 字节，含指标/产品线/成本项/订单四层，3 张单合计影响金额约 203,400 元（≈ 20.3 万敞口，与素材对齐）。
- `经营复盘看板.md`：生成成功，size 3402 字节，含五条线判定、两处矛盾、四层归因、三个带责任人问题。
- 数字对齐：订单 2,440 万 / OTD 96.8% / 毛利 15.6% vs 18.0% / 缺口 61.24 万 / 目标单价 481.4 / 加急插单 ≤12 次。

## 四、怎么用
1. 在 WorkBuddy 左侧「专家·技能·连接器」导入并启用 `03_技能包/经营复盘/SKILL.md` 所在 Skill 包。
2. 准备五份部门报表（可参考 `五条线部门报表.csv` 字段口径）。
3. 复制 `主提示词.md` 内容发送，附报表数据。
4. 核对简报：五条线判定、两处矛盾、归因是否到订单号、三问题是否带责任人/时限。
5. 下载 `经营复盘看板.md` 作为签字级复盘底稿。
