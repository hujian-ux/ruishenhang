# MOB-01 · 数据治理痛点梳理与机制设计 —— 场景使用说明

- **行业**：汽车与出行
- **角色**：数据治理专员（林岫）
- **场景编号**：MOB-01
- **案例主体**：某汽车集团

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/数据治理痛点梳理与机制设计/SKILL.md` | Skill 定义 | 5 类痛点归类规则、三层机制映射、双视角表述模板、优先级判定规则与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `数据问题原始清单.csv` | 原始输入 | 25 个分散数据问题（含系统、部门、数据域、发现频率） |
| `治理机制框架.md` | 原始输入 | 痛点归类维度、机制分层、双视角表述模板、优先级判定规则 |
| `痛点归纳与机制设计表.csv` | **交付物** | 25 行痛点-机制-优先级归纳表 |
| `数据治理专员-数据治理痛点梳理与机制设计.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `数据问题原始清单.csv`、`治理机制框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 高优先级 9 项整理进治理委员会汇报材料，机制立项由委员会评审。

### 可复算口径

- 痛点归类 = 按框架触发关键词顺序（安全 → 口径 → 录入 → 协同 → 质量）取首个命中
- 优先级 = 高频且（口径 or 质量）→ 高；高频其他类或中频 → 中；低频 → 低
- 高优先级 9 = 口径类高频 5（DQ-01~05）+ 质量类高频 4（DQ-07~10）
- 覆盖系统 8 = 对输入「所在系统」列去重计数

## 五、真实性等级与边界

- **构造**：问题清单与框架「某汽车集团」的业务化构造，归类与统计口径全部可复算。
- **人工边界**：机制立项、资源排序与治理路线图由数据治理委员会评审决定，AI 不代做结论，输出中不出现效率百分比或效果承诺。
