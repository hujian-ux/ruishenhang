# 供应商风险专题汇报结构说明（某汽车集团 · 采购与供应链）

本说明定义专题汇报的结构、评分与定级口径、处理建议映射和对外技术要点改写规则。汇报数据表的全部计算字段依据本说明执行，不允许脱离口径自行调整。

## 一、专题汇报结构

| 章节 | 内容 | 数据来源 |
| --- | --- | --- |
| 一、执行摘要 | 审核范围（15 家）、总体结论（评级分布、平均综合评分、高风险供应商数） | 供应商风险专题汇报数据表汇总 |
| 二、风险定级 | 综合评级分布与高风险供应商清单（含高风险项数与风险维度） | 逐行高风险判定结果 |
| 三、分类解读 | 质量体系 / 交付能力 / 成本竞争力 / 合规管理四维度的弱项分析 | 各维度评分分布 |
| 四、处理建议与评审结论 | 逐家处理建议与评审会终审选项框架 | 处理建议映射规则 |

## 二、评分权重与评级标准

- 综合评分 = 质量体系 × 0.40 + 交付能力 × 0.25 + 成本竞争力 × 0.20 + 合规管理 × 0.15（四舍五入保留 1 位小数）
- 综合评级：A ≥ 85.0；B 75.0–84.9；C 65.0–74.9；D < 65.0

## 三、高风险判定规则

- 高风险项：任一单项评分 < 70 即记 1 个高风险项；高风险项数 = 单项低于 70 的维度个数
- 高风险供应商：高风险项数 ≥ 1

## 四、处理建议映射

| 判定 | 处理建议 |
| --- | --- |
| 高风险项数 ≥ 2 | 暂停新项目定点，30 天内完成整改并现场复审 |
| 高风险项数 = 1 | 维持现有定点，风险维度列入季度专项跟踪 |
| 无高风险项且评级 A | 维持定点，纳入年度优选供应商名录 |
| 无高风险项且评级 B / C | 维持定点，最低维度列入改进跟踪 |

## 五、评审结论框架

评审会对每家供应商做四选一终审：维持定点 / 观察运行 / 限期整改 / 暂停定点（A级候选另含「优选名录」选项），结论须附整改期限或跟踪节点。评审结论框架字段给出该行适用的选项与必附要素，终审签字由评审会完成。

## 六、对外技术要点改写规则

把内部技术方案要求改写为面向供应商的技术要点时：

1. 每条要点用一句完整的主谓宾句子说清楚，不允许出现只有内部人员才懂的缩写与代号；
2. 验收方式紧跟要点写明（看什么记录、测什么指标、什么时间点看）；
3. 一条要点只说一件事，内部背景与推导过程不进入对外文本；
4. 内部评审材料与对外沟通话术共用同一份底稿，只做表述层改写，不改变技术要求本身。

## 七、排版统一规则

正式文档成稿前统一处理：标题层级（一 / 1.1 / 1.1.1）、正文与表格字体字号、供应商名称与编号的全半角写法、表格列宽与表头加粗、日期格式（YYYY-MM-DD）与金额单位（元，千分位）。
