# MOB-02 · 供应商审核与专题汇报材料 —— 场景使用说明

- **行业**：汽车与出行
- **角色**：采购与供应链专员（程一帆）
- **场景编号**：MOB-02
- **案例主体**：某汽车集团

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/供应商审核与专题汇报材料/SKILL.md` | Skill 定义 | 评分权重与评级阈值、高风险判定、处理建议映射、对外改写规则与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `供应商审核记录.csv` | 原始输入 | 15 家供应商四维评分与主要审核发现 |
| `汇报结构说明.md` | 原始输入 | 汇报四章结构、评分口径、处理建议映射、对外技术要点改写与排版统一规则 |
| `供应商风险专题汇报数据表.csv` | **交付物** | 15 行风险定级与处理建议表 |
| `采购与供应链专员-供应商审核与专题汇报材料.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `供应商审核记录.csv`、`汇报结构说明.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 高风险供应商处理建议提交供应商评审会四选一终审。

## 三、交付物验证记录

生成脚本 `gen_MOB-02.py`（Python 标准库 csv，整数百分位运算避免浮点误差）从原始输入实际计算写出交付物并在脚本内断言验证。执行结果：

| 交付物数据行 = 15，列数 = 8 | 通过 |
| 评级分布 = A 3 / B 6 / C 5 / D 1 | 通过 |

| 平均综合评分 = 76.0（综合评分总和 113.99 ÷ 15） | 通过 |

### 可复算口径

- 综合评分 = 质量体系×0.40 + 交付能力×0.25 + 成本竞争力×0.20 + 合规管理×0.15（四舍五入保留 1 位小数）
- 评级：A ≥85.0 / B 75.0–84.9 / C 65.0–74.9 / D <65.0
- 高风险项数 = 单项评分 <70 的维度个数；≥1 即高风险供应商
- 平均综合评分 = 15 家综合评分之和 ÷ 15 = 76.0

## 五、真实性等级与边界

- **构造**：供应商数据与审核发现「某汽车集团」的业务化构造，评分、评级与高风险判定全部按固定口径可复算。
- **人工边界**：定点、暂停等终审决定由供应商评审会四选一并签字完成，AI 只输出数据表、处理建议与结论框架；输出中不出现效率百分比或效果承诺。
