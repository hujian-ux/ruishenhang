## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某汽车集团 · 供应商风险专题汇报」整理审核材料并输出汇报数据表，随后按汇报结构成稿。

【输入 1 · 供应商审核记录】供应商审核记录.csv（15 行）
- 含供应商编号、供应商名称、供应类别、质量体系评分、交付能力评分、成本竞争力评分、合规管理评分、主要审核发现
【输入 2 · 汇报结构说明】汇报结构说明.md
- 汇报四章结构：执行摘要 / 风险定级 / 分类解读 / 处理建议与评审结论
- 综合评分 = 质量×0.40 + 交付×0.25 + 成本×0.20 + 合规×0.15（保留 1 位小数）
- 评级：A ≥85.0 / B 75.0–84.9 / C 65.0–74.9 / D <65.0
- 高风险项 = 任一单项 <70 记 1 项；高风险项数 ≥1 即高风险供应商
- 处理建议映射与评审会四选一结论框架、对外技术要点改写规则、排版统一规则

【输出】供应商风险专题汇报数据表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「供应商审核与专题汇报材料」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **睿铭电控为什么是暂停新项目定点的建议？** 期望回答：三个单项低于 70（质量 55 / 交付 65 / 合规 62），高风险项数 3 ≥2，按映射规则给「暂停新项目定点，30 天整改复审」；终审仍由评审会四选一。
2. **天欣电子只有质量体系 62 分低于 70，为什么不是暂停？** 期望回答：高风险项数 =1，按规则只做季度专项跟踪；暂停门槛是 ≥2 项。
3. **联泰底盘和冠嵘精密冲压都是 A 级，处理建议差在哪？** 期望回答：均为「维持定点，纳入年度优选名录」；差异在最低维度——联泰底盘成本竞争力 76，冠嵘成本 80，分类解读中的弱项提示不同。
4. **平均综合评分 76.0 怎么算的？** 期望回答：15 家综合评分（各保留 1 位小数）之和 ÷ 15 = 76.0，权重为 0.40/0.25/0.20/0.15。
5. **对外技术要点为什么要附验收方式？** 期望回答：一句话说明白 + 验收方式紧跟，供应商才知道交什么、怎么被查；只改表述层，不删减要求。

## 验收清单

- [ ] 15 行输出，综合评分均按权重可复算（1 位小数）
- [ ] 评级分布 = A 3 / B 6 / C 5 / D 1
- [ ] 高风险供应商 = 5 家（SUP-03 / SUP-04 / SUP-08 / SUP-13 / SUP-15），高风险项合计 9
- [ ] 平均综合评分 = 76.0
- [ ] 每行有评审结论框架（四选一 + 必附要素），无终审结论字样
- [ ] 对外技术要点每条一句话 + 验收方式，无内部缩写代号
