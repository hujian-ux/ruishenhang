# MOB-05 · 经营度量体系分层设计 —— 场景使用说明

- **行业**：汽车与出行
- **角色**：经营分析与数据（沈衡）
- **场景编号**：MOB-05
- **案例主体**：某新能源汽车企业

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/经营度量体系分层设计/SKILL.md` | Skill 定义 | 一阶/二阶分层定义、三种关联递进类型、命名校准规范与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `业务场景与维度清单.csv` | 原始输入 | 10 个业务场景 × 各 4 个初始维度关键词（分号分隔） |
| `度量体系设计规则.md` | 原始输入 | 一阶/二阶定义、递进关系规则、命名规范（OTD/FTQ/OEE/ITR/NPS/PMBOK）、版式适配与验收口径 |
| `一阶二阶指标体系表.csv` | **交付物** | 40 行：业务场景 × 一阶维度 × 一阶衡量指标 × 二阶度量 × 关联递进关系 × 命名校准参照 |
| `经营分析与数据-经营度量体系分层设计.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `业务场景与维度清单.csv`、`度量体系设计规则.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 定稿体系按版式规则适配到既有看板页面；一阶过程度量转 MOB-07 做结构化加工口径对齐。

### 断言项

### 可复算口径

- 交付物行数 = 输入 10 场景 × 每场景 4 个初始维度关键词
- 一阶维度频次 = 对交付物「一阶维度」列分组计数（周期与响应 8 为最高频主维）
- 页面引用的「10 个业务场景 / 8 个一阶维度 / 40 项二阶度量」分别 = 输入数据行数 / 交付物一阶维度去重计数 / 交付物数据行数

## 四、与案例链的数字对齐

| 数字 | 出处 | 在本场景的落点 |

## 五、真实性等级与边界

- **方法论**：一阶/二阶分层度量与命名校准方法（OTD/FTQ/OEE/ITR/NPS/PMBOK 均为业内通用体系名称）。
- **构造**：业务场景清单与体系表口径可复算。
- **。**
- **人工边界**：度量对象与业务边界的确认、指标责任主体与考核口径的裁定、与既有制度的融合决定一律人工。
