# MOB-04 · 经营与职能文档事务化闭环 —— 场景使用说明

- **行业**：汽车与出行
- **角色**：职能与综合管理岗（苏晓蔓）
- **场景编号**：MOB-04
- **案例主体**：某汽车集团

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/经营与职能文档事务化闭环/SKILL.md` | Skill 定义 | 节时计算规则、月度频次口径、事务登记要求与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `周期性文档任务清单.csv` | 原始输入 | 15 项周期性文档任务：频率、单次耗时、模板状态、责任岗位 |
| `会议纪要原始记录.md` | 原始输入 | 一份设备与安全专题会的讨论流水记录（含跑题与散落决议） |
| `文档事务化闭环方案表.csv` | **交付物** | 15 行事务化闭环方案（节时可复算） |
| `职能与综合管理岗-经营与职能文档事务化闭环.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `周期性文档任务清单.csv`、`会议纪要原始记录.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 已固化模板沉淀进部门模板库；纪要待办在同一次对话中完成登记。

生成脚本 `gen_MOB-04.py`（Python 标准库 csv）从原始输入实际计算写出交付物并在脚本内断言验证。执行结果：

### 断言项

| 断言 | 结果 |
| --- | --- |
| 输入 `周期性文档任务清单.csv` 数据行 = 15 | 通过 |
| 交付物数据行 = 15，列数 = 9 | 通过 |
| 模板状态分布 = 已固化 6 / 部分固化 5 / 未固化 4 | 通过 |
| 月度文档工时 = 3160 分钟（Σ 单次耗时 × 月度频次） | 通过 |
| 月度预期节时 = 1521 分钟（Σ 节时 × 频次） | 通过 |
| 1521 ÷ 3160 = 48.1%（比率可复算） | 通过 |
| 每行自动化改造点与事务登记动作非空 | 通过 |

### 可复算口径

- 月度频次：每日 = 22 / 每周 = 4 / 每双周 = 2 / 每月 = 1
- 单次预期节时 = 单次耗时 × {已固化 0.60 / 部分固化 0.45 / 未固化 0.30}，四舍五入取整分钟
- 月度节时 = 单次预期节时 × 月度频次
- 月度文档工时 = Σ(单次耗时 × 月度频次) = 3160；月度节时 = 1521

## 五、真实性等级与边界

- **构造**：任务清单与会议流水记录「某汽车集团」的业务化构造，节时与工时全部按固定规则可复算。
- **人工边界**：模板与排班规则等口径确定、成稿导出与待办发出前的确认、决议最终裁定由责任人完成；节时为按规则计算的预期值，不作为效果承诺。
