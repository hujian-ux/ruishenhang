# MOB-08 · 测评体系方案与流程文档建设 —— 场景使用说明

- **行业**：汽车与出行
- **角色**：产品与整车功能（苏一苇）
- **场景编号**：MOB-08
- **案例主体**：某新能源汽车企业

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/测评体系方案与流程文档建设/SKILL.md` | Skill 定义 | 四类文档成套规则、命名与版本规范、优先级判定与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `测评能力项清单.csv` | 原始输入 | 15 个测评能力项 × 模块 × 测评类型 × 验收标准现状 |
| `文档命名与版本规范.md` | 原始输入 | 命名结构、V1.0/V2.0 版本规则、优先级与交付日期、责任人映射、流程归档规则 |
| `成套文档产出计划表.csv` | **交付物** | 15 行：能力项 × 四类文档文件名 × 优先级 × 交付日期 × 责任人 × 补齐动作 |
| `产品与整车功能-测评体系方案与流程文档建设.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `测评能力项清单.csv`、`文档命名与版本规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送（先确认结构骨架再展开成套产出）。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 文档计划按交付日期排入研发节奏；流程文件与 RACI 职责表同步归档。

### 可复算口径

- `文档计划数 = 能力项数 15 × 文档类型数 4 = 60 份`
- `优先级` = 按验收标准现状判定：缺失→P0、口头约定→P1、部分文档→P2
- `版本` = 缺失/口头约定→V1.0（新建），部分文档→V2.0（升版）
- `文件名` = `<能力项编号>-<能力项名称>-<文档类型>_V<版本>_<交付日期 YYYYMMDD>.md`
