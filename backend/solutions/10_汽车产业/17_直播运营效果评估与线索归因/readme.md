# MOB-17 · 直播运营效果评估与线索归因 —— 场景使用说明

- **行业**：汽车与出行
- **角色**：直播运营分析岗（顾晓岚）
- **场景编号**：MOB-17
- **案例主体**：某汽车互联网营销企业

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/直播运营效果评估与线索归因/SKILL.md` | Skill 定义 | 形式拆分规则、时段口径、转化率档位、人工边界 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `直播场次明细.csv`、`分析口径说明.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。

## 三、交付物验证记录

生成脚本 `gen_MOB-17.py` 以 Python 标准库 `csv` 从 60 行明细真实计算写出交付物，并在脚本内做断言验证。执行结果：

```

晚间黄金场线索 866 条，占总线索 61.68%
线索率对比：品牌自播 0.77% / 门店直播 0.63% / 达人带货 0.32%
ALL MOB-17 ASSERTIONS PASSED
```

### 断言项

| 断言 | 结果 |
| --- | --- |
| `直播场次明细.csv` 数据行 = 60（10 家门店，日期 2026-08-01 至 08-30） | 通过 |
| 形式分布 = 品牌自播 24 / 门店直播 26 / 达人带货 10 | 通过 |
| 总线索 = 1,404 | 通过 |
| 品牌自播线索 = 678 条 = 48.29%（678 ÷ 1,404） | 通过 |
| 晚间黄金场线索 = 866 条 = 61.68%（866 ÷ 1,404） | 通过 |
| 交付物 = 12 行（3 形式 × 4 时段，含 2 个未排期空格） | 通过 |

### 可复算口径

- `线索转化率% = 线索数合计 ÷ 观看数合计 × 100`（保留 2 位小数）
- `线索占比% = 该格线索数 ÷ 1,404 × 100`（保留 2 位小数）
- `品牌自播贡献占比 = 678 ÷ 1,404 = 48.29%`
- `晚间黄金场占比 = 866 ÷ 1,404 = 61.68%`

## 四、与案例链的数字对齐

| 数字 | 出处 | 在本场景的落点 |

## 五、真实性等级与边界

- **T2**：直播运营复盘方法与线索归因口径来自行业通行实践。
- **T3**：岗位痛点来自运营岗位 JD 与社区。
- **构造**：场次数据为构造数据，口径可复算。
- **人工边界**：排期调整的最终决策、与门店的沟通预期管理、达人合作谈判一律人工；AI 只出汇总与档位判断。
