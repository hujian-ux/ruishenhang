# MOB-09 · 供需平衡表与月度经营分析 —— 场景使用说明

- **行业**：汽车与出行
- **角色**：销售运营分析岗（某商用车企业）
- **场景编号**：MOB-09
- **案例主体**：某商用车企业

| 文件 | 类型 | 作用 |

| `03_技能包/供需平衡表与月度经营分析/SKILL.md` | Skill 定义 | 主键合并规则、平衡测算公式、三档状态判定、维度切换与刷新规则 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `需求预测表.csv`、`库存与在途表.csv`、`分析口径说明.md` 三份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 数据源更新后把新版两张表再次上传，要求「整体刷新」，核对表结构未变。

### 可复算口径

- `可用供给 = 当前库存 + 在途 − 预留`
- `平衡差 = 可用供给 − 本月需求量`
- `上月平衡差 = 上月末可用供给 − 上月需求量`
- `较上月变化 = 平衡差 − 上月平衡差`
- 任何维度汇总 = 对应行级平衡差求和

## 五、真实性等级与边界

- **方法论来源**：供需平衡测算（供给 = 库存 + 在途 − 预留）为行业通用口径。
- **构造**：车型配置、区域、需求与库存数据为构造数据，全部数字可由输入复算。
- **人工边界**：需求预测假设的确认、预留量口径裁定、缺口处置决策（调拨/排产/延期）一律人工；AI 只输出测算结果与变化说明。
