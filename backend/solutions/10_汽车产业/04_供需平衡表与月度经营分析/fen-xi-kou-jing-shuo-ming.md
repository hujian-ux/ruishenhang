# 供需平衡测算 · 分析口径说明（某商用车企业 · 销售运营）

适用范围：月度供需平衡测算与经营分析。数据主体为「车型配置 × 区域」组合，本期覆盖 10 个车型配置 × 3 个销售区域，共 30 行。

## 一、主键定义

- 共同主键 = `车型配置代码 + 区域`。需求预测表与库存与在途表按此主键一一对应合并，两侧各 30 行，不允许出现只有一侧有数据的悬挂主键。

## 二、平衡测算公式

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| 可用供给（台） | 当前库存 + 在途 − 预留 | 预留含已分配未发运的订单占用 |
| 平衡差（台） | 可用供给 − 本月需求量 | 正值为富余，负值为缺口 |
| 上月平衡差（台） | 上月末可用供给 − 上月需求量 | 与本月同一公式，仅换月度口径 |
| 较上月变化（台） | 本月平衡差 − 上月平衡差 | 负值代表缺口扩大或富余收窄 |

## 三、供需状态判定

| 平衡差取值 | 供需状态 |
| --- | --- |
| < 0 | 供给缺口 |
| 0 ~ 2 | 紧平衡 |
| > 2 | 供给富余 |

## 四、维度切换规则

- 支持三种分组口径：按业务属性（批发 / 零售）、按区域（华东 / 华南 / 华北）、按车型配置；也支持不分组的全量合并统计。
- 维度切换只改变分组汇总方式（对行级平衡差按组求和），**不改变行级可用供给与平衡差的计算**。
- 切换维度时无需重建表格结构，在既有结果上重新组织汇总即可。

## 五、结果刷新规则

- 数据源（需求预测表 / 库存与在途表）更新后，对全部 30 行**整体重算**可用供给、平衡差、较上月变化与供需状态；表头与列定义保持不变，禁止因数据更新而重建表结构。
- 刷新后必须复核：行数仍为 30、无悬挂主键、状态三档分布合计等于 30。

## 六、版式适配规则

- 汇报场景使用横版视图：列顺序为「主键 → 需求 → 供给 → 平衡差 → 变化 → 状态」，缺口行置顶排序。
- 打印场景使用 A4 横向可打印版式：字号与列宽按打印重新设定，数字列右对齐，缺口行加粗标注。
- 两种版式共享同一份数据，不允许出现两份不一致的结果。
