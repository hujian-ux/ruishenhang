## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `仿真任务与约束清单.csv`、`分阶段实现规则.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 按计划表逐阶段实现，每阶段末跑基准用例再进入下一阶段。

### 可复算口径

- 阶段数 = 该任务约束条件按「；」拆分后的条数 + 1
- 阶段总数 = Σ各任务阶段数 = 29 + 12 = 41
- 自由度合计 = 12 项任务自由度列求和 = 56
- 示例文件命名 = `{任务编号}_stage1_base.py` 与 `{任务编号}_stage{k}.py`（k = 2…阶段数）

## 五、真实性等级与边界

- **构造**：任务清单与规则「某汽车集团」的业务化构造，阶段数、约束数、自由度全部可复算。
- **术语说明**：本场景中「示例」指分阶段产出的代码入口文件，为仿真工程领域术语，非修饰性用语。
- **人工边界**：约束顺序的工程判断、模型参数取舍与阶段通过裁定由工程师负责，AI 只做拆分、验收标准与隔离方案生成；输出中不出现效率百分比或效果承诺。
