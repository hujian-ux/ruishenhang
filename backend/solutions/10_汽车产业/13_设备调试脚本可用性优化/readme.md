# MOB-15 · 设备调试脚本可用性优化 —— 场景使用说明

- **行业**：汽车与出行
- **角色**：工具与脚本开发岗（柯鸣）
- **场景编号**：MOB-15
- **案例主体**：某智能座舱软件企业

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/设备调试脚本可用性优化/SKILL.md` | Skill 定义 | 四类改造标准、验收方式口径与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `调试脚本问题清单.csv` | 原始输入 | 12 个调试脚本的问题明细：脚本名、用途、问题类别、问题描述、影响人群 |
| `可用性标准.md` | 原始输入 | 编码规范、输出精简规则、本地化标准、交互标准与四类验收方式 |
| `脚本优化改造清单.csv` | **交付物** | 12 行改造清单：脚本 × 问题类别 × 改造项 × 改造后行为 × 验收方式 |
| `工具与脚本开发岗-设备调试脚本可用性优化.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `调试脚本问题清单.csv`、`可用性标准.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 按清单逐个改造：转存编码、重定向回显、改中文输出、加按键等待，逐项现场实测验收。

### 可复算口径

- `问题类别分布`：按问题清单「问题类别」列计数
- `改造项 / 改造后行为 / 验收方式`：问题类别按 `可用性标准.md` 第五节四类映射生成
- `影响人群分布`：按问题清单「影响人群」列计数

## 四、与页面的数字对齐

## 五、真实性等级与边界

- **T2**：编码修复、输出精简、本地化、按键等待四类改造方法来自企业应用实践总结。
- **T3**：岗位痛点来自一线调试依赖批处理脚本的典型场景。
- **构造**：脚本名、问题描述与影响人羽数据为构造数据，口径可复算。
- **人工边界**：脚本的实际修改、转存与现场实测验收一律人工；AI 只输出改造清单与行为说明。
