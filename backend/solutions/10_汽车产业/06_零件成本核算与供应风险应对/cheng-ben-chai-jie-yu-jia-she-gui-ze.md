# 成本拆解与假设规则（应该成本 · 目标线 · 风险标注）

适用企业：某新能源汽车企业
适用范围：成本工程岗在年度定点核价前，对批量零件做「应该成本」要素拆解与供应风险标注。

## 一、应该成本拆解公式

```
应该成本 = 材料成本 + 工艺成本 + 物流包装成本 + 管理销售财务费用 + 供应商利润
```

五要素定义：

| 要素 | 定义 | 参考占比带 |
| --- | --- | --- |
| 材料成本 | 原材料/外购件按用量×单价计入 | 50% - 70% |
| 工艺成本 | 压铸/注塑/机加/装配等工艺工时与设备摊销 | 15% - 25% |
| 物流包装成本 | 运输、料箱与包装分摊 | 2% - 6% |
| 管理销售财务费用 | 供应商管理、销售与资金成本分摊 | 5% - 10% |
| 供应商利润 | 供应商合理利润 | 5% - 10% |

成本树按「零件 → 五要素 → 假设」三级展开：每个要素金额必须能下钻到关键假设。

## 二、关键假设标注规则（假设库）

每个零件按类别挂接假设，单源件追加人员连续性假设：

| 适用条件 | 关键假设 |
| --- | --- |
| 类别 = 内外饰 | 改性塑料粒子价格按 12800 元/吨测算 |
| 类别 = 座舱电子 | 车规芯片按当前长协价锁定，汇率按 7.15 测算 |
| 类别 = 三电 | 铜价按 78000 元/吨、铝价按 19500 元/吨测算 |
| 类别 = 底盘 | 铝价按 19500 元/吨测算，模具摊销按 8 万台分摊 |
| 类别 = 热管理 | 不锈钢与铜价按季度均价测算，模具摊销按 8 万台分摊 |
| 供应商数 = 1（追加） | 单一来源，供应商年人员流动率按 12% 测算 |
| 供应端人员波动 = 是（追加） | 供应端关键岗位已出现人员波动，需复核产能连续性假设 |

## 三、目标成本线与判定规则

- 目标成本：按市场对标价与年度降本路线设定，见输入表 `目标成本元` 列。
- 判定：`与目标成本差 = 应该成本合计 - 目标成本`；差 > 0 即「超目标线」。
- 降本空间口径：超目标线零件的 `与目标成本差` 即该零件的理论降本空间。
- 差异率 = 与目标成本差 ÷ 目标成本（保留 2 位小数）。

## 四、成本结构主因与风险等级

### 成本结构主因

取五要素中金额最大者：材料 / 工艺 / 物流包装 / 管理销售财务 / 供应商利润。

### 风险等级判定（不可协商）

| 条件 | 风险等级 |
| --- | --- |
| 超目标线 且（供应商数 = 1 或 供应端人员波动 = 是） | 高 |
| 超目标线 且 供应端无波动且多源；或 未超线 且（供应商数 = 1 或 供应端人员波动 = 是） | 中 |
| 未超线 且 供应商数 ≥ 2 且 供应端无波动 | 低 |

### 风险应对建议口径

| 情形 | 建议口径 |
| --- | --- |
| 高 | 本轮核价重点对象：要求供应商按假设清单逐项复核，同步启动第二来源导入 |
| 中 且 超目标线 | 定点谈判按关键假设逐项对表，明确降本路线与时间点 |
| 中 且 未超线 | 评估安全库存上浮与双源导入，覆盖人员波动导致的断供风险 |
| 低 | 维持现价，随下一轮批量窗口复测成本 |

### 供应端人员波动的库存保障提升措施

对「供应端人员波动 = 是」的零件，无论是否超线，同步执行四项库存保障动作：

1. 安全库存上浮一档（按波动期产能折扣设定）；
2. 关键岗位人员技能矩阵与顶岗预案要求写入供应商保障承诺；
3. 启动第二来源或备用产能认证评估；
4. 波动期内到货节奏加密监测（按周跟踪）。

## 五、验收口径

- 拆解必须五要素齐全，缺任一要素不得输出；
- 每行必须挂接关键假设，单源与人员波动件必须追加对应假设；
- 成本结构主因、风险等级、应对建议必须逐行给出，不得留空；
- 交付物由脚本从输入计算生成，页面引用的「超目标线零件数 / 合计超支 / 平均降本空间 / 单车折算超支」必须可复算。
