## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `零件成本要素明细.csv`、`成本拆解与假设规则.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 高风险零件转 MOB-07 按周跟踪到货台账；成本口径进入月度经营分析。

### 可复算口径

- `应该成本合计 = 材料成本 + 工艺成本 + 物流包装成本 + 管理销售财务费用 + 供应商利润`
- `与目标成本差 = 应该成本合计 - 目标成本`；`差异率 = 差 ÷ 目标成本 × 100`
- `平均降本空间 = 超线零件差值合计 120 ÷ 超线零件数 6 = 20 元/件`
- `折算单车超支 = Σ(超线零件差值 × 单台用量) = 45×1 + 14×1 + 25×1 + 12×1 + 12×4 + 12×4 = 192 元`
- `材料占比 = 材料合计 6590 ÷ 应该成本合计 11113 = 59.3%`
