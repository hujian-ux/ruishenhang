## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某新能源汽车企业」的 20 个批量零件做应该成本核算与供应风险标注，输出一张可追溯的零件成本树与风险标注表。

【输入 1 · 零件成本要素明细】零件成本要素明细.csv（20 行）
- 含零件号、零件名称、零件类别（内外饰/座舱电子/三电/底盘/热管理）、单台用量、五要素金额、目标成本、供应商数、供应端人员波动
【输入 2 · 成本拆解与假设规则】成本拆解与假设规则.md
- 拆解公式：应该成本 = 材料 + 工艺 + 物流包装 + 管理销售财务 + 供应商利润
- 假设库按类别挂接：内外饰挂塑料粒子价格、座舱电子挂芯片长协与汇率、三电挂铜铝价、底盘挂铝价与模具摊销、热管理挂季度均价与模具摊销；单源件追加人员流动率 12%，人员波动件追加产能连续性复核
- 判定：与目标成本差 &gt; 0 即超目标线；降本空间 = 差值；差异率 = 差 ÷ 目标成本
- 风险等级：高 = 超线且（单源或人员波动）；中 = 超线且多源无波动，或未超线但供应脆弱；低 = 未超线且多源无波动
- 人员波动零件执行四项库存保障动作：安全库存上浮一档、关键岗位技能矩阵与顶岗预案、第二来源认证评估、按周跟踪到货

【输出】零件成本树与风险标注表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「零件成本核算与供应风险应对」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **座舱域控制器为什么是最高风险零件？** 期望回答：应该成本 1010 元超目标线 45 元（超支率 4.66%），且单一来源、供应端已出现人员波动——超线与供应脆弱两条同时命中，风险等级高，需按假设逐项复核并启动第二来源导入。
2. **20 个零件整体低于目标线 72 元，为什么还要整改 6 个？** 期望回答：整体净低于目标不等于结构健康——6 个零件超线折算单车 192 元，降本必须逐零件对表，不能用低线零件的富余掩盖超线零件。
3. **电池模组端板没超线，为什么是中风险？** 期望回答：未超线但单一来源且人员波动，属供应脆弱件——按规则标注中风险，执行安全库存上浮与双源导入评估。
4. **电驱控制器壳体的成本主因为什么是工艺而不是材料？** 期望回答：工艺成本 138 元高于材料 118 元（压铸后机加工时重），是 20 个零件中唯一工艺主因件，谈判焦点应放在工艺工时与设备摊销假设上。
5. **降本空间 20 元/件是怎么算的？** 期望回答：6 个超线零件合计超支 120 元 ÷ 6 = 20 元/件（平均超支率 3.62%），是理论谈判空间，不是降本承诺。

## 验收清单

- [ ] 20 行输出，五要素齐全且每行合计等于应该成本合计
- [ ] 超目标线零件 6 个：YN-IC-2001 / YN-IC-2003 / YN-EM-3101 / YN-EM-3103 / YN-CH-4003 / YN-WH-6001
- [ ] 合计超支 120 元；平均降本空间 20 元/件；平均超支率 3.62%；折算单车超支 192 元
- [ ] 风险等级分布 = 高 3 / 中 5 / 低 12；人员波动零件 3 个均执行库存保障动作
- [ ] 成本结构主因分布 = 材料 19 / 工艺 1；材料要素合计占比 59.3%
- [ ] 单源件与人员波动件的关键假设均含追加条目，无「按市场价测算」类模糊表述
