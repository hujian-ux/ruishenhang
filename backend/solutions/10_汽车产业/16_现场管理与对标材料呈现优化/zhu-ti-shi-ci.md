# MOB-12 主提示词 · 现场管理与对标材料呈现优化

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/现场管理与对标材料呈现优化/SKILL.md`）。
2. 上传三个附件：`现场状态检查记录.csv`、`对标测量数据.csv`、`呈现规范.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `偏差呈现与对标框架表.csv` 后，按文末「验收清单」逐项核对。

## 主提示词（复制即用）

```
请基于我上传的三份素材，为「某商用车企业 · 产品对标与规划」把现场管理与对标两类材料整理成统一的管理层汇报框架，输出偏差呈现与对标框架表。要求框架先行：先定呈现模块与图表类型，细节留给人工补充，版式最后一轮收敛。

【输入 1 · 现场检查】现场状态检查记录.csv（20 行）
- 5 个区域（总装/焊装/涂装/物流/检验）× 4 项检查
- 每行含：检查项编号、检查项、理想状态、当前状态、偏差描述、偏差评分（1-5）
【输入 2 · 对标测量】对标测量数据.csv（12 行）
- 本车型 NV-T440 对 3 个对标车型（甲/乙/丙）× 4 项参数（整车整备质量 kg、百公里综合油耗 L、首保里程间隔 km、制动距离 m）
- 每行含：参数项、单位、改善方向（越低越好/越高越好）、本车型值、对标车型、对标值
【输入 3 · 呈现规范】呈现规范.md
- 偏差等级：评分 ≥4 高偏差 / =3 中偏差 / ≤2 低偏差
- 模块判定 R1-R4：关联对标参数 → 对标差距分析（并列柱状图）；否则评分 ≥4 → 现状偏差看板（横向条形图）；=3 → 整改跟踪表（进度甘特图）；≤2 → 达标确认清单（汇总表格）
- 对标差距率 = (本车型值 − 最优对标值) ÷ 最优对标值 × 100，保留 1 位小数、带正负号；最优对标值按改善方向取最小/最大
- 汇报优先级：P1 优先汇报 / P2 常规汇报 / P3 附录备查

【输出】偏差呈现与对标框架表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「现场管理与对标材料呈现优化」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **为什么对标一律跟最优比？** 期望回答：呈现规范规定对标差距率以各参数最优对标车型为基准；对标车型甲在 4 项参数上全部最优，是唯一基准——跟弱者比出来的「领先」没有汇报价值。
2. **差距最大的是哪个参数？** 期望回答：首保里程间隔，本车型 50,000 km vs 对标车型甲 60,000 km，差距率 -16.7%，落后 16.7 个百分点，是 12 组对比中幅度最大的。
3. **高偏差项都进看板了吗？** 期望回答：6 个高偏差项中 3 个关联对标的（QC-03/QC-04/QC-19）先进对标差距分析（R1 先命中），其余 3 个（QC-05 焊点符合率、QC-09 膜厚达标率、QC-17 复检闭环）进现状偏差看板。
4. **评分最高的是哪项？** 期望回答：QC-19 制动管路装配质量门，评分 5（1 次单检漏检），关联制动距离参数（+4.5% 落后），P1 优先汇报。
5. **框架定了之后人做什么？** 期望回答：现场照片、事例描述、整改责任人与时限由现场团队在预留位置人工补充；版式最后一轮统一收敛；口播稿按模块拆分镜，先画面后解说。

## 验收清单

- [ ] 交付物 20 行，11 列表头与【输出格式】完全一致
- [ ] 偏差等级：高 6 / 中 6 / 低 8；呈现模块：对标差距分析 4 / 现状偏差看板 3 / 整改跟踪表 5 / 达标确认清单 8
- [ ] 汇报优先级：P1 7 / P2 5 / P3 8
- [ ] 12 组对标对比：落后 8 / 领先 3 / 持平 1；最优基准 = 对标车型甲
- [ ] 关联项差距率：整备质量 +3.5% / 油耗 +2.1% / 首保 -16.7% / 制动 +4.5%，全部落后
- [ ] 同一呈现模块内图表类型唯一；细节列未代填（责任人与时限不在表内）
