## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `现场状态检查记录.csv`、`对标测量数据.csv`、`呈现规范.md` 三份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 拿框架表组织汇报制作：现场团队补细节，版式最后一轮收敛，口播稿按模块拆分镜。

### 可复算口径

- `偏差等级`：评分 ≥4 高 / =3 中 / ≤2 低
- `呈现模块`：R1 关联对标 → 对标差距分析；R2 评分 ≥4 → 现状偏差看板；R3 =3 → 整改跟踪表；R4 ≤2 → 达标确认清单
- `最优对标值`：越低越好取对标车型最小值，越高越好取最大值（4 项参数最优均为对标车型甲）
- `对标差距率% = (本车型值 − 最优对标值) ÷ 最优对标值 × 100`（首保：(50000 − 60000) ÷ 60000 × 100 = -16.7）
- `对标结论`：差距率方向与改善方向相悖为落后，一致为领先，为 0 为持平

## 五、真实性等级与边界

- **方法论来源**：框架先行（先结构后内容）、图表规格统一、分镜化口播为汇报材料制作通用方法。
- **构造**：检查项、偏差评分、对标车型与测量值为构造数据（对标车型甲/乙/丙为对标企业代称），全部数字可由输入复算。
- **人工边界**：偏差评分的现场评定、对标车型选择与测量方案、现场事例与责任人补充、解说词终稿一律人工；AI 只输出框架、量化口径与模块分配。
