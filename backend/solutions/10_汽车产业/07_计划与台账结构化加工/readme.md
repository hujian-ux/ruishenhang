# MOB-07 · 计划与台账结构化加工 —— 场景使用说明

- **行业**：汽车与出行
- **角色**：供应链与制造管理（陆嘉川）
- **场景编号**：MOB-07
- **案例主体**：某新能源汽车企业

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/计划与台账结构化加工/SKILL.md` | Skill 定义 | 多级拆解口径、跨表比对规则、两级汇总键与数据源资产登记规则 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `生产计划主表.csv` | 原始输入 | 30 行计划明细：计划号 × 车型 × 工厂 × 车间 × 层级 × 数量 × 节点 × 状态 |
| `车间执行台账.csv` | 原始输入 | 30 行执行明细：计划号 × 实际完成数量 × 台账状态 × 记录日期 |
| `汇总口径说明.md` | 原始输入 | 多级拆解、比对判定、两级汇总口径、数据源配置与资产登记规则 |
| `计划台账比对与分层汇总.csv` | **交付物** | 30 行：逐行比对结论 × 数量差异 × 工厂级/车间级汇总归属 |
| `供应链与制造管理-计划与台账结构化加工.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `生产计划主表.csv`、`车间执行台账.csv`、`汇总口径说明.md` 三份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 差异明细转车间级整改跟踪；工厂级汇总进入月度经营分析（MOB-09）。

### 可复算口径

- `数量差异 = 实际数量 - 计划数量`（每行）
- `差异计数` 仅针对 `比对结论 ∈ {数量差异, 状态差异}` 的行
- `应完成达成 = Σ应完成行实际数量 1072 ÷ Σ应完成行计划数量 1174`
- `两级归属`：工厂级 = `工厂-车型`（4 个），车间级 = `工厂-车间`（6 个）
