# MOB-19 · 宣传物料与多媒体素材快速产出 —— 场景使用说明

- **行业**：汽车与出行
- **角色**：市场与物料设计岗（白牧遥）
- **场景编号**：MOB-19
- **案例主体**：某汽车互联网营销企业

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/宣传物料与多媒体素材快速产出/SKILL.md` | Skill 定义 | 模块分配规则、位次规则、素材匹配与二次生成判定、人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `产品能力清单.csv` | 原始输入 | 12 行产品清单（产品/能力点/目标客户/卖点） |
| `物料版式规范.md` | 原始输入 | 单页三模块结构、长图排版规则、素材需求与规格、二次生成规则 |
| `物料产出计划与素材清单.csv` | **交付物** | 12 行物料计划：模块分配 + 长图位次 + 素材需求 + 二次生成标记 |
| `市场与物料设计岗-宣传物料与多媒体素材快速产出.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `产品能力清单.csv`、`物料版式规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。

## 三、交付物验证记录

生成脚本 `gen_MOB-19.py` 以 Python 标准库 `csv` 按版式规范规则从 12 行清单真实计算写出交付物，并在脚本内做断言验证。执行结果：

```
OK  产品能力清单.csv                12 data rows
OK  物料产出计划与素材清单.csv          12 data rows
单页三模块各4席：模块A品牌与数据 / 模块B门店增长 / 模块C行业协同
长图位次1-12按清单行序 | 素材件合计 37 个
二次生成 5 个（复用既有素材库）：['客户旅程看板', '投放效果归因', '直播排期台', '经营数据罗盘', '行业趋势洞察']
需新拍 7 个 | ALL MOB-19 ASSERTIONS PASSED
```

### 断言项

| 断言 | 结果 |
| --- | --- |
| `产品能力清单.csv` 数据行 = 12 | 通过 |
| 目标客户分布 = 经销商门店 4 / 车企品牌方 4 / 行业合作伙伴 4 | 通过 |
| 三模块各 4 席（A 品牌与数据 / B 门店增长 / C 行业协同） | 通过 |
| 长图位次 = 清单行号 1-12 | 通过 |
| 二次生成 = 5 个「是」：直播排期台 / 经营数据罗盘 / 投放效果归因 / 客户旅程看板 / 行业趋势洞察 | 通过 |
| 素材件合计 = 37（直播类 1×4 + 看板类 4×3 + 新拍类 7×3） | 通过 |

### 可复算口径

- `单页模块分配 = 目标客户字段映射`（经销商门店→B / 车企品牌方→A / 行业合作伙伴→C）
- `长图位次 = 清单行号`
- `素材件总数 = 1×4 + 4×3 + 7×3 = 37`
- `二次生成数 = 能力点含「直播」1 个 + 含「数据/看板/归因/罗盘/洞察」4 个 = 5`

## 五、真实性等级与边界

- **T2**：物料版式规范与素材复用方法来自行业通行实践。
- **T3**：岗位痛点来自市场与设计岗位 JD 与社区。
- **构造**：产品清单为构造数据，规则口径可复算。
- **人工边界**：美术终稿、素材库扩容决策、新拍档期预算一律人工；AI 只出结构化的产出计划与规则映射。
