# 门店账号矩阵方法论沉淀

## 一、这个 Skill 解决什么

账号矩阵运营的真实困难不是「没有方法」，而是**方法在每个人脑子里**：

- 成长阶段怎么划分，各家说法不一，门店之间无法横向比较
- 从零到一怎么搭，靠老员工口口相传，换个品牌就要重讲一遍
- 单个门店现在处于哪个阶段，判断标准模糊，诊断结论说服不了门店
- 方法论文档闭门写、推倒重来，越写越厚、越没人看

本 Skill 的核心动作，是**先搭框架、再调结构、后补细节**，把方法论变成一套可复制、可诊断、可迁移的资产：同一套框架服务不同品牌与门店时，只需替换输入。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 为品牌 / 经销商体系沉淀账号矩阵方法 | 主用场景：成长模型 + 搭建 SOP + 门店诊断三件套 |
| 月度盘点 20 家门店账号的运营阶段 | 输出诊断行动表，卡点归因 |
| 新品牌要复用既有矩阵方法论 | 换一份现状数据即可，四阶段结构与判定顺序不变 |
| 方法论文档结构反复推翻 | 先定框架再逐块微调，避免推倒重来 |

**不适用**：单条内容的创意策划；投流预算分配（属于投放域）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `门店账号现状数据.csv` | 必需 | 门店、粉丝数、月更条数、平均播放、互动率 |
| 2 | `成长阶段模型.md` | 必需 | 四阶段划分标准、判定规则、八步 SOP、各阶段动作 |

> **缺 2（阶段模型）时必须先产出模型再诊断**——没有门槛值就没有诊断，这是本 Skill 最重要的一条硬规则。

## 四、输出（outputs）

唯一交付物：`门店阶段诊断与SOP行动表.csv`，20 行（每家门店一行），字段固定为 4 列：

```
门店, 所处阶段, 诊断依据, 下一步SOP动作
```

- `所处阶段` ∈ {冷启动期, 起步期, 成长期, 成熟期}，按模型判定规则自上而下命中即停
- `诊断依据` 必须写明实际值与门槛值的对照（如「粉丝 8,600≥2,000 且月更 11≥8」），**不允许只写「经评估为起步期」**
- `下一步SOP动作` 从模型的各阶段动作表映射，与阶段一一对应

## 五、工作流程（workflow）

### STEP 1 · 分阶段成长模型设计

四阶段横向排布：冷启动期 / 起步期 / 成长期 / 成熟期从左到右一字排开，同一字段对齐，阶段差异一眼可比。每阶段定义粉丝、月更、互动率三档门槛与阶段使命。

### STEP 2 · 从零到一搭建 SOP

沉淀八步标准动作：账号定位 → 命名与装修 → 首批 8 条内容 → 全员转发冷启 → 固定周更 → 直播导流绑定 → 数据月度复盘 → 矩阵联动。

### STEP 3 · 阶段诊断

按判定规则自上而下匹配（成熟 → 成长 → 起步 → 冷启动，命中即停），输出「所处阶段 + 诊断依据（实际值对照门槛值）+ 下一步 SOP 动作」。矩阵整体另统计各阶段门店分布。

### STEP 4 · 取舍调整

按当前关注度增减模块：聚焦诊断时砍掉 IP 人设等后置模块；门店培训时保留横向模型 + 各阶段动作两张主表；迁移新品牌时门槛值按体量缩放，**结构与判定顺序不变**。

### STEP 5 · 自检

输出前逐项自检，任一不过则不得输出：

1. 20 行输出与 20 家门店一一对应？
2. 每行诊断依据都含实际值与门槛值对照？
3. 各阶段门店数分布与矩阵整体诊断一致？
4. SOP 动作与阶段一一对应，无错位？

## 六、关键规则（不可协商）

1. **判定只依赖硬字段。** 粉丝数、月更条数、互动率三个门槛字段决定阶段；平均播放只作辅助证据，不参与判定。
2. **自上而下命中即停。** 同时满足多档门槛时，取最高阶段；判定顺序不可颠倒。
3. **诊断依据必须可对照。** 实际值与门槛值同句出现，「综合评估」这类表述不允许出现。
4. **框架可迁移，结构不可变。** 门槛值可按品牌体量缩放，四阶段与判定顺序固定。
5. **不承诺增长幅度。** 输出中不写「涨粉 X%」这类无法核验的表述。

## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先搭框架：把四阶段成长模型整理为横向排布对照表（阶段 × 粉丝/月更/互动率/内容形态/阶段使命），同一字段对齐，不展开细步骤。
2. 逐店诊断：按判定规则自上而下匹配，输出每家门店的所处阶段；诊断依据必须写明实际值与门槛值的对照（如「粉丝8,600≥2,000且月更11≥8」），平均播放作为辅助证据附在句末。
3. SOP 映射：每家门店按所处阶段映射下一步 SOP 动作，与模型动作表逐字对齐，不允许错位。
4. 矩阵整体诊断：统计各阶段门店数与占比，指出矩阵重心与短板阶段。
5. 结构说明：从零到一搭建 SOP 八步与取舍调整规则原样沉淀在回答末尾，供新品牌迁移复用。

### 硬性约束

【硬性约束】
- 阶段判定只依赖粉丝数、月更条数、互动率三个硬字段，平均播放不参与判定。
- 诊断依据不允许写「综合评估为某阶段」，必须含实际值与门槛值对照。
- 判定自上而下命中即停，同时满足多档门槛时取最高阶段。
- 不写任何涨粉百分比或增长承诺。

### 生成后自检

【生成后自检，逐条回答】
1. 输出是否为 20 行且门店无重复？
2. 每行诊断依据是否都含实际值与门槛值对照？
3. 各阶段分布是否与矩阵整体诊断一致？（本批应为：冷启动期 5 / 起步期 8 / 成长期 5 / 成熟期 2）
4. SOP 动作与阶段是否一一对应？
自检全过再输出 CSV。

### 输出格式

【输出格式】CSV，4 列，20 行（每家门店一行），列名与顺序固定：
门店, 所处阶段, 诊断依据, 下一步SOP动作
