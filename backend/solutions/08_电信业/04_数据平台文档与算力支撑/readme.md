# TCM-04 · 数据平台文档与算力支撑 —— 场景使用说明

- **行业**：运营商生态
- **角色**：平台文档岗（韩青临）
- **场景编号**：TCM-04
- **案例主体**：某系统集成与行业数字化企业（与本场景库 TCM-01 / TCM-02 / TCM-03 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/数据平台文档与算力支撑/SKILL.md` | Skill 定义 | 文档三态判定、算力水位三档阈值、优先级与期限映射规则 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `平台文档与算力清单.csv` | 原始输入 | 18 项条目：平台文档 10 项（章节与超范围图片计量）+ 算力资源 8 项（核/卡/TB 计量） |
| `文档体系规范.md` | 原始输入 | 文档判定与期限、水位阈值、优先级映射、多版方案同步规则 |
| `平台文档与算力支撑表.csv` | **交付物** | 18 行支撑盘点表：文档缺口 + 容量水位 + 支撑结论 + 期限 |
| `平台文档岗-数据平台文档与算力支撑.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `平台文档与算力清单.csv`、`文档体系规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 预警项 15 天内提交扩容申请；文档缺口项进 30 天补建计划。

### 可复算口径

- `文档完成度` = 已完成章节 ÷ 章节总数（保留 1 位小数百分比）
- `算力水位` = 已分配量 ÷ 总容量（保留 1 位小数百分比）
- `文档平均完成度` = 已完成章节合计 ÷ 章节总数合计（按章节加权）
- `算力平均水位` = 已分配合计 ÷ 总容量合计（按容量加权）
- `判定等级` = 文档三态 × 水位三档，与支撑结论、优先级、期限一一对应

## 五、真实性等级与边界

- **T2**：文档体系评审周期与算力水位阈值来自平台运维通行做法。
- **T3**：岗位痛点来自平台文档岗常见工作场景。
- **构造**：清单数据与判定口径可复算。
- **升 T1 还缺**：客户真实文档评审记录与一次扩容决策复盘。
- **人工边界**：扩容申请审批与额度分配、文档技术内容审核与发布、平台例会支撑决策一律人工；本场景全部输出中不出现任何效率百分比承诺。
