# TCM-02 · 运营日报周报月报批量生成 —— 场景使用说明

- **行业**：运营商生态
- **角色**：运营支持岗（顾晓岚）
- **场景编号**：TCM-02
- **案例主体**：某系统集成与行业数字化企业（与本场景库 TCM-01 / TCM-03 / TCM-04 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/运营日报周报月报批量生成/SKILL.md` | Skill 定义 | 三周期取数口径、三类异常判定规则、合并校正与守恒校验规则 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `项目运营日数据.csv` | 原始输入 | 4 个交付项目 × 5 个工作日的进度/工单/风险日数据与月初基线 |
| `三周期报表规范.md` | 原始输入 | 统计窗口与报送时间、期初值取数口径、判定阈值与闭环率口径 |
| `运营三周期报表.csv` | **交付物** | 12 行三周期报表：项目 × 周期汇总 + 三类异常标记 |
| `运营支持岗-运营日报周报月报批量生成.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `项目运营日数据.csv`、`三周期报表规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 异常项目清单转项目经理处置；项目经验素材转 TCM-03 沉淀教程。

### 断言项

| 断言 | 结果 |
| --- | --- |
| 输入数据行 = 20（4 项目 × 5 工作日） | 通过 |
| 交付物数据行 = 12（4 项目 × 3 周期） | 通过 |
| 日级与月级工单守恒式全表成立 | 通过 |
| 异常分布 = 进度滞后 9 / 工单积压 7 / 风险升级 6 | 通过 |
| 异常行 9/12，其余 3 行异常标记为「无」 | 通过 |
| 全项目月度闭环率 = 111/144 = 77.1% | 通过 |
| XM-04 月报（阶段）期初 81.9% → 期末 90.4%，存量 7 → 28，闭环率 59.6% | 通过 |

### 可复算口径

- `周期工单守恒` = 期初存量 + 周期新增 − 周期关闭 = 期末存量
- `进度增量%` = 期末进度% − 期初进度%（期初按三周期口径分别取数）
- `月度闭环率` = 月报（阶段）关闭工单 ÷ 新增工单（保留 1 位小数百分比）
- `异常标记` = {进度滞后, 工单积压, 风险升级} 中命中项用「、」连接，全不命中写「无」

## 五、真实性等级与边界

- **T2**：日报/周报/月报三周期口径与工单守恒校验来自交付运营通行做法。
- **T3**：岗位痛点来自运营支持岗常见工作场景。
- **构造**：项目日数据与异常分布口径可复算。
- **升 T1 还缺**：客户真实运营台账与一次异常处置复盘。
- **人工边界**：运营数据真实性确认、异常处置与升级决策、报表签发一律人工；本场景全部输出中不出现任何效率百分比承诺。
