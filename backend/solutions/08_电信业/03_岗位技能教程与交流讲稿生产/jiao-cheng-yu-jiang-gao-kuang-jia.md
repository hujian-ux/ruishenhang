# 教程与讲稿框架（岗位技能培训与对外技术交流）

> 适用范围：面向内部与客户的技能培训材料生产。教程要「保姆级」——非专业读者也看得懂；讲稿要「结构-案例-演示」三段式——匹配现场时长。

## 一、教程结构规范

按技能类别套用章节串模板，先讲功能模块关系，再进操作细节：

| 技能类别 | 教程大纲章节串 |
| --- | --- |
| 网络类 | 模块关系总览→操作前检查→标准操作流程→异常处置→验收与归档 |
| 系统类 | 功能模块关系→日常巡检项→故障排查决策树→演练操作→记录归档 |
| 交付类 | 适用场景→文档结构与模板→填写要点→评审流程→归档与复用 |
| 平台类 | 能力总览→配置入口→参数逐项说明→联调验证→常见问题 |

交互要求：凡教程类交付物，代码与命令逐段补充注释，目录项必须可跳转到对应位置。

## 二、图示配置规则（按受众类别）

| 受众类别 | 图示需求 |
| --- | --- |
| 非专业读者（客户管理层） | 概念图 2 张、拓扑图 1 张 |
| 客户技术侧（含数据管理员/开发团队/运维值班员/安全负责人） | 拓扑图 1 张、操作截图逐步骤配 |
| 新入职（网络/交付/运营岗） | 操作截图逐步骤配、流程图 1 张 |
| 内部横向序列 | 流程图 1 张 |

受众归类：受众字段含「客户」且含「管理层」归非专业读者；含「客户」归客户技术侧；含「新入职」归新入职；其余归内部横向序列。

## 三、讲稿规范（结构-案例-演示三段式）

| 受众类别 | 讲稿要点 |
| --- | --- |
| 新入职 | 结构：从零到一的主线；案例：真实项目操作复盘；演示：分步操作走查 |
| 客户技术侧 | 结构：能力与边界主线；案例：客户环境实例；演示：关键配置现场演示 |
| 非专业读者 | 结构：价值与场景主线；案例：同类客户成效案例；演示：概念图讲解为主 |
| 内部横向序列 | 结构：协作接口主线；案例：跨岗协作实例；演示：模板填报演示 |

## 四、时长裁剪规则

- 讲稿字数上限 = 场合时长（分钟） × 200 字/分钟
- 现有材料字数超过上限时必须裁剪，顺序固定：**先删技术细节 → 再删案例背景 → 保留主线结论**，删减量 = 现有字数 − 上限
- 现有材料字数为 0 的讲稿为新制，按字数上限控制篇幅
- 纯教程类交付物无现场时长约束，不做裁剪判定

## 五、素材缺口判定与生产优先级

| 现有材料状态 | 素材缺口 | 生产优先级 |
| --- | --- | --- |
| 无材料 | 全量缺口：大纲、图示、注释、案例均需新制 | 高 |
| 散落文档 | 归集重构：按教程框架重组现有内容并补图示 | 中 |
| 已有初稿 | 局部完善：补充图示与目录跳转 | 低 |

## 六、责任人分工

按技能类别指派素材责任人：网络类→顾北辰；系统类→白景行；交付类→陆知行；平台类→秦风眠。知识运营岗负责统一成稿与可读性把关。
