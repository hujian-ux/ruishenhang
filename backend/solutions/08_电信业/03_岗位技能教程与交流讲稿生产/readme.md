# TCM-03 · 岗位技能教程与交流讲稿生产 —— 场景使用说明

- **行业**：运营商生态
- **角色**：知识运营岗（温书言）
- **场景编号**：TCM-03
- **案例主体**：某系统集成与行业数字化企业（与本场景库 TCM-01 / TCM-02 / TCM-04 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/岗位技能教程与交流讲稿生产/SKILL.md` | Skill 定义 | 大纲章节串、图示配置、三段式讲稿、时长裁剪与缺口判定规则 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `岗位技能与分享需求.csv` | 原始输入 | 15 项岗位技能的类别、受众、场合时长、现有材料状态与字数 |
| `教程与讲稿框架.md` | 原始输入 | 四类大纲模板、图示规则、200 字/分钟裁剪规则、优先级判定 |
| `教程与讲稿生产表.csv` | **交付物** | 15 行生产表：大纲 × 图示 × 讲稿要点 × 裁剪方案 × 缺口与优先级 |
| `知识运营岗-岗位技能教程与交流讲稿生产.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `岗位技能与分享需求.csv`、`教程与讲稿框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 高优先级技能排内训首期；客户场合材料在演示前完成脱敏确认。

### 可复算口径

- `讲稿字数上限` = 场合时长（分钟） × 200 字/分钟
- `裁剪量` = 现有材料字数 − 讲稿字数上限（为正时必须裁剪）
- `受众归类` = 含「客户+管理层」→非专业读者；含「客户」→客户技术侧；含「新入职」→新入职；其余→内部横向序列
- `生产优先级` = 无材料→高 / 散落文档→中 / 已有初稿→低

## 五、真实性等级与边界

- **T2**：教程结构与三段式讲稿规范来自培训通行做法。
- **T3**：岗位痛点来自知识运营岗常见工作场景。
- **构造**：技能清单与裁剪口径可复算。
- **升 T1 还缺**：客户真实培训反馈与讲师评分记录。
- **人工边界**：技术内容正确性审核、现场演讲答疑、客户环境案例脱敏确认一律人工；本场景全部输出中不出现任何效率百分比承诺。
