# TCM-03 主提示词 · 岗位技能教程与交流讲稿生产

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/岗位技能教程与交流讲稿生产/SKILL.md`）。
2. 上传两个附件：`岗位技能与分享需求.csv`、`教程与讲稿框架.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `教程与讲稿生产表.csv` 后，按文末「验收清单」逐项核对。

---

## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某系统集成与行业数字化企业 · 岗位技能培训与对外技术交流」做岗位技能教程与交流讲稿的生产规划，输出一张可复核的教程与讲稿生产表。

【输入 1 · 技能与分享需求】岗位技能与分享需求.csv（15 行）
- 含技能编号、技能主题、技能类别（网络/系统/交付/平台）、受众、分享场合、场合时长、现有材料状态与字数、期望交付
- 受众先归类（非专业读者/客户技术侧/新入职/内部横向序列）再决定图示与讲稿姿态

【输入 2 · 教程与讲稿框架】教程与讲稿框架.md
- 四类教程大纲章节串、按受众的图示配置规则、结构-案例-演示三段式讲稿规范、200 字/分钟的时长裁剪规则、素材缺口与优先级判定

【输出】教程与讲稿生产表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「岗位技能教程与交流讲稿生产」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **15 项技能一共要出多少份交付物？** 期望回答：20 份——教程 11 份 + 讲稿 9 份，其中 5 项（JN-01/02/09/11/15）是教程+讲稿双交付。
2. **哪两份讲稿要裁剪？各删多少？** 期望回答：JN-03 汇报演示技巧 11000 字超 45 分钟上限 9000 字，删 2000；JN-07 基线加固 7300 字超 30 分钟上限 6000 字，删 1300——先删技术细节，再删案例背景，保留主线结论。
3. **JN-08 面向客户管理层，图示怎么配？** 期望回答：非专业读者——概念图 2 张、拓扑图 1 张，讲稿以价值与场景为主线，演示环节以概念图讲解为主。
4. **哪些技能排最高优先级？** 期望回答：5 项无材料技能（政企专线割接、弱电井布线、物联感知勘点、无线勘测、算力申请）——全量缺口，大纲、图示、注释、案例都要新制。
5. **责任人怎么分工？** 期望回答：按技能类别指派——网络类顾北辰、系统类白景行、交付类陆知行、平台类秦风眠，知识运营岗统一成稿。

## 验收清单

- [ ] 交付物 15 行，交付形态只含 {教程, 讲稿, 教程+讲稿}
- [ ] 交付物合计 = 教程 11 + 讲稿 9（双交付 5 项）
- [ ] 受众分布 = 客户技术侧 7 / 新入职 4 / 内部横向 3 / 非专业读者 1
- [ ] 讲稿字数上限全部 = 场合时长 × 200（JN-08 为 20 分钟 × 200 = 4000 字）
- [ ] 裁剪 2 份共 3300 字：JN-03 删 2000 / JN-07 删 1300，顺序为先技术细节再案例背景
- [ ] 图示合计 = 概念图 2 / 拓扑图 8 / 流程图 7 / 操作截图 11 套
- [ ] 素材缺口与优先级分布均为 5/5/5，全表无「待定」「占位」字样
