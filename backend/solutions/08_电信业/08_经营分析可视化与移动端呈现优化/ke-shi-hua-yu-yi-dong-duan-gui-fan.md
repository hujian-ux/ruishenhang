# 经营可视化与移动端呈现规范（三季度经营分析）

## 1. 图表选型决策表

| 分析意图 | 推荐图表 |
| --- | --- |
| 看构成（占比） | 环形图（≤5 类目）/ 占比条 |
| 看趋势（时间序列） | 折线图；需对比同期时用双系列折线图 |
| 看达成（对目标） | 横向条形图 + 100% 基准线 |
| 看对比（业务线之间） | 条形图 |
| 关键指标 | 大数字指标卡 |

## 2. 业务线选型规则（按优先级判定，命中即止）

1. 收入占比 ≥ 30% → **环形图（构成占比）+ 月度折线图（趋势）**
2. 综合同比增速 ≥ 15% → **双系列折线图（本期 vs 同期）**
3. 综合达成率 < 95% → **横向条形图（达成对比，100% 基准线）**
4. 其余业务线 → **条形图（业务线对比）**
5. 合计行 → **关键指标卡 + 月度折线图（总趋势）**

## 3. 移动端适配要点

- **布局**：单列布局，关键指标卡置顶，图表纵向排布，去横向滚动
- **字号**：正文 ≥14px，指标大数字 ≥28px，SVG 图表内文字 ≥14px
- **图表**：高度 ≤320px，图例系列 ≤3 个，100% 基准线标签清晰
- **表格**：宽表转卡片式两列表，关键数字加粗突出
- **交互**：触控热区 ≥44px，点击图表可放大查看，精简悬停类交互

## 4. 呈现口径（与数据表一致）

- 综合达成率 = 三个月合计收入 ÷ 合计目标收入
- 同期收入 = 当月收入 ÷（1 + 同比增速）
- 综合同比增速 = 合计收入 ÷ 同期收入合计 − 1
- 收入占比 = 业务线合计收入 ÷ 全部业务线合计收入
- 保留 1 位小数；达成率、增速、占比均带 % 呈现

## 5. 视觉规范

- 主色 #0052D9，辅助灰阶；不使用红 / 绿 / 橙等状态色区分好坏
- 达成不足 95% 的业务线用 100% 基准线呈现差距，不用颜色渲染

## 6. 人工边界

- 图表选型与适配要点由规范自动判定；经营结论解读、汇报口径与数据源取舍由经营分析人员人工决定
- AI 不代写经营分析结论，只输出可视化选型与呈现要点
