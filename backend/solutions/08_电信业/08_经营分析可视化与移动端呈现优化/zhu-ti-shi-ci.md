## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某终端分销与供应链企业 · 三季度经营分析」做经营分析可视化与移动端呈现规划，输出一张可复核的经营可视化数据表。

【输入 1 · 经营分析月度数据】经营分析月度数据.csv（15 行）
- 5 条业务线 × 3 个月（7-9 月）的收入、目标收入与同比增速
- 综合口径：合计收入÷合计目标=综合达成率；当月收入÷(1+同比增速)=同期收入

【输入 2 · 可视化与移动端规范】可视化与移动端规范.md
- 图表选型决策表：构成→环形图、趋势→折线图、达成→横向条形图+100%基准线、对比→条形图
- 业务线选型规则（按优先级）：占比≥30%→环形+月度折线；同比≥15%→双系列折线；达成率<95%→横向条形图；其余→条形图
- 移动端：单列布局、正文≥14px、图表高度≤320px、图例≤3、触控热区≥44px

【输出】经营可视化数据表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「经营分析可视化与移动端呈现优化」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **合计口径是多少？** 期望回答：三季度合计收入 127,700 万元 / 目标 129,800 万元，综合达成率 98.4%，综合同比 +8.9%。
2. **终端销售为什么选环形图？** 期望回答：收入占比 49.2% ≥ 30%，命中选型优先级第一条——环形图呈现构成、月度折线看趋势。
3. **泛智能终端为什么选双系列折线？** 期望回答：综合同比 +17.0% ≥ 15%（五条业务线最快），双系列折线对比本期与同期。
4. **行业直供怎么呈现差距？** 期望回答：综合达成率 92.0% < 95%，横向条形图 + 100% 基准线呈现差距，同比 −1.3% 为唯一负增长线；不用红绿橙渲染好坏。
5. **移动端要点具体在哪？** 期望回答：每条业务线的适配要点都带数值下限——正文 ≥14px、指标大数字 ≥28px、图表高度 ≤320px、图例 ≤3、触控热区 ≥44px、单列布局去横向滚动。

## 验收清单

- [ ] 输出 5 条业务线 + 1 行合计，共 6 行
- [ ] 合计：收入 127,700 万元 / 目标 129,800 万元 / 达成 98.4% / 同比 +8.9%
- [ ] 图表选型：终端销售环形+折线（占比 49.2%）/ 泛智能双系列折线（+17.0%）/ 行业直供横向条形（92.0%）/ 配件与运营商合作条形图
- [ ] 每条业务线的图表要点绑定实测数字，不空泛
- [ ] 移动端适配要点全部带数值下限，视觉只用主色 #0052D9 与灰阶
- [ ] 没有任何「经营好坏」的结论性表述（解读属于人工）
