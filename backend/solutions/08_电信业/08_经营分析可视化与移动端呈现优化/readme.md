## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `经营分析月度数据.csv`、`可视化与移动端规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 按选型与适配要点搭看板：关键指标卡置顶、各业务线主图表单列纵排；经营结论解读由经营分析人员人工完成。

### 断言项

### 可复算口径

- `综合达成率 = 三个月合计收入 ÷ 合计目标收入`
- `同期收入 = 当月收入 ÷ (1 + 同比增速)`
- `综合同比增速 = 合计收入 ÷ 同期收入合计 − 1`
- `收入占比 = 业务线合计收入 ÷ 全部业务线合计收入`

## 五、真实性等级与边界

- **T2**：分省指标分析、价位段分布、图表生成、移动端适配方法论来自客户应用案例素材。
- **T3**：岗位痛点来自素材中的效果总结（「能算出来」到「随时随地看得懂」）。
- **构造**：15 行月度数据与选型结论全部可由脚本复算。
- **人工边界**：经营结论解读、汇报口径、数据源取舍、看板上线决定一律人工；AI 只输出口径、选型与要点。
