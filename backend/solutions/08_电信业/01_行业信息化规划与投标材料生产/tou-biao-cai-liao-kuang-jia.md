# 投标材料框架与生产规则（政企客户规划与投标季）

> 适用范围：面向政企客户的信息化规划汇报与行业方案投标材料。三件套成套产出，编号统一、规范固化、可复核。

## 一、三件套构成与编号规则

每项客户需求对应三份材料：**技术方案（JS）、实施方案（SS）、服务承诺（CN）**。

- 材料编号规则：`ZB-客户序号-JS / SS / CN` + 版本号
- 技术方案版本跟随提纲迭代轮次（V1.轮次）；实施方案固定 V1.1；服务承诺固定 V1.0
- 每行需求 × 3 份材料，形成本季材料清单

## 二、章节方向判定（按核心需求关键词，自上而下命中即止）

| 章节方向 | 关键词 | 技术方案章节模板 |
| --- | --- | --- |
| 统一门户类 | 门户 | 统一认证→门户框架→系统集成→权限体系 |
| 平台建设类 | 共享、指挥，及未命中其余规则的平台型需求 | 总体架构→共性能力复用→数据流向→安全体系 |
| 物联感知类 | 物联网、联网、巡检、采集、能源 | 感知层选型→传输网络→平台接入→边缘处理 |
| 流程再造类 | 调度、治理、追溯、预约、协同、实训、招商 | 流程现状→再造设计→系统集成→移动端适配 |
| 数据分析类 | 数据、报表、案例、分析 | 数据归集→治理规则→分析模型→报表口径 |

## 三、共性能力引用规则

| 章节方向 | 共性能力引用 |
| --- | --- |
| 平台建设类 | 数据中台、统一门户 |
| 数据分析类 | 数据中台 |
| 物联感知类 | 物联感知平台 |
| 统一门户类 | 统一门户 |
| 流程再造类 | 无共性能力引用，定制开发为主 |

可映射共性能力的需求，成文时必须复用统一的共性能力表述，体现统建与复用思路。

## 四、受众定位规则（按需求优先级）

| 需求优先级 | 方案定位（受众） |
| --- | --- |
| 高 | 面向客户决策层汇报，引用最新规划政策与先进地区对标案例 |
| 中 | 面向评审专家组应答，突出技术路线与实施可行性 |
| 低 | 面向客户业务部门沟通，控制范围与成本基线 |

实施方案要点随优先级分档：高→「分期计划→里程碑→驻场团队→割接方案」；中→「分期计划→里程碑→远程加现场→风险应对」；低→「一次性实施→验收标准→远程支持」。

## 五、服务承诺分级口径

| 需求优先级 | 服务承诺要点 |
| --- | --- |
| 高 | 7×24 响应，2 小时到场，驻场保障 |
| 中 | 5×8 响应，4 小时远程响应，季度巡检 |
| 低 | 次日响应，远程支持，年度巡检 |

## 六、生产流程规则

1. **先提纲后成文**：提纲按受众定位先出多版，迭代轮次记录在调研表，未过提纲评审不得进入成文。
2. **定位纠偏而非细节修改**：内容偏向时不做局部修补，重新给定受众与政策对标后整体重写；提纲迭代轮次 ≥2 视为一次定位纠偏。
3. **规范一次交代长期生效**：字体字号、章节顺序、报送口径一次交代，固化为后续默认行为。
4. **结构可视化**：成文同步输出可编辑导图，方案结构关系一图呈现。

## 七、生产状态口径（按调研阶段）

| --- | --- |

| 深度访谈 | 提纲评审中 |
| 初访 | 调研补充中 |
