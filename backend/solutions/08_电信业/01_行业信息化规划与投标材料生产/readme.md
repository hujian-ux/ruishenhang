# TCM-01 · 行业信息化规划与投标材料体系化生产 —— 场景使用说明

- **行业**：运营商生态
- **角色**：行业方案岗（沈亦帆）
- **场景编号**：TCM-01
- **案例主体**：某系统集成与行业数字化企业（与本场景库 TCM-02 / TCM-03 / TCM-04 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/行业信息化规划与投标材料体系化生产/SKILL.md` | Skill 定义 | 章节方向判定、共性能力引用、受众定位与服务承诺分级规则 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `行业客户需求与调研要点.csv` | 原始输入 | 20 个政企客户的需求与调研明细（痛点/需求/现状系统/优先级/调研阶段/迭代轮次） |
| `投标材料框架.md` | 原始输入 | 三件套编号规则、关键词章节映射、共性能力与服务承诺分级口径、先提纲后成文规则 |
| `规划与投标材料表.csv` | **交付物** | 20 行材料生产表：章节方向 × 受众定位 × 三件套要点 × 材料清单 × 生产状态 |
| `行业方案岗-行业信息化规划与投标材料体系化生产.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `行业客户需求与调研要点.csv`、`投标材料框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 已成文材料转投标递交；交付启动后项目运营数据转 TCM-02。

## 四、与案例链的数字对齐

| 数字 | 出处 | 在本场景的落点 |
| --- | --- | --- |
| 20 个政企客户需求 | 输入调研表 | `行业客户需求与调研要点.csv` 20 行 |
| 每行需求三件套（技术方案/实施方案/服务承诺） | 框架规则 | 交付物材料清单 60 份 |
| 共性能力复用思路（统建与复用） | 素材「共性能力表述」 | 13/20 客户引用数据中台/统一门户/物联感知平台 |
| 定位纠偏整体重写而非逐句改 | 素材「方向纠偏」 | 迭代 ≥2 轮记 10 次纠偏，技术方案版本跟随轮次 |
| 规范一次交代长期生效 | 素材「规范记忆」 | 框架固化编号/章节/承诺口径，成文自动沿用 |

## 五、真实性等级与边界

- **T2**：三件套材料构成与编号规则来自行业通行投标规范。
- **T3**：岗位痛点来自售前方案岗常见工作场景。
- **构造**：客户需求与方向分布口径可复算。
- **升 T1 还缺**：客户真实标书与评标反馈复盘。
- **人工边界**：投标报价、商务承诺兑现、方案终审一律人工；本场景全部输出中不出现任何效率百分比承诺。
