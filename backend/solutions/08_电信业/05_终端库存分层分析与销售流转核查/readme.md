# TCM-05 · 终端库存分层分析与销售流转核查 —— 场景使用说明

- **行业**：运营商生态
- **角色**：库存分析岗（陈越）
- **场景编号**：TCM-05
- **案例主体**：某终端分销与供应链企业（运营商旗下终端分销企业）

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `终端库存与销售明细.csv`、`分层与核查规则.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 流转差异行转省仓对账；滞销预警机型转人工做调拨/促销/退换裁决。

## 三、交付物验证记录

生成脚本 `gen_TCM-05.py` 以 Python 标准库 `csv` 实际写出文件，并在脚本内做断言验证。执行结果：


### 断言项

| 断言 | 结果 |
| --- | --- |
| 输入明细 30 行，归一后机型数 = 10 | 通过 |
| 前导零变体行数 = 5（01002/01005/01007/01009/01010） | 通过 |
| 分层分布 = 畅销 4 / 关注 2 / 滞销 4 | 通过 |
| 滞销机型 = 老款4G手机D / 智能平板F / 老款智能手表G / 4G功能机J | 通过 |
| 滞销库存 12,600 台 ÷ 合计 56,500 台 = 22.3% | 通过 |
| 进销存差异恰 1 行：华东省仓 老款4G手机D，上报 1,000 台 vs 理论 1,040 台，−40 台 | 通过 |

### 可复算口径

- `归一编码 = 机型编码去前导零`
- `省仓库存 = 华东省仓 + 华南省仓`
- `加权平均库龄 = Σ(上报期末库存 × 库龄天数) ÷ 机型合计库存`
- `周转月数 = 机型合计库存 ÷ 近30天合计销量`
- `理论期末 = 期初库存 + 本期入库 − 近30天销量`

## 五、真实性等级与边界

- **T2**：分层库存展示、编码索引匹配、周转字段核查方法论来自客户应用案例素材。
- **T3**：岗位痛点来自素材中的传统/WorkBuddy 模式对比。
- **构造**：30 行明细与分层结论全部可由脚本复算。
- **人工边界**：差异原因认定（串货/录入/在途）与滞销处置决定（调拨/促销/退换）一律人工。
