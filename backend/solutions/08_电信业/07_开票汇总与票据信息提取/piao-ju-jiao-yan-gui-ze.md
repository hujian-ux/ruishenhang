# 票据校验规则（开票汇总与票据信息提取）

## 1. 票据类型与票号规则

- **数电发票（蓝字 / 红字）**：票号为 **20 位连续数字**，可能混在含红冲说明等冗余文本的单元格里，需先提取再校验
- **增值税专用发票 / 增值税普通发票（纸质）**：票号为 **8 位数字**
- **应开未开票据**：尚未出具号码，票号校验记「不适用（未开票）」

## 2. 票号提取规则

- 从「票据号码原文」提取 20 位（数电）/ 8 位（纸质）连续数字作为提取后票据号
- 原文含红冲说明且出现**多个** 20 位号码时：排除「关联原票据号」列已登记的号码，取剩余号码（红字现票）
- 原文最长数字串位数不足 → 票号校验记「位数不足」，转人工核实

## 3. 税号校验

- 购方税号为 **18 位统一社会信用代码**（数字 + 大写字母）
- 位数 ≠ 18 → 记「税号位数异常」，转人工补录

## 4. 红冲票据规则

- 红字票据金额**必须为负数**
- 必须**登记关联原票据号**；缺失 → 记「红冲关联缺失」，转人工补关联

## 5. 开票类别与汇总口径

| 开票类别 | 判定 |
| --- | --- |
| 当日已开 | 开票状态 = 已开出 |
| 按规则直开 | 应开未开，且票种符合直开规则 |
| 需转换票种 | 应开未开，但票种需转换（如纸质普票转数电专票） |
| 红字冲销 | 数电发票（红字），金额为负 |

- 当日净开票金额 = 已开票据合计 + 红字票据合计（红字为负数）
- 需转换票种的判定以「业务内容」列的转开说明为准

## 6. 资产归集

- 购方为**本企业（某终端分销与供应链企业）**的资产采购票据（检测设备 / 货架系统 / 服务器设备等）→ 归集资产明细
- 购方为渠道客户的销售票据 → 不归集，计入销售开票台账

## 7. 人工边界

- 异常票据的补录与更正、需转换票种的转开决定，属于财务开票岗人工
- AI 只做提取、校验、汇总与标记，不代开、不代改
