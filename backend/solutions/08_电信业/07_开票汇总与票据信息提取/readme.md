# TCM-07 · 开票汇总与票据信息提取 —— 场景使用说明

- **行业**：运营商生态
- **角色**：财务开票岗（何静）
- **场景编号**：TCM-07
- **案例主体**：某终端分销与供应链企业（运营商旗下终端分销企业）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/开票汇总与票据信息提取/SKILL.md` | Skill 定义 | 票号/税号校验规则、红冲链条闭合要求、开票类别口径与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `开票与票据数据.csv` | 原始输入 | 22 行票据数据：票号原文含冗余文本、红字票据、资产采购票据 |
| `票据校验规则.md` | 原始输入 | 票号位数（数电 20/纸质 8）、税号 18 位、红冲规则、开票类别与资产归集口径 |
| `开票汇总与票据校验表.csv` | **交付物** | 22 行逐票校验：提取后票据号、校验结果、异常类型、资产归集、开票类别 |
| `gen_TCM-07.py` | 生成脚本 | 从原始输入计算生成交付物，含断言验证与 Skill zip 打包 |
| `财务开票岗-开票汇总与票据信息提取.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `开票与票据数据.csv`、`票据校验规则.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 3 票异常转人工补录台账；2 票需转换票种转开数电专票；3 票资产归集转固定资产台账。

### 可复算口径

- `提取后票据号 = 票据号码原文中位数匹配的连续数字（红冲文本排除关联原票据号）`
- `当日净开票 = 已开票据合计 + 红字票据合计（红字为负）`
- `资产归集合计 = 186,000 + 142,000 + 158,000 = 486,000 元`

## 五、真实性等级与边界

- **T2**：开票口径汇总、数电票号提取、资产明细识别方法论来自客户应用案例素材。
- **T3**：岗位痛点来自素材中的传统/WorkBuddy 模式对比。
- **构造**：22 票明细与校验结论全部可由脚本复算。
- **人工边界**：异常补录与更正、需转换票种的转开决定、红字发票开具一律人工；AI 只提取、校验、汇总与标记。
