# 模板映射规则（多渠道报表同步）

## 1. 目标标准模板（V2.0 字段集）

`机型编码` / `销售台数` / `销售金额元` / `库存台数` / `退机台数` / `渠道编码` / `数据日期`

所有渠道的源数据最终按上述标准字段同步入库。

## 2. 版本差异对照（V1.2 → V2.0）

| V1.2 源字段 | V2.0 标准字段 |
| --- | --- |
| 机型号 | 机型编码 |
| 当日销量 | 销售台数 |
| 销售额 | 销售金额元 |
| 月末库存 | 库存台数 |
| 退货数量 | 退机台数 |

V1.2 报表沿用旧字段名，同步时按上表对照映射；对照表由报表管理岗维护，新增差异须先入表再同步。

## 3. 映射方式与优先级

1. **直接映射**：源字段与标准字段同名（V2.0 报表）
2. **版本对照映射**：按第 2 节对照表映射（V1.2 报表）
3. **模糊匹配**：源字段去空格后与标准字段一致（如「销售 台数」→ `销售台数`；「机型 编码」→ `机型编码`）
4. **未映射**：以上三种均不命中 → 标记「字段未映射」，**待人工处理，禁止猜测目标字段**

## 4. 数值校验

- 数值型标准字段（`销售台数` / `销售金额元` / `库存台数` / `退机台数`）：源数值必须可解析为非负数字（台数为整数，金额单位为元）
- 编码型标准字段（`机型编码` / `渠道编码`）：源数值为非空文本即通过
- 数值型源数值含文字（如「待门店确认」）或无法解析 → 标记「数值格式异常」，**待人工处理，禁止按 0 处理**
- 映射成功但数值异常的行，`标准模板字段` 保留映射结果，`转换后数值` 置空

## 5. 同步状态

| 状态 | 条件 |
| --- | --- |
| 已同步入库 | 映射方式 ∈ {直接映射, 版本对照映射, 模糊匹配} 且 数值校验通过 |
| 待人工处理 | 字段未映射 / 数值格式异常 |

## 6. 人工边界

- AI 负责按对照表匹配、模糊匹配、数值校验与同步状态标记
- V1.2 对照表的新增维护、未映射字段的归类、异常数值的补录属于人工
- 未映射与异常行**不得**自行猜测或改写后入库
