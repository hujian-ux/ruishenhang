# TCM-06 主提示词 · 报表模板匹配与批量同步

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/报表模板匹配与批量同步/SKILL.md`）。
2. 上传两个附件：`多渠道报表数据.csv`、`模板映射规则.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `模板匹配同步表.csv` 后，按文末「验收清单」逐项核对。

## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某终端分销与供应链企业 · 多渠道日报同步」做报表模板匹配与批量同步，输出一张可复核的模板匹配同步表。

【输入 1 · 多渠道报表数据】多渠道报表数据.csv（25 行）
- 四个渠道（线上商城/授权门店/运营商营业厅/行业直供）的字段-数值对，模板版本分 V1.2 与 V2.0
- 源字段存在空格变体（如「销售 台数」），源数值存在非数值内容（如「待门店确认」）

【输入 2 · 模板映射规则】模板映射规则.md
- V1.2→V2.0 版本字段对照表（机型号→机型编码等 5 组）
- 映射优先级：直接映射＞版本对照映射＞模糊匹配（去空格）；均不命中记「字段未映射」
- 数值校验：数值型标准字段须为非负数字，否则记「数值格式异常」，禁止按 0 处理

【输出】模板匹配同步表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「报表模板匹配与批量同步」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **25 行按什么优先级匹配？** 期望回答：直接映射（同名，V2.0）＞版本对照映射（V1.2 对照表）＞模糊匹配（去空格）；分布为直接 7 / 对照 11 / 模糊 5 / 未映射 2。
2. **哪些行没有入库？为什么？** 期望回答：3 行待人工处理——行业直供「销售额=待门店确认」（数值格式异常，置空不按 0 处理）、「结算价」与「运费」（字段未映射，不猜字段）。
3. **空格变体怎么处理的？** 期望回答：营业厅报表的「机型 编码」「销售 台数」「销售金额 元」「库存 台数」去空格后与标准字段一致，走模糊匹配，共 5 行。
4. **同步结果能交叉复算吗？** 期望回答：能。机型 T8201 三渠道合计销售 356+142+523=1,021 台，金额 1,281,600+511,200+1,882,800=3,675,600 元，均价恰为 3,600 元/台。
5. **「结算价」为什么不映射到相近字段？** 期望回答：未映射不猜字段是硬规则——对照表与标准字段集都不含「结算价」，归类决定（入模板或单独台账）属于人工。

## 验收清单

- [ ] 输出 25 行，序号与输入一一对应，逐行可回溯
- [ ] 映射方式分布 = 直接映射 7 / 版本对照映射 11 / 模糊匹配 5 / 未映射 2
- [ ] 同步状态 = 已同步入库 22 / 待人工处理 3
- [ ] 异常标记 = 数值格式异常 1（行业直供·销售额）+ 字段未映射 2（结算价、运费）
- [ ] T8201 三渠道合计 1,021 台 / 3,675,600 元（均价 3,600 元/台）可复算
- [ ] 没有任何异常数值被按 0 处理入库，源字段与源数值原样保留
