# FIN-12 · 周期性报表数据摘录与模板固化 —— 场景使用说明

- **行业**：金融业
- **角色**：数据摘录与报表岗
- **场景编号**：FIN-12
- **案例主体**：某城商行

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/周期性报表数据摘录与模板固化/SKILL.md` | Skill 定义 | M1-M6 映射与覆盖规则、差异留痕口径、版式规范与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `源数据表A.csv` | 原始输入 | 30 行营销条线报送明细（机构全称 + 储蓄/对公/笔数/贷款/理财） |
| `源数据表B.csv` | 原始输入 | 30 行总行口径通报（机构简称 + 亿元/百万元/千元三种不同单位 + 批次号） |
| `字段映射规则.md` | 原始输入 | M1-M6 字段映射与覆盖规则、差异标注规则、版式规范、自检要求 |
| `营销周报数据表.csv` | **交付物** | 30 行按映射规则合并摘录的结果 + 差异标注列 |
| `数据摘录与报表岗-周期性报表数据摘录与模板固化.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `源数据表A.csv`、`源数据表B.csv`、`字段映射规则.md` 三份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 报表岗对 7 处差异做业务原因追溯后成稿报送；下期只换 2026-W38 数据源重跑。

### 可复算口径

- `各项存款余额万元` = A 储蓄 + A 对公（M2）；B 亿元 ×10000 交叉核对
- `贷款投放金额万元` = A 贷款（M3）；B 百万元 ×100 交叉核对
- `理财销售额万元` = A 理财（M4）；B 千元 ÷10 交叉核对
- `两源不一致处数` = 换算后 B ≠ A 的字段个数（M6 覆盖后合计随之变动）

## 五、真实性等级与边界

- **T3**：岗位痛点来自商业银行办公室条线周期性报送的典型工作方式。
- **构造**：分支机构数据与差异设计为构造数据；口径可复算。
- **人工边界**：映射规则制定与修订、差异的业务原因追溯、对外报送审核一律人工；本场景全部输出**不改写 A 表原始数值**（B 覆盖处均留痕）。
