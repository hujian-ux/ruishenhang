# 周期性报表数据摘录与模板固化

## 一、这个 Skill 解决什么

银行存在大量「按固定模板、周期性重做」的材料：营销周报、月度重点工作、风险名单、数据通报。模板结构稳定，但每次都要重新取数、填数、排版。真实困难集中在三处：

- **两份数据源口径不同**：A 表（条线报送）与 B 表（总行通报）单位不一（亿元/百万元/千元）、机构名写法不一（简称/全称），语义匹配直接贴数会出错
- **字段对应关系靠人工判断**：上一轮按语义匹配写入的结果，业务方发现口径混用后必须能被显式规则纠正
- **版式问题最后一刻才发现**：页码、字体、页边距每次都要人工检查

本 Skill 的核心动作是：**规则一次说清，后续按规则覆盖**——把字段映射规则显式化，把已跑通的任务固化成模板，下期只换数据源。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 每周/每月按固定模板生成周报月报 | 主用场景：换数据源重跑 |
| 两份数据源单位口径不同需要摘录 | 按 M1-M6 映射规则换算核对 |
| 业务方给出明确映射规则要求覆盖旧结果 | 按 M6 覆盖并在差异标注列留痕 |
| 换人接手周期性报表 | 模板固化后按 README 步骤即可复跑 |

**不适用**：模板结构本身需要调整的场景（先由业务方更新字段映射规则文件，再回到本 Skill 流程）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `源数据表A.csv` | 必需 | 机构名称、储蓄存款余额万元、对公存款余额万元、贷款投放笔数、贷款投放金额万元、理财销售额万元 |
| 2 | `源数据表B.csv` | 必需 | 机构简称、各项存款余额亿元、贷款投放金额百万元、理财销售额千元、数据批次 |
| 3 | `字段映射规则.md` | 必需 | M1-M6 映射与覆盖规则、差异标注规则、版式规范、自检要求 |

> 缺 3（字段映射规则）时，本 Skill **必须拒绝摘录**——没有显式规则就跨表取数，等于回到语义匹配贴数的老路。这是本 Skill 最重要的一条硬规则。

## 四、输出（outputs）

唯一交付物：`营销周报数据表.csv`，字段固定为 8 列：

```
机构名称, 储蓄存款余额万元, 对公存款余额万元, 各项存款余额万元, 贷款投放笔数, 贷款投放金额万元, 理财销售额万元, 差异标注
```

- `机构名称` 取 A 表全称（M1）
- `各项存款余额万元` = A 表储蓄 + 对公（M2），交叉核对不一致时按 M6 以 B 表换算值覆盖
- `差异标注`：无差异填「两源一致」；有差异逐字段写明「字段名：A源X/B源Y，按M6采用B」，多处用「；」分隔
- 差异处数按**字段级**计数

## 五、工作流程（workflow）

### STEP 1 · 数据源上传

接收两份原始表：A 表（条线报送明细 30 行）、B 表（总行口径通报 30 行，2026-W37 批次）。

### STEP 2 · 规则给定

读入字段映射规则 M1-M6，写成显式映射表：机构对齐、存款分项合计、三项单位换算（×10000、×100、÷10）、覆盖与留痕规则。

### STEP 3 · 摘录填入并交叉核对

30 个机构 × 3 个双源字段 = 90 个交叉核对点逐一核对；不一致处按 M6 以 B 表最新批次值覆盖。

### STEP 4 · 版式规范

按默认规则前置版式：页脚居中「第 X 页 / 共 Y 页」、标题黑体三号、正文宋体小四、数字 Times New Roman、页边距上下 2.5 厘米左右 3 厘米、金额单位万元千分位。

### STEP 5 · 固化复用

本期跑通后任务固化成模板，下期只上传新数据源即可生成；换人也能跑。

## 六、关键规则（不可协商）

1. **显式规则优先于语义匹配。** 任何字段的取数必须能引用 M1-M6 编号；上一轮语义匹配写入的结果一律按本规则覆盖。
2. **单位换算不可凭感觉。** B 表亿元 ×10000、百万元 ×100、千元 ÷10，换算后才能与 A 表比较。
3. **差异必须留痕。** 两源不一致处以 B 表（总行最新批次）为准覆盖，差异标注列写明两源数值与采用规则，不允许静默取舍。
4. **版式规范前置。** 页码、字体、页边距作为默认规则在生成时设定，不做事后修补。
5. **数字可复算。** 差异处数、覆盖方向、全行合计必须能从两源重新计算得出。
6. **不承诺效率百分比。** 输出中不写「提升 X%」这类无法核验的表述。

## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读映射规则再取数：把 M1-M6 写成显式映射表，不要边看数边猜对应关系。
2. 逐机构摘录：30 个机构无遗漏无重复，机构名称取 A 表全称。
3. 交叉核对：30 机构 × 3 个双源字段 = 90 个核对点逐一核对；不一致处按 M6 以 B 覆盖并留痕，多处用「；」分隔，无差异填「两源一致」。
4. 版式规范前置：页脚居中「第 X 页 / 共 Y 页」、标题黑体三号、正文宋体小四、数字 Times New Roman、页边距上下 2.5 厘米左右 3 厘米、金额单位万元千分位。
5. 数字可复算：差异处数（字段级）、全行合计必须从两源重新计算。

### 硬性约束

【硬性约束】
- 任何字段的取数必须引用 M1-M6 规则，不允许「按语义就近填写」。
- 单位换算必须显式完成（亿元 ×10000 / 百万元 ×100 / 千元 ÷10），禁止原样贴数。
- 两源不一致不允许静默取舍，必须按 M6 覆盖并在差异标注列写明两源数值。
- A 表的储蓄、对公、笔数三列数值必须原样摘录，不得改写。
- 不写任何效率百分比或效果承诺。

### 生成后自检

【生成后自检，逐条回答】
1. 30 行输出与 A 表机构一一对应，无遗漏无重复？
2. 交叉核对点是否为 90 个，其中两源不一致 7 处（城东、湖东、江湾、运河、星海各 1 处，云谷 2 处）？
3. 每处差异是否都按 M6 采用 B 值并在差异标注列留痕？
4. 全行合计是否为：各项存款 1,474,500 万元 / 贷款投放 236,330 万元、688 笔 / 理财销售 13,783 万元？
5. 版式规范是否作为默认规则前置说明？
自检全过再输出 CSV。
