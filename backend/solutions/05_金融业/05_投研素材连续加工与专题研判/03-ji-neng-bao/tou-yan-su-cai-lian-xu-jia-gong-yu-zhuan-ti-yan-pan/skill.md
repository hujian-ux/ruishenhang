# 投研素材连续加工与专题研判

## 一、这个 Skill 解决什么

投研素材加工的真实困难不是「拿不到数据」，而是**加工过程被切碎在不同载体与多轮返工里**：

- 市场观察表格埋在邮件页签里，逐个手工摘取
- 表内数字与文字表述偶尔矛盾，靠肉眼核对，改一版要全文重看
- 行业轮动的分域口径散落在讨论里，每次研判都重新解释一遍
- 跨市场联动要人工拼接 A 股板块与海外行情
- 修订一轮（换配色、改口径、补维度）往往牵动全稿重新核对

本 Skill 的核心动作，是把「提取 → 核对 → 分域 → 联动 → 修订」固定成一套可复算的流水线，并让所有修订留在同一上下文里可追溯。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 每日市场观察邮件到达，需要提取板块行情表 | 主用场景：批量提取 + 一致性核对 |
| 需要按强势轮动 / 蓄势 / 拥挤 / 弱势讨论行业分域 | 按「时间序列 × 横截面」双维度口径分域 |
| 研判 A 股某板块与海外市场走势的联动关系 | 按映射表 + 波幅阈值输出联动观察信号 |
| 专题图表配色 / 口径需要按反馈多轮调整 | 只改指定段落，其余保持原样 |

**不适用**：正式投资决策输出（本 Skill 全部结论不构成投资建议）；需要逐笔交易数据加工的实时行情场景。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `市场观察素材表.csv` | 必需 | 板块编号、板块名称、当日涨跌幅%、当日成交额亿元、上周强势度排名、本周强势度排名、换手率%、邮件文字表述、原标注分域 |
| 2 | `研究口径说明.md` | 必需 | 强势排名分界、高集中阈值、一致性核验规则、跨市场联动映射表、多轮修订规则 |

> 缺 2（口径说明）时，本 Skill **必须拒绝输出分域与联动结论**——没有口径的加工只是搬数据。这是本 Skill 最重要的一条硬规则。

## 四、输出（outputs）

唯一交付物：`投研素材加工与联动分析表.csv`，字段固定为 10 列：

```
板块编号, 板块名称, 当日涨跌幅%, 成交集中度%, 排名变化(上周-本周),
所属分域, 分域修正, 口径校验结果, 跨市场联动信号, 修订标记
```

- `所属分域` ∈ {强势轮动域, 蓄势关注域, 高位拥挤域, 弱势整理域}
- `口径校验结果` ∈ {一致, 不一致：…（写明矛盾点与实测值）}
- `跨市场联动信号` ∈ {与{海外指标}联动观察，建议引入额外信源, 已映射{海外指标}，未达阈值, —}
- `修订标记` ∈ {分域修正, 表述已纠正, 分域修正+表述已纠正, —}

## 五、工作流程（workflow）

### STEP 1 · 提取素材表并核对数字与表述

从市场观察邮件定位策略页签下的表格，批量提取为 `市场观察素材表.csv`。随后逐行核验「邮件文字表述」与数字字段的一致性：

- 正向词（上涨/收涨/上行/走强/反弹/领涨/大涨）对应涨跌幅 ≤ 0 → 不一致
- 负向词（下跌/收跌/回落/走弱/回调）对应涨跌幅 ≥ 0 → 不一致
- 「放量」对应成交额 < 300 亿元 → 不一致（缩量为相对概念，不设反向校验）

不一致处**按数字为准**纠正表述，记「表述已纠正」。

### STEP 2 · 行业轮动双维度分域

```
时间序列强势 = 本周强势度排名 ≤ 14
轮动改善     = 本周排名 < 上周排名（数值下降 = 走强）
横截面高集中 = 成交集中度（板块成交额 ÷ 全部板块合计）≥ 3.00%
```

四域判定：强势轮动域（强势+改善+高集中）/ 蓄势关注域（强势+改善+非高集中）/ 高位拥挤域（强势+未改善+高集中）/ 弱势整理域（其余）。

与素材原有「原标注分域」不同的，记「分域修正」并写明迁移方向。

### STEP 3 · 跨市场联动研判

按映射表（12 个板块 ↔ 海外指标）判定：|当日涨跌幅| ≥ 1.5% → 输出联动观察信号并建议引入额外信源；已映射未达阈值 / 未映射的如实标注。**联动结论仅为观察建议**，是否引入信源由研究员决定。

### STEP 4 · 专题图表与配色反馈

按专题口径生成走势对比图；收到配色反馈时**只切换被点名的图**，不重绘全稿。

### STEP 5 · 多轮修订只改指定段落

任何一轮修订只动指定板块行或指定列，其余保持上一版原样，修订处在「修订标记」留痕。口径调整必须先改 `研究口径说明.md` 再重跑，不允许在结果表里临时改数。

### STEP 6 · 自检

输出前逐项自检，任一不过则不得输出：

1. 表内每个数字结论是否都能按口径说明复算得出？
2. 每处「不一致」是否写明矛盾点与实测值？
3. 分域四类的判定条件是否与口径说明逐字一致？
4. 修订是否只发生在指定段落，其余与上一版逐行一致？

## 六、关键规则（不可协商）

1. **口径先行。** 先读口径说明再加工，先改口径文件再重跑，禁止在结果表里临时改数。
2. **数字为准。** 表述与数字矛盾时一律按数字纠正表述，并留痕。
3. **修订不扩散。** 只改指定段落；全稿重排 / 全表重算必须由人明确发起。
4. **联动是观察不是结论。** 联动信号只建议「引入额外信源」，不输出任何买卖方向判断。
5. **不写效率百分比。** 输出中不写「提升 X%」这类无法核验的表述。

## 七、人工边界

| AI 负责 | 人负责（投研岗） |
| --- | --- |
| 表格提取与一致性核对 | 口径本身的制定与调整 |
| 双维度分域计算 | 分域结果的业务解读 |
| 跨市场联动信号计算 | 是否引入额外信源 |

## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读口径再加工：把四域判定、一致性规则、联动映射写成显式判定表，不要先看素材再定标准。
2. 提取与核对：逐行核对邮件文字表述与数字字段的一致性，不一致处以数字为准纠正，写明矛盾点与实测值。
3. 分域计算：逐行计算成交集中度（板块成交额 ÷ 全部板块当日成交额合计）与排名变化，按四域判定归类；与「原标注分域」不同的记分域修正，写明迁移方向。
4. 联动研判：按映射表逐行判定联动信号；触发阈值的输出「与{海外指标}联动观察，建议引入额外信源」；已映射未达阈值的如实标注；未映射记「—」。
5. 修订留痕：每行输出修订标记（分域修正 / 表述已纠正 / 分域修正+表述已纠正 / —），修订只涉及指定段落，其余保持原样。

### 硬性约束

【硬性约束】
- 每个数字结论（集中度、排名变化、分域、联动）都必须能按研究口径说明复算得出，不允许「综合判断」。
- 口径校验结果为「不一致」时必须写明矛盾点与实测值。
- 联动信号仅为观察建议，不输出任何买卖方向判断，不构成投资建议。
- 修订不扩散：只改指定段落，不重算未点名行。
- 不写任何效率百分比或效果承诺。

### 生成后自检

【生成后自检，逐条回答】
1. 40 行是否全部完成分域归类，四域判定条件是否与口径说明逐字一致？
2. 不一致处的矛盾点与实测值是否全部写明？
3. 分域修正是否写明迁移方向？
4. 联动触发是否严格按 |涨跌幅| ≥1.5% 与映射表执行？
5. 修订标记是否与分域修正、表述纠正一一对应？
自检全过再输出 CSV。

### 输出格式

【输出格式】CSV，10 列，列名与顺序固定：
板块编号, 板块名称, 当日涨跌幅%, 成交集中度%, 排名变化(上周-本周), 所属分域, 分域修正, 口径校验结果, 跨市场联动信号, 修订标记
