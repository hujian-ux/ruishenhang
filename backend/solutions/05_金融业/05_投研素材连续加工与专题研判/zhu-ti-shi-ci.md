# FIN-05 主提示词 · 投研素材连续加工与专题研判

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/投研素材连续加工与专题研判/SKILL.md`）。
2. 上传两个附件：`市场观察素材表.csv`、`研究口径说明.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `投研素材加工与联动分析表.csv` 后，按文末「验收清单」逐项核对。

---

## 主提示词（复制即用）

```
请基于我上传的两份素材，完成当日市场观察素材的连续加工与专题研判，输出一张可复算的投研素材加工与联动分析表。

【输入 1 · 市场观察素材】市场观察素材表.csv（40 行）
- 含板块编号、板块名称、当日涨跌幅%、当日成交额亿元、上周强势度排名、本周强势度排名、换手率%、邮件文字表述、原标注分域
【输入 2 · 研究口径】研究口径说明.md
- 分域设计：时间序列强势（本周排名 ≤14）× 轮动改善（本周 < 上周）× 横截面高集中（成交集中度 ≥3.00%），构成强势轮动 / 蓄势关注 / 高位拥挤 / 弱势整理四域
- 一致性核验：正向词但涨跌幅 ≤0、负向词但涨跌幅 ≥0、「放量」但成交额 <300 亿元，均判不一致
- 联动判定：12 个板块映射海外指标，|当日涨跌幅| ≥1.5% 触发联动观察

【输出】投研素材加工与联动分析表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「投研素材连续加工与专题研判」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **今天有几个板块进入强势轮动域？** 期望回答：9 个——半导体、证券Ⅱ、计算机应用、消费电子、电力设备、有色金属、石油石化、电池、光伏设备（强势 + 排名改善 + 集中度 ≥3.00% 三条件同时成立）。
2. **哪些表述与数字矛盾被纠正了？** 期望回答：6 处——汽车（表述收涨实际 -1.4%）、房地产开发（表述收跌实际 +0.3%）、农林牧渔（表述上涨实际 -1.1%）3 处方向矛盾；家居用品（120 亿元）、商贸零售（115 亿元）、环保（105 亿元）3 处「放量」与量能矛盾。
3. **游戏Ⅱ 成交额只有 350 亿元，为什么也算强势？** 期望回答：分域的时间序列维度只看排名（本周第 10，上周第 19，改善）；集中度属于横截面维度，低集中但强势改善归「蓄势关注域」而非「强势轮动域」。
4. **医药生物排名还在前 8，为什么标高位拥挤？** 期望回答：排名 7→8 未改善（轮动钝化）且集中度 5.17% 高集中，按口径归「高位拥挤域」，提示拥挤风险而非继续追主线。
5. **哪些板块建议引入海外信源？** 期望回答：8 个触发联动观察——半导体、消费电子、电池、光伏设备、有色金属、石油石化、游戏Ⅱ、航空装备Ⅱ；医药生物 / 汽车 / 银行 / 贵金属已映射但未达 1.5% 阈值。
