# 研究口径说明 · 市场观察素材加工与联动分析（FIN-05）

> 本说明定义「投研素材连续加工与专题研判」全流程的判定口径。所有数字结论必须按本说明可复算；口径本身如需调整，先改本文件再重跑，不允许在结果表里临时改数。

## 一、素材与范围

- 素材来源：每日《市场观察》邮件「策略页签」下的板块行情表（已落盘为 `市场观察素材表.csv`），共 40 个板块。
- 加工目标：表格提取与核对 → 行业轮动分域 → 跨市场联动研判 → 专题分析表落盘，多轮修订只改指定段落。

## 二、行业轮动分域设计（双维度）

分域采用「时间序列 × 横截面」两个维度构造 2×2 四域：

| 判定项 | 口径 | 说明 |
| --- | --- | --- |
| 时间序列强势 | 本周强势度排名 ≤ 14 | 排名越靠前越强势，14 为强势域分界 |
| 轮动改善 | 本周排名 < 上周排名 | 排名数值下降 = 走强；持平或上升 = 未改善 |
| 横截面高集中 | 成交集中度 ≥ 3.00% | 成交集中度 = 板块当日成交额 ÷ 全部 40 个板块当日成交额合计 |

| 分域 | 判定条件 | 含义 |
| --- | --- | --- |
| 强势轮动域 | 强势 且 改善 且 高集中 | 资金与动能同步确认的主线板块 |
| 蓄势关注域 | 强势 且 改善 且 非高集中 | 动能改善但资金确认不足，列入观察 |
| 高位拥挤域 | 强势 且 未改善 且 高集中 | 资金仍集中但动能钝化，注意拥挤风险 |
| 弱势整理域 | 其余情形 | 不进入本周主线讨论 |

## 三、数字与文字表述一致性核验

对每行核对「邮件文字表述」与数字字段是否一致，规则如下：

1. 表述含「上涨 / 收涨 / 上行 / 走强 / 反弹 / 领涨 / 大涨」任一正向词，但当日涨跌幅 ≤ 0 → 不一致（表述与涨跌方向矛盾）。
2. 表述含「下跌 / 收跌 / 回落 / 走弱 / 回调」任一负向词，但当日涨跌幅 ≥ 0 → 不一致（表述与涨跌方向矛盾）。
3. 表述含「放量」，但当日成交额 < 300 亿元 → 不一致（表述与量能矛盾）。不设「缩量」反向校验（缩量为相对概念，不设绝对阈值）。
4. 其余情形 → 一致。

不一致处按数字为准纠正表述，并在结果表「修订标记」中记为「表述已纠正」。

## 五、多轮修订规则

- 修订只改指定段落（指定板块行 / 指定列），其余行保持上一版原样，修订处在「修订标记」中留痕。
- 「修订标记」取值：`分域修正` / `表述已纠正` / `分域修正+表述已纠正` / `—`。
- 配色与图表反馈同样按段落处理：只切换被点名的专题图配色，不重绘全稿。

## 六、人工边界

- 联动信号仅为观察建议；是否引入额外信源、是否调整分域口径，由研究员决定。
- 本口径产出的分域与信号不构成投资建议，仅用于内部研究流程组织。
