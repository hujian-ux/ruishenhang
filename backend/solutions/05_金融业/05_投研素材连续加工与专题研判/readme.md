## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `市场观察素材表.csv`、`研究口径说明.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 需要调整口径（如集中度阈值）时：先改 `研究口径说明.md` 再重跑，不在结果表临时改数。

### 可复算口径

- `成交集中度% = 板块当日成交额 ÷ 全部板块当日成交额合计 × 100`
- `排名变化(上周-本周)：正值 = 排名走强，负值 = 排名回落`
- `四域判定：强势(本周排名≤14) × 改善(本周<上周) × 高集中(≥3.00%)`
- `联动触发：|当日涨跌幅| ≥ 1.5% 且板块在 12 板块映射表内`

## 五、真实性等级与边界

- **方法论来源**：行业轮动双维度分域（时间序列强势轮动速度 × 横截面成交集中度）、跨市场联动研判、多轮修订只改指定段落，来自投研条线的通用工作方式。
- **构造**：板块行情数据与文字表述为构造数据，全部结论可按口径说明复算。
- **人工边界**：联动信号仅为观察建议；是否引入额外信源、口径调整与专题结论发布一律由研究员决定；本场景全部输出不构成投资建议。
