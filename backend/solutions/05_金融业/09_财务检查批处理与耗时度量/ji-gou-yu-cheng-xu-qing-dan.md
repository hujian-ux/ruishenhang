# 机构与程序清单 · 财务检查批处理口径说明

> 某保险集团 · 财务检查条线 · 2026 年 8 月批处理试运行口径

## 一、参与机构（6 家分公司）

| 机构代码 | 机构名称 | 输出目录 |
| --- | --- | --- |
| SH | 诚安人寿上海分公司 | output/SH/ |
| JS | 诚安财险江苏分公司 | output/JS/ |
| ZJ | 诚安养老浙江分公司 | output/ZJ/ |
| GD | 诚安资产广东分公司 | output/GD/ |
| SC | 诚安人寿四川分公司 | output/SC/ |
| SD | 诚安财险山东分公司 | output/SD/ |

机构作为命令行参数传入（如 `run_batch.py --org SH`），输出文件与进度文件一律按机构代码隔离，禁止混写。

## 二、抽取程序（3 个）

| 程序号 | 程序名 | 材料类型 | 说明 |
| --- | --- | --- | --- |
| P1 | 凭证要素抽取 | 费用报销凭证 | 从凭证图像中识别发票代码、发票号码、价税合计、报销人、费用发生日期 |
| P2 | 审批意见抽取 | 审批单 | 从审批单文本中提取审批人、审批意见、审批层级、审批日期 |
| P3 | 签证单字段抽取 | 签证单 | 按签证单文本描述的配置表驱动，提取签证单号、结算金额、供应商名称、费用科目，减少硬编码 |

三个程序均已补 batch 版本：按机构隔离输出文件与进度文件，进度文件记录已处理材料编号，支持断点续跑。

## 三、日志口径

- 每个程序每次运行记录一行日志：机构、程序、开始时间、结束时间、进度文件状态。
- 耗时 = 结束时间 - 开始时间（分钟），以整分钟记录。
- 进度文件状态取值：已完成 / 断点续跑后完成。
- 同一机构内 P1 → P2 → P3 串行执行；机构之间并行执行，互不影响。

## 四、统计口径

- 交付物按「机构 × 程序」一行，共 6 × 3 = 18 行。
- 处理材料数 = 审批材料抽取结果.csv 中该机构该程序的材料行数。
- 存疑材料数 = 其中「是否存疑 = 是」的行数，需人工复核。
