# FIN-09 主提示词 · 财务检查批处理与耗时度量

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/财务检查批处理与耗时度量/SKILL.md`）。
2. 上传三个附件：`审批材料抽取结果.csv`、`批处理运行日志.csv`、`机构与程序清单.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `批处理与耗时统计.csv` 后，按文末「验收清单」逐项核对。

---

## 主提示词（复制即用）

```
请基于我上传的三份素材，为「某保险集团 · 财务检查条线 2026-08-12 批处理试运行」生成一张可复核的批处理与耗时统计表。

【输入 1 · 抽取结果】审批材料抽取结果.csv（50 行）
- 列：机构、材料编号、材料类型、抽取程序、抽取字段、抽取值、是否存疑
- 材料类型 ∈ {费用报销凭证, 审批单, 签证单}，分别对应 P1/P2/P3 三个抽取程序
【输入 2 · 运行日志】批处理运行日志.csv（18 行）
- 列：机构、程序、开始时间、结束时间、进度文件状态
- 耗时 = 结束时间 − 开始时间（分钟），这是耗时的唯一数据源，禁止估算
【输入 3 · 口径说明】机构与程序清单.md
- 6 家分公司的机构代码与输出目录约定、3 个抽取程序与材料类型对应关系
- 日志口径与统计口径（交付物按机构 × 程序一行，共 6 × 3 = 18 行）

【输出】批处理与耗时统计.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「财务检查批处理与耗时度量」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **哪个程序最耗时？** 期望回答：P1 凭证要素抽取，合计 264 分钟，占总耗时 504 分钟的 52.4%——凭证图像识别是瓶颈，优化优先级第一。
2. **为什么浙江分公司的 P3 是「断点续跑后完成」？** 期望回答：进度文件记录已处理材料编号，中断后从断点继续，不重跑已完成的材料——这是进度文件的价值。
3. **新增一家机构要改代码吗？** 期望回答：不需要。机构是参数（`--org`），输出目录、日志名、进度文件按机构代码隔离，加参数即可。
4. **存疑的 11 份材料怎么处理？** 期望回答：程序只标注数量，认定与处置交财务检查岗人工复核，AI 不下结论。
5. **最慢的机构是哪家？** 期望回答：诚安财险山东分公司，三程序合计 121 分钟（P1 57 + P2 35 + P3 29）。

## 验收清单

- [ ] 交付物 18 行 = 6 机构 × 3 程序
- [ ] 处理材料数合计 = 50，存疑材料数合计 = 11（占 22%）
- [ ] 耗时合计 = 504 分钟，平均 28.0 分钟，单份平均 10.08 分钟
- [ ] 程序耗时合计 = P1 凭证要素抽取 264 / P2 审批意见抽取 144 / P3 签证单字段抽取 96
- [ ] P1 占比 52.4%，为最慢环节；最慢机构 = 诚安财险山东分公司 121 分钟
- [ ] 浙江分公司 P3 进度文件状态 = 断点续跑后完成；全表无估算耗时、无效率百分比
