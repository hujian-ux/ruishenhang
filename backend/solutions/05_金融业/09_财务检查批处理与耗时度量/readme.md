# FIN-09 · 财务检查批处理与耗时度量 —— 场景使用说明

- **行业**：金融业（保险）
- **角色**：财务检查岗
- **场景编号**：FIN-09
- **案例主体**：某保险集团

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/财务检查批处理与耗时度量/SKILL.md` | Skill 定义 | 批处理改造推进顺序、耗时统计口径、配置表驱动规则与人工边界 |

| `批处理与耗时统计.csv` | **交付物** | 18 行（机构 × 程序）：开始、结束、耗时分钟、材料数、存疑数、进度状态 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `审批材料抽取结果.csv`、`批处理运行日志.csv`、`机构与程序清单.md` 三份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 存疑材料（11 份）转人工复核；耗时基线留作后续批处理优化的对照。

### 断言项

| 断言 | 结果 |
| --- | --- |
| 四个文件存在且 size > 0 | 通过 |
| `审批材料抽取结果.csv` 数据行 = 50 | 通过 |
| `批处理运行日志.csv` 数据行 = 18 | 通过 |
| `批处理与耗时统计.csv` 数据行 = 18（6 机构 × 3 程序全覆盖） | 通过 |
| 处理材料数合计 = 50 | 通过 |
| 存疑材料数合计 = 11（占 22.0%） | 通过 |
| 逐行耗时 = 结束时间 − 开始时间（复算一致） | 通过 |
| 总耗时 = 504 分钟 | 通过 |
| 平均耗时 = 504 ÷ 18 = 28.0 分钟；单份平均 = 504 ÷ 50 = 10.08 分钟 | 通过 |
| 程序合计：P1 = 264 / P2 = 144 / P3 = 96（264 + 144 + 96 = 504） | 通过 |
| P1 占比 = 264 ÷ 504 = 52.4% | 通过 |
| 最慢机构 = 诚安财险山东分公司 121 分钟 | 通过 |

### 可复算口径

- `耗时分钟 = 结束时间 − 开始时间`（逐行复算）
- `处理材料数 = 审批材料抽取结果.csv 按机构 × 程序分组计数`
- `存疑材料数 = 其中「是否存疑 = 是」的行数`
- `平均耗时 = 总耗时 ÷ 任务数`；`单份平均 = 总耗时 ÷ 材料总数`
- `程序耗时占比 = 该程序耗时合计 ÷ 总耗时`

## 五、真实性等级与边界

- **T2**：批处理、日志耗时统计、配置表驱动的方法论来自公开的工程实践。
- **T3**：财务检查岗位痛点来自素材中的传统模式描述。
- **构造**：机构、材料、日志数据口径可复算。
- **升 T1 还缺**：真实检查批次的日志与一次瓶颈优化的前后对照。
- **人工边界**：存疑材料的认定、检查结论与整改建议的签发一律人工；本场景全部输出不出现效率百分比承诺。
