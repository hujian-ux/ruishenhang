# FIN-06 · 市场复盘与同业研究技能搭建 —— 场景使用说明

- **行业**：金融业
- **角色**：金融市场投研岗
- **场景编号**：FIN-06
- **案例主体**：某城商行

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/市场复盘与同业研究技能搭建/SKILL.md` | Skill 定义 | 六栏目固定结构、资金活跃度口径、同业要素解析规则与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `收盘行情快照.csv` | 原始输入 | 50 行收盘行情：6 指数 + 24 行业板块 + 20 只涨跌停个股（涨停 12 / 跌停 8） |
| `复盘结构说明.md` | 原始输入 | 六栏目固定结构、资金活跃度口径定义、排序规则、同业调研口径 |
| `同业产品公开要素摘录.csv` | 原始输入 | 8 家同业银行个贷小额信用产品的公开要素摘录原文 |
| `当日市场复盘速递.csv` | **交付物** | 22 行按固定栏目组织的当日速递（栏目/条目/数值/单位/口径说明） |
| `同业产品要素调研表.csv` | **交付物** | 8 家同业银行产品要素统一对比表 |
| `金融市场投研岗-市场复盘与同业研究技能搭建.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 交易日收盘后导出 `收盘行情快照.csv`，连同 `复盘结构说明.md`、`同业产品公开要素摘录.csv` 一并上传。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对两个交付物。
5. 复盘观点与市场解读由投研岗人工撰写后并入日报；新增口径走交互式问答增量追加。

### 可复算口径

- `涨停成交额合计` = Σ 类别=个股 且 涨跌停=涨停 的成交额亿元
- `跌停成交额合计` = Σ 类别=个股 且 涨跌停=跌停 的成交额亿元
- `净活跃度` = 涨停合计 − 跌停合计
- `板块涨跌前五` = 类别=板块 按 涨跌幅% 降序/升序取前五
- `利率下限区间` = 调研表利率下限列的最小值/最大值

## 五、真实性等级与边界

- **T3**：岗位痛点来自商业银行金融市场条线每日复盘的典型工作方式。
- **构造**：行情数据与同业产品为构造数据及 8 家构造同业银行。
- **人工边界**：复盘观点与市场解读、新口径定义、对外发布审核一律人工；本场景全部输出中**不出现投资建议、收益预测或利率报价**。
