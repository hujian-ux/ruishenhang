# FIN-06 主提示词 · 市场复盘与同业研究技能搭建

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/市场复盘与同业研究技能搭建/SKILL.md`）。
2. 上传三个附件：`收盘行情快照.csv`、`复盘结构说明.md`、`同业产品公开要素摘录.csv`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `当日市场复盘速递.csv` 与 `同业产品要素调研表.csv` 后，按文末「验收清单」逐项核对。

## 主提示词（复制即用）

```
请基于我上传的三份素材，为「某城商行 · 金融市场条线」生成当日市场复盘速递与同业产品要素调研表，两个交付物都按固定结构输出。

【输入 1 · 收盘行情快照】收盘行情快照.csv（50 行）
- 含名称、类别（指数/板块/个股）、涨跌幅%、成交额亿元、涨跌停标记、领涨领跌个股
- 构成：6 个指数 + 24 个行业板块 + 20 只涨跌停个股（涨停 12 / 跌停 8）
【输入 2 · 复盘结构说明】复盘结构说明.md
- 六栏目固定结构：指数表现 / 板块涨幅前五 / 板块跌幅前五 / 资金活跃度 / 个股与家数 / 同业动态
- 资金活跃度口径（第三节）：涨停成交额合计 = Σ当日涨停个股成交额；跌停成交额合计 = Σ当日跌停个股成交额；净活跃度 = 涨停合计 − 跌停合计；只统计收盘涨停/跌停个股
【输入 3 · 同业产品公开要素摘录】同业产品公开要素摘录.csv（8 行）
- 含银行名称、产品摘录原文、信息来源类型、摘录日期

【输出】当日市场复盘速递.csv、同业产品要素调研表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「市场复盘与同业研究技能搭建」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **资金活跃度为什么只算涨跌停个股？** 期望回答：口径定义在复盘结构说明.md 第三节，涨停/跌停个股的成交额代表短线多空活跃资金，普通大幅波动个股不计入。
2. **净活跃度 62.6 亿元怎么算的？** 期望回答：涨停成交额合计 92.6 − 跌停合计 30.0 = 62.6 亿元，三个数都能从快照 20 只涨跌停个股逐笔复算。
3. **涨幅第六的机器人板块为什么没进前五？** 期望回答：板块涨幅前五只取降序前五，机器人 +2.05% 排在第六。
4. **澄海银行的产品有什么不同？** 期望回答：最高额度 100 万元、最长期限 5 年，为 8 家中最高；且是线下网点与线上渠道均可申请。
5. **明天新增换手率口径怎么办？** 期望回答：作为增量计算量追加到对应栏目，不推翻既有六栏目结构。
