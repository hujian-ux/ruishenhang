- **角色**：精算与资产负债管理岗
- **场景编号**：FIN-07
- **案例主体**：某人寿保险公司

## 一、文件清单

| 文件 | 类型 | 作用 |

| `03_技能包/资产负债管理新规研究与汇报/SKILL.md` | Skill 定义 | 逐条对照方法、两类指标口径拆解规则、准则衔接与分端看板口径 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `新规条款对照.md`、`指标清单.csv` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 口径变化 7 项转数据与报表改造需求；展板骨架确认后进入细化。

### 可复算口径

- 口径变化 = 新规口径与现行口径逐字对照不一致的项数
- 类型分布 = 指标类型列分组计数
- 差异类型分布 = 12 条条款的「差异类型」字段计数（新增 2 条为 T11 展板结构 / T12 看板分端框架条款，不关联指标）
- 汇报展示落端 = 按（类型 × 是否变化）四象限规则生成

## 五、真实性等级与边界

- **T2**：资产负债管理监管研究与两类指标拆解的方法论来自公开的保险业资产负债管理实践。
- **T3**：岗位痛点来自精算与资产负债管理岗位的常见工作场景。
- **构造**：新规条款与指标口径为构造演练内容，用于口径拆解方法演练，不构成对任何真实监管文件的解释。
- **升 T1 还缺**：真实新规研究的条款底稿与一次落地切换复盘。
- **人工边界**：新规条文的正式解读与会计政策决定一律人工；AI 只做逐条对照、口径拆解、衔接整理与结构设计。
