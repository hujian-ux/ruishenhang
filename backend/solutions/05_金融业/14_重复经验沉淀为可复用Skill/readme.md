# FIN-14 · 重复经验沉淀为可复用Skill —— 场景使用说明

- **行业**：金融业
- **角色**：研发与效能岗
- **场景编号**：FIN-14
- **案例主体**：某投资银行

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/重复经验沉淀为可复用Skill/SKILL.md` | Skill 定义 | 识别-评估-封装-归档流水线、节时口径、交互式四问、人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `重复动作清单.csv` | 原始输入 | 15 行：动作 × 业务方 × 频率 × 当前耗时 × 已有做法 × 典型输入/期望输出 |
| `技能目录规范.md` | 原始输入 | 目录结构、命名规范（域代码）、优先级与节时口径、归档流程 |
| `技能封装与归档清单.csv` | **交付物** | 15 行：技能名 × 输入/输出 × 目录路径 × 优先级 × 节时 |
| `gen_FIN-14.py` | 生成脚本 | 从原始输入计算生成交付物并断言验证（Python 标准库） |
| `研发与效能岗-重复经验沉淀为可复用Skill.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `重复动作清单.csv`、`技能目录规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. P0 项按交互式四问（输入/输出/规则/复核人）逐个搭出 SKILL.md 并归档；规范调整先改 `技能目录规范.md` 再重跑。

### 断言项

| 断言 | 结果 |
| --- | --- |
| `重复动作清单.csv` 数据行 = 15，业务方均在域代码表内 | 通过 |
| 交付物数据行 = 15（与输入行数一致） | 通过 |
| 优先级分布 P0 5 / P1 9 / P2 1 | 通过 |
| P0 覆盖周频 36 次/周 | 通过 |
| P0 周度节时合计 582 分钟 | 通过 |
| 全部动作周频合计 68 次 / 周度节时合计 1257 分钟 | 通过 |

### 可复算口径

- `预期节时分钟/次 = 当前耗时分钟 × 60%`
- `周度预期节时分钟 = 频率（次/周）× 预期节时分钟/次`
- `优先级：周度节时 ≥90 → P0；45–89 → P1；<45 → P2`
- `技能名 = 域代码·动作名；目录路径 = 团队技能目录/<业务方>/<技能名>/`

## 四、关键数字对齐（页面引用 ↔ 数据出处）

| 数字 | 出处 | 复算方式 |
| --- | --- | --- |
| 15 个重复动作 | `重复动作清单.csv` 15 数据行 | 行数直接可数 |
| 优先封装 5 项 | 交付物「优先级」列 | P0 行计数（信用提取 / 定级材料 / 摘表 / 损益汇总 / 确认书） |
| 覆盖周频 36 次/周 | 输入「频率-次/周」列 | P0 行频率求和（12+10+5+5+4） |
| P0 周度节时 582 分钟 | 交付物「周度预期节时分钟」列 | P0 行求和（180+90+90+90+132） |
| 全部动作周频 68 次 / 节时 1257 分钟 | 输入与交付物 | 15 行分别求和 |

## 五、真实性等级与边界

- **方法论来源**：主体信用信息提取、会务人员排序、招聘定级、周报整理等重复动作沉淀为 Skill 并统一归档，来自「把个人做法沉淀为 Skill」的通用推进方式。
- **构造**：动作清单的频率与耗时为构造数据的合理量级，节时按「当前耗时 × 60%」统一估算口径，全部结论可按规范复算。
- **人工边界**：封装排期、技能首次产出复核、目录规范修订、涉敏动作数据安全评审一律人工；节时为估算口径，非实测承诺。
