# 专项主题说明 · 本月区域经营诊断（某保险科技平台 · 筹款运营）

## 一、本月诊断主题

**捐单量环比变化的「量」与「质」拆解**：本月整体捐单量环比上升，管理层要求讲清——增长（或下滑）到底来自「案例量变化」还是「单案例质量变化」，并落实到区域。

## 二、量质拆解口径（全区域统一，不得各自解释）

1. **单案例捐单均值** = 捐单量 ÷ 发起案例数（保留 1 位小数）
2. **捐单量变化** = 案例量贡献 + 单案例质量贡献，其中：
   - **案例量贡献（量）** = （本月发起案例数 − 上月发起案例数）× 上月单案例捐单均值
   - **单案例质量贡献（质）** = 本月发起案例数 × （本月单案例捐单均值 − 上月单案例捐单均值）
   - 两者之和 = 捐单量环比变化绝对值（逐区域闭合，允许 ±0.5 单以内舍入差）
3. **驱动类型判定**：
   - |捐单量环比| ≤ 5% → 「平稳」
   - 环比为正且 |案例量贡献| ≥ |单案例质量贡献| → 「量驱动增长」
   - 环比为正且 |案例量贡献| < |单案例质量贡献| → 「质驱动增长」
   - 环比为负且 |案例量贡献| ≥ |单案例质量贡献| → 「量拖累」
   - 环比为负且 |案例量贡献| < |单案例质量贡献| → 「质拖累」
4. **重点复盘线**：|捐单量环比| ≥ 15% 的区域，标注「重点复盘」，须在月度经营会上单独讲
5. **分区周报校对**：分区周报上报案例数 ≠ 月度系统发起案例数时，标注「周报口径差 N（月度系统 X vs 周报 Y），需校对」，以月度系统数为准出月报，差异转分区核实

## 三、月报固定结构（区域月报技能输出）

1. 整体结论：本月捐单量、环比、同比（本表聚焦环比）
2. 量质拆解：整体与分区域的案例量贡献 / 单案例质量贡献
3. 分区明细：12 个区域逐行诊断（驱动类型 + 异常标注 + 结论）
4. 下月策略建议：按驱动类型给出方向（扩量 / 提质 / 补量 / 控损 / 常规）

## 四、培训与宣导口径

月度经营会后 3 个工作日内，读取区域运营群聊记录与既有培训文档，总结本轮诊断培训要点并生成汇报页，要点须与本表驱动类型一致。
