1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/区域月报技能与月度经营诊断/SKILL.md`）。

## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某保险科技平台 · 筹款运营」生成本月区域月度诊断表：先用区域月报技能按固定结构生成月报框架，再围绕专项主题做量质拆解，输出一张可复核的区域月度诊断表。

【输入 1 · 区域月度指标】区域月度指标.csv（12 行）
- 含区域、发起案例数、上月发起案例数、捐单量、上月捐单量、参与人数、分区周报上报案例数
【输入 2 · 专项主题与口径】专项主题说明.md
- 本月诊断主题：捐单量环比变化的量质拆解
- 拆解口径：案例量贡献 =（本月案例数 − 上月案例数）× 上月单案例均值；单案例质量贡献 = 本月案例数 ×（本月单案例均值 − 上月单案例均值）；两者之和 = 捐单量变化
- 判定规则：|环比| ≤5% 为平稳；≥15% 触重点复盘线；正增长按 |量贡献| 与 |质贡献| 孰大定「量驱动 / 质驱动」，负增长同理定「量拖累 / 质拖累」

【输出】区域月度诊断表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「区域月报技能与月度经营诊断」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **整体捐单量涨了 4.8%，量质各占多少？** 期望回答：+1,572 单中案例量贡献 +970 单（61.7%）、单案例质量贡献 +602 单（38.3%），整体偏量驱动。
2. **华南一区环比 +17%，全是好事吗？** 期望回答：量驱动增长（量贡献 +600 单），但质贡献 −90 单（单案例均值 20.0 → 19.5），且周报口径差 +5（系统 180 vs 周报 175）需校对。
3. **华北二区为什么拖累最大？** 期望回答：捐单量环比 −16.7%（−600 单），案例数 180 → 150，纯量拖累，需补活动量并回查线索承接。
4. **哪些区域值得单独在经营会上讲？** 期望回答：华东一区（+15.5%）、华南一区（+17.0%）、西北区（+17.3%）、华北二区（−16.7%）四个区域触及 ±15% 重点复盘线。
5. **质驱动增长的区域怎么用？** 期望回答：华东二区、华南二区、华中区三个区域靠单案例均值提升，应沉淀其单案例运营打法并向量驱动区域推广。

## 验收清单

- [ ] 输出 12 行，列名与【输出格式】完全一致
- [ ] 整体：捐单量 32,860 → 34,432，环比 +4.8%，量贡献 +970 / 质贡献 +602
- [ ] 驱动分布 = 量驱动增长 4 / 质驱动增长 3 / 量拖累 2 / 质拖累 1 / 平稳 2
