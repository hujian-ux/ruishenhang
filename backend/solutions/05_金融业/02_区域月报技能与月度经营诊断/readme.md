## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `区域月度指标.csv`、`专项主题说明.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 拖累区域转渠道侧回查（→ FIN-03）；整体结论转经营分析（→ FIN-11）。

### 可复算口径

- `单案例捐单均值 = 捐单量 ÷ 发起案例数`（保留 1 位小数）
- `案例量贡献 = (本月案例数 − 上月案例数) × 上月单案例均值`
- `单案例质量贡献 = 本月案例数 × (本月单案例均值 − 上月单案例均值)`
- `捐单量环比% = (本月捐单量 − 上月捐单量) ÷ 上月捐单量 × 100`
- 复算过程（华东一区）：量贡献 = (220−200)×20.0 = +400；质贡献 = 220×(21.0−20.0) = +220；合计 +620 = 4,620−4,000 ✓

## 五、真实性等级与边界

- **T3**：区域月度复盘的岗位痛点来自保险科技平台运营实践。
- **构造**：区域指标数据为构造数据（案例主体某保险科技平台），口径可复算。
- **人工边界**：专项主题选择、分析主线决定、周报差异的分区核实、下月策略最终取舍一律人工；AI 只输出拆解、判定与建议方向。
