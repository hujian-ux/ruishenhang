# 区域月报技能与月度经营诊断

## 一、这个 Skill 解决什么

区域月度复盘的真实困难不是「没有数据」，而是**指标口径多、区域之间不可比，且只给结论不给拆解**：

- 月报靠模板手工套数据，每月重做一遍，结构还常常不一致
- 捐单量涨了 15%，说不清是案例变多了，还是单个案例运营得更好了
- 分区周报与月度系统对不上，人工逐格核对，不一致发现得晚
- 培训要点散在群聊记录和旧文档里，靠人工翻找

本 Skill 的核心动作，是把月度复盘固化成「**定主题 → 拆量质 → 校分区 → 出诊断**」的固定流水线：月报由技能按固定结构生成，量质拆解口径全区域统一，分区数据逐项校对，每个区域落一行可复核的诊断结论。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 每月经营数据已出，要写区域月报与深度分析 | 主用场景：月报生成 + 专项主题诊断 |
| 管理层问「捐单量变化到底来自量还是质」 | 用量质拆解口径逐区域归因 |
| 分区周报与月度系统数据疑似不一致 | 逐项校对发起案例数等指标并标注差异 |
| 月度经营会后要总结培训要点 | 读取群聊与既有培训文档后总结成页 |

**不适用**：渠道维度的分时段看板与异常人员标注（→ FIN-03 渠道经营看板与异常线索标注）；机制设计与方案比较（→ FIN-11 经营分析机制设计与汇报版拆分）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `区域月度指标.csv` | 必需 | 区域、发起案例数、上月发起案例数、捐单量、上月捐单量、参与人数、分区周报上报案例数 |
| 2 | `专项主题说明.md` | 必需 | 本月诊断主题、量质拆解口径、驱动类型判定规则、重点复盘线、周报校对规则、月报固定结构 |

> 缺 2（口径说明）时，本 Skill **必须拒绝输出驱动类型判定**——量质拆解口径不允许临场发挥，否则区域之间不可比。

## 四、输出（outputs）

唯一交付物：`区域月度诊断表.csv`，12 行（每区域 1 行），9 列，列名与顺序固定：

```
区域, 发起案例数, 捐单量, 捐单量环比%, 案例量贡献, 单案例质量贡献, 驱动类型, 异常标注, 诊断结论
```

- `驱动类型` ∈ {量驱动增长, 质驱动增长, 量拖累, 质拖累, 平稳}
- `案例量贡献` + `单案例质量贡献` = 该区域捐单量环比变化（逐区域闭合，允许 ±0.5 单舍入差）
- `异常标注` 含周报口径差与重点复盘线两类标记，无异常写「—」
- `诊断结论` 必须含主导贡献的方向与数量，**不允许只写「整体向好」这类无拆解的结论**

## 五、工作流程（workflow）

### STEP 1 · 读口径，先定规则再看数

从 `专项主题说明.md` 读入量质拆解口径与判定规则，写成显式判定表。**顺序不可颠倒**——先看数再定口径，等于给结论找理由。

```
单案例捐单均值 q = 捐单量 ÷ 发起案例数
案例量贡献（量）= (本月案例数 − 上月案例数) × 上月单案例均值
单案例质量贡献（质）= 本月案例数 × (本月单案例均值 − 上月单案例均值)
平稳线：|捐单量环比| ≤ 5%
重点复盘线：|捐单量环比| ≥ 15%
```

### STEP 2 · 月报生成（固定结构）

按月报固定结构生成整体结论、量质拆解、分区明细、下月策略建议四段，作为深度分析的前提步骤。

### STEP 3 · 量质拆解

对 12 个区域逐行计算量贡献与质贡献，校验逐区域闭合（量 + 质 = 捐单量变化）。整体层面同样拆解：总量贡献与总质贡献之和 = 捐单量环比变化绝对值。

### STEP 4 · 驱动类型判定

按统一规则判定每个区域的驱动类型；同时给出多个分析方向（扩量 / 提质 / 补量 / 控损 / 常规）供业务方选择主线。

### STEP 5 · 分区周报校对

逐区域比对 `分区周报上报案例数` 与 `发起案例数`，不一致即标注「周报口径差 N（月度系统 X vs 周报 Y），需校对」，以月度系统数为准出月报，差异转分区核实。

### STEP 6 · 自检与人工边界声明

输出前逐项自检，任一不过则不得输出：

1. 每个区域的量贡献 + 质贡献是否与捐单量变化闭合？
2. 驱动类型分布是否与环比方向一致（增长区域不可能判为拖累）？
3. 周报口径差是否逐区域标注且以月度系统为准？
4. 重点复盘区域是否全部标注？
5. 是否没有任何一行只写结论不写拆解？

## 六、关键规则（不可协商）

1. **口径先于结论。** 量质拆解公式、平稳线、重点复盘线以 `专项主题说明.md` 为准，不允许临场调整。
2. **拆解必须闭合。** 每一行的量贡献与质贡献之和必须等于捐单量变化，对不上就必须回查，不允许「大约是量的原因」。
3. **周报差异不静默修正。** 发现分区周报与月度系统不一致时，标注出来转分区核实，不允许悄悄改数。
4. **结论必须带数字。** 诊断结论要写明主导贡献的方向与单数，供管理层直接引用。
5. **AI 不做策略拍板。** 输出多个分析方向供业务方决定主线，下月策略的最终取舍属于人。
6. **不承诺效率百分比。** 输出中不写「提升 X%」这类无法核验的表述。

## 七、人工边界

| AI 负责 | 人负责（区域运营岗 / 管理层） |
| --- | --- |

## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读口径再看数：把拆解公式、平稳线、重点复盘线写成显式判定表，不要先看数据再定标准。
2. 月报固定结构：整体结论（捐单量、环比）→ 量质拆解（整体 + 分区域）→ 分区明细（12 区域逐行）→ 下月策略建议方向。
3. 量质拆解：对 12 个区域逐行计算案例量贡献与单案例质量贡献（保留 1 位小数），并逐区域校验「量 + 质 = 捐单量变化」闭合。
4. 驱动类型：按统一规则判定每个区域，同时在下月策略建议中给出多个方向（扩量 / 提质 / 补量 / 控损 / 常规）供业务方选择主线。
5. 分区周报校对：逐区域比对「分区周报上报案例数」与「发起案例数」，不一致即标注「周报口径差 N（月度系统 X vs 周报 Y），需校对」，以月度系统数为准。
6. 异常标注：|环比| ≥15% 的区域追加「环比 X% 达重点复盘线」；无异常写「—」。

### 硬性约束

【硬性约束】
- 每行的案例量贡献 + 单案例质量贡献必须等于该区域捐单量变化（允许 ±0.5 单舍入差），对不上必须回查。
- 诊断结论必须写明主导贡献的方向与单数，不允许只写「整体向好」这类无拆解结论。
- 周报口径差不静默修正：标注差异并转分区核实，以月度系统数为准出月报。
- 拆解口径以专项主题说明.md 为准，不允许临场调整公式或阈值。
- 不写任何效率百分比或效果承诺。

### 生成后自检

【生成后自检，逐条回答】
1. 12 行是否每行量质闭合？
2. 驱动类型分布是否与环比方向一致？
3. 周报口径不一致的区域是否全部标注？
4. 重点复盘线区域是否全部标注？
5. 是否没有任何一行只写结论不写拆解？
自检全过再输出 CSV。

### 输出格式

【输出格式】CSV，12 行（每区域 1 行），9 列，列名与顺序固定：
区域, 发起案例数, 捐单量, 捐单量环比%, 案例量贡献, 单案例质量贡献, 驱动类型, 异常标注, 诊断结论
