## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `渠道费用清单.csv`、`分摊规则.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 结构视图转报行合一审查材料；两级金额转总分公司预算分解；双语版本转跨语种沟通场合。

### 可复算口径

- 渠道合计 = 直接归集（按渠道汇总）+ 间接池 × 渠道保费比例
- 个险渠道费用占比 = 个险合计 7980.75 ÷ 全口径 20403.00 = 39.12%
- 手续费及佣金占比 = 18160.00 ÷ 20403.00 = 89.01%
- 两级金额：直接费用按录入归属；间接分摊全额计总公司层；总 + 分 = 全口径

## 五、真实性等级与边界

- **T2**：报行合一费用治理与分摊方法论来自公开的保险业渠道费用管理实践。
- **T3**：岗位痛点来自渠道费用管理岗位的常见工作场景。
- **构造**：费用数据与分摊规则为构造演练内容，口径可复算，不构成对任何真实监管要求的解释。
- **升 T1 还缺**：客户真实渠道费用台账与一次报行合一审查的对照复盘。
- **人工边界**：分摊因子业务确认、两级流程制度发布、双语法律文本审核、资质分级正式口径一律人工；AI 只做结构梳理、分摊计算、两级落表与双语列输出。
