# 报行合一渠道费用梳理与双语产出

## 一、这个 Skill 解决什么

报行合一背景下，渠道费用管理的真实困难不是「没有费用数据」，而是**结构、分摊、流程、语言四件事彼此脱节**：

- 费用结构靠手工搭表对比，渠道之间口径不一
- 总公司统一支付的间接费用（品牌宣传、系统维护）分摊无统一因子
- 总分公司两级流程步骤在试点后才暴露缺口
- 费用方案需要双语版本供跨语种场合使用，翻译另找渠道

本 Skill 的核心动作，是把「结构梳理 + 分摊研究 + 流程补全 + 双语输出」连成一体产出。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 报行合一要求下，渠道费用结构需要重新梳理 | 主用场景：分渠道费用结构视图 |
| 总公司统一支付的间接费用需要分摊到渠道 | 按渠道保费比例分摊，两级金额同步落表 |
| 费用清单需要补齐培训费等细项 | 细项单列，不并入手续费科目混同展示 |
| 费用分摊方案需要双语输出 | 中英名称列直接进交付物 |

**不适用**：财务核算层面的科目重分类（属于财务条线）；渠道竞赛方案的业务规则设计（本场景只处理其费用呈现）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `渠道费用清单.csv` | 必需 | 渠道（个险/银保/经代/不分渠道）、费用项目、费用性质（直接/间接）、金额万元、两级归属（总公司/分公司） |
| 2 | `分摊规则.md` | 必需 | 分摊因子（渠道保费比例）、总分公司两级分工规则、费用项目双语对照、销售资质分级适当性表述 |

> 缺 2（分摊规则）时，本 Skill **必须拒绝分摊间接费用**——没有统一分摊因子的分摊等于各说各话。这是本 Skill 最重要的一条硬规则。

## 四、输出（outputs）

唯一交付物：`渠道费用结构视图.csv`，字段固定为 9 列：

```
渠道, 费用项目, 费用项目英文, 直接归集金额万元, 分摊计入金额万元, 合计金额万元,
渠道内占比%, 总公司金额万元, 分公司金额万元
```

- 行 = 渠道 × 费用项目组合（直接项目 ∪ 间接分摊项目）
- `费用项目英文` 来自分摊规则的双语对照表，逐项必有
- `直接归集金额万元` + `分摊计入金额万元` = `合计金额万元`，两级金额之和与合计逐行平
- 金额保留两位小数，占比保留两位小数

## 五、工作流程（workflow）

### STEP 1 · 分渠道费用结构梳理

读入 40 行费用清单，先按渠道（个险 / 银保 / 经代）与费用性质（直接 20 行 / 间接 20 行）分层，输出各渠道直接费用项目集。**先分层再分摊**——直接与间接混在一起就没有分摊的必要性。

### STEP 2 · 间接费用分摊研究

总公司统一支付的间接费用池（渠道列「不分渠道」）按渠道保费比例分摊：个险 37.5% / 银保 50% / 经代 12.5%（对应保费 48,000 / 64,000 / 16,000 万元）。分摊金额全额计入总公司层。

### STEP 3 · 两级流程步骤补全

按两级分工规则落表：直接费用按录入归属计入（分公司 = 渠道属地展业费用，总公司 = 总对总协议费用），间接费用分摊后计入总公司层。总分公司两级金额逐行与合计对平，两级流程的每个环节都在视图里可见。

### STEP 4 · 费用项目补齐与双语输出

培训费等细项在视图中单列（不并入手续费及佣金科目），费用项目输出中英双语名称两列，供跨语种场合直接使用。

### STEP 5 · 资质衔接精简表述

销售资质分级与产品分类、适当性管理要求压缩成一句话说明（「按销售资质分级匹配产品分类，适当性要求嵌入两级流程」），嵌入费用视图的口径说明层，避免各写各的。

### STEP 6 · 自检

输出前逐项自检，任一不过则不得输出：

1. 40 行输入是否全部进入视图（直接 20 + 间接 20）？
2. 渠道 × 项目组合是否为 23 行（个险 8 + 银保 8 + 经代 7）？
3. 逐行「直接 + 分摊 = 合计」且两级金额之和与合计平？
4. 双语列是否 23 行全有值？
5. 渠道合计与全口径合计是否对得上（7980.75 + 9720.00 + 2702.25 = 20403.00）？

## 六、关键规则（不可协商）

1. **分摊因子唯一。** 间接费用只按渠道保费比例分摊，不允许按项目设多套因子。
2. **两级金额必须平。** 每行总公司金额 + 分公司金额 = 合计金额；两级合计 = 全口径合计，不平即输出无效。
3. **细项单列。** 培训费等细项不得并入手续费及佣金科目混同展示——报行合一审查的第一件事就是费用科目穿透。
4. **双语逐项必有。** 费用项目英文列来自对照表，任何一行缺失即输出无效。
5. **资质表述统一一句话。** 资质分级与适当性要求压缩成统一表述，不允许各写各的。
6. **不承诺效率百分比。** 输出中不写「提升 X%」这类无法核验的表述。

## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先分层再分摊：先按渠道与费用性质把 40 行清单分层（直接 20 / 间接 20，间接池按项目归集），再开始分摊。
2. 间接费用分摊：间接池按渠道保费比例分摊到个险/银保/经代，分摊金额全额计入总公司层；分摊前后总额必须相等。
3. 两级流程落表：直接费用按录入归属计入（分公司=渠道属地展业费用，总公司=总对总协议费用）；输出每行的总公司金额与分公司金额两列，逐行与合计对平。
4. 费用项目补齐：培训费等细项单列成行，不并入手续费及佣金科目；输出渠道 × 费用项目组合（直接项目 ∪ 间接分摊项目）。
5. 双语输出：费用项目输出中英双语名称两列（英文列来自分摊规则的双语对照表），供跨语种沟通直接使用。
6. 资质衔接：在口径说明中以一句话表述销售资质分级与产品分类、适当性管理要求（「按销售资质分级匹配产品分类，适当性要求嵌入两级流程」）。

### 硬性约束

【硬性约束】
- 40 行输入一行不落，全部进入视图；行数 = 渠道 × 费用项目组合（应为 23 行：个险 8 + 银保 8 + 经代 7）。
- 逐行满足：直接归集 + 分摊计入 = 合计；总公司金额 + 分公司金额 = 合计；两级合计 = 全口径合计。
- 金额保留两位小数，占比保留两位小数。
- 双语列逐行必有值；不写任何效率百分比或效果承诺。

### 生成后自检

【生成后自检，逐条回答】
1. 40 行输入是否全部进入视图（直接 20 + 间接 20）？
2. 视图是否为 23 行（个险 8 + 银保 8 + 经代 7）？
3. 逐行两级金额与合计是否对平，两级合计是否等于全口径？
4. 渠道合计是否为 个险 7980.75 / 银保 9720.00 / 经代 2702.25，全口径 20403.00？
5. 个险渠道费用占比是否为 39.12%，手续费及佣金合计是否 18160.00 万元（占 89.01%）？
自检全过再输出 CSV。

### 输出格式

【输出格式】CSV，9 列，列名与顺序固定：
渠道, 费用项目, 费用项目英文, 直接归集金额万元, 分摊计入金额万元, 合计金额万元, 渠道内占比%, 总公司金额万元, 分公司金额万元
