## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某人寿保险公司 · 渠道费用管理条线」做报行合一背景下的渠道费用梳理与双语产出，输出渠道费用结构视图。

【输入 1 · 渠道费用清单】渠道费用清单.csv（40 行）
- 含渠道（个险/银保/经代/不分渠道）、费用项目、费用性质（直接/间接）、金额万元、两级归属（总公司/分公司）
- 直接费用 20 行（按渠道归集，含两级归属）；间接费用 20 行（总公司统一支付，渠道列为「不分渠道」）
【输入 2 · 分摊规则】分摊规则.md
- 分摊因子：渠道保费比例 个险 37.5% / 银保 50% / 经代 12.5%（对应保费 48,000 / 64,000 / 16,000 万元）
- 两级分工：直接费用按录入归属；间接费用分摊后全额计入总公司层
- 费用项目双语对照 8 项；培训费等细项单列不并入手续费科目；资质适当性一句话表述

【输出】渠道费用结构视图.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「报行合一渠道费用梳理与双语产出」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **间接费用为什么只按保费比例分摊？** 期望回答：分摊因子唯一是硬规则——渠道保费占比（个险 37.5% / 银保 50% / 经代 12.5%）对应 48,000 / 64,000 / 16,000 万元保费；按项目设多套因子会造成渠道间口径不可比。
2. **两级流程怎么落表的？** 期望回答：直接费用按录入归属（分公司 = 渠道属地展业，总公司 = 总对总协议），间接费用分摊后全额计入总公司层；总 4,360.00 + 分 16,043.00 = 全口径 20,403.00 万元，逐行两级与合计对平。
3. **培训费为什么要单列？** 期望回答：报行合一审查第一件事是费用科目穿透，培训费并入手续费及佣金科目会被认定为混同展示；补齐后培训费合计 328.00 万元（直接 198 + 分摊 130）。
4. **个险渠道费用占比怎么算的？** 期望回答：个险合计 7,980.75 万元（直接 7,584 + 分摊 396.75）÷ 全口径 20,403.00 万元 = 39.12%；银保 47.64%、经代 13.24%。
5. **双语列怎么保证可用？** 期望回答：英文列逐行来自分摊规则的双语对照表（8 个项目），23 行全有值，可直接用于跨语种董事会与外方股东沟通场合。
