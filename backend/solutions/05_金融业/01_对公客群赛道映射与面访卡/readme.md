# FIN-01 · 对公客群赛道映射与面访作战卡 —— 场景使用说明

- **行业**：金融业
- **角色**：对公客户经理
- **场景编号**：FIN-01
- **案例主体**：某城商行

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/对公客群赛道映射与面访作战卡/SKILL.md` | Skill 定义 | 赛道边界规则、置信度分级、作战卡生成口径与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `待经营企业名单.csv` | 原始输入 | 40 行待经营企业明细（企业名称/主营业务/营收规模/所在区域/已有业务线索） |
| `赛道清单与边界.md` | 原始输入 | S1-S6 赛道定义、纳入边界、E1-E8 易混淆裁决规则、置信度规则 |
| `赛道映射与面访作战卡.csv` | **交付物** | 40 行面访作战卡：企业 × 赛道 × 置信度 × 判定依据 × 3 条要点 × 开场话题 × 关注信号 |
| `对公客户经理-对公客群赛道映射与面访作战卡.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `待经营企业名单.csv`、`赛道清单与边界.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 边界企业（置信度中）面访确认后回写名单；授信申报线索转人工授信流程。

### 可复算口径

- `置信度中` = 主营业务命中 E1-E8 任一裁决规则的企业
- `营收过亿` = 名单「营收规模」字段含「亿元」的行数
- `已有账户基础` = 名单「已有业务线索」含「已开立」的行数
- `拟申报授信线索` = 名单「已有业务线索」含「拟申报」的行数
- `赛道分布` = 交付物「映射赛道」列分组计数

## 五、真实性等级与边界

- **T3**：岗位痛点来自城商行对公条线客群经营的典型工作方式。
- **构造**：企业名单与赛道分布为构造数据；口径可复算。
- **人工边界**：赛道归属的最终确认、授信判断与申报发起一律人工；本场景全部输出中**不出现授信结论与额度建议**。
