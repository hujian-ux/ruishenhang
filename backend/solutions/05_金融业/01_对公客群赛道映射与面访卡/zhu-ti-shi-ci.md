# FIN-01 主提示词 · 对公客群赛道映射与面访作战卡

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/对公客群赛道映射与面访作战卡/SKILL.md`）。
2. 上传两个附件：`待经营企业名单.csv`、`赛道清单与边界.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `赛道映射与面访作战卡.csv` 后，按文末「验收清单」逐项核对。

## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某城商行 · 公司条线三季度客群经营」做赛道映射与面访作战卡，输出 40 行一线可直接执行的作战卡。

【输入 1 · 待经营企业名单】待经营企业名单.csv（40 行）
- 含企业名称、主营业务、营收规模、所在区域、已有业务线索
【输入 2 · 赛道清单与边界】赛道清单与边界.md
- 6 条赛道（S1 半导体 / S2 机器人 / S3 人工智能算力 / S4 生物医药 / S5 新能源 / S6 新材料）的纳入边界
- 8 条易混淆裁决规则（E1-E8）与置信度判定规则

【输出】赛道映射与面访作战卡.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「对公客群赛道映射与面访作战卡」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **澜芯功率为什么归半导体而不是新材料？** 期望回答：功率半导体模块封测涉及碳化硅衬底等新材料环节，按 E1 裁决「器件封测环节归 S1、衬底材料生产归 S6」；置信度中，面访要点三为赛道确认问题。
2. **手术机器人为什么归生物医药？** 期望回答：按 E5 裁决，持有医疗器械注册证的医疗场景机器人归 S4，非医疗场景才归 S2。
3. **置信度中的 8 家在作战卡上有什么不同？** 期望回答：面访要点三是「核实边界业务收入占比、锁定赛道归属」的赛道确认问题。
4. **「拟申报技改贷款 8000 万元」这条线索去哪了？** 期望回答：转成面访要点三的推进动作——授信申报节点、用款计划与材料清单。
5. **34 家营收过亿这个数字怎么来的？** 期望回答：对名单「营收规模」字段含「亿元」的行重新计数，40 行中 34 家。
