# FIN-03 · 渠道经营看板与异常线索标注 —— 场景使用说明

- **行业**：金融（保险科技与健康保障平台）
- **角色**：渠道经营岗（顾岩）
- **场景编号**：FIN-03
- **案例主体**：某保险科技平台

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/渠道经营看板与异常线索标注/SKILL.md` | Skill 定义 | 汇总口径、异常双阈值判定规则、截图比对要求与人工边界 |

| `渠道看板汇总与异常标注.csv` | **交付物** | 19 行看板表：12 时段汇总 + 3 渠道合计 + 1 总体合计 + 3 异常人员标注 |
| `渠道经营岗-渠道经营看板与异常线索标注.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `渠道人员明细.csv`、`看板口径说明.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 异常人员转线索跟进回访（2 个工作日内）；阈值与口径沉淀进看板规则下次沿用。

### 可复算口径

- `发起率% = 发起案例数 ÷ 承接线索量 × 100`（按行内两数复算，保留 1 位小数）
- `渠道 × 时段汇总 = 同渠道同时段全员求和`；`渠道合计 = 四时段求和`；`总体 = 三渠道求和`
- `异常判定 = 人员全天承接 ≥ 100 且 全天发起率 < 8`（双阈值同时满足）
- 复算过程（李强）：承接 40+35+35+30=140 ≥100，发起 2+2+1+2=7，140 条发起 7 个 → 5.0% <8% → 异常 ✓

## 五、真实性等级与边界

- **T3**：渠道经营与线索运营的岗位痛点来自保险科技平台运营实践。
- **构造**：渠道人员数据为构造数据（案例主体某保险科技平台），口径可复算。
- **人工边界**：取数字段最终裁定、异常原因分析（培训 / 线索质量 / 话术）、回访执行与人员辅导一律人工；AI 只输出汇总、标注与跟进优先级，不输出问责结论。
