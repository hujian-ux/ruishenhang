- **行业**：金融业（人寿保险）
- **角色**：客服知识运营岗
- **场景编号**：FIN-04
- **案例主体**：某人寿保险公司

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/客服知识库标准问与相似问治理/SKILL.md` | Skill 定义 | 四类问法判定框架、归并目标计算规则、边界补全与扫描量评估口径 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `相似问原始条目.csv`、`标准问清单.csv` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 边界问法补全清单转应答口径撰写；改挂记录转知识库变更审计。

### 可复算口径

- 问法类型按优先级判定：边界（如果/超过/未成年/异地/外地/断缴/已经/过了/还能）> 追问（之后/那开头/接着/后续/再问）> 口语（咋/啥/帮我/麻烦问/想问下/一下/多少钱）> 标准
- 归并目标 = 归并关键词命中数最高者；平手取标准问ID较小者
- 需补边界问法条数 = 边界问法条数
- 两级索引最坏扫描量 = 类目数（5） + 单问最大相似问条数（4）= 9

## 五、真实性等级与边界

- **T2**：知识库治理方法论与问答运营流程能力来自公开的客服中心运营实践。
- **T3**：岗位痛点来自客服运营岗位的常见工作场景。
- **构造**：相似问与标准问数据为构造数据，判定与归并口径可复算。
- **升 T1 还缺**：客户真实知识库治理前后对比与一次边界问法投诉率复盘。
- **人工边界**：标准问业务口径确认、归并争议裁定、边界应答内容撰写、上线决定一律人工；AI 只出判定、归并与评估结果。
