# EDU-03 · 课件逻辑提取与沉浸式内容研发 —— 场景使用说明

- **行业**：教育培训
- **角色**：内容研发岗（简溪）
- **场景编号**：EDU-03
- **案例主体**：某在线教育企业（本场景库 EDU-01 / EDU-02 / EDU-03 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/课件逻辑提取与沉浸式内容研发/SKILL.md` | Skill 定义 | 四环节拆解规则、四类沉浸式改造规范、优先级规则与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `优秀课件样本清单.csv` | 原始输入 | 12 份课件：学科年级、教学环节结构、核心亮点、可复用元素、拟改造方向、情境素材 |
| `课件逻辑框架.md` | 原始输入 | 四环节拆解规则、沉浸式设计规范与模板、优先级规则、课件与知识点对齐表 |
| `课件逻辑与内容研发计划表.csv` | **交付物** | 12 行研发计划：教学骨架、沉浸式改造点、改造类型、对齐知识点、优先级 |
| `内容研发岗-课件逻辑提取与沉浸式内容研发.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `优秀课件样本清单.csv`、`课件逻辑框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. P1 批次（6 份）排入下一期次课件排产；知识点占比衔接 EDU-01 考情结论；沉淀的骨架库作为新课件起手模板。

### 可复算口径

- `提取的教学骨架 = 环节结构按「-」拆分 → 末二字映射标准环节（讲解/演示→讲解）→ 「环节·手法」串联`
- `沉浸式改造点 = 拟改造方向模板（框架文件「二」）填入情境素材与课件名称`
- `研发优先级 = 小学学段或互动剧情 → P1；讲解层动画 → P3；其余 → P2`
- `对齐知识点 = 框架文件「四、课件与知识点对齐表」取数`

## 五、真实性等级与边界

- **构造**：课件样本与对齐关系为构造数据，骨架、改造点、优先级全部由规则复算。
- **方法论来源**：四环节教学结构与沉浸式（情境化 / 游戏化）设计参照课程研发通行做法改写。
- **人工边界**：优秀课件遴选与定级、剧情脚本与互动组件定稿、排产顺序的业务确认一律人工；AI 只输出规则化的研发计划表。
