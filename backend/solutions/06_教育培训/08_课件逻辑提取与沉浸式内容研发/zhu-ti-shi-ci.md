# EDU-03 主提示词 · 课件逻辑提取与沉浸式内容研发

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/课件逻辑提取与沉浸式内容研发/SKILL.md`）。
2. 上传两个附件：`优秀课件样本清单.csv`、`课件逻辑框架.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `课件逻辑与内容研发计划表.csv` 后，按文末「验收清单」逐项核对。

## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某在线教育企业 · 秋季期次内容研发」完成 12 份优秀课件的逻辑提取与沉浸式内容研发计划，输出一张可复算的课件逻辑与内容研发计划表。

【输入 1 · 优秀课件样本清单】优秀课件样本清单.csv（12 行）
- 每行一份课件：课件编号、课件名称、学科年级、教学环节结构、核心亮点、可复用元素、拟改造方向、情境素材
【输入 2 · 课件逻辑框架】课件逻辑框架.md
- 四环节拆解规则：任何课件拆解为「导入-讲解-练习-总结」标准骨架；环节结构按「-」拆分后，每段按末二字映射（导入→导入；讲解/演示→讲解；练习→练习；总结→总结），四环节必须齐备
- 沉浸式改造四类：互动剧情 / 情境化练习 / 游戏化交互 / 讲解层动画；每类改造必须绑定一个可复用元素
- 研发优先级：P1（首批）= 小学学段或互动剧情；P2（次批）= 初中学段的情境化练习与游戏化交互；P3（观察池）= 讲解层动画
- 课件与知识点对齐表：12 份课件对应的公司知识点体系条目

【输出】课件逻辑与内容研发计划表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「课件逻辑提取与沉浸式内容研发」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **骨架提取是怎么做的？** 期望回答：环节结构按「-」拆分、末二字映射标准环节（「动态演示」归讲解层），12 份课件 × 4 环节 = 48 个环节全部齐备，如 CW-01 沉淀为「导入·情境 → 讲解·分步 → 练习·基础 → 总结·图表」。
2. **CW-01 的沉浸式改造是什么？** 期望回答：互动剧情类，以「超市购物收银台」为剧情主线，学生扮演收银员完成《分数与小数的互化》关键任务练习，复用情境化导入模板，小学学段执行生活化改写，P1 首批。
3. **为什么 CW-08 只排 P2？** 期望回答：初中学段的情境化练习（篮球投篮命中轨迹 + 参数联动交互组件），需要补充情境素材与组件验证，P2 次批；但其对齐知识点「数与代数·函数及其图象」正是 EDU-01 中占 20.0% 分值的第一重点，P2 内部应优先。
4. **讲解层动画为什么进观察池？** 期望回答：CW-11 只增强讲解层、不重构练习层，改造收益相对小，随批次迭代安排，P3。
5. **和考情结论怎么衔接？** 期望回答：对齐表把课件挂到知识点体系——函数及其图象（20.0%）、方程与不等式（12.5%）、概率（2.5%）各有对应课件，练习配比随占比走，研发排序时考情权重由人确认。

## 验收清单

- [ ] 输出 12 行（12 份课件一行不落），9 列结构一致
- [ ] 每行骨架四环节齐备（12 × 4 = 48 个环节），顺序为 导入→讲解→练习→总结
- [ ] 改造类型分布 = 互动剧情 4 / 情境化练习 3 / 游戏化交互 4 / 讲解层动画 1
- [ ] 研发优先级分布 = P1 6 / P2 5 / P3 1，小学学段（CW-01/02/03）全部 P1
- [ ] 每条改造点引用清单中的情境素材；对齐知识点全部来自框架对齐表
- [ ] 全表无凭空新增素材、无效率百分比承诺
