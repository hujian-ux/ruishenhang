# EDU-04 · 技术趋势洞察与竞品方案调研 —— 场景使用说明

- **行业**：教育培训
- **角色**：产品市场岗（沈亦澜）
- **场景编号**：EDU-04
- **案例主体**：某教育信息化企业（与 EDU-05 / EDU-06 同一案例链；）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/技术趋势洞察与竞品方案调研/SKILL.md` | Skill 定义 | 六类要素口径、S/A/B 趋势分级、命中判定与竞争压力分级规则 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `竞品方案要素调研表.csv` | 原始输入 | 20 行竞品调研记录（官网 + 招标 + 媒体 + 白皮书四类信源归一后） |
| `趋势分析框架.md` | 原始输入 | 要素口径、趋势分级规则、命中判定规则、影响等级判定规则 |
| `竞品对照与趋势洞察表.csv` | **交付物** | 8 行对照记录：5 家竞品对照 + 3 条趋势洞察 |
| `产品市场岗-技术趋势洞察与竞品方案调研.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `竞品方案要素调研表.csv`、`趋势分析框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. S 级趋势的影响建议交产品委员会裁决后，转入 EDU-05 能力矩阵作为基线更新输入。

### 可复算口径

- `趋势命中` = 关键词（Wi-Fi 7 / 物联 / AI）在「组网架构 + 核心特性」两列中检索
- `竞品行定价带` = 该竞品 4 条记录定价带字段的 min-max
- `竞品行影响等级` = 趋势覆盖数 3 → 高 / 2 → 中 / 0-1 → 低
- `竞品行证据来源` = 信源类型计数（如「官网2+技术白皮书1+公开招标1」）
- `趋势行影响等级` = S 级 → 高 / A 级 → 中 / B 级 → 低

## 五、真实性等级与边界

- **T2**：调研方法论与要素归类口径来自行业通行实践。
- **T3**：岗位痛点来自 JD 与社区。
- **构造**：5 家竞品（沧澜网络、星桥智联、岳衡科技、南川数科、云岭网科）与全部数据口径可复算。
- **升 T1 还缺**：客户真实调研底稿与一次趋势判断的事后验证。
- **人工边界**：趋势定级与影响建议为讨论底稿，产品路线调整由产品委员会人工裁决；本场景全部输出中不出现路线决策类结论。
