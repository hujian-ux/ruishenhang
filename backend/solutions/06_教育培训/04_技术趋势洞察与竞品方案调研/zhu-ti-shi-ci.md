# EDU-04 主提示词 · 技术趋势洞察与竞品方案调研

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/技术趋势洞察与竞品方案调研/SKILL.md`）。
2. 上传两个附件：`竞品方案要素调研表.csv`、`趋势分析框架.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `竞品对照与趋势洞察表.csv` 后，按文末「验收清单」逐项核对。

## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某教育信息化企业 · 教育行业」做技术趋势洞察与竞品方案调研，输出一张可溯源的竞品对照与趋势洞察表。

【输入 1 · 调研记录】竞品方案要素调研表.csv（20 行）
- 每行 = 一家竞品在一个方案场景的调研记录，含记录编号、竞品厂商、方案场景、方案定位、组网架构、核心特性、定价带（万元/校）、标杆案例、信源、信源类型、采集日期
- 六类要素：方案定位 / 组网架构 / 核心特性 / 定价带 / 标杆案例 / 信源
【输入 2 · 分析框架】趋势分析框架.md
- 趋势分级：S 级（12 个月内主流落地）/ A 级（12-24 个月放量）/ B 级（观察）
- 本期三条趋势：Wi-Fi 代际演进（S 级）、物联感知融合（A 级）、AI 智能运维（A 级）
- 趋势命中判定：关键词在「组网架构 + 核心特性」中检索（Wi-Fi 7 / 物联 / AI）
- 影响等级：竞品行按趋势覆盖数（3→高 / 2→中 / 0-1→低）；趋势行按定级（S→高 / A→中 / B→低）

【输出】竞品对照与趋势洞察表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「技术趋势洞察与竞品方案调研」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **为什么把 Wi-Fi 代际演进定为 S 级？** 期望回答：框架判定标准是「12 个月内主流落地、头部竞品已规模出货」；调研记录中沧澜、岳衡、南川 3 家高校无线方案均已采用 Wi-Fi 7，命中 3 条记录。
2. **沧澜网络和南川数科为什么竞争压力是「高」？** 期望回答：两家均覆盖全部三条趋势（Wi-Fi 7 / 物联 / AI 运维），且定价带落在 12.2-16.5 万/校，正面挤压云梯主力产品线。
3. **云岭网科定价最低为什么不构成趋势性压力？** 期望回答：其记录未命中任何趋势关键词，差异化在价格与本地服务（影响等级低），应对是保持成本与交付优势。
4. **物联感知融合的证据链是什么？** 期望回答：命中 5 条记录（R03、R04、R11、R15、R16），涉及沧澜、岳衡、南川 3 家，主要落在智慧教室与职校场景。
5. **趋势建议怎么落到产品动作？** 期望回答：S 级趋势当期对标并纳入 EDU-05 能力矩阵基线；A 级趋势下个版本规划纳入或预留接口。

## 验收清单

- [ ] 8 行输出：5 行竞品对照 + 3 行趋势洞察
- [ ] 20 条记录 = 5 家竞品 × 4 类方案场景，六类要素全覆盖
- [ ] Wi-Fi 7 命中 3 条记录 / 3 家竞品；物联命中 5 条 / 3 家；AI 命中 6 条 / 2 家
- [ ] 竞品行影响等级分布 = 高 2 / 中 1 / 低 2
- [ ] 定价带极值 = 6.8-16.5 万/校，各竞品行定价带为其记录的 min-max
- [ ] 全表无路线决策类表述，所有结论可指回记录编号或信源类型
