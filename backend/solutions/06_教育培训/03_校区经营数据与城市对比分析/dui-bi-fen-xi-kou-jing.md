# 对比分析口径 · 校区经营数据与城市对比（某教育培训集团 · 经营数据岗）

> 本口径是「校区经营数据与城市对比分析」场景的判定依据：城市怎么分层、均值怎么算、对标怎么比、建议怎么给，全部以本文件为准。

## 一、城市分层规则

| 城市层级 | 城市 | 对比原则 |
| --- | --- | --- |
| 一线 | 上海、北京 | 只在层级内横向对比，不同层级不直接排名 |
| 新一线 | 成都、杭州 | 同上 |
| 二线 | 武汉、西安 | 同上 |

**规则：同级城市口径对齐。** 跨层级直接比绝对值没有意义——二线城市满班率天然低于一线，把西安校区和上海校区放进同一张排行榜是常见分析事故。

## 二、指标与均值口径

| 指标 | 口径 | 均值算法 |
| --- | --- | --- |
| 营收万元 | 季度校区营收 | 城市行 = 同城校区合计 |
| 满班率% | 季度平均满班率 | 城市行 = 同城校区算术平均 |
| 获客成本元 | 单个新学员获客成本 | 城市行 = 同城校区算术平均 |
| 续班率% | 季度续报完成率 | 城市行 = 同城校区算术平均 |

- 城市均值为**同城校区算术平均**（非营收加权），校区规模差异通过营收列单独体现。
- 层级均值 = 层级内全部校区算术平均，用于城市行的层级内对标。
- 均值保留 1 位小数；对标差值 = 校区值 − 城市均值，保留 1 位小数，单位 pct（百分点）。

## 三、对标与归因规则

校区行对标（同城对比）：

| 信号 | 判定 | 归因方向 |
| --- | --- | --- |
| 满班率低于城市均值 | 差值 < 0 | 排班密度或续报转化待查 |
| 获客成本高于城市均值 | 差值 > 0 | 渠道投放效率待查 |
| 续班率低于城市均值 | 差值 < 0 | 续报动作与家长沟通待查 |

- 一个校区可同时命中多个信号，逐条列出，不允许只报最差的一项。
- 全部高于/不差于城市均值的校区，诊断写「各项均衡」，不强行找问题。

城市行对标（层级内对比）：城市均值 vs 本层级均值，写明高于/低于层级均值多少。

## 四、改进建议库（按层级固定口径）

城市行建议（按层级）：

| 层级 | 建议基线 |
| --- | --- |
| 一线 | 满班率与续班率领先，重点控制获客成本，加密核心商圈班型 |
| 新一线 | 满班率中等，复制一线排班与续报动作，扩大优势校区模型 |
| 二线 | 获客成本偏高，收缩低效投放渠道，强化转介绍与续报留存 |

附加规则：城市内存在满班率 <65% 的校区时，城市行建议追加「专项排查低满班校区的班型结构与排班密度」。

校区行动作库（按命中信号，多项命中逐条拼接）：

| 命中信号 | 对应动作 |
| --- | --- |
| 满班率低于城市均值 | 排查排班密度与班型结构 |
| 获客成本高于城市均值 | 复盘渠道投放结构 |
| 续班率低于城市均值 | 落实续报沟通节奏 |
| 三项均未命中 | 保持现有经营动作 |

## 五、输出口径

- 交付物 = 20 行校区明细 + 6 行城市汇总 = 26 行。
- 行类型 ∈ {校区明细, 城市汇总}。
- 校区行「满班率对标」写法：`高于城市均值 +X.Xpct` / `低于城市均值 -X.Xpct`（绝对值取正数书写）。
- 「X 校区满班率低于城市均值」= 校区行中满班率对标为「低于城市均值」的行数，逐城可复算。
- 不做跨层级排名，不输出「全国校区排行榜」。
