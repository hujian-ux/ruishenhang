## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `校区经营数据表.csv`、`对比分析口径.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 把 9 个满班率预警校区清单分发对应城市经理实地核查；城市行建议作为管理层复盘汇报底稿。

### 可复算口径

- `城市均值` = 同城校区算术平均（非加权），保留 1 位小数；城市行营收 = 同城合计
- `层级均值` = 层级内全部校区算术平均（一线 8 校区、新一线 6、二线 6）
- `满班率对标` = 校区满班率 − 城市均值（pct）；「9 个低于」逐城可数：上海均值 80.5（浦东 79、杨浦 76 低于）、北京 84.0（朝阳 81、丰台 83 低于）、成都 74.7（锦江 74、武侯 72 低于）、杭州 68.0（滨江 63 低于）、武汉 61.7（光谷 55 低于）、西安 55.0（未央 47 低于）
- `二线比一线高 31.1%` = 595.0 ÷ 453.8 − 1（一线均值 = 3630 元 ÷ 8，二线均值 = 3570 元 ÷ 6）
- `三信号归因` = 满班率低/获客成本高/续班率低逐条列出，命中几条列几条

## 五、真实性等级与边界

- **方法论来源**：多表归并 + 统一报告结构 + 跨城市对比的链路来自企业应用案例素材。
- **构造**：20 个校区经营数据与城市分布为构造数据，口径全部可复算。
- **人工边界**：归因方向的实地核查、改进方案资源配给、低满班校区专项处置一律人工；AI 只做口径对齐、对标计算与建议输出。
