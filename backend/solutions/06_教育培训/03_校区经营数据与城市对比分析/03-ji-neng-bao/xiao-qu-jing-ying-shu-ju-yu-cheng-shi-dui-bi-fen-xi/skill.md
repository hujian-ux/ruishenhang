# 校区经营数据与城市对比分析

## 一、这个 Skill 解决什么

校区经营分析的两个老问题：

- **数据散**：20 个校区的营收、满班率、获客成本、续班率分散在不同表格里，跨城市对比要手工取数拼接，口径还常常对不上；
- **比不对**：把西安校区和上海校区放进同一张排行榜，得出「二线校区经营不善」的结论——层级差异被当成了经营差异，改进方向从一开始就错了。

本 Skill 的核心动作：**同城口径对齐 + 分层对比 + 三信号归因**，每个结论都能指到具体校区的具体数字。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 季度/学期经营复盘，需要横向比较各校区表现 | 主用场景：同城对标 + 城市汇总 |
| 管理层要跨城市对比报告 | 层级内对比，结构统一可复用 |
| 某校区被投诉经营不善，需要定位问题维度 | 三信号归因：排班/获客/续报 |
| 新城市拓点前评估现有城市模型 | 层级均值与建议库 |

**不适用**：单校区深度诊断（需课程级明细数据）；财务口径审计（→ 财务对账流程）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `校区经营数据表.csv` | 必需 | 校区编号、校区名称、城市、城市层级、营收万元、满班率%、获客成本元、续班率% |
| 2 | `对比分析口径.md` | 必需 | 城市分层规则、指标均值口径、对标与归因规则、层级建议库、输出口径 |

> 缺 2（对比分析口径）时，本 Skill **必须拒绝输出排名与归因**——分层规则与均值口径必须来自口径文件，不允许临场发明对比标准。

## 四、输出（outputs）

唯一交付物：`城市对比与改进建议表.csv`，字段固定为 12 列：

```
行类型, 名称, 城市, 城市层级, 校区数, 营收万元, 满班率%, 获客成本元, 续班率%, 满班率对标, 诊断与归因, 改进建议
```

- `行类型` ∈ {校区明细, 城市汇总}
- 校区行：满班率对标 = 与所在城市均值的差值；诊断逐条列命中信号
- 城市行：营收为同城合计，其余指标为同城算术平均；对标为本层级内比较
- 「X 校区满班率低于城市均值」= 校区行中满班率对标为「低于城市均值」的行数

## 五、工作流程（workflow）

### STEP 1 · 读口径，先分层再取数

从 `对比分析口径.md` 读入城市分层规则与均值口径。一线/新一线/二线只在层级内对比，跨层级不直接排名。

### STEP 2 · 归并与均值计算

按城市归并 20 个校区：城市行营收 = 合计，满班率/获客成本/续班率 = 算术平均（保留 1 位小数）；同步计算层级均值。

### STEP 3 · 同城对标与三信号归因

每个校区与所在城市均值逐项对标，命中信号逐条列出：

| 信号 | 归因方向 |
| --- | --- |
| 满班率低于城市均值 | 排班密度或续报转化待查 |
| 获客成本高于城市均值 | 渠道投放效率待查 |
| 续班率低于城市均值 | 续报动作与家长沟通待查 |

多项命中逐条列出；全部均衡的校区如实写「各项均衡」，不强行找问题。

### STEP 4 · 层级内对比与建议

城市行与层级均值对比；改进建议按层级建议库输出，城市内存在满班率 <65% 校区时追加专项排查提示。

### STEP 5 · 自检与人工边界声明

输出前逐项自检，任一不过则不得输出：

1. 交付物行数 = 校区数 + 城市数（20 + 6 = 26）？
2. 城市行营收 = 同城校区营收合计（逐城核对）？
3. 是否没有任何跨层级排名？
4. 每个低于城市均值的校区是否都逐条列出命中信号？
5. 改进建议是否与层级建议库一致？

## 六、关键规则（不可协商）

1. **同级城市口径对齐。** 层级差异不是经营差异，跨层级排行榜一律不输出。
2. **均值口径固定。** 城市均值 = 同城算术平均（非加权），口径来自文件而非临场选择。
3. **归因只给方向。** 「排班密度待查」「渠道效率待查」是排查方向，不是结论；定位到具体原因需要校区级深挖。
4. **多项命中必须全列。** 只报最差一项等于隐藏问题。
5. **均衡就是均衡。** 不强行给健康校区找问题。
6. **不承诺效率百分比。** 输出中不写「提升 X%」这类无法核验的表述。

## 七、人工边界

| AI 负责 | 人负责（经营分析主管 / 城市经理） |
| --- | --- |
| 多表归并与均值计算 | 归因方向的实地核查 |
| 同城对标与信号标记 | 改进方案的资源配给决定 |
| 层级内对比与建议输出 | 低满班校区的专项处置决定 |
| 对比表结构化输出 | 对管理层的演示与答辩 |


## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读口径再取数：把城市分层与均值口径写成显式判定表，不要先看数据再定标准。
2. 按城市归并 20 个校区，计算城市行指标（营收合计 + 三指标算术平均）与层级均值。
3. 校区行同城对标：逐校区与所在城市均值比较满班率、获客成本、续班率，命中信号逐条列入诊断，多项命中必须全列；全部均衡的校区写「各项均衡」。
4. 城市行层级内对标：与所在层级均值比较并写明差值方向；改进建议按层级建议库输出，命中附加规则的追加专项排查提示。
5. 不做跨层级排名，不输出全国校区排行榜。

### 硬性约束

【硬性约束】
- 同级城市口径对齐：层级差异不是经营差异，禁止跨层级直接排名。
- 城市均值一律用同城算术平均，不得改用加权平均。
- 归因只给排查方向（排班/渠道/续报），不下经营不善的结论。
- 每个低于城市均值的校区必须逐条列出全部命中信号，不允许只报最差一项。
- 不写任何效率百分比或效果承诺。

### 生成后自检

【生成后自检，逐条回答】
1. 交付物是否 26 行 = 20 校区明细 + 6 城市汇总？
2. 城市行营收是否逐城等于同城校区营收合计（全国合计 13,690 万元）？
3. 满班率低于所在城市均值的校区是否恰好 9 个（上海 2 / 北京 2 / 成都 2 / 杭州 1 / 武汉 1 / 西安 1）？
4. 二线城市获客成本均值是否 595 元、比一线 453.8 元高 31.1%？
5. 是否没有任何跨层级排名？
自检全过再输出 CSV。

### 输出格式

【输出格式】CSV，12 列，列名与顺序固定：
行类型, 名称, 城市, 城市层级, 校区数, 营收万元, 满班率%, 获客成本元, 续班率%, 满班率对标, 诊断与归因, 改进建议
