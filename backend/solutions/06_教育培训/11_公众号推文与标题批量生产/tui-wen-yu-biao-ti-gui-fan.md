# 推文与标题规范（某职业考试培训企业 · 新媒体内容）

本规范是「公众号推文与标题批量生产」场景的两条硬约束来源：结构模板决定推文骨架怎么搭，红线清单决定哪些表述不允许出现在成稿里。

## 一、推文骨架结构模板（四段式）

每篇推文按固定四段骨架组织，段与段之间职责不混：

| 段落 | 职责 | 写法要求 |
| --- | --- | --- |
| 钩子 | 3 秒内留住读者 | 按选题的「钩子方向」（数据冲击 / 时间紧迫 / 痛点直击 / 考官视角 / 经验分享 / 通关目标 / 难点聚焦 / 政策解读 / 反常识 / 策略选择 / 路径规划 / 身份共鸣）设计首段切入 |
| 痛点 | 让目标人群对号入座 | 必须落到「目标人群」列写明的人群，用具体备考场景而非抽象描述 |
| 方案 | 给出解法并自然带出课程 | 只允许引用「核心卖点」列的内容，不得外扩承诺 |
| 转化 | 引导行动 | 固定动作：扫码领取试听课与备考资料包；若有活动，必须注明真实起止时间 |

## 二、标题变体规则（三种心理诉求）

每个选题必须同时产出 3 版标题，分别对应三种心理诉求，供编辑筛选与 A/B 比选：

| 变体 | 心理诉求 | 写法要求 |
| --- | --- | --- |
| 标题变体一 · 利益型 | 「读完我能得到什么」 | 直接给出人群可感知的具体收益，落在核心卖点上 |
| 标题变体二 · 警醒型 | 「不这样做会怎样」 | 点出目标人群最典型的动作误区或时间风险，制造适度紧迫 |
| 标题变体三 · 好奇型 | 「答案是什么」 | 用悬念句式引出选题答案，引导点击，但不得夸大 |

标题长度统一不超过 30 字；三版变体不得雷同。

## 三、合规红线清单（L1–L5）

以下红线适用于推文骨架与全部标题变体。命中即拦截，改写后才可进入筛选环节：

| 编号 | 红线 | 说明 |
| --- | --- | --- |
| L1 | 禁止通过率与效果承诺 | 不出现「保过」「包过」「押题命中率」「提分 XX 分」「一次通过」类表述 |
| L2 | 禁止绝对化用语 | 不出现「最权威」「第一名师」「顶级」类表述 |
| L3 | 禁止虚假紧迫 | 限时、限量表述必须有真实活动依据，注明起止时间 |
| L4 | 禁止贬损同行 | 不出现指向同行的对比性贬损表述 |
| L5 | 学员信息合规 | 学员案例与成绩须获授权并脱敏，未授权素材一律替换为场景化描述 |

## 四、合规校验结论口径

- 选题行的「合规风险点」列不为「无」时，该行必须在成稿前完成拦截改写，结论格式：`拦截：{风险点}——已按 {红线编号} 改写并复核`
- 风险点为「无」的行，结论格式：`通过：未命中 L1-L5 红线`
- 拦截数量 = 风险点非「无」的行数，可由输入表直接复算
