# EDU-10 · 公众号推文与标题批量生产 —— 场景使用说明

- **行业**：教育培训
- **角色**：新媒体内容岗
- **场景编号**：EDU-10
- **案例主体**：某职业考试培训企业

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/公众号推文与标题批量生产/SKILL.md` | Skill 定义 | 四段骨架模板、三版标题变体规则、L1-L5 合规红线与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `推文选题与素材表.csv` | 原始输入 | 15 行选题：目标人群 / 核心卖点 / 钩子方向 / 合规风险点 |
| `推文与标题规范.md` | 原始输入 | 四段骨架结构模板、标题变体规则、L1-L5 红线清单、校验结论口径 |
| `推文与标题批量生产表.csv` | **交付物** | 15 行：推文骨架 + 3 版标题变体 + 合规校验结论 |
| `新媒体内容岗-公众号推文与标题批量生产.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `推文选题与素材表.csv`、`推文与标题规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 编辑在三版标题中筛选比选，不满意的方向追加「换个方向再来一组」。

生成脚本 `gen_EDU-10.py`（仓库不含入 zip）以 Python 标准库 `csv` 实际写出文件，并在脚本内做断言验证。执行结果：

### 断言项

| 断言 | 结果 |
| --- | --- |
| `推文选题与素材表.csv` 数据行 = 15 | 通过 |
| 规范含四段骨架 / 三版变体 / L1-L5 全部规则关键词 | 通过 |
| 交付物数据行 = 15，与输入选题一一对应 | 通过 |
| 标题变体合计 = 45（15 选题 × 3 版心理诉求） | 通过 |
| 合规拦截行数 = 6（= 输入表合规风险点非「无」的行数） | 通过 |
| 拦截红线分布 = L1×2 / L2×1 / L3×1 / L4×1 / L5×1 | 通过 |
| 骨架与标题列零红线词命中（保过 / 押题命中率 / 最权威 / 仅剩最后一天等） | 通过 |
| 三版标题均不超过 30 字 | 通过 |

### 可复算口径

- `拦截行数` = `推文选题与素材表.csv` 中「合规风险点」列不为「无」的行数（直接 count 可复算）
- `标题变体总数 45` = 选题行数 15 × 变体数 3
- `L1×2` 对应「押题命中率100%」与「保过」两行；`L2` 对应「最权威师资」；`L3` 对应「仅剩最后一天」；`L4` 对应「贬损同行」；`L5` 对应「学员案例照片未经授权」

## 四、与案例数字对齐

| 数字 | 出处 | 在本场景的落点 |
| --- | --- | --- |
| 15 个选题一次产出 | 案例漏斗设定 | 输入表 15 行 → 交付物 15 行 |
| 45 个标题候选 | 15 × 3 心理诉求 | 交付物三列标题变体 |
| 6 处合规风险被拦截 | 输入表风险点行数 | 交付物「拦截」结论 6 行，红线分布 L1-L5 可复算 |
| 通过 9 行 | 15 − 6 | 交付物「通过：未命中 L1-L5 红线」9 行 |

## 五、真实性等级与边界

- **T2**：批量候选 + 人工筛选的协作模式、素材直接进入成文环节的能力来自官方案例素材。
- **T3**：公众号合规红线（不承诺通过率、不虚假限时）为行业通行要求。
- **构造**：某职业考试培训企业及其选题数据为构造数据，口径可复算。
- **人工边界**：选题取舍、改写后的语气拿捏与终审、A/B 上线后的数据判定一律人工；AI 只产出结构、候选与机械校验结论。
