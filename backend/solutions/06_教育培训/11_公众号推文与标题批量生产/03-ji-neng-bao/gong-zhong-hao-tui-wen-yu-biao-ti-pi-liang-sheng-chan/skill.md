# 公众号推文与标题批量生产

## 一、这个 Skill 解决什么

职业考试培训的公众号内容是典型的**考期驱动**生意：报名、笔试、面试、资格复审的每个节点都会带来一波热点选题。真实的困难不是没选题，而是三件事被揉在编辑一个人身上：

- 从素材到成稿全靠人工，热点响应速度被写作速度卡住
- 标题数量取决于编辑当天的灵感，好坏无从保证，也没有可比选的余地
- 合规红线（不承诺通过率、不虚假限时）散落在口头经验里，靠事后审核兜底，风险前置不了

本 Skill 的核心动作，是把「选题 → 骨架 → 标题 → 合规」变成一条流水线：**素材直接进入结构化成文，标题按三种心理诉求批量产出候选，红线在成稿前拦截**。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 考期节点临近，公众号需要集中出一批推文 | 主用场景：选题批量进、骨架批量出 |
| 一篇推文需要多版标题做 A/B 比选 | 每选题固定产出 3 版心理诉求变体 |
| 素材里混有命中红线的原始表述（如「保过」） | 成稿前逐行拦截改写，并留档 |
| 不同编辑产出风格差异大，需要统一结构 | 四段骨架与标题规则统一约定 |

**不适用**：单篇深度品牌稿（不走批量模板）；渠道投放数据的周期复盘（→ EDU-12 渠道投放战报与转化复盘）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `推文选题与素材表.csv` | 必需 | 选题、目标人群、核心卖点、钩子方向、合规风险点 |
| 2 | `推文与标题规范.md` | 必需 | 四段骨架结构模板、三版标题变体规则、L1-L5 合规红线清单、合规校验结论口径 |

> 缺 2（规范）时，本 Skill 必须拒绝输出——没有红线清单的批量成稿等于把合规风险放大 15 倍。

## 四、输出（outputs）

唯一交付物：`推文与标题批量生产表.csv`，字段固定为 7 列：

```
选题, 目标人群, 推文骨架（钩子-痛点-方案-转化）, 标题变体一·利益型, 标题变体二·警醒型, 标题变体三·好奇型, 合规校验结论
```

- 行数 = 输入选题行数，一选题一行
- `推文骨架` 必须按「钩子｜痛点｜方案｜转化」四段组织，方案段只允许引用该行的核心卖点
- 三版标题分别对应利益型 / 警醒型 / 好奇型，单版不超过 30 字
- `合规校验结论` ∈ {拦截：…——已按 L? 改写并复核, 通过：未命中 L1-L5 红线}，拦截数量必须等于输入表风险点非「无」的行数

## 五、工作流程（workflow）

### STEP 1 · 选题与素材归集

读入 `推文选题与素材表.csv`，确认每行五要素齐全（选题 / 目标人群 / 核心卖点 / 钩子方向 / 合规风险点）。风险点非「无」的行单独标记，进入 STEP 4 重点校验。

### STEP 2 · 按四段骨架生成推文结构

对每个选题按规范的四段模板搭骨架：钩子段按「钩子方向」设计切入，痛点段落到目标人群的具体备考场景，方案段只引用核心卖点，转化段固定为扫码领试听与资料包（活动须注明真实起止时间）。

### STEP 3 · 三版标题批量产出

每个选题按三种心理诉求各产出一版标题：利益型给具体收益、警醒型点误区与时间风险、好奇型留悬念。三版不得雷同，供编辑筛选与 A/B 比选；不满意的方向可以要求「换个方向再来一组」。

### STEP 4 · L1-L5 合规校验与拦截

对全部骨架与标题跑红线清单：L1 通过率与效果承诺 / L2 绝对化用语 / L3 虚假紧迫 / L4 贬损同行 / L5 学员信息合规。输入表标记了风险点的行必须拦截改写，结论栏写明红线编号；其余行写「通过」。

### STEP 5 · 自检与输出

输出前逐项自检，任一不过则不得输出：

1. 行数是否与输入选题数一致？
2. 每行骨架是否四段齐全、方案段是否只含本行核心卖点？
3. 三版标题是否分别对应三种心理诉求且互不雷同？
4. 拦截行数是否 = 输入表风险点非「无」的行数？
5. 骨架与标题列是否零红线词命中？

## 六、关键规则（不可协商）

1. **红线前置。** 合规校验发生在成稿筛选之前，不是事后审核。命中 L1-L5 的表述在进入编辑筛选前必须完成改写。
2. **方案段不外扩。** 推文只能引用选题表给定的核心卖点，不得自行添加「不过退费」等未经确认的承诺。
3. **标题海选不是标题大战。** 三版变体服务 A/B 筛选，风格可以放开，但红线与 30 字上限不放开。
4. **人群必须对号入座。** 痛点段写的是输入表的目标人群，不是泛化的「所有考生」。
5. **不承诺效果。** 输出中不出现「阅读量提升 X%」这类无法核验的表述。

## 七、人工边界

| AI 负责 | 人负责（新媒体编辑） |
| --- | --- |
| 骨架批量生成与标题变体产出 | 选题判断与热点取舍 |
| 红线词机械校验与拦截标记 | 改写后的语气拿捏与终审 |
| 三版变体的心理诉求归位 | A/B 上线后的数据判定 |

## 八、下游衔接

- 筛选出的推文与标题 → 公众号排版发布，A/B 数据回流到选题表
- 转化段的领资料动作 → 承接进入 EDU-12 渠道投放战报的线索口径


## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读规范再看选题：把四段骨架、三版变体规则与 L1-L5 红线写成显式判定表，不要边写边定标准。
2. 逐行搭骨架：钩子段按该行「钩子方向」设计切入；痛点段落到该行「目标人群」的具体备考场景；方案段只允许引用该行「核心卖点」；转化段固定为扫码领试听与备考资料包。
3. 逐行产三版标题：利益型给具体收益、警醒型点典型误区或时间风险、好奇型留悬念；单版不超过 30 字，三版不得雷同。
4. 全量合规校验：对全部骨架与标题跑 L1-L5。风险点非「无」的行结论写「拦截：{风险点}——已按 L? 改写并复核」；其余行写「通过：未命中 L1-L5 红线」。
5. 改写后复核：被拦截行的骨架与标题必须给出改写后的版本，改写版不得再命中任何红线。

### 硬性约束

【硬性约束】
- 骨架与标题列不允许出现「保过」「包过」「押题命中率」「最权威」「仅剩最后一天」等红线词（拦截说明列引用原表述除外）。
- 方案段不得外扩卖点：只写选题表「核心卖点」列的内容，不得添加退费、命中率等未经确认的承诺。
- 痛点段不得泛化为「所有考生」，必须对准该行目标人群。
- 不写任何阅读量、涨粉、转化率的效果承诺或百分比。
- 三版标题必须分别是利益型、警醒型、好奇型，不得同一诉求出两版。

### 生成后自检

【生成后自检，逐条回答】
1. 输出行数是否 = 15，与输入选题一一对应？
2. 每行骨架是否四段齐全，方案段是否只含本行核心卖点？
3. 三版标题是否分别对应三种心理诉求、互不雷同、均不超过 30 字？
4. 拦截行数是否 = 输入表合规风险点非「无」的行数（应为 6：L1×2 / L2×1 / L3×1 / L4×1 / L5×1）？
5. 骨架与标题列是否零红线词命中？
自检全过再输出 CSV。

### 输出格式

【输出格式】CSV，7 列，列名与顺序固定：
选题, 目标人群, 推文骨架（钩子-痛点-方案-转化）, 标题变体一·利益型, 标题变体二·警醒型, 标题变体三·好奇型, 合规校验结论
