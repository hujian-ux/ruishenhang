# EDU-10 主提示词 · 公众号推文与标题批量生产

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/公众号推文与标题批量生产/SKILL.md`）。
2. 上传两个附件：`推文选题与素材表.csv`、`推文与标题规范.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `推文与标题批量生产表.csv` 后，按文末「验收清单」逐项核对。

## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某职业考试培训企业 · 秋季考期内容季」做公众号推文与标题的批量生产，输出一张可筛选、可复核的批量生产表。

【输入 1 · 选题与素材】推文选题与素材表.csv（15 行）
- 含选题、目标人群、核心卖点、钩子方向、合规风险点五个字段
- 合规风险点不为「无」的行，必须在成稿前拦截改写
【输入 2 · 生产规范】推文与标题规范.md
- 四段骨架模板：钩子 → 痛点 → 方案 → 转化
- 三版标题变体：利益型 / 警醒型 / 好奇型
- 合规红线 L1-L5：通过率与效果承诺 / 绝对化用语 / 虚假紧迫 / 贬损同行 / 学员信息合规

【输出】推文与标题批量生产表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「公众号推文与标题批量生产」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **哪 6 行被拦截，各命中哪条红线？** 期望回答：押题命中率 100%（L1）、保过（L1）、最权威师资（L2）、仅剩最后一天（L3）、贬损同行（L4）、学员照片未授权（L5）。
2. **「保过」那行改写后方案段写的什么？** 期望回答：只保留「职测与综应双科系统班」这一核心卖点，承诺表述替换为备考规划与阶段服务描述。
3. **三版标题的心理诉求怎么归位？** 期望回答：利益型=读完得到什么，警醒型=不这样做的后果，好奇型=答案悬念；任何一版都不含红线词。
4. **为什么转化段要写真实活动时间？** 期望回答：L3 虚假紧迫红线要求限时表述必须有真实依据，无依据的「最后一天」会被拦截。
5. **15 行骨架的结构是否完全一致？** 期望回答：均为钩子｜痛点｜方案｜转化四段，段间职责不混，仅内容随选题变化。

## 验收清单

- [ ] 15 行输出，与输入选题一一对应
- [ ] 拦截 6 行：L1×2（押题命中 / 保过）、L2×1（最权威）、L3×1（虚假限时）、L4×1（贬损同行）、L5×1（学员照片）
- [ ] 其余 9 行结论为「通过：未命中 L1-L5 红线」
- [ ] 共 45 版标题（15×3），三版心理诉求互不雷同
- [ ] 骨架与标题列零红线词命中
