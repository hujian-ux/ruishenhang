- **行业**：教育培训
- **角色**：质量与测试岗
- **场景编号**：EDU-06
- **案例主体**：某教育信息化企业

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/测试方案故障分析与质量月报/SKILL.md` | Skill 定义 | 三级归类口径、月报指标公式、改进指向映射、测试方案骨架约束 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `现网故障记录.csv` | 原始输入 | 25 行 2026-08 现网故障台账（编号/现象/根因/责任域/解决时长） |
| `测试与质量框架.md` | 原始输入 | 三级归类口径、指标定义、改进指向映射表 |
| `故障分析与质量月报数据表.csv` | **交付物** | 22 行月报：5 现象 + 6 根因 + 5 责任域 + 6 指标，算式可复算 |
| `质量与测试岗-测试方案故障分析与质量月报.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `现网故障记录.csv`、`测试与质量框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出（三级行数 5+6+5、平均时长算式、超长故障清单、改进映射一致）。
5. 软件缺陷改进项纳入下期测试方案回归范围，用例编号追溯到故障编号。
