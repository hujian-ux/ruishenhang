# 矩阵构建规则（产品能力矩阵与规格对照底稿）

某教育信息化企业 · 解决方案岗 · 用于把产品与规格数据构建成场景 × 产品的能力矩阵与选型对照底稿。

## 一、能力分级定义（L1-L5）

能力等级 = 该产品在该场景相对「场景需求基线」的满足程度，取产品部规格库的调研综合判断：

| 等级 | 定义 | 判定参考 |
| --- | --- | --- |
| L1 | 基础可用 | 仅满足基线中 1 项，功能可跑通但明显吃力 |
| L2 | 满足常规 | 达标 2/3 项，低于场景主流一档 |
| L3 | 良好适配 | 基线 3 项全部达标，达到场景主流水平 |
| L4 | 优势场景 | 3 项达标且 1 项代际领先，优于主流一档 |
| L5 | 领先标杆 | 3 项达标且 2 项代际领先，代际领先组合 |

代际领先 = 该规格项超出场景主流配置一代以上（如高校无线场景 Wi-Fi 7 相对 Wi-Fi 6）。

## 二、场景需求基线（5 场景 × 3 项）

| 场景 | 基线三项 |
| --- | --- |
| 高校大型校园网 | 万级终端并发 / 核心交换容量 ≥6.4Tbps / 双控制器热备 |
| 职校实训基地 | 千台桌面并发 / 实训分区隔离 / 骨干万兆互联 |
| 普教多媒体教室 | 百兆到桌面够用 / 整教室成本可控 / 免专业运维 |
| 智慧教室互动教学 | 互动时延 <50ms / 多屏协同 / 环境感知联动 |
| 校区安防物联 | PoE 供电整网 / 物联协议接入 / 安防分区隔离 |

## 三、选型建议规则

| 能力等级 | 矩阵定位 | 选型建议口径 |
| --- | --- | --- |
| L4 及以上 | 优势组合 | 优先推荐，可作该场景主推或标杆组合 |
| L3 | 适配可选 | 可选，按项目预算与既有利旧情况选配 |
| L2 及以下 | 不建议 | 不建议，改选同类更高配或专用方案 |

## 四、规格对照口径

- 每行对照 = 关键规格 3 项 vs 场景需求基线 3 项，输出「X/3 项达标」结论；
- 达标项数、代际领先项数取自 `产品能力与规格数据.csv`，矩阵行不做二次判断；
- 同一产品在不同场景下的能力等级不同，禁止用「产品高级 = 全场景高分」平推。

## 五、矩阵更新机制

| 触发 | 动作 |
| --- | --- |
| 产品软件版本变更（大版本） | 重估该产品全部 5 个场景行 |
| EDU-04 趋势洞察出现 S 级趋势 | 把该趋势纳入受影响场景的需求基线后重估 |
| 竞品发布同代际规格 | 复核「代际领先」项是否仍然成立 |
| 季度例行 | 全量重跑，追加新场景或新产品行 |

## 六、人工边界

矩阵定位与选型建议口径由 AI 按上述规则计算，**具体项目的最终选型由解决方案岗与客户共同确认**；矩阵输出不构成报价与承诺依据。
