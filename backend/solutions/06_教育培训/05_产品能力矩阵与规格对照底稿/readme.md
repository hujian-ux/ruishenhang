# EDU-05 · 产品能力矩阵与规格对照底稿 —— 场景使用说明

- **行业**：教育培训
- **角色**：解决方案岗（陆知远）
- **场景编号**：EDU-05
- **案例主体**：某教育信息化企业（与 EDU-04 / EDU-06 同一案例链；）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/产品能力矩阵与规格对照底稿/SKILL.md` | Skill 定义 | L1-L5 能力分级、选型映射规则、规格对照口径与更新机制 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `产品能力与规格数据.csv` | 原始输入 | 30 行产品数据（6 产品 × 5 场景，规格书与产品页归一后） |
| `矩阵构建规则.md` | 原始输入 | 能力分级定义、场景需求基线、选型建议规则、更新触发机制 |
| `产品能力矩阵与对照底稿.csv` | **交付物** | 30 行矩阵：场景 × 产品 × 能力等级 × 规格对照 × 选型建议 |
| `解决方案岗-产品能力矩阵与规格对照底稿.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `产品能力与规格数据.csv`、`矩阵构建规则.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 「不建议」组合的缺口反馈产品部；版本变更或 EDU-04 出现 S 级趋势时按更新机制重估对应行。

### 可复算口径

- `矩阵定位` = 能力等级映射：L≥4 → 优势组合；L3 → 适配可选；L≤2 → 不建议
- `规格对照` = 规格达标项数 / 3 + 代际领先项数，两列均来自输入
- `规格总账` = 30 行 × 3 项场景基线 = 90 项；达标合计 = Σ达标项数 = 82；领先合计 = Σ领先项数 = 17
- `定位分布` = 优势（4+9）13 / 可选 11 / 不建议（4+2）6，合计 30

## 五、真实性等级与边界

- **T2**：能力分级与场景基线方法来自行业通行选型实践。
- **T3**：岗位痛点来自 JD 与社区。
- **构造**：6 个产品（ES-7500 / ES-3200 / AW-6800 / VD-500 / SF-300 / TC-9）与全部数据口径可复算。
- **升 T1 还缺**：客户真实选型底稿与一次选型事后复盘。
- **人工边界**：矩阵定位是口径化建议，具体项目最终选型由解决方案岗与客户共同确认；输出不构成报价与承诺依据。
