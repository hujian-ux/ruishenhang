# 渠道投放战报与转化复盘

## 一、这个 Skill 解决什么

投放复盘的真实困难不是没数据，而是**数据散、口径多、结构漂**：

- 各渠道后台口径不一，截图和明细表先要人工归一
- CAC、到课率、转化率各算各的，同一张战报里出现两种算法
- 异常渠道靠肉眼扫，哪个该点名、高多少，没有统一判定
- 这期战报和上期结构不一样，环比无从谈起

本 Skill 的核心动作，是把「明细汇总 → 指标计算 → 异常判定 → 归因建议」变成一条流水线：**公式写死、阈值写死、结构写死**，任何一期的战报都能对着同一套口径复算。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 周期（周 / 月）结束，要做投放战报 | 主用场景：明细进、战报出 |
| 老板问「哪个渠道该砍预算」 | 需要异常判定规则点名，而非肉眼扫 |
| 各渠道数据口径混乱需要归一 | 公式统一，同一张表可复算 |
| 与上一周期对比变化 | 战报结构跨周期固定，可直接环比 |

**不适用**：公众号内容批量生产（→ EDU-10 公众号推文与标题批量生产）；讲义与练习编排（→ EDU-11 系列讲义与课后练习批量编排）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `渠道投放明细.csv` | 必需 | 渠道、日期、消耗元、线索数、到课数、成单数 |
| 2 | `战报与归因框架.md` | 必需 | 效率指标公式、异常判定规则（A1/A2）、归因框架、战报结构约定 |

> 缺 2（框架）时，本 Skill 必须拒绝输出——没有统一公式的汇总表不是战报，是口径事故现场。

## 四、输出（outputs）

唯一交付物：`投放战报与转化复盘表.csv`，字段固定为 12 列，行数 = 渠道数：

```
渠道, 消耗合计元, 线索合计, 到课合计, 成单合计, 线索到课率, 到课成单率, 线索成单率, CAC元, CAC较均值, 异常标记, 归因与调整建议
```

- 每渠道一行，四项合计由明细逐日求和得出
- 三级转化率与 CAC 按框架公式计算，比率保留 1 位小数
- `CAC较均值` =（渠道 CAC − 全渠道加权均值 CAC）÷ 均值，带 +/− 方向
- `异常标记` ∈ {无异常, CAC偏高, 到课率偏低, CAC偏高+到课率偏低}，命中 A1/A2 规则判定
- 异常渠道必须写归因与调整建议，归因对应框架四类之一

## 五、工作流程（workflow）

### STEP 1 · 明细接入与归一

读入 `渠道投放明细.csv`，核对渠道名与字段口径（消耗 / 线索 / 到课 / 成单），按渠道分组逐日求和。

### STEP 2 · 指标计算

按框架公式逐渠道计算：消耗 / 线索 / 到课 / 成单四项合计、线索到课率、到课成单率、线索成单率、CAC；再算全渠道加权均值 CAC（总消耗 ÷ 总成单）与加权到课率（总到课 ÷ 总线索）。

### STEP 3 · 异常判定

逐渠道跑两条规则：A1（CAC > 均值 × 1.2 → 「CAC偏高」）、A2（到课率 < 加权到课率 × 0.8 → 「到课率偏低」），可叠加；两项均未命中标记「无异常」。

### STEP 4 · 归因与建议

异常渠道按框架四类归因（素材人群错配 / 落地承接偏弱 / 渠道结算方式 / 预算节奏）写调整建议；正常渠道给量级判断（维持 / 加投 / 优化方向），建议落到预算、素材、承接三维度。

### STEP 5 · 战报组装与自检

按框架战报结构组装周期总览、渠道效率对比、异常与归因、调整建议四个板块。输出前逐项自检，任一不过则不得输出：

1. 行数是否 = 渠道数，四项合计是否与明细逐日求和一致？
2. 每行 CAC 与三级转化率是否可按公式复算？
3. 异常标记是否严格按 A1/A2 阈值判定，无肉眼加减？
4. 异常渠道是否都有归因与调整建议？
5. 全表消耗 / 线索 / 到课 / 成单的渠道合计是否 = 明细总计？

## 六、关键规则（不可协商）

1. **均值是加权口径。** 全渠道均值 CAC = 总消耗 ÷ 总成单，不是各渠道 CAC 的简单平均；加权到课率同理。混用口径会误判异常。
2. **阈值写死。** A1 用 1.2 倍、A2 用 0.8 倍，不允许「看起来偏高就标一下」。
3. **异常必须留痕。** 每个异常标记都能回溯到公式与阈值；归因必须对应框架四类之一，不得写「综合表现不佳」。
4. **结构跨周期不变。** 战报四板块固定，保证环比可比。
5. **不写效果承诺。** 输出中不出现「预计提升 X%」类表述；调整建议是动作，不是预测。

## 七、人工边界

| AI 负责 | 人负责（投放运营） |
| --- | --- |
| 明细归一与指标计算 | 渠道预算的最终调整决策 |
| 异常判定与归因整理 | 与渠道商务的谈判（改结算方式等） |
| 战报结构组装 | 素材方向与定向的创意判断 |

## 八、下游衔接

- 战报调整建议 → 下一周期的预算分配与素材迭代
- 渠道效率排序 → 线索质量口径回流内容场景（EDU-10）的转化段设计


## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读框架再看数据：把指标公式与 A1/A2 阈值写成显式判定表，不要看完数据再定标准。
2. 按渠道汇总：6 个渠道各一行，消耗/线索/到课/成单四项合计由明细逐日求和。
3. 逐渠道算指标：三级转化率与 CAC 按公式计算，比率保留 1 位小数；另算全渠道加权均值 CAC 与加权到课率。
4. 逐渠道判异常：严格按 A1/A2 阈值判定，可叠加；未命中标「无异常」。
5. 逐渠道写归因与建议：异常渠道对应框架四类归因之一，建议落到预算/素材/承接三维度；正常渠道给量级判断（维持/加投/优化方向）。

### 硬性约束

【硬性约束】
- 均值一律用加权口径：均值CAC=总消耗÷总成单，加权到课率=总到课÷总线索，不得用各渠道数值的简单平均。
- 异常判定只认阈值：CAC>均值×1.2 与 到课率<加权到课率×0.8，不允许主观增删标记。
- CAC较均值必须可复算：（渠道CAC−均值）÷均值，保留 1 位小数并带 +/− 方向。
- 归因不允许写「综合表现不佳」，必须对应四类之一并写明具体调整动作。
- 不写「预计提升X%」类效果预测。

### 生成后自检

【生成后自检，逐条回答】
1. 输出行数是否 = 6，四项合计是否与明细逐日求和一致（总消耗 271,000 / 总线索 5,480 / 总到课 2,468 / 总成单 300）？
2. 每行 CAC 与三级转化率是否都能按公式复算？
3. 异常渠道是否恰为 2 个（CAC 高于均值 20% 以上），CAC较均值最高是否约 +66%？
4. 异常渠道是否都有四类归因之一的说明与具体调整动作？
5. 全表渠道合计是否 = 明细总计？
自检全过再输出 CSV。

### 输出格式

【输出格式】CSV，12 列，列名与顺序固定：
渠道, 消耗合计元, 线索合计, 到课合计, 成单合计, 线索到课率, 到课成单率, 线索成单率, CAC元, CAC较均值, 异常标记, 归因与调整建议
