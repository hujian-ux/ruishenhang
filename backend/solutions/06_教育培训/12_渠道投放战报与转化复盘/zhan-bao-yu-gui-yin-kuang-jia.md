# 投放战报与归因框架（某职业考试培训企业 · 渠道投放）

本框架是「渠道投放战报与转化复盘」场景的两条硬约束来源：效率指标公式决定每个渠道怎么算，异常判定规则决定哪些渠道要被点名。

## 一、效率指标公式

周期内按渠道汇总明细后，统一按以下口径计算：

| 指标 | 公式 | 口径说明 |
| --- | --- | --- |
| 渠道 CAC（元/单） | 渠道消耗合计 ÷ 渠道成单合计 | 获客成本，越低越好 |
| 全渠道均值 CAC（元/单） | 总消耗 ÷ 总成单 | 加权口径，不是各渠道 CAC 的简单平均 |
| 线索到课率 | 渠道到课合计 ÷ 渠道线索合计 | 衡量线索质量与承接 |
| 到课成单率 | 渠道成单合计 ÷ 渠道到课合计 | 衡量转化承接强度 |
| 线索成单率 | 渠道成单合计 ÷ 渠道线索合计 | 综合转化效率 |

比率统一保留 1 位小数；CAC 与均值对比保留 1 位小数并带方向（+/−）。

## 二、异常判定规则

| 编号 | 规则 | 标记 |
| --- | --- | --- |
| A1 | 渠道 CAC > 全渠道均值 CAC × 1.2 | CAC偏高 |
| A2 | 渠道线索到课率 < 全渠道加权到课率 × 0.8 | 到课率偏低 |

- 加权到课率 = 总到课 ÷ 总线索（全渠道合并口径）
- 命中 A1 与 A2 可叠加；两项均未命中的渠道标记「无异常」
- 异常渠道必须写归因与调整建议，正常渠道给出量级判断（维持 / 加投 / 优化方向）

## 三、归因框架（四类常见归因与对应动作）

| 归因类型 | 典型信号 | 对应调整建议 |
| --- | --- | --- |
| 素材与人群错配 | 到课率偏低 + CAC 偏高 | 收缩预算，更换定向与素材后再测 |
| 落地承接偏弱 | 到课率正常但到课成单率偏低 | 优化落地页与到课后的社群运营节奏 |
| 渠道结算方式 | 固定费用类合作摊薄到课少 | 改按效果结算或缩减合作位 |
| 预算节奏问题 | 消耗集中在周期尾段 | 均衡投放节奏，避免堆积 |

## 四、战报结构约定

周期战报按固定板块组织，跨周期保持同一结构便于环比：
1. 周期总览：总消耗 / 总线索 / 总到课 / 总成单 / 综合转化率
2. 渠道效率对比：六渠道 CAC、三级转化率排序
3. 异常与归因：命中 A1 / A2 的渠道逐个说明
4. 调整建议：预算、素材、承接三维度，逐渠道落到具体动作
