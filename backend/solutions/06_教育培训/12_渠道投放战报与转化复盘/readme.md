## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `渠道投放明细.csv`、`战报与归因框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 战报的调整建议进入下一周期预算分配；框架与战报结构跨周期复用，直接环比。

### 断言项

| 断言 | 结果 |
| --- | --- |
| `渠道投放明细.csv` 数据行 = 30（6 渠道 × 5 日） | 通过 |
| 框架含指标公式 / A1/A2 阈值 / 四类归因全部关键词 | 通过 |
| 交付物数据行 = 6，与明细渠道一一对应 | 通过 |
| 周期总计 = 消耗 271,000 / 线索 5,480 / 到课 2,468 / 成单 300 | 通过 |
| 加权均值 CAC = 271,000 ÷ 300 = 903.3 元/单 | 通过 |
| 异常渠道恰 2 个，均命中 A1（阈值 = 均值 × 1.2 = 1,084 元） | 通过 |
| 信息流-工具社区 CAC 1,500 = +66.1%（A1+A2） | 通过 |
| 应用市场-榜单合作 CAC 1,300 = +43.9%（A1） | 通过 |
| 逐行 CAC = 消耗合计 ÷ 成单合计，可复算 | 通过 |
| 渠道四项合计之和 = 明细总计（防漏行） | 通过 |

### 可复算口径

- `渠道 CAC` = 渠道消耗合计 ÷ 渠道成单合计（如 45,000 ÷ 30 = 1,500）
- `全渠道均值 CAC` = 总消耗 ÷ 总成单 = 271,000 ÷ 300 = 903.3 元/单（加权口径，非简单平均）
- `CAC较均值` =（渠道 CAC − 903.3）÷ 903.3（如工具社区 = +66.1%）
- `A1 阈值` = 903.3 × 1.2 ≈ 1,084 元，工具社区 1,500 与应用市场 1,300 越线，资讯平台 1,000 未越
- `A2 阈值` = 加权到课率 45.0% × 0.8 = 36.0%，工具社区到课率 30.0% 越线
- `综合转化率` = 300 ÷ 5,480 = 5.5%

## 五、真实性等级与边界

- **T2**：数据接入、周期对比、结构约定跨周期复用的协作模式来自官方案例素材。
- **T3**：CAC / 转化漏斗 / 异常阈值判定为投放运营通行做法。
- **构造**：某职业考试培训企业及其投放数据为构造数据，口径可复算。
- **人工边界**：渠道预算的最终调整决策、与渠道商务的谈判、素材方向与定向的创意判断一律人工；AI 只做归一、计算、判定与归因整理，不出效果预测。
