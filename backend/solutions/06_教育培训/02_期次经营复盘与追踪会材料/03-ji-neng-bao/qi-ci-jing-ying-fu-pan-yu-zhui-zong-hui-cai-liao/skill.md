# 期次经营复盘与追踪会材料

## 一、这个 Skill 解决什么

期次复盘的真实困难不是「没有数据」，而是**数据散在四个系统里、材料口径靠人记、每期从零拼装**：

- 招生在招生系统、续报退费在教务系统、完课在直播平台、活跃在家长端后台，取数就要跑四个口
- 材料与数据源的对应关系靠老员工记忆，人一换口径就错位
- 每期复盘重新取数、重新拼表，追踪会行动项散落在会议纪要里没人跟踪
- 偏差归因凭印象写「生源竞争激烈」，指不到具体越线指标

本 Skill 的核心动作，是把评级、预警、归因、议题、行动项全部规则化：**每个评级可复算、每条归因能指到具体越线指标、每个行动项对应一个追踪会议题**。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 期次收官，5 个工作日内要出复盘材料 | 主用场景：12 校区 × 评级 + 归因 + 议题 + 行动项 |
| 追踪会前需要按校区拉数据卡 | 材料表即数据卡，逐校区一行 |
| 有人问「为什么这个校区被重点整改」 | 评级与归因都可回溯到规则与指标 |
| 数据源切换后校验口径 | 材料结构不变，只换数据源映射 |

**不适用**：单校区日级运营监控（属日常运营看板）；教师个体绩效分析（属人力口径，不在本场景范围）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `期次经营数据.csv` | 必需 | 校区、目标招生数、实际招生数、续报率%、退费率%、完课率%、家长端活跃率% |
| 2 | `复盘与追踪会框架.md` | 必需 | 评级规则（A/B/C/D）、四条预警线、偏差归因规则表、议题与行动项模板、期次口径 |

> 缺 2（框架文件）时，本 Skill **必须拒绝输出评级与归因**——规则必须来自显式记录，不允许临场发挥口径。

## 四、输出（outputs）

唯一交付物：`期次复盘与追踪会材料表.csv`，字段固定为 9 列、12 行（每个校区一行）：

```
校区, 目标招生数, 实际招生数, 目标达成率%, 达成评级, 越线指标, 偏差归因, 追踪会议题, 行动项
```

- `达成评级` ∈ {A（超额达成）, B（基本达成）, C（偏差关注）, D（重点整改）}，只由达成率区间决定
- `越线指标` 按「续报率/退费率/完课率/活跃率」顺序列出，全部达标写「无」
- `偏差归因` 每条必须能指到具体越线指标，**不允许写「综合判断」**
- `追踪会议题` 与 `行动项` 按模板生成，可重复执行

## 五、工作流程（workflow）

### STEP 1 · 先读框架再看数

把评级规则、四条预警线、归因规则表写成显式判定表。**顺序不可颠倒**——先看数据再定标准，等于给结论找理由。

### STEP 2 · 计算达成率并定级

逐校区计算目标达成率 = 实际 ÷ 目标 × 100（保留 1 位小数），按区间定 A/B/C/D。评级只看达成率，不允许参考其他指标调整。

### STEP 3 · 逐项跑预警线

续报率 ≥75%、退费率 ≤5%、完课率 ≥85%、活跃率 ≥65%，逐项判定并按固定顺序列出越线指标。

### STEP 4 · 组合偏差归因

按规则表组合：退费越线 → 教学与服务质量异常；续报越线 → 续期转化不足；完课越线 → 到课与交付节奏；活跃越线 → 家长端触达不足；无越线的 A 级写经验沉淀、B 级写线索量缺口。

### STEP 5 · 套用议题与行动项模板

议题按评级（经验复制 / 收尾管理 / 偏差归因 / 重点整改），行动项按越线指标逐项对应，会后每周五追踪会逐项跟踪。

### STEP 6 · 自检与边界声明

输出前逐项自检，任一不过则不得输出：

1. 12 行合计目标 = 5,590、实际 = 5,280，总达成率 = 94.5%？
2. 评级分布 = A 3 / B 5 / C 3 / D 1？
3. 退费率越线 4 校区与续报率越线 4 校区完全重合？
4. 翠苑与湖畔四项预警全部越线、湖畔为唯一 D 级（77.9%）？
5. 每条归因是否都能指到具体越线指标？

## 六、关键规则（不可协商）

1. **评级只认达成率区间。** 续报、退费、完课、活跃只用于越线判定与归因，不得反过来改评级。
2. **归因必须指到指标。** 「生源竞争激烈」这类无指标支撑的表述一律不允许出现。
3. **预警线是显式约定。** 四条线来自框架文件，不允许按单校区情况临时放宽。
4. **材料结构跨期次稳定。** 切换数据源后结构与口径必须保持一致，只更新数据源映射。
5. **行动项必须可跟踪。** 每个行动项有明确动作与责任角色，追踪会逐项销号。
6. **不承诺效率百分比。** 输出中不写「提升 X%」这类无法核验的表述。

## 七、人工边界

| AI 负责 | 人负责（陆蘅 / 校区负责人） |
| --- | --- |
| 多源数据归一与达成率计算 | 评级结果的业务确认 |
| 预警判定与规则化归因 | 追赶方案与资源投入决策 |
| 议题与行动项模板化生成 | 追踪会主持与行动项验收 |

## 八、下游衔接

- D 级校区行动项 → 区域负责人专项支持与四周追赶方案
- A 级校区经验清单 → 招生与续报动作复制到偏差校区
- 期次材料表归档 → 下一期次复盘的同比基线


## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读框架再看数：把评级规则、四条预警线、归因规则写成显式判定表。
2. 逐校区计算目标达成率并定级；12 个校区合计目标 5,590、实际 5,280，总达成率应为 94.5%。
3. 逐项跑预警线：越线指标按「续报率/退费率/完课率/活跃率」顺序列出，全部达标写「无」。
4. 偏差归因按规则表组合：退费率越线 → 教学与服务质量异常引发退费；续报率越线 → 续期转化不足，老学员留存承压；完课率越线 → 到课率与课程交付节奏问题；活跃率越线 → 家长端触达与陪伴运营不足；无越线的 A 级写经验沉淀、B 级写线索量缺口。
5. 追踪会议题按评级套模板（A 经验复制 / B 收尾管理 / C 偏差归因 / D 重点整改）；行动项按越线指标逐项套模板，用「；」连接。
6. 不允许出现「综合判断」，每条归因必须能指到具体越线指标。

### 硬性约束

【硬性约束】
- 12 个校区一行不落；达成率必须可复算（实际 ÷ 目标）。
- 评级只依据达成率区间，不允许参考其他指标调整。
- 续报率、退费率、完课率、活跃率只用于越线判定与归因，不改评级。
- 不写任何效率百分比或效果承诺。

### 生成后自检

【生成后自检，逐条回答】
1. 12 行合计目标是否 = 5,590、实际是否 = 5,280、总达成率是否 = 94.5%？
2. 评级分布是否 = A 3 / B 5 / C 3 / D 1？
3. 退费率越线校区是否 = 城北、望江、翠苑、湖畔 4 个，且与续报率越线校区完全重合？
4. 翠苑与湖畔是否四项预警指标全部越线？
5. 湖畔校区是否为唯一 D 级（达成率 77.9%），追踪会议题为重点整改？
自检全过再输出 CSV。
