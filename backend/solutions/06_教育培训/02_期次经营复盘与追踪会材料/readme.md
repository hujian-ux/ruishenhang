- **行业**：教育培训
- **角色**：校区经营分析岗（陆蘅）
- **场景编号**：EDU-02
- **案例主体**：某在线教育企业（本场景库 EDU-01 / EDU-02 / EDU-03 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/期次经营复盘与追踪会材料/SKILL.md` | Skill 定义 | 评级规则、四条预警线、归因规则表、议题与行动项模板 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `期次经营数据.csv` | 原始输入 | 12 个校区 × 目标/实际招生数 + 续报率/退费率/完课率/家长端活跃率 |
| `复盘与追踪会框架.md` | 原始输入 | 期次口径、评级规则、预警线、归因规则表、议题与行动项模板 |
| `期次复盘与追踪会材料表.csv` | **交付物** | 12 行复盘材料：达成率、评级、越线指标、归因、议题、行动项 |
| `校区经营分析岗-期次经营复盘与追踪会材料.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `期次经营数据.csv`、`复盘与追踪会框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 材料表用于期次复盘会与每周五追踪会；D 级行动项转区域负责人专项跟进，本表归档为下一期次同比基线。

### 可复算口径

- `目标达成率% = 实际招生数 ÷ 目标招生数 × 100`（例：滨江 608 ÷ 560 = 108.6%）
- `总达成率 = 5,280 ÷ 5,590 = 94.5%`
- 评级只依据达成率区间：≥100 A / 90（含）–100 B / 80（含）–90 C / <80 D
- 越线判定：续报 <75% / 退费 >5% / 完课 <85% / 活跃 <65%

## 五、真实性等级与边界

- **构造**：校区经营数据为构造数据，评级、预警、归因全部由规则复算。
- **方法论来源**：期次复盘与追踪会机制参照在线教育期次化运营通行做法改写。
- **人工边界**：评级结果的业务确认、追赶方案与资源投入决策、追踪会主持与行动项验收一律人工；AI 只输出规则化的复盘材料。
