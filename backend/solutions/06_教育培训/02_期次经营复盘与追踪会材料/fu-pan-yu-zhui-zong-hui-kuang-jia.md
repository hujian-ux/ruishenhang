# 复盘与追踪会框架 · 期次经营复盘材料口径

适用范围：某在线教育企业 · 校区经营分析岗 · 期次经营复盘与追踪会材料（EDU-02）。

## 一、期次口径

- 期次定义：业务以学期为期次滚动运营（寒假 / 春季 / 暑假 / 秋季），本框架对应秋季期次 12 个教学周。
- 复盘节奏：期次结束后 5 个工作日内产出复盘材料；追踪会每周五召开，逐项跟踪行动项直至下期次开班。
- 数据源映射：招生与目标来自招生系统，续报率 / 退费率来自教务系统，完课率来自直播平台，家长端活跃率来自家长端产品后台。切换数据源后必须校验口径一致。

## 二、评级规则

目标达成率 = 实际招生数 ÷ 目标招生数 × 100，保留 1 位小数。

| 达成率区间 | 评级 | 含义 |
| --- | --- | --- |
| ≥ 100% | A | 超额达成 |
| 90%（含）– 100% | B | 基本达成 |
| 80%（含）– 90% | C | 偏差关注 |
| < 80% | D | 重点整改 |

评级只依据达成率区间，不允许参考其他指标调整。

## 三、预警线（四项）

| 指标 | 预警线 | 判定 |
| --- | --- | --- |
| 续报率 | ≥ 75% | 低于 75% 越线 |
| 退费率 | ≤ 5% | 高于 5% 越线 |
| 完课率 | ≥ 85% | 低于 85% 越线 |
| 家长端活跃率 | ≥ 65% | 低于 65% 越线 |

越线指标按「续报率 / 退费率 / 完课率 / 活跃率」顺序列出；全部达标写「无」。

## 四、偏差归因规则

按优先级组合（多条命中用「；」连接），每条归因必须能指到具体越线指标：

| 命中条件 | 归因表述 |
| --- | --- |
| 退费率越线 | 教学与服务质量异常引发退费 |
| 续报率越线 | 续期转化不足，老学员留存承压 |
| 完课率越线 | 到课率与课程交付节奏问题 |
| 活跃率越线 | 家长端触达与陪伴运营不足 |
| 无越线且 A 级 | 各项指标均在预警线内，超额达成经验待沉淀 |
| 无越线且 B 级 | 指标均在预警线内，缺口集中在招生漏斗前段线索量 |

## 五、追踪会议题与行动项模板

议题按评级套用：

| 评级 | 议题 |
| --- | --- |
| A | 经验复制：超额达成校区动作拆解 |
| B | 收尾管理：续期准备与线索补充 |
| C | 偏差归因：预警指标逐项说明与追赶计划 |
| D | 重点整改：校区专项支持与四周追赶方案 |

行动项按越线指标逐项套用（多条用「；」连接）：

| 命中条件 | 行动项 |
| --- | --- |
| 退费率越线 | 两周内完成退费学员全员回访并输出原因清单 |
| 续报率越线 | 下周启动老学员续报挽留专项，班主任逐人触达 |
| 完课率越线 | 调整排课节奏，启用到课提醒双通道 |
| 活跃率越线 | 家长端周报推送改版，绑定班主任每周点评 |
| 无越线且 A 级 | 沉淀超额达成动作清单，供偏差校区参照 |
| 无越线且 B 级 | 补充区域线索投放，监控最后两周转化 |

## 六、输出要求

- 交付物为 12 行（每个校区一行）× 9 列固定结构。
- 目标达成率必须可复算（实际 ÷ 目标）；全表目标合计 5,590、实际合计 5,280，总达成率 94.5%。
- 评级、归因、议题、行动项全部由上述规则得出，不允许写「综合判断」。
- 不写任何效率百分比或效果承诺。
