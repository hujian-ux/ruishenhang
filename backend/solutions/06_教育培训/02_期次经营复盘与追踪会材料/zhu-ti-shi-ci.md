## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某在线教育企业 · 秋季期次经营复盘」生成 12 个校区的期次复盘与追踪会材料表，每个校区的达成评级、偏差归因、追踪会议题与行动项都必须能从规则复算出来。

【输入 1 · 期次经营数据】期次经营数据.csv（12 行）
- 每行一个校区：目标招生数、实际招生数、续报率%、退费率%、完课率%、家长端活跃率%
- 目标达成率 = 实际招生数 ÷ 目标招生数 × 100，保留 1 位小数
【输入 2 · 复盘与追踪会框架】复盘与追踪会框架.md
- 评级规则：达成率 ≥100% → A 超额达成；90%（含）–100% → B 基本达成；80%（含）–90% → C 偏差关注；<80% → D 重点整改
- 预警线：续报率 ≥75%、退费率 ≤5%、完课率 ≥85%、家长端活跃率 ≥65%
- 归因规则表与议题 / 行动项模板

【输出】期次复盘与追踪会材料表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「期次经营复盘与追踪会材料」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **为什么湖畔被定为重点整改？** 期望回答：达成率 296 ÷ 380 = 77.9% < 80% 命中 D 级；且续报 65%、退费 7.5%、完课 80%、活跃 55% 四项预警全部越线。
2. **翠苑四项也全越线，为什么只是 C 级？** 期望回答：评级只认达成率区间，翠苑 391 ÷ 460 = 85.0% 落在 80%–90%，属 C 偏差关注；指标越线只影响归因与议题，不改评级。
3. **退费和续报是什么关系？** 期望回答：本期退费率越线的城北、望江、翠苑、湖畔 4 个校区与续报率越线校区完全重合——退费引发的口碑与留存问题直接拖累续报，归因里两条并列。
4. **A 级校区怎么用？** 期望回答：滨江 108.6%、城东 105.0%、文华 101.9% 共 3 个 A 级，议题为「经验复制」，行动项是沉淀动作清单供偏差校区参照。
5. **这些数字都能复算吗？** 期望回答：每个达成率 = 实际 ÷ 目标（如滨江 608 ÷ 560 = 108.6%），合计 5,280 ÷ 5,590 = 94.5%，评级与归因全部由框架文件规则得出。

## 验收清单

- [ ] 输出 12 行（12 个校区一行不落），9 列结构一致
- [ ] 合计目标 5,590 / 实际 5,280 / 总达成率 94.5%
- [ ] 评级分布 = A 3（城东、滨江、文华）/ B 5 / C 3 / D 1（湖畔）
- [ ] 退费率越线 = 续报率越线 = 城北、望江、翠苑、湖畔 4 校区
- [ ] 翠苑与湖畔四项预警全越线；湖畔 77.9% 唯一 D 级，议题「重点整改」
- [ ] 全表无「综合判断」，每条归因指到具体越线指标，无效率百分比承诺
