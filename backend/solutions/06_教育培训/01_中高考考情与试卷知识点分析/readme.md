- **行业**：教育培训
- **角色**：教研分析岗（沈砚）
- **场景编号**：EDU-01
- **案例主体**：某在线教育企业（本场景库 EDU-01 / EDU-02 / EDU-03 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/中高考考情与试卷知识点分析/SKILL.md` | Skill 定义 | 知识点分类体系口径、Δ1/Δ2 趋势判定规则、能力层级定义与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `试卷逐题分析表.csv` | 原始输入 | 40 个小题行（选择 16 + 填空 8 + 解答拆小问 16），全卷 120 分 |
| `考情分析框架.md` | 原始输入 | 4 模块 11 知识点分类体系、前两年分值表、趋势判定规则、输出要求 |
| `知识点分布与趋势分析表.csv` | **交付物** | 11 行知识点汇总：分值占比、三年变化、趋势判定、高阶能力占比 |
| `教研分析岗-中高考考情与试卷知识点分析.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `试卷逐题分析表.csv`、`考情分析框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 知识点占比与趋势结论转 EDU-03 做练习配比与内容选题；本年分值表回填为下一期框架文件的前两年基线。

### 可复算口径

- `分值占比% = 知识点分值 ÷ 120 × 100`（知识点分值 = 逐题表 40 行按知识点累加）
- `前年/去年分值占比% = 框架文件前两年分值表 ÷ 120 × 100`
- `三年变化百分点 = 今年占比 − 前年占比`
- `高阶能力分值占比% =（应用 + 综合分值）÷ 该知识点分值 × 100`
- 例：函数及其图象 = 题 9、10、14、21 各 3 分 + 题 30(1)(2)(3) 各 4 分 = 24 分；24 ÷ 120 = 20.0%

## 五、真实性等级与边界

- **构造**：试卷数据与三年基线为构造数据，口径全部可复算。
- **方法论来源**：知识点分类体系与趋势判定规则参照教研通行做法改写。
- **人工边界**：命题方向研判、内容选题决策、教研通报签发一律人工；AI 只输出可复算的分布与趋势，**不做命题预测**。
