## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某在线教育企业 · 秋季期次考情研究」完成中考数学卷的知识点分布统计与三年趋势分析，输出一张可复算的知识点分布与趋势分析表。

【输入 1 · 试卷逐题分析】试卷逐题分析表.csv（40 行）
- 每行一个小题行：题号、题型（选择/填空/解答）、分值、知识点、能力层级（识记/理解/应用/综合）
- 全卷 120 分：选择 16 题 × 3 分 + 填空 8 题 × 3 分 + 解答题 7 大题拆 16 个小问行共 48 分
【输入 2 · 考情分析框架】考情分析框架.md
- 知识点分类体系：4 模块 11 个知识点及归属关系
- 前两年分值表：各知识点前年、去年分值（每年合计 120 分）
- 趋势判定规则：Δ1 = 今年占比 − 去年占比，Δ2 = 去年占比 − 前年占比（百分点）；Δ1 ≥ +2 且 Δ2 > 0 → 持续上升；Δ1 ≤ −2 且 Δ2 < 0 → 持续下降；Δ1 ≥ +2 且 Δ2 ≤ 0 → 小幅上升；Δ1 ≤ −2 且 Δ2 ≥ 0 → 小幅下降；|Δ1| < 2 → 基本稳定
- 能力层级定义：高阶能力 = 应用 + 综合

【输出】知识点分布与趋势分析表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「中高考考情与试卷知识点分析」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **为什么说函数是第一重点？** 期望回答：函数及其图象 24 分占 20.0%（7 个小题行），三年占比 12.5% → 15.0% → 20.0% 持续上升，累计 +7.5 个百分点。
2. **综合与实践凭什么排进前三？** 期望回答：数学应用与建模分值 3 → 6 → 14，占比 11.7%，三年 +9.2 个百分点，持续上升，是增幅最大的知识点。
3. **圆的结论是什么？** 期望回答：分值 12 → 9 → 6 持续下降，今年占比 5.0%，三年 −5.0 个百分点。
4. **试卷的能力取向怎么量化？** 期望回答：应用 46 分 + 综合 35 分 = 高阶能力 81 分，占全卷 67.5%；锐角三角函数高阶占比 100%，实数与整式、图形变换为 0%。
5. **这些数字都能复算吗？** 期望回答：每个占比 = 知识点分值 ÷ 120，分值由逐题表 40 行按知识点累加，三年基线来自框架文件的前两年分值表。
