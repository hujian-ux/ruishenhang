# 考情分析框架 · 中考数学知识点分布与三年趋势

适用范围：某在线教育企业 · 教研分析岗 · 中高考考情与试卷知识点分析（EDU-01）。

## 一、分析口径

- 分析对象：某市中考数学卷，全卷 120 分。
- 拆解粒度：逐小题行——选择题、填空题逐题一行；解答题按小问拆行。本卷共 40 行：选择 16 题 × 3 分 + 填空 8 题 × 3 分 + 解答题 7 大题拆 16 个小问行共 48 分。
- 统计维度：按知识点归集题量与分值，分值占比 = 知识点分值 ÷ 120，保留 1 位小数。
- 能力层级：识记 / 理解 / 应用 / 综合 四级；高阶能力 = 应用 + 综合。

## 二、知识点分类体系（4 模块 11 知识点）

| 模块 | 知识点 |
| --- | --- |
| 数与代数 | 实数与整式、方程与不等式、函数及其图象 |
| 图形与几何 | 三角形与全等相似、四边形、圆、图形变换、锐角三角函数 |
| 统计与概率 | 统计与数据分析、概率 |
| 综合与实践 | 数学应用与建模 |

拆解时每个小题行的知识点必须能在上表中找到归属模块；找不到的先停下说明，不允许自行归类。

## 四、趋势判定规则

设 Δ1 = 今年占比 − 去年占比（百分点），Δ2 = 去年占比 − 前年占比（百分点）：

| 条件 | 判定 |
| --- | --- |
| Δ1 ≥ +2 且 Δ2 > 0 | 持续上升 |
| Δ1 ≤ −2 且 Δ2 < 0 | 持续下降 |
| Δ1 ≥ +2 且 Δ2 ≤ 0 | 小幅上升 |
| Δ1 ≤ −2 且 Δ2 ≥ 0 | 小幅下降 |
| \|Δ1\| < 2 | 基本稳定 |

三年变化 = 今年占比 − 前年占比（百分点）。趋势判定只依据上述规则，不加入主观命题预测。

## 五、输出要求

- 交付物为知识点汇总表，11 行（每个知识点一行），10 列固定结构，占比保留 1 位小数。
- 全表分值合计必须 = 120，占比合计必须 = 100.0%。
- 每个占比、变化值必须能从逐题分析表与前两年分值表复算得出。
- 通报结论只描述分布与趋势，不做「明年必考」类命题预测。
