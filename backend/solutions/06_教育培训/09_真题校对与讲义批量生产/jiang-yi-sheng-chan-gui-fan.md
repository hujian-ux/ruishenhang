# 讲义生产规范 · 真题校对与批量生产（某教育培训集团 · 教学内容生产岗）

> 本规范是「真题校对与讲义批量生产」场景的判定依据：四要素怎么核、错误怎么分、讲义怎么编，全部以本文件为准。

## 一、四要素一致性规则

每道真题的录入必须保证四个要素与原始来源一致，缺一不可：

| 要素 | 一致性要求 | 权威参照 |
| --- | --- | --- |
| 题干 | 文字、数字、单位与图表描述逐字一致 | 原卷扫描件 |
| 选项 | 内容与 A/B/C/D 顺序均一致，不得错位 | 原卷扫描件 |
| 答案 | 与官方发布答案一致 | 官方答案 |
| 解析 | 推导步骤完整，且结论与答案一致 | 官方解析 |

## 二、错误分类与处理规则

校对发现的错误分两类，处理路径不同：

| 错误类型 | 类别 | 处理方式 |
| --- | --- | --- |
| 题干识别错误 | 可自动纠正 | 以原卷扫描件为唯一参照纠正题干，纠正后标记「已纠正」 |
| 选项错位 | 可自动纠正 | 按原卷重排选项顺序，纠正后标记「已纠正」 |
| 答案录入笔误 | 可自动纠正 | 以官方答案为唯一参照修订，纠正后标记「已纠正」 |
| 解析与答案矛盾 | 需教师裁定 | 无唯一权威参照（无法判定是解析错还是答案错），移交学科教师核对原卷后定稿 |

判定逻辑：**存在唯一权威参照的，机器按参照纠正；不存在唯一权威参照的，一律移交教师裁定，机器不得自行改写。**

对应的校对结论口径：

| 发现错误类型 | 校对结论 |
| --- | --- |
| 无 | 通过 |
| 题干识别错误 / 选项错位 / 答案录入笔误 | 修正后通过 |
| 解析与答案矛盾 | 待教师裁定 |

## 三、讲义结构与归章规则

1. **章节命名**：`<科目>·<知识点模块>`，如「数学·函数与导数」。
2. **每章固定结构**：考点讲解 + 例题精讲 1 道 + 课堂练习 1 道 + 课后练习若干。
3. **编排顺序**：章内按题目编号顺序，第一道校对通过的题作「例题精讲」（配考点讲解），第二道作「课堂练习」，其余作「课后练习」。
4. **待裁定题**：讲义动作标注「裁定后编排」——教师裁定通过前不得进入讲义正文；裁定通过后按编号顺序补入对应位置。
5. **校对与生产同链路**：校对结论直接决定该题能否进入讲义；「修正后通过」的题以修正后版本进入，「待教师裁定」的题暂缓编排。

## 四、进度表口径

- 校对结论 ∈ {通过, 修正后通过, 待教师裁定}
- 「X 处录入错误被纠正」= 校对结论为「修正后通过」的题数（本批按错误类型统计：题干识别错误 + 选项错位 + 答案录入笔误）
- 全量校对覆盖率 = 进度表行数 ÷ 任务清单行数，必须为 100%
- 讲义动作 ∈ {例题精讲, 课堂练习, 课后练习, 裁定后编排}
