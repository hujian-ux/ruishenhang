# EDU-07 主提示词 · 真题校对与讲义批量生产

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/真题校对与讲义批量生产/SKILL.md`）。
2. 上传两个附件：`真题校对任务清单.csv`、`讲义生产规范.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `校对与讲义生产进度表.csv` 后，按文末「验收清单」逐项核对。

---

## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某教育培训集团 · 秋季学期真题入库」做真题校对与讲义批量生产，输出一张校对与生产一体的进度表。

【输入 1 · 真题校对任务清单】真题校对任务清单.csv（25 行）
- 含题目编号、科目、题型、题目简称、知识点模块、录入状态、校对要点、发现错误类型
- 发现错误类型 ∈ {无, 题干识别错误, 选项错位, 答案录入笔误, 解析与答案矛盾}
【输入 2 · 讲义生产规范】讲义生产规范.md
- 四要素一致性规则：题干对原卷扫描件 / 选项对原卷 / 答案对官方答案 / 解析结论对答案
- 错误分类：题干识别错误、选项错位、答案录入笔误为「可自动纠正」（有唯一权威参照）；解析与答案矛盾为「需教师裁定」
- 讲义结构：每章 = 考点讲解 + 例题精讲 1 道 + 课堂练习 1 道 + 课后练习若干

【输出】校对与讲义生产进度表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「真题校对与讲义批量生产」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **T10 和 T17 为什么不移交后直接改？** 期望回答：解析与答案矛盾没有唯一权威参照，无法判定是解析错还是答案错，必须教师核对原卷后裁定；AI 改答案违反人工边界。
2. **9 处自动纠正的依据分别是什么？** 期望回答：题干识别错误 4 处按原卷扫描件纠正、选项错位 3 处按原卷重排、答案录入笔误 2 处按官方答案修订——全部有唯一权威参照。
3. **力学章只有 3 题且 T10 待裁定，例题怎么排？** 期望回答：按编排顺序规则，第一道校对通过的 T09 作例题精讲，T11 作课堂练习，T10 标注裁定后编排、暂不进入正文。
4. **哪些题进了讲义、哪些没进？** 期望回答：23 道进入讲义（例题精讲 8 + 课堂练习 8 + 课后练习 7），2 道待裁定题暂缓，裁定通过后按编号补入。
5. **讲义章节数怎么来的？** 期望回答：25 题按「科目·知识点模块」归并，共 8 章：函数与导数、立体几何、力学、电磁学、语法专项、阅读理解、古诗文、现代文阅读。
