# EDU-07 · 真题校对与讲义批量生产 —— 场景使用说明

- **行业**：教育培训
- **角色**：教学内容生产岗（沈知意）
- **场景编号**：EDU-07
- **案例主体**：某教育培训集团（本场景库 EDU-07 / EDU-08 / EDU-09 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/真题校对与讲义批量生产/SKILL.md` | Skill 定义 | 四要素一致性口径、错误分类与处理规则、归章编排与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `真题校对任务清单.csv` | 原始输入 | 25 道待校对真题（科目/题型/知识点模块/校对要点/发现错误类型） |
| `讲义生产规范.md` | 原始输入 | 四要素一致性规则、错误分类（可自动纠正 vs 需教师裁定）、讲义结构与归章规则 |
| `校对与讲义生产进度表.csv` | **交付物** | 25 行：每题校对结论 + 错误处理 + 归入讲义章节 + 讲义动作 |
| `教学内容生产岗-真题校对与讲义批量生产.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `真题校对任务清单.csv`、`讲义生产规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 将「待教师裁定」的 2 题移交学科教师，裁定通过后按编号补入讲义对应章节。

### 可复算口径

- `校对结论`：无 → 通过；题干识别错误/选项错位/答案录入笔误 → 修正后通过；解析与答案矛盾 → 待教师裁定
- 「9 处录入错误被纠正」= 修正后通过 9 行 = 题干识别错误 4 + 选项错位 3 + 答案录入笔误 2（错误类型列逐行可数）
- `归入讲义章节` = `<科目>·<知识点模块>`（8 个唯一组合）
- `讲义动作`：章内按题目编号顺序，第 1 道校对通过的题 = 例题精讲，第 2 道 = 课堂练习，其余 = 课后练习；待裁定 = 裁定后编排
- 23 道进入讲义 = 例题精讲 8 + 课堂练习 8 + 课后练习 7 = 25 − 2 待裁定

## 五、真实性等级与边界

- **方法论来源**：机器前置校对 + 模板化批量生产 + 人工终审的链路来自企业应用案例素材。
- **构造**：25 道题目、错误分布与讲义章节为构造数据，口径全部可复算。
- **人工边界**：解析与答案矛盾的裁定、例题讲解口径审订、讲义定稿签发一律人工；AI 只做有权威参照的纠正与编排。
