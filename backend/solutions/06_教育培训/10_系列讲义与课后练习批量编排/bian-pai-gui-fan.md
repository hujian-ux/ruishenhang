# 讲义与练习编排规范（某职业考试培训企业 · 教研教辅）

本规范是「系列讲义与课后练习批量编排」场景的两条硬约束来源：讲义结构决定每个知识点写哪些模块，分层规则决定每个知识点配多少题、配到哪一层。

## 一、讲义结构（版式锚定）

系列讲义按讲次推进，每一讲的版式、标题层级与模块结构完全一致（版式锚定上一版产物，仅替换内容）：

| 掌握要求 | 讲义模块（顺序固定） |
| --- | --- |
| 熟练运用 / 理解掌握 | 考点精讲 + 经典例题 + 逐步解析 + 易错提示（四模块） |
| 了解识记 | 考点精讲 + 要点速记 + 自测清单（三模块） |

每讲开头固定一段「讲次导读」：本讲知识点清单、考频分布、建议学习时长。

## 二、练习分层规则（题数按知识点逐个计算）

课后练习按难度分三层，题数由「考频 × 掌握要求」唯一确定，不做主观判断：

| 难度层 | 定位 | 题数规则 |
| --- | --- | --- |
| 基础题 | 概念与公式的直接应用 | 高频 4 题 / 中频 3 题 / 低频 2 题 |
| 进阶题 | 综合运用与题型变形 | 熟练运用 3 题 / 理解掌握 2 题 / 了解识记 1 题 |
| 冲刺题 | 真题难度限时练 | 仅高频配冲刺：熟练运用 3 题、其他 2 题；中频低频不配 |

计算口径：高频 + 熟练运用 = 基础 4 + 进阶 3 + 冲刺 3，共 10 题；低频 + 了解识记 = 基础 2 + 进阶 1，共 3 题。

## 三、覆盖校验规则

编排完成后逐知识点校验，任一不满足即标记「缺口待补」：

1. 讲义模块齐全：按掌握要求配齐对应模块组合；
2. 基础题 ≥2：任何知识点的基础层不得少于 2 题；
3. 高频考点三层配齐：基础 / 进阶 / 冲刺每层 ≥1 题；
4. 校验结论口径：满足全部规则写「通过：讲义模块齐全，基础≥2，基础/进阶/冲刺三层配齐」（高频）或「通过：讲义模块齐全，基础≥2」（中频低频）。

## 四、版式统一规则

- 系列推进：按讲次顺序逐份生成，讲义标题层级（讲 → 知识点 → 模块）三级不变；
- 版式锚定：直接参照上一版产物的版式，只替换本讲知识点内容；
- 练习排版：每个知识点的练习紧跟其讲义模块之后，按基础 → 进阶 → 冲刺排序。
