# EDU-11 主提示词 · 系列讲义与课后练习批量编排

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/系列讲义与课后练习批量编排/SKILL.md`）。
2. 上传两个附件：`课程大纲知识点表.csv`、`编排规范.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `讲义练习编排计划表.csv` 后，按文末「验收清单」逐项核对。

## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某职业考试培训企业 · 省考行测系统班（10 讲）」做系列讲义与课后练习的批量编排，输出一张可校验、可复算的编排计划表。

【输入 1 · 课程大纲】课程大纲知识点表.csv（30 行）
- 含讲次、知识点、考频、掌握要求、难度分层五个字段
- 30 个知识点分布于第 1-10 讲，每讲 3 个
【输入 2 · 编排规范】编排规范.md
- 讲义模块结构：熟练运用/理解掌握走四模块（考点精讲+经典例题+逐步解析+易错提示）；了解识记走三模块（考点精讲+要点速记+自测清单）
- 练习分层规则：基础看考频（高频4/中频3/低频2）；进阶看掌握要求（熟练运用3/理解掌握2/了解识记1）；冲刺只给高频（熟练运用3/其他2）
- 覆盖校验：模块齐全、基础≥2、高频考点三层配齐

【输出】讲义练习编排计划表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「系列讲义与课后练习批量编排」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **190 道练习怎么来的？** 期望回答：基础 96（高频 12×4 + 中频 12×3 + 低频 6×2）+ 进阶 63（熟练运用 9×3 + 理解掌握 15×2 + 了解识记 6×1）+ 冲刺 31（高频熟练运用 7×3 + 高频其他 5×2）= 190。
2. **12 个高频考点怎么验证三层配齐？** 期望回答：高频行基础均为 4、进阶 ≥2、冲刺 ≥2，三层均 ≥1，覆盖校验结论逐行写明。
3. **「容斥原理」为什么只有 3 道题？** 期望回答：低频 + 了解识记 → 基础 2 + 进阶 1 + 冲刺 0；低频不配冲刺是规则，不是遗漏。
4. **「行程问题」中频熟练运用配几道？** 期望回答：基础 3 + 进阶 3 + 冲刺 0 = 6 道；进阶层看掌握要求，与考频无关。
5. **讲义模块有几种组合？** 期望回答：两种——四模块（熟练运用/理解掌握）与三模块（了解识记），全表无混搭。

## 验收清单

- [ ] 30 行输出，与输入知识点一一对应
- [ ] 练习合计 190 = 基础 96 + 进阶 63 + 冲刺 31
- [ ] 12 个高频考点覆盖校验结论均为「通过：…三层配齐」
- [ ] 全部基础题数 ≥2，无「缺口待补」行
- [ ] 讲义模块仅两种合法组合，练习按基础→进阶→冲刺排序
