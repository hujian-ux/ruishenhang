# EDU-11 · 系列讲义与课后练习批量编排 —— 场景使用说明

- **行业**：教育培训
- **角色**：课程编排岗
- **场景编号**：EDU-11
- **案例主体**：某职业考试培训企业

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/系列讲义与课后练习批量编排/SKILL.md` | Skill 定义 | 讲义模块结构、三层题数规则、覆盖校验规则与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `课程大纲知识点表.csv` | 原始输入 | 30 个知识点（第 1-10 讲 × 3）：考频 / 掌握要求 / 难度分层 |
| `编排规范.md` | 原始输入 | 讲义模块结构、练习分层题数规则、覆盖校验与版式统一规则 |
| `讲义练习编排计划表.csv` | **交付物** | 30 行：讲义模块 + 三层题数 + 练习合计 + 覆盖校验结论 |
| `课程编排岗-系列讲义与课后练习批量编排.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `课程大纲知识点表.csv`、`编排规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 教研按计划表抽题组卷，讲义按讲次推进排版，版式锚定上一版仅替换内容。

### 断言项

| 断言 | 结果 |
| --- | --- |
| `课程大纲知识点表.csv` 数据行 = 30（第 1-10 讲 × 3） | 通过 |
| 规范含模块结构 / 三层题数规则 / 覆盖校验全部关键词 | 通过 |
| 交付物数据行 = 30，与输入知识点一一对应 | 通过 |
| 练习合计 190 = 基础 96 + 进阶 63 + 冲刺 31 | 通过 |
| 高频考点 12 个，全部基础 / 进阶 / 冲刺三层 ≥1 且结论「三层配齐」 | 通过 |
| 全部基础题数 ≥2，无「缺口待补」行 | 通过 |
| 逐行练习合计 = 基础 + 进阶 + 冲刺 | 通过 |

### 可复算口径

- `基础题数` = 考频（高频 4 / 中频 3 / 低频 2），与掌握要求无关
- `进阶题数` = 掌握要求（熟练运用 3 / 理解掌握 2 / 了解识记 1），与考频无关
- `冲刺题数` = 高频且熟练运用 3 / 高频其他 2 / 非高频 0
- `基础 96` = 高频 12×4 + 中频 12×3 + 低频 6×2
- `进阶 63` = 熟练运用 9×3 + 理解掌握 15×2 + 了解识记 6×1
- `冲刺 31` = 高频熟练运用 7×3 + 高频其他 5×2
- `高频 12 / 中频 12 / 低频 6`、`熟练运用 9 / 理解掌握 15 / 了解识记 6` 均可由输入表分组 count 复算

## 四、与案例数字对齐

| 数字 | 出处 | 在本场景的落点 |
| --- | --- | --- |
| 30 个知识点、10 讲 | 输入表结构 | 交付物 30 行、第 1-10 讲 |
| 190 道分层练习 | 三层规则求和 | 交付物练习合计列求和 = 190 |
| 12 个高频考点全部配齐分层练习 | 高频行数 × 三层校验 | 交付物高频 12 行结论均为「三层配齐」 |
| 基础 96 / 进阶 63 / 冲刺 31 | 分层规则分组求和 | 交付物三列分别求和 |

## 五、真实性等级与边界

- **T2**：版式复用、系列推进、规则沉淀的协作模式来自官方案例素材。
- **T3**：分层练习与覆盖校验为教研通行做法。
- **构造**：某职业考试培训企业及其大纲数据为构造数据，口径可复算。
- **人工边界**：考频与掌握要求的教研判定、例题与练习题的最终选用、大纲修订一律人工；AI 只做模块锚定、题数计算与机械校验。
