# 系列讲义与课后练习批量编排

## 一、这个 Skill 解决什么

系列课程的配套讲义按讲次推进，每一讲的版式、标题层级与题型结构必须完全一致。真实的困难不是不会写，而是三件事靠人工撑不住：

- 每份材料都要重新排版，前后版式容易走样
- 每个知识点该配几道题、配到哪一层，全凭教研个人经验，口径不一
- 知识点覆盖有没有漏、高频考点有没有配齐冲刺题，没有系统校验

本 Skill 的核心动作，是把「大纲 → 讲义模块 → 分层练习 → 覆盖校验」变成一条流水线：**题数由规则唯一确定，版式一次锚定，覆盖逐点校验**。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 新一轮系统班开课，整册讲义与练习要按讲次成系列产出 | 主用场景：30 个知识点一次编排 |
| 大纲修订后需要重排整册练习的难度结构 | 分层规则可整册复算 |
| 教研换人后要保证口径不漂移 | 题数规则写死，不依赖个人经验 |
| 检查高频考点是否都配了冲刺层练习 | 覆盖校验逐点过、结论可复算 |

**不适用**：单份真题解析整理；渠道投放数据的周期复盘（→ EDU-12 渠道投放战报与转化复盘）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `课程大纲知识点表.csv` | 必需 | 讲次、知识点、考频、掌握要求、难度分层 |
| 2 | `编排规范.md` | 必需 | 讲义模块结构、练习分层题数规则、覆盖校验规则、版式统一规则 |

> 缺 2（规范）时，本 Skill 必须拒绝输出——没有分层规则的编排等于把口径问题原样放大 30 倍。

## 四、输出（outputs）

唯一交付物：`讲义练习编排计划表.csv`，字段固定为 10 列：

```
讲次, 知识点, 考频, 掌握要求, 讲义模块, 基础题数, 进阶题数, 冲刺题数, 练习合计, 覆盖校验结论
```

- 行数 = 输入知识点行数，一知识点一行
- `讲义模块` 按掌握要求二选一：四模块（考点精讲+经典例题+逐步解析+易错提示）或三模块（考点精讲+要点速记+自测清单）
- 三层题数由「考频 × 掌握要求」按规范规则唯一确定，`练习合计` = 三层之和
- `覆盖校验结论` ∈ {通过：讲义模块齐全，基础≥2，基础/进阶/冲刺三层配齐, 通过：讲义模块齐全，基础≥2, 缺口待补：…}，高频考点必须三层均 ≥1

## 五、工作流程（workflow）

### STEP 1 · 大纲拆解

读入 `课程大纲知识点表.csv`，确认每行五要素齐全（讲次 / 知识点 / 考频 / 掌握要求 / 难度分层），并核对「难度分层」列与考频一致（高频=基础+进阶+冲刺，其余=基础+进阶）。

### STEP 2 · 讲义模块锚定

按掌握要求锚定模块结构：熟练运用 / 理解掌握走四模块（考点精讲、经典例题、逐步解析、易错提示），了解识记走三模块（考点精讲、要点速记、自测清单）。每讲开头配讲次导读。

### STEP 3 · 分层题数计算

逐知识点按规则算题：基础层看考频（高频 4 / 中频 3 / 低频 2），进阶层看掌握要求（熟练运用 3 / 理解掌握 2 / 了解识记 1），冲刺层只给高频（熟练运用 3 / 其他 2）。题数唯一确定，不做主观增减。

### STEP 4 · 覆盖校验

逐知识点校验三条规则：模块齐全、基础 ≥2、高频三层配齐。任一不满足标记「缺口待补」并写明缺口项；全部满足写「通过」结论。

### STEP 5 · 版式统一与系列推进

按讲次顺序产出，讲义标题层级三级不变，练习紧跟对应知识点、按基础 → 进阶 → 冲刺排序。版式锚定上一版产物，仅替换内容。

### STEP 6 · 自检与输出

输出前逐项自检，任一不过则不得输出：

1. 行数是否与输入知识点数一致？
2. 每行三层题数是否可由「考频 × 掌握要求」复算得出？
3. 高频考点是否全部三层配齐（数量是否 = 输入高频行数）？
4. 全部基础题数是否 ≥2？
5. 练习合计总数是否 = 基础 + 进阶 + 冲刺三层总和？

## 六、关键规则（不可协商）

1. **题数由规则唯一确定。** 基础看考频、进阶看掌握要求、冲刺只给高频。不凭感觉加题减题。
2. **版式一次锚定。** 系列讲义按讲次推进，标题层级与模块结构不变，只替换内容；不允许某讲自创新版式。
3. **覆盖必须留痕。** 每个知识点一行校验结论，高频考点三层配齐情况可从交付物直接复算。
4. **练习排序固定。** 基础 → 进阶 → 冲刺，不允许穿插。
5. **不写效果承诺。** 输出中不出现「提分 X 分」「通过率提升」类表述。

## 七、人工边界

| AI 负责 | 人负责（教研专员） |
| --- | --- |
| 模块锚定与分层题数计算 | 考频与掌握要求的教研判定 |
| 覆盖校验与缺口标记 | 例题与练习题的最终选用 |
| 系列版式统一约束 | 大纲修订与知识点增删 |

## 八、下游衔接

- 编排计划表 → 讲义排版与题库抽题的执行依据
- 知识点掌握情况数据 → 回流大纲修订，驱动下一轮编排


## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读规范再看大纲：把讲义模块结构、三层题数规则与覆盖校验写成显式判定表，不要边排边定标准。
2. 逐行锚定讲义模块：按「掌握要求」列确定四模块或三模块组合，每讲开头配讲次导读。
3. 逐行算三层题数：基础、进阶、冲刺题数由「考频 × 掌握要求」按规范唯一确定，不做主观增减。
4. 逐行覆盖校验：模块齐全、基础≥2、高频三层每层≥1；不满足写「缺口待补」并注明缺口项，满足按规范口径写「通过」。
5. 系列推进：按讲次顺序输出，讲义标题层级三级不变，练习按基础→进阶→冲刺排序，版式锚定上一讲仅替换内容。

### 硬性约束

【硬性约束】
- 三层题数必须可复算：基础只看考频、进阶只看掌握要求、冲刺只给高频，任何一行的题数都要能对着规则表推出来。
- 高频考点的覆盖校验结论必须写明「基础/进阶/冲刺三层配齐」，且数量 = 输入表高频行数。
- 讲义模块只有两种合法组合，不得混搭或增删模块。
- 练习合计 = 基础 + 进阶 + 冲刺，逐行成立。
- 不出现「提分」「通过率」类效果承诺。

### 生成后自检

【生成后自检，逐条回答】
1. 输出行数是否 = 30，与输入知识点一一对应？
2. 每行三层题数是否都能按规则表复算？
3. 高频考点是否全部三层配齐（应为 12 个 = 输入高频行数）？
4. 是否所有基础题数 ≥2？
5. 练习合计总数是否 = 基础/进阶/冲刺三层分别求和（应为 96/63/31，总计 190）？
自检全过再输出 CSV。

### 输出格式

【输出格式】CSV，10 列，列名与顺序固定：
讲次, 知识点, 考频, 掌握要求, 讲义模块, 基础题数, 进阶题数, 冲刺题数, 练习合计, 覆盖校验结论
