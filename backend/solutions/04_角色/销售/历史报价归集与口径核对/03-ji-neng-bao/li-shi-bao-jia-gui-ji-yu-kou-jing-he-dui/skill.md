# 历史报价归集与口径核对 · SKILL

## 适用场景
客户情报与风险 · 真实业务触发 精工项目报价进入让利谈判

## 输入
- 历史报价归集与口径核对·原始数据.xlsx

## 工作流程（5 步）
1. 散件归集：每个报价找到原始出处 微信截图、邮件、旧表逐条录入：日期、金额、报价人、场合 —— 出处标注到聊天记录位置
2. 口径翻译：三个价放回同一把尺 152（不含税不含运）/ 158（含税）→ 139.8（折不含税）/ 149（含税含运）→ 130.…
3. 轨迹呈现：我们到底降没降价 统一口径下：152 → 139.8 → 130.7，一年半累计降价 14% —— 真实降幅第一次有数
4. 异常检测：有一报价偏离轨迹 若某次报价突然高于轨迹 20% 以上，标注「探价？」或「口径存疑待核」—— 异常不解释，标出来问当事人
5. 谈判弹药：客户价格档案一页 统一口径轨迹 + 每个价的原始口径注释 + 本次报价的锚点建议 —— 梁总谈判前看这一页

## 产出
- 历史报价归集与口径核对·交付物.xlsx

## 不承诺
本场景基于真实业务叙事整理；最终结论与提交由人确认。
