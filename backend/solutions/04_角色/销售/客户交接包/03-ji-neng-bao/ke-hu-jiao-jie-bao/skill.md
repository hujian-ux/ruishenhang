# 客户交接包 · SKILL

## 适用场景
客户情报与风险 · 真实业务触发 陈昊月底离职（回老家）

## 输入
- 客户交接包·原始数据.xlsx

## 工作流程（5 步）
1. 客户清单重建：27 个客户到底是谁 微信 + 邮箱 + 订单三源对齐 —— 「微信里叫王工的」还原成公司全称 + 职位
2. 在谈商机分级：12 个商机的接手优先级 临门的（2 个，本周内必须无缝接手）/ 中期的（5 个）/ 观望的（5 个 —— 与 商机健康…
3. 雷区与口头承诺显性化：「答应过 Q4 前不涨价」「老板和对方董事长是校友」—— 这些从聊天记录和口述里挖出，单独成页，新接手人第一天就要看
4. 交接档案交付：接手人的第一周地图 每客户一页：先联系谁、说什么、别碰什么 —— 林嘉怡的第一周从「挨个破冰」变成「按图索骥」
5. 交付归档：产出可复核交付物并归档。

## 产出
- 客户交接包·交付物.xlsx

## 不承诺
本场景基于真实业务叙事整理；最终结论与提交由人确认。
