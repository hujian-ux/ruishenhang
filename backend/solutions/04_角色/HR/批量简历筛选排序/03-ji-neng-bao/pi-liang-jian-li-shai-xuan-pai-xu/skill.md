# Skill · 简历筛选排序

## 一句话定位

**输入一份 JD（岗位画像）+ 一批简历，输出三色匹配度排序表 + 每份简历的匹配理由 + 待澄清清单。**

不是"关键词匹配器"，是招聘 HR 的**第一道筛选大脑**——把"逐份翻简历 2-4 小时"压到"30 秒出排序结论"。

---

## 触发条件

当用户表达以下意图时召唤本 Skill：
- "这批简历帮我筛一下" / "哪些人可以约面？"
- "这份 JD 匹配的候选人帮我排个序"
- "帮我看看这几份简历够不够格"
- 关键词：**简历、筛选、匹配、初筛、候选人、约面、推荐人选**

---

## 输入契约

| 字段 | 必填 | 说明 |
|---|---|---|
| jd | ✅ | JD / 岗位画像（含硬性条件、软性加分项、红线） |
| resumes | ✅ | 一份或多份简历（文本 / PDF / Word 解析后内容） |
| screening_rules | 可选 | 自定义筛选规则（如"必须会 Python""薪资必须 <30K"）覆盖默认规则 |
| context | 可选 | 情境（批量初筛 / 定向推荐 / 猎头推荐验证） |

---

## 执行步骤（内部流程）

1. **解析 JD**：提取硬性条件（学历/专业/年限/技能）、软性加分项、红线（跳槽频率/薪资超预算比例）
2. **逐份解析简历**：提取学历、专业、年限、技能关键词、行业、期望薪资、跳槽频率、量产/项目经验
3. **硬性条件闸门**（一票否决）：
   - 学历 < 要求 → 红
   - 总经验年限 < 要求 → 红
   - 核心技能方向不符（如硬件岗无电路设计经验）→ 红
4. **匹配度评分**（通过闸门后）：
   - 行业匹配（工控经验年限权重最高）
   - 技能关键词命中率（画板工具/电路设计/EMC）
   - 量产/项目经验数量
   - 加分项命中（IATF/EMC认证/PLC伺服电源）
   - 扣分项（跳槽频率超红线 / 薪资超预算 / 到岗时间慢）
5. **三色分级**：
   - 🟢 **绿 · 可约面**：硬性全过 + 评分 ≥ 75 分
   - 🟡 **黄 · 待澄清**：硬性边界 + 需电话初面确认（薪资弹性/行业转型意愿/稳定性/学历破格）
   - 🔴 **红 · 淘汰**：硬性未过或注水嫌疑
6. **输出排序表** + 待澄清清单 + 邀约顺序建议

## 输出格式说明（Excel 交付）

**对话内默认输出**：Markdown 表格/结构化结果，直接在对话中展示。

**交付 Excel**：当用户需要 .xlsx 文件（对应 demo 中的参考输出）时，用 Python openpyxl 生成：
- 文件名：`批量简历筛选排序·交付物.xlsx`
- Sheet「简历评分结果」：序号/候选人/分级/评分/学历/学校/经验/期望薪资/到岗/跳槽/匹配理由1-3/顾虑点/建议动作
- Sheet「待澄清清单」：优先级/候选人/问题/建议动作
- Sheet「邀约顺序」：排序/候选人/说明/标记
- 生成方式：调用 `openpyxl` 创建工作簿 → 写入表头与数据行 → 保存到输出目录 → 在回复中告知文件路径（参考 `` 中的同名样例）

**输入格式**：PDF/Word 简历直接解析为文本后评分；若简历是 Excel 表则用 read_file 读取。


---

## 依赖工具（底层 MCP / 能力）

- `read_file` / 附件解析（简历 PDF/Word → 文本）
- `parse_resume`（简历字段抽取：学历/年限/技能/薪资/经历）
- `match_jd`（JD 画像 vs 简历匹配度评分）
- 后置：可调用 `面试评估汇总` Skill 承接后续面试流程

---

## 适用场景清单

| 岗位 | 场景 | 复用点 |
|---|---|---|
| **招聘 TA** | 批量简历初筛 | 主用（本包场景一） |
| **招聘 TA** | 猎头推荐验证 | 每份推荐先用本 Skill 打评分，避免被"包装简历"带偏 |
| **招聘 TA** | 定向挖人 | 给 JD 让 Skill 从人才库找最接近的人 |
| **HRBP** | 内推评估 | 内推简历统一过闸门，避免人情单绕过标准 |
| **销售/管理层** | 招聘周会 | 只汇报三色统计 + 邀约顺序即可 |

**至少 4-5 个场景可复用同一 Skill**——简历筛选是招聘里复用度最高的能力。

---

## 一句话结论

**简历筛选排序 = 招聘 HR 的入口守门员**。它把"看人"这件最吃经验、最耗时的事变成可重复、可解释、口径统一的标准化动作；同一个 Skill 换一份 JD，就是为不同岗位守门——这就是 WorkBuddy 相对于"招聘网站自带的过滤功能"的差异化：不是按关键词硬筛，而是**按岗位画像算匹配度、给结论、说明理由**。
