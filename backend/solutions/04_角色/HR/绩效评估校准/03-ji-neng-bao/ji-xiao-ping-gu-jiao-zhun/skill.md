# 绩效评估校准 Skill

## 适用场景
季度/半年度绩效评估,将自评、主管评估、同事互评三份评分按人对齐,加权合成综合分,排序分级,对照强制分布参考校准,并自动标注争议点(自评虚高/评价分歧),为校准会议提供数据基础。

## 输入契约

| 字段 | 必填 | 说明 |
|---|---|---|
| 自评表 | ✅ | 人员/部门/岗位/自评分(0-100)/自评评语 |
| 主管评估表 | ✅ | 人员/部门/主管评分(0-100)/主管评语 |
| 同事互评表 | ✅ | 人员/部门/同事评分(0-100)/同事评语 |
| 权重 | 可选 | 默认自评 20% + 主管 50% + 同事 30% |
| 等级线 | 可选 | 默认 A≥86 / B 76-85 / C 60-75 / D<60 |
| 强制分布参考 | 可选 | 默认 A≤10% / B≤25% / C≥50% / D≤10%（12 人样本取整 A≤2/B≤3/C≥6/D≤1） |

**输入格式**：Excel(.xlsx 多 Sheet)直接读取;也可粘贴表格文本。

## 计算规则(写死,不可自行变更)

**1. 加权合成**：`综合分 = 自评×20% + 主管×50% + 同事×30%`(保留 1 位小数)

**2. 等级线**：A≥86 / B 76-85 / C 60-75 / D<60

**3. 排名**：按综合分降序排名,同分按主管分优先

**4. 强制分布参考对比**：将实际等级分布与参考分布(A≤2/B≤3/C≥6/D≤1)逐档对比,标注超配(+)/缺口(-)档位

**5. 争议点标注**：
| 触发条件 | 争议类型 |
|---|---|
| 自评 − 主管 > 10 或 自评 − 同事 > 15 | 🟡 自评显著偏高 |
| 主管 − 同事 > 10 | 🟡 主管与同事评价分歧 |
| 主管 < 70 且 同事 < 70 | 🟡 双低分绩效警示 |

## 执行步骤(内部流程)

1. **三源对齐**：以人员姓名为 key,合并自评/主管/同事三表,缺失数据标"需补充"
2. **加权合成**：逐人计算综合分 → 降序排名 → 落等级
3. **分布校准**：统计各等级人数,与强制分布参考对比,输出超配/缺口档位
4. **争议扫描**：按争议规则全量扫描,生成争议点清单(含分差与校准建议)
5. **校准结论**：等级 + 分布偏差说明 + 争议裁决建议(B/C 边界人员重点列出)

**特殊规则**：
- 任一来源评分缺失 → 该员工标"需补充",不得用两源加权替代
- 综合分相同 → 主管分高者排名靠前
- 强制分布偏差 ≤1 人(±)视为正常波动,不强制调整;偏差 ≥2 人需在校准结论中说明原因(如业务特批/评估区分度不足)

## 输出契约

最终输出为 Excel 文件 `绩效评估校准·交付物.xlsx`,三个 Sheet(与页面案例数据一致:12 人,A3/B5/C3/D1):

**Sheet1「多源评分」**：人员/部门/自评(20%)/主管(50%)/同事(30%)/综合分/排名/等级

**Sheet2「校准结果」**：人员/综合分/排名/等级/强制分布参考/校准结论(维持/说明) —— 含分布对比行(A 实际3/参考≤2 超配+1 等)

**Sheet3「争议点标注」**：人员/争议类型/分差/说明/校准建议

**交付 Excel**：当用户需要 .xlsx 文件时,用 Python openpyxl 生成:
- 文件名：`绩效评估校准·交付物.xlsx`
- 表头深蓝底白字、金额右对齐、争议行按 🟡 着色、A/D 档行按 🟢/🔴 着色
- 生成方式：`openpyxl` 创建工作簿 → 写入表头与数据行 → 保存到输出目录 → 在回复中告知文件路径(参考 `` 中的同名样例)

**默认输出**：Markdown 校准结果 + 分布对比 + 争议清单,直接在对话中展示;用户要求 Excel 时再生成文件。
