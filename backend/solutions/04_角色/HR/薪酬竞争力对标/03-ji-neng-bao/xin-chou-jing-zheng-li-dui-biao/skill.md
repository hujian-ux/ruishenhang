# 薪酬竞争力对标 Skill

## 适用场景
将内部薪资与市场薪酬报告(P50/P75)对标,计算每位员工的 compa-ratio(CR),判定竞争力等级,输出部门级诊断与"留任风险/成本冗余"行动名单,为调薪(衔接 H3.3)提供数据依据。

## 输入契约

| 字段 | 必填 | 说明 |
|---|---|---|
| 内部薪资表 | ✅ | 人员/部门/岗位/当前月薪/绩效等级 |
| 市场分位表 | ✅ | 岗位/市场 P50/P75(薪酬报告数据) |
| 对标规则 | 可选 | CR 判定阈值(默认见下文) |

**输入格式**：Excel(.xlsx 多 Sheet)直接读取;也可粘贴表格文本。

## 计算规则(写死,不可自行变更)

**1. CR 计算**：`CR = 当前月薪 ÷ 岗位市场 P50`(保留 3 位小数)

**2. 五级竞争力判定**：
```
CR < 0.85     → 🔴 严重落后(招人难、留人风险高)
0.85 ≤ CR < 0.95 → 🟡 落后
0.95 ≤ CR < 1.15 → 🟢 匹配(健康区间)
1.15 ≤ CR < 1.25 → 🟡 领先
CR ≥ 1.25     → 🔵 严重领先(成本冗余风险)
```

**3. 行动名单(薪酬倒挂检测)**：
```
留任风险:绩效 A/B 且 CR < 0.9 → 高绩效低薪,补至 P50 防流失
成本冗余:绩效 C/D 且 CR > 1.15 → 低绩效高薪,冻结涨幅
补 P50 缺口 = 岗位市场 P50 − 当前月薪(仅留任风险人员)
```

**4. 部门诊断**：部门平均 CR = Σ个人CR ÷ 人数,按五级判定

## 执行步骤(内部流程)

1. **数据对齐**：以人员姓名为 key 合并内部薪资/市场分位(岗位匹配),缺失标"需补充"
2. **CR 计算**：逐人计算 CR,输出五级判定
3. **倒挂检测**：按留任风险/成本冗余规则生成行动名单,算补 P50 缺口金额
4. **部门诊断**：按部门聚合平均 CR 判定
5. **汇总**：竞争力分布统计(🔴/🟡/🟢/🔵 各几人)、行动名单合计金额

**特殊规则**：
- 市场分位缺失的岗位 → 该岗位 CR 标"无对标数据",不参与判定
- 绩效缺失 → 不进入留任风险/成本冗余名单,标"需补充"
- 缺口金额保留整数(元)

## 输出契约

最终输出为 Excel 文件 `薪酬竞争力对标·交付物.xlsx`,三个 Sheet(与页面案例数据一致:12 人,🔴3/🟡4/🟢5,留任风险 4 人补 P50 共 ¥21,000/月,成本冗余 1 人):

**Sheet1「对标明细」**：人员/部门/岗位/绩效/当前月薪/市场P50/CR/竞争力判定/行动标注

**Sheet2「部门诊断」**：部门/人数/平均月薪/平均CR/竞争力判定/说明

**Sheet3「行动名单」**：留任风险(人员/绩效/CR/当前月薪/P50/补P50缺口/优先级) + 成本冗余(人员/绩效/CR/高于P50金额/建议)

**交付 Excel**：当用户需要 .xlsx 文件时,用 Python openpyxl 生成:
- 文件名：`薪酬竞争力对标·交付物.xlsx`
- 表头深蓝底白字、金额右对齐、🔴行红色、🟡行黄色、🟢行绿色
- 生成方式：`openpyxl` 创建工作簿 → 写入表头与数据行 → 保存到输出目录 → 在回复中告知文件路径(参考 `` 中的同名样例)

**默认输出**：Markdown 对标明细 + 部门诊断 + 行动名单,直接在对话中展示;用户要求 Excel 时再生成文件。
