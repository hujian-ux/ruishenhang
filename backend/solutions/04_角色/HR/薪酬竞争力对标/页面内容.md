现状与痛点

老板和业务部门总问公司薪酬有没有竞争力，HR 拿不出数据，逐岗比对一天还说不清楚统一口径。

"我们薪资到底啥水平？"没人答得上来

老板和业务部门总问公司薪酬有没有竞争力，HR 拿不出数据：内部薪资散在系统里，市场报告躺抽屉里，谁也没做过系统对标。

高频
薪酬倒挂看不见，招人难留人难

高绩效人才拿低于市场 P50 的薪水，自己不知道、HR 不知道，等人家提离职才发现——下季度就是流失名单。

高风险
手工比对逐岗翻，一查就是一天

内部月薪对照市场分位表，逐人算比例、逐岗写结论，12 人半天，全公司几百岗位做一次对标要一两周，而且口径不统一。

耗时
诊断结论靠感觉，没有统一口径

"研发好像偏低""销售还行"都是拍脑袋，没有一个统一的 compa-ratio（CR）阈值把"落后/匹配/领先"定死。

易遗漏

诊断完不落地——就算发现倒挂，也没有行动名单：谁该加薪补到 P50、谁薪资已超市场该冻结，没有一张表可以直接拿去跟老板要预算。

WorkBuddy 的解决和价值

内部薪资与市场分位一键导入，10分钟完成CR计算、五级判定、部门诊断与行动名单。

传统做法

内部薪资拉 Excel → 逐岗翻市场报告 → 手工算比例 → 结论靠感觉 → 无行动清单，一两天起步，口径不统一。

WorkBuddy 做法

内部薪资 + 市场分位一键导入 → AI 10分钟完成：逐人 CR 计算 → 竞争力五级判定 → 部门级诊断 → 留任风险/成本冗余双名单 + 补 P50 缺口金额 → 一张表直接上会要预算。

三个核心价值
01CR 口径统一，诊断可解释

compa-ratio（CR）=当前月薪÷市场P50，五级阈值写死：<0.85 严重落后 / 0.85-0.95 落后 / 0.95-1.15 匹配 / 1.15-1.25 领先 / >1.25 严重领先，谁落后谁匹配一张表说清。

02倒挂自动识别，双名单直击要害

高绩效（A/B）低薪（CR<0.9）自动进留任风险名单；低绩效（C/D）高薪（CR>1.15）自动进成本冗余名单——招人难、养冗余两个问题一次暴露。

03行动落地，补 P50 缺口直接算钱

每个留任风险人员给出"补至市场 P50 需要 +¥X/月"，一张表量化要预算的金额，跟老板谈不是谈感受是谈数据。

方案定位

不是替 HR 下结论，而是把"手工比对+拍脑袋诊断"变成"统一 CR 口径+量化行动名单"，把一两天的对标工作压缩到 10 分钟。

解决方案的工作流程

从数据导入到行动名单，共5步。

01数据导入

内部薪资表与市场分位表按岗位匹配对齐。

02CR 计算

CR=当前月薪÷岗位市场P50，逐人计算保留3位小数。

03五级判定

按CR区间判定严重落后/落后/匹配/领先/严重领先五级。

04部门诊断

部门平均CR聚合，输出部门级竞争力判定。

05行动名单

留任风险与成本冗余双名单，算出补P50缺口金额。

帮我做薪酬竞争力对标，两份数据已上传（内部薪资 / 市场分位）。

请帮我处理，要求：
1. 逐人计算 CR = 当前月薪 ÷ 岗位市场 P50（保留 3 位小数）
2. 五级判定：CR<0.85 严重落后 / 0.85-0.95 落后 / 0.95-1.15 匹配 / 1.15-1.25 领先 / >1.25 严重领先
3. 倒挂检测：绩效 A/B 且 CR<0.9 → 留任风险（补至 P50 防流失）；绩效 C/D 且 CR>1.15 → 成本冗余（冻结涨幅）
4. 部门诊断：部门平均 CR 聚合判定
5. 输出：对标明细 + 部门诊断 + 行动名单（含补 P50 缺口金额）

注意：市场分位缺失岗位标"无对标数据"；绩效缺失不进入行动名单；缺口金额保留整数。
