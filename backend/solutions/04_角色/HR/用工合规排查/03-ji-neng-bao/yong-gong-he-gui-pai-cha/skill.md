# Skill · 用工合规排查

## 一句话定位

**输入用工台账（合同 / 考勤 / 加班），输出风险点清单 + 三色分级（🔴高危/🟡关注/🟢正常）+ 整改台账（责任人/期限/状态）。**

不是"翻一遍台账"，是用<b>合规规则引擎全量扫描</b>，把"漏检一条合同到期未续签 = 双倍工资"的高风险项**一条不漏地挖出来、分级排优先级、跟到整改闭环**——让季度合规排查从"1 天起步"压到"20 分钟出清单"。

---

## 触发条件

当用户表达以下意图时召唤本 Skill：
- "帮我做一次用工合规排查" / "合规检查"
- "查一下有没有合同到期没续签的"
- "加班超时的人有哪些"
- 关键词：**用工合规、合同风险、合同到期、未签合同、双倍工资、加班超时、劳动法、整改台账**

---

## 输入契约

| 字段 | 必填 | 说明 |
|---|---|---|
| contracts | ✅ | 合同台账（人员/入职日期/合同到期日/状态），推荐上传《用工合规排查·原始数据.xlsx》Sheet1 |
| attendance | ✅ | 考勤记录（人员/迟到/缺勤/状态），Sheet2 |
| overtime | ✅ | 加班记录（人员/本月加班时长/核算/调休），Sheet3 |
| thresholds | 可选 | 风险阈值（默认：合同到期 ≤30 天预警、加班 >36h/月 违规） |
| context | 可选 | 排查周期（季度/年度）/ 法规版本 |

---

## 执行步骤（内部流程）

1. **台账对齐**：按"人员"主键把合同 / 考勤 / 加班 3 表 join 成一行一条记录
2. **规则扫描**（全量，规则写死在 Skill 里）：
   - **合同类**：已到期未续签（>0 天）→ 🔴；30 天内到期 → 🟡 预警
   - **加班类**：月加班 >36 小时（《劳动法》第 41 条）→ 🔴；>30h 或未核算 → 🟡
   - **考勤类**：迟到 ≥6 次/月 或 缺勤 ≥2 天 → 🟡；连续异常 → 标注
   - **调休类**：调休结余长期未清零 → 🟡
3. **三色分级**：
   - 🔴 **高危**：合同已到期未续签（双倍工资风险）/ 加班超 36h 红线
   - 🟡 **关注**：合同 30 天内到期 / 考勤异常 / 加班费未核算 / 调休未结
   - 🟢 **正常**：无风险项
4. **生成整改台账**：每个风险点带 责任人 / 期限 / 状态 / 依据（法律条款）
5. **复查闭环**：整改台账跨季度保留，下季度复查直接对表，问题从"发现"到"关闭"全程可追

**特殊规则**：
- 合同到期未续签 → 必须给出"倒签 + 双倍工资风险敞口评估"双动作
- 涉及孕期/工伤/医疗期员工 → 合同处理强制标注，禁止到期直接终止
- 数据缺失 → 标"需补充"，不得默认合规

## 输出格式说明（Excel 交付）

**对话内默认输出**：Markdown 风险点清单 + 三色分级 + 整改台账，直接在对话中展示。

**交付 Excel**：当用户需要 .xlsx 文件（对应 demo 中的参考输出）时，用 Python openpyxl 生成：
- 文件名：`用工合规排查·交付物.xlsx`
- Sheet「风险点清单」：风险点/涉及人员/风险等级/法律依据/整改动作（5 条，与页面案例一致：🔴2 合同到期未续签 + 🟡3 加班超时/考勤异常/调休未结）
- Sheet「三色汇总」：等级/数量/风险说明（🔴高危 2 / 🟡关注 3 / 🟢正常 7）
- Sheet「整改台账」：风险点/责任人/期限/状态/复查备注（闭环跟踪）
- 生成方式：调用 `openpyxl` 创建工作簿 → 写入表头与数据行 → 保存到输出目录 → 在回复中告知文件路径（参考 `` 中的同名样例）

**输入格式**：三类台账 Excel（.xlsx 多 Sheet：合同/考勤/加班）直接上传解析；CSV 同理。参考分发包 `用工合规排查·原始数据.xlsx`。

## 依赖工具（底层 MCP / 能力）

- `read_file` / 表格解析（合同 / 考勤 / 加班 3 表）
- `join_by_employee`（按人员主键三表对齐）
- `scan_compliance_rules`（合同到期 / 加班超时 / 考勤异常规则引擎）
- `tier_risk`（三色分级）
- `gen_rectification`（整改台账生成）
- 后置：涉违纪/汰换可接 `人员汰换评估` Skill（H2.3），涉法务可转法务团队

## 适用场景清单

| 岗位 | 场景 | 复用点 |
|---|---|---|
| **HRBP** | 季度用工合规排查 | 主用（本包场景） |
| **HRBP** | 合并/重组前用工尽调 | 全量风险扫描 |
| **员工关系** | 仲裁应诉前证据梳理 | 合同/加班证据链核对 |
| **管理者** | 合规风险月度简报 | 三色风险清单 |

**至少 4 个场景可复用同一 Skill**——用工合规是 HRBP 年度循环里"漏一条就赔钱"的最高风险场景。

## 一句话结论

**用工合规排查 = HRBP 的"防雷巡检"**。规则引擎全量扫描 → 三色分级 → 整改台账闭环，让"合同到期没续签""加班超时没人管"这些雷,在爆之前就被排掉——漏检归零,整改可追。
