# 月度薪资核算 Skill

## 适用场景
每月发薪前,将薪资档案、考勤汇总、绩效结果三个表按人对齐,计算每位员工当月应发工资、社保公积金、个税与实发工资,并标注异常项(缺勤过多/绩效低/加班超红线/加班费未核算)。

## 输入契约

| 字段 | 必填 | 说明 |
|---|---|---|
| 薪资档案表 | ✅ | 人员/部门/岗位/基本工资/岗位工资/绩效基数/绩效等级/补贴 |
| 考勤汇总表 | ✅ | 人员/出勤天数/缺勤天数/迟到次数/加班时长(h)/加班费核算状态 |
| 绩效结果表 | ✅ | 人员/绩效等级/绩效系数/绩效工资 |
| 个税规则 | 可选 | 默认 7 级超额累进税率表 + 速算扣除数(见下文) |

**输入格式**：Excel(.xlsx 多 Sheet)直接读取;也可粘贴表格文本。附件解析用 `read_file` / openpyxl。

## 计算规则(写死,不可自行变更)

**1. 绩效系数映射**：A=1.3 / B=1.1 / C=0.9 / D=0.7

**2. 应发工资**：
```
绩效工资   = 绩效基数 × 绩效系数
日薪       = (基本工资 + 岗位工资) ÷ 21.75
缺勤扣款   = 日薪 × 缺勤天数
应发工资   = 基本工资 + 岗位工资 + 绩效工资 + 补贴 − 缺勤扣款
```

**3. 社保与公积金(个人部分)**：
```
社保基数   = 基本工资 + 岗位工资
社保(个人) = 基数 × 10.5%   (养老 8% + 医疗 2% + 失业 0.5%)
公积金     = 基数 × 7%
```

**4. 个税(累计预扣简化版)**：
```
应纳税所得额 = 应发工资 − 社保 − 公积金 − 5000(起征点)
若 ≤ 0 则个税 = 0
税率表(7 级超额累进)：
   ≤3,000       3%    速算扣除 0
   3,000-12,000 10%   速算扣除 210
   12,000-25,000 20%  速算扣除 1,410
   25,000-35,000 25%  速算扣除 2,660
   35,000-55,000 30%  速算扣除 4,410
   55,000-80,000 35%  速算扣除 7,160
   >80,000      45%   速算扣除 15,160
个税 = 应纳税所得额 × 税率 − 速算扣除数
```

**5. 实发工资**：`实发 = 应发 − 社保 − 公积金 − 个税`

## 异常标注规则(自动)

| 触发条件 | 标注 |
|---|---|
| 缺勤天数 > 3 | 🟡 缺勤过多,核对扣款 |
| 绩效等级 = D | 🟡 绩效 D,收入断崖风险 |
| 加班时长 > 36h | 🔴 超《劳动法》红线,补调休/核算加班费 |
| 加班费 = 未核算 | 🟡 加班费未核算,提醒补录 |
| 应发工资 > 50,000 | 🟡 高薪档位,复核个税 |

## 执行步骤(内部流程)

1. **三表对齐**：以人员姓名为 key,合并薪资档案/考勤/绩效三表,缺失数据标"需补充"
2. **逐人计算**：按上述规则计算绩效工资→应发→社保→公积金→个税→实发
3. **异常扫描**：按异常标注规则全量扫描,生成异常清单
4. **汇总校验**：应发合计 / 个税合计 / 实发合计,与上表交叉验证(实发合计 = 应发合计 − 社保合计 − 公积金合计 − 个税合计)
5. **输出工资表**：完整工资明细 + 个税试算 + 异常标注

**特殊规则**：
- 任何一项数据缺失 → 该员工标"需补充",不得默认给 0
- 应发为负(极端缺勤) → 标"异常,人工复核"
- 个税、社保、公积金均保留 2 位小数;展示时金额四舍五入到元

## 输出契约

最终输出为 Excel 文件 `月度薪资核算·交付物.xlsx`,三个 Sheet(与页面案例数据一致:12 人,应发 ¥451,759.78 / 个税 ¥56,873.99 / 实发 ¥344,835.79):

**Sheet1「工资明细」**：人员/部门/岗位/绩效等级/基本/岗位/绩效工资/补贴/缺勤扣款/应发/社保/公积金/个税/实发/异常标注

**Sheet2「个税试算」**：人员/应发/社保/公积金/应纳税所得额/适用税率/速算扣除数/个税

**Sheet3「异常标注」**：人员/异常类型/风险等级/说明/处理建议

**交付 Excel**：当用户需要 .xlsx 文件时,用 Python openpyxl 生成:
- 文件名：`月度薪资核算·交付物.xlsx`
- 表头深蓝底白字、金额右对齐、异常行按 🟡/🔴 着色
- 生成方式：`openpyxl` 创建工作簿 → 写入表头与数据行 → 保存到输出目录 → 在回复中告知文件路径(参考 `` 中的同名样例)

**默认输出**：Markdown 工资表 + 异常清单,直接在对话中展示;用户要求 Excel 时再生成文件。
