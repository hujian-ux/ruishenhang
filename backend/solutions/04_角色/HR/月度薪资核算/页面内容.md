现状与痛点

发薪日前后，薪酬专员要把三个 Excel 逐人手工对齐，每个月都要重来一遍，还容易算错。

每月固定重复，一天起步

发薪日前后，薪酬专员要把薪资档案、考勤汇总、绩效结果三个 Excel 逐人手工对齐：一个人对一条，12 人就是半天，全公司几百人就是一两天的纯重复劳动，而且每个月都要来一遍。

高频
Excel 公式套公式，错一个全盘错

应发里叠着基本、岗位、绩效系数、补贴、缺勤扣款，再叠社保、公积金、个税，一个单元格公式错了，整列全错，错到员工工资卡上才知道。

高风险
个税累计预扣最容易出错

个税是 7 级超额累进，还要累计预扣，手工算经常"看着差不多"，一个档位选错，差出来几百块，员工投诉直接找 HR。

高风险
异常静默，没人主动报

缺勤超过 3 天的、绩效 D 的、加班超 36 小时红线的，散在三个表里没人自动汇总，等员工来问才发现。

易遗漏

这月为什么比上月少 300？"——补扣/调整口头一说就过去了，没有一张表说得清楚。

WorkBuddy 的解决和价值

三表一键导入，5分钟生成完整工资表，异常自动标注，变动自动说清楚。

传统做法

薪酬专员每月打开 3 个 Excel → 手工逐人套公式 → 个税手工算 → 异常靠人肉盯 → 发薪前加班到深夜，1-2 天，错一个全盘重算。

WorkBuddy 做法

三表一键导入 → AI 5 分钟生成完整工资表（应发构成/社保公积金/个税试算/实发）+ 异常自动标注（缺勤/绩效D/加班红线）+ 变动说明 → 复核后直接发薪。

三个核心价值
01规则写死，每月同一把尺子

应发构成、社保比例、个税税率表全部固化在 Skill 里，这个月和下个月、这个人跟那个人，口径完全一致，不会"这次忘了算加班"。

02个税累计预扣自动算

7 级税率表 + 速算扣除数内置，应纳税所得额自动计算，不会再出现"档位选错差几百块"。

03异常主动标注，变动说得清

缺勤>3 天、绩效 D、加班超 36h 红线、加班费未核算，全部自动标出；工资变动自动生成说明，员工问起来一张表解释。

方案定位

不是替薪酬专员做决定，而是把"手工套公式+人肉盯异常"变成"规则固化+自动扫描"，把 1-2 天的核算工作压缩到 5 分钟。

解决方案的工作流程

从三表导入到完整工资表，共5步。

01三表导入

薪资档案、考勤汇总、绩效结果按人员姓名对齐合并。

02应发计算

基本+岗位+绩效基数×系数+补贴-缺勤扣款，逐人算出应发工资。

03社保公积金

按基数×比例计算社保（个人10.5%）与公积金（7%）。

04个税试算

7级超额累进+速算扣除数，自动算出应纳税所得额与个税。

05异常标注

缺勤过多、绩效D、加班超红线、加班费未核算全部自动扫描标注。

TRAINING PROMPT · 复制即用
帮我做本月薪资核算，三表已上传（薪资档案 / 考勤汇总 / 绩效结果）。

请帮我计算，要求：
1. 按人员对齐三表，逐人计算应发工资（基本+岗位+绩效基数×系数+补贴-缺勤扣款）
2. 绩效系数：A=1.3 / B=1.1 / C=0.9 / D=0.7；日薪=（基本+岗位）/21.75
3. 社保(个人)=基数×10.5%（养老8%+医疗2%+失业0.5%）；公积金=基数×7%
4. 个税累计预扣：应纳税所得额=应发-社保-公积金-5000，7级超额累进+速算扣除
5. 输出：工资明细表 + 个税试算表 + 异常标注（缺勤>3天/绩效D/加班>36h/加班费未核算/应发>5万）

注意：数据缺失标"需补充"；应发为负标"异常人工复核"；金额保留2位小数。
