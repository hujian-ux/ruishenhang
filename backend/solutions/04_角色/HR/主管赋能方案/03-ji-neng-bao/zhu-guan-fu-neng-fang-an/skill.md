# Skill · 业务主管赋能

## 一句话定位

**输入主管的求助描述（面谈/激励/冲突/低绩效/离职挽留），输出 策略 + 话术 + 步骤 + 风险提示 的标准化赋能方案。**

不是"替主管做决定"，是把主管反复求助的<b>高频场景变成口径统一、可沉淀、可复用的标准答案</b>——让 HRBP 从"问一次答一次"变成"查一下就给"。

---

## 触发条件

当用户表达以下意图时召唤本 Skill：
- "这个面谈我该怎么谈？" / "员工要离职怎么挽留"
- "班组里吵架了怎么处理" / "低绩效员工怎么谈"
- "帮我给主管出个话术"
- 关键词：**主管赋能、面谈话术、员工关系、冲突调解、绩效面谈、离职挽留、激励**

---

## 输入契约

| 字段 | 必填 | 说明 |
|---|---|---|
| scenario | ✅ | 求助场景描述（主管原话，口语化即可），推荐上传《主管赋能方案·原始数据.docx》 |
| subject | 推荐 | 涉及对象（员工名/岗位/工龄/背景） |
| goal | 推荐 | 主管期望目标（挽留 / 化解 / 改进 / 汰换） |
| sensitive | 可选 | 敏感点（已说错的话 / 仲裁风险 / 合规红线） |
| context | 可选 | 组织背景（团队规模 / 业务压力 / 过往类似案例） |

---

## 执行步骤（内部流程）

1. **场景识别**：把求助归到 5 类之一——员工面谈 / 激励 / 冲突调解 / 低绩效管理 / 离职挽留
2. **补全信息**：确认 对象 / 背景 / 目标 / 敏感点，信息缺失时主动追问（最多 3 个问题）
3. **策略生成**：给出 处理目标 + 核心思路 + 优先级（先做什么后做什么），不替主管拍板最终决定
4. **话术输出**：逐句给出可直接使用的话术（开场 / 过程 / 收尾），口语化、贴合场景
5. **操作步骤**：从谈话前准备到谈话后留痕的完整步骤清单
6. **风险提示**：标注 禁区话术（不能说）/ 合规红线（流程不能跳）/ 留痕要求（书面化）

**特殊规则**：
- 涉及离职/违纪/仲裁风险 → 风险提示必须前置、加粗，不得遗漏
- 主管已说错话（如"走了别后悔"）→ 先教"补救话术"，再给完整方案
- 信息严重不足（不知道对象/目标）→ 先追问再输出，不硬编
- 涉及法定保护人群（孕期/工伤/医疗期）→ 强制标注，建议咨询法务

## 输出契约

```json
{
  "scenario": "① 老员工离职挽留（王建国·设备维修·12年）",
  "category": "离职挽留",
  "strategy": {"goal": "摸清真实诉求再谈方案", "priority": ["先倾听→再探因→后给方案"]},
  "scripts": [
    {"phase": "开场", "text": "您在厂里十几年了，我不瞒您，您这手艺真没几个人会。您说干不动，具体是哪块让您最累？"}
  ],
  "steps": ["谈话前:准备近 3 年绩效/考勤", "谈话中:倾听+记录", "谈话后:书面记录+后续跟进"],
  "risks": ["⚠️ 不要说'走了随时回来'", "⚠️ 不要当场承诺加薪幅度", "✅ 面谈内容书面留痕"]
}
```

## 输出格式说明（Excel 交付）

**对话内默认输出**：Markdown 策略 + 话术 + 步骤 + 风险，直接在对话中展示。

**交付 Excel**：当用户需要 .xlsx 文件（对应 demo 中的参考输出）时，用 Python openpyxl 生成：
- 文件名：`主管赋能方案·交付物.xlsx`
- Sheet「赋能方案」：场景/类型/策略要点/话术（开场+过程+收尾）/操作步骤/风险提示（3 个场景逐行，与页面案例一致：①挽留 ②冲突 ③低绩效）
- Sheet「话术卡片」：场景/阶段/话术原文/使用时机（可单独打印给主管）
- Sheet「风险清单」：场景/禁区话术/合规红线/留痕要求（规避仲裁）
- 生成方式：调用 `openpyxl` 创建工作簿 → 写入表头与数据行 → 保存到输出目录 → 在回复中告知文件路径（参考 `` 中的同名样例）

**输入格式**：主管求助描述 Word（.docx）/ 直接粘贴文字，无需转换。参考分发包 `主管赋能方案·原始数据.docx`。

## 依赖工具（底层 MCP / 能力）

- `read_file` / 附件解析（求助记录 Word → 文本）
- `classify_scenario`（5 类场景识别）
- `gen_strategy`（策略 + 优先级生成）
- `gen_script`（逐句话术生成）
- `scan_risks`（合规/仲裁风险扫描）
- 后置：低绩效类可接 `人员汰换评估` Skill（H2.3），冲突/违纪类可接 `用工合规排查` Skill（H2.6）

## 适用场景清单

| 岗位 | 场景 | 复用点 |
|---|---|---|
| **HRBP** | 主管高频求助赋能 | 主用（本包场景） |
| **HRBP** | 新人 HRBP 培养 | 场景库即培训教材 |
| **管理者** | 一线主管自助查话术 | 口径统一 + 风险兜底 |
| **员工关系** | 离职/违纪敏感面谈 | 风险前置 + 留痕要求 |

**至少 4 个场景可复用同一 Skill**——主管赋能是把 HRBP 从"重复答疑"里解放出来的杠杆型场景。

---

## 一句话结论

**业务主管赋能 = HRBP 的"标准答案库"**。主管每次求助,5 分钟拿到策略+话术+步骤+风险,口径统一、风险前置、可沉淀复用——HRBP 从"问一次答一次"变成"建库一次,查用百次"。
