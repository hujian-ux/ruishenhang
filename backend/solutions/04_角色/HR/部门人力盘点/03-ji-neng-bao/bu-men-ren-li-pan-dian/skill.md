# Skill · 部门人力盘点

## 一句话定位

**输入组织架构表 + 编制(HC) + 在岗表 + 流动记录，输出"编制 vs 现状 vs 缺口"三色报告 + 人力健康度 + 招聘/培养建议。**

不是"数人头"，是回答老板最关心的问题：**人够不够、缺在哪、先补谁**。

---

## 触发条件

当用户表达以下意图时召唤本 Skill：
- "做一次部门人力盘点" / "看看人够不够"
- "这个季度人力缺口多少？" / "哪些岗位要优先补人"
- "帮我做编制 vs 在岗对比"
- 关键词：**人力盘点、编制、HC、缺口、超编、在岗、定编**

---

## 输入契约

| 字段 | 必填 | 说明 |
|---|---|---|
| org_structure | ✅ | 组织架构表（部门 / 一级组 / 岗位序列） |
| headcount | ✅ | 编制表（HC，可带岗位序列维度） |
| on_board | ✅ | 在岗人员表（人数 / 试用期 / 离职在途标记） |
| turnover | 推荐 | 近季度离职 / 转岗 / 招聘在途记录 |
| context | 可选 | 情境（季度盘点 / 新产线规划 / 年度预算） |

---

## 执行步骤（内部流程）

1. **对齐结构**：按"部门 → 一级组 → 岗位序列"把编制与在岗统一到同一维度
2. **算差异**：每单位 缺口 = 编制 − 在岗（含在途离职需叠加为"实际缺口"）
3. **三色标注**（关键岗缺失优先，与页面案例口径一致）：
   - 🔴 **高危**：存在关键岗缺失（停线风险岗 / 项目依赖岗 / 稀缺技能岗）→ 无论缺口率，直接高危（示例：制造部 8.3% 因设备维修技师缺失 → 🔴；研发部 11.1% 因硬件/嵌入双缺 → 🔴）
   - 🟡 **关注**：无关键岗缺失，但缺口率 ≥6% 或缺口 ≥2 人，或非关键岗空缺暂无在途解决方案（示例：质量部 11.1% IQC 转岗在途 → 🟡）
   - 🟢 **正常**：无关键岗缺失，且缺口 ≤1 人 / 缺口率 <6%，或空缺已有在途解决方案（示例：销售部 5.6% 大客户经理猎头推进中 → 🟢）
4. **识别关键岗**：设备维修 / 核心研发等"一个萝卜一个坑"岗位单独标注
5. **归因**：结合流动记录（离职原因 / 招聘在途状态）说明缺口成因
6. **输出建议**：优先补人顺序 + 招聘 or 内部培养 or 转岗调配 + 配套动作（如离职风险岗先解决留存）

---

## 输出契约

最终输出为 Excel 文件 `部门人力盘点·交付物.xlsx`，三个 Sheet（与页面案例数据一致：制造部 72/66、研发部 18/16、质量部 9/8、销售部 18/17，合计 117/107/10）：

**Sheet1「编制vs现状」**（核心输出，一行一条部门）：

| 列 | 内容 | 示例 |
|---|---|---|
| 部门 | 组织单位名 | 制造部 |
| 编制数 | 标准编制数 | 72 |
| 在岗数 | 当前实际在岗人数 | 66 |
| 缺口数 | 编制 − 在岗 | 6 |
| 缺编率 | 缺口 / 编制 | 8.3% |
| 关键空缺岗位 | P0/P1 级标注 | 设备维修技师×1(停线风险) |
| 风险等级 | 🔴🟡🟢 三色 | 🔴（关键岗缺失） |

**Sheet2「人力健康度」**（补充维度，一条一个维度）：

| 列 | 内容 | 示例 |
|---|---|---|
| 维度 | 评估维度名称 | 人员充足率 |
| 当前值 | 实际指标值 | 91.5% |
| 目标值 | 健康基准 | ≥95% |
| 状态 | 🟢🟡🔴 | ⚠️ 接近 |
| 建议 | 改进动作 | 优先补齐 P0 关键岗 |

**Sheet3「补人优先级」**（对应 demo ④ 补人优先级排序表）：

| 列 | 内容 | 示例 |
|---|---|---|
| 优先级 | P0/P1/P2 | P0 |
| 岗位 | 空缺岗位 | 设备维修技师 |
| 所属部门 | 部门 | 制造部 |
| 缺口原因 | 成因 | 老员工退休 + 夜班流失 |
| 建议渠道 | 招聘/培养/调配 | 内部培养(2)+社招(1) |
| 预计周期 | 时间 | 4-6 周 |
| 预算影响 | 薪资范围 | ¥18-25K/月×1 |

## 输出格式说明（Excel 交付）

**对话内默认输出**：Markdown 表格/结构化结果，直接在对话中展示。

**交付 Excel**：当用户需要 .xlsx 文件（对应 demo 中的参考输出）时，用 Python openpyxl 生成：
- 文件名：`部门人力盘点·交付物.xlsx`
- Sheet「编制vs现状」：部门/编制数/在岗数/缺口数/缺编率/关键空缺岗位/风险等级（4 部门逐行 + 合计，与页面案例一致：制造部 72/66/6/8.3%🔴、研发部 18/16/2/11.1%🔴、质量部 9/8/1/11.1%🟡、销售部 18/17/1/5.6%🟢）
- Sheet「人力健康度」：维度/当前值/目标值/状态/建议（人员充足率/关键岗位覆盖率/停线风险/离职率/编制合理性）
- Sheet「补人优先级」：优先级/岗位/所属部门/缺口原因/建议渠道/预计周期/预算影响（P0 3 项 + P1 3 项 + P2 1 项）
- 生成方式：调用 `openpyxl` 创建工作簿 → 写入表头与数据行 → 保存到输出目录 → 在回复中告知文件路径（可参考 `` 下的同名样例文件）

**输入格式**：HRIS 导出的 **Excel（.xlsx）为主**——编制表 / 在岗花名册 / 异动记录通常是 3 个 Sheet 或 3 个文件（参考分发包 `部门人力盘点·原始数据.xlsx`）；也用 read_file 直接读取，无需转换。CSV 同理。

## 依赖工具（底层 MCP / 能力）

- `read_file` / 表格解析（组织架构 / 编制 / 在岗）
- `aggregate_headcount`（按组织维度聚合）
- `calc_gap`（编制 vs 在岗差异计算，含在途离职叠加）
- `flag_critical_role`（关键技能岗识别）
- 后置：可调用 `组织诊断` Skill 深入分析离职原因

## 适用场景清单

| 岗位 | 场景 | 复用点 |
|---|---|---|
| **HRBP** | 部门人力盘点 | 主用（本包场景一） |
| **HRBP** | 新产线 / 新项目人力规划 | 输入未来编制，输出招聘需求清单 |
| **招聘 TA** | 年度招聘计划 | 盘点的缺口 = 下年招聘目标来源 |
| **管理层** | 人力成本与编制会 | 只汇报三色缺口 + 优先补人顺序 |
| **培训发展** | 内部培养计划 | 缺口岗先看能否内部培养再外招 |

**至少 5 个场景可复用同一 Skill**。

---

## 一句话结论

**部门人力盘点 = HRBP 的"组织健康体检"**。把"感觉人不够"变成"缺在哪、缺几个、先补谁、补进来留不留得住"的可量化结论——同一个 Skill 换个组织表，就能服务不同部门、不同周期的盘点需求。
