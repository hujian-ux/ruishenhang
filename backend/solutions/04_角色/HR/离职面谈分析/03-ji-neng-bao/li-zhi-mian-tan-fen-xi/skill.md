# 离职面谈分析 Skill

## 适用场景
季度/月度离职面谈完成后,将散乱的访谈纪要按六大离职原因（薪酬福利/职业发展/管理风格/工作强度/家庭个人/企业文化）自动归类,叠加绩效与核心岗位标签做可挽留性评估,输出流失预警清单与对策建议,替代人工逐条读纪要、拍脑袋归因。

## 输入契约

| 字段 | 必填 | 说明 |
|---|---|---|
| 访谈记录 | ✅ | 员工姓名/部门/岗位/司龄/绩效等级/是否核心岗位/面谈摘录（原话要点） |
| 人员信息 | ✅ | 员工ID/姓名/部门/岗位/入职日期/离职日期/司龄/绩效/核心岗位/薪酬档位 |
| 归类规则 | ✅ | 六大离职原因 + 关键词清单（见 Sheet3，可扩展） |

**输入格式**：Excel(.xlsx 多 Sheet)直接读取;也可粘贴表格文本。

## 计算规则(写死,不可自行变更)

**1. 关键词归类（最长优先去重计数）**：
```
对每条面谈摘录,按六类关键词逐一匹配,命中即计数。
去重规则：关键词按长度降序扫描,命中后从摘录中移除该词,避免"晋升通道"与"晋升"重复计数。
主因 = 命中数最多的类别;次因 = 第二多(仅一类命中时次因填"—")
```

**2. 置信度**：主因命中词数 ≥3 → 高 / =2 → 中 / =1 → 低

**3. 可挽留性**：
```
低   : 主因 ∈ {家庭个人, 企业文化} 或 绩效等级 = C
高   : 核心岗位=是 且 绩效 ∈ {A,B} 且 主因 ∈ {薪酬福利, 管理风格, 职业发展}
中   : 其余情况
```

**4. 流失预警等级**：可挽留性 高 → 🔴 红（重点挽留）/ 中 → 🟡 黄（关注）/ 低 → 🟢 绿（接受离职）

## 执行步骤(内部流程)

1. **数据对齐**：以员工姓名为 key 合并访谈记录/人员信息,缺失标"需补充"
2. **关键词归类**：逐条按六类关键词计数 → 主因/次因/置信度
3. **可挽留评估**：叠加绩效等级 + 核心岗位标签 → 可挽留性
4. **原因分布统计**：六大类人数/占比,按部门交叉
5. **流失预警**：按预警等级排序输出建议动作与期限(红 1 周内 / 黄 2 周内 / 绿 常规流程)

**特殊规则**：
- 摘录无任何关键词命中 → 主因标"未归类",提示人工复核
- 主因/次因相同类别 → 仅记主因,次因"—"
- 司龄缺失 → 按 0 计并标注"需补充"

## 输出契约

最终输出为 Excel 文件 `离职面谈分析·交付物.xlsx`,三个 Sheet(与页面案例数据一致:8 人离职,薪酬福利 25% + 职业发展 25% + 其余各 12.5%,预警 🔴×3 / 🟡×2 / 🟢×3):

**Sheet1「面谈台账」**：员工姓名/部门/岗位/司龄/绩效等级/是否核心岗位/主因/次因/置信度/可挽留性/预警等级

**Sheet2「原因分布」**：离职原因大类/人数/占比/典型表述/对策建议(六类全列)

**Sheet3「流失预警」**：预警等级/员工姓名/部门/岗位/司龄/主因/建议动作/期限(红黄绿分组排序)

**交付 Excel**：当用户需要 .xlsx 文件时,用 Python openpyxl 生成:
- 文件名：`离职面谈分析·交付物.xlsx`
- 表头深蓝底白字、预警列红/黄/绿三色填充(🔴红行/🟡黄行/🟢绿行)
- 生成方式：`openpyxl` 创建工作簿 → 写入表头与数据行 → 保存到输出目录 → 在回复中告知文件路径(参考 `` 中的同名样例)

**默认输出**：Markdown 台账 + 原因分布 + 流失预警,直接在对话中展示;用户要求 Excel 时再生成文件。
