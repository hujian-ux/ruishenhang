现状与痛点

面谈纪要散乱在各自文件夹，HR 靠人肉读原话、凭经验判断，真实原因往往藏在场面话背后。

纪要散乱，靠人肉归类

一季度的离职面谈纪要躺在各自文件夹里，HR 逐条读原话、凭经验判断谁为什么走，8个人读完一整天，口径还不统一。

耗时
场面话陷阱，真实原因被隐藏

员工离职面谈大多说"个人原因""想换环境"，真实诉求（薪酬倒挂、领导不合）藏在话术里，不拆关键词根本看不到。

识别难
核心人才流失滞后发现

等离职流程走到HR手上才知道，没有把"绩效等级×核心岗位×离职原因"叠加评估，高价值人才走了才追悔。

高风险
个案当系统，误判组织问题

一个人说加班多就全员搞加班管控，一个人说领导不行就全员搞管理培训，没有把个案和系统性问题分开。

决策失真

张总说硬件部要加个人……"不，这次是离职面谈："个人原因，想换个环境。"——这就是HR拿到的场面话，真实原因藏在后面。

WorkBuddy 的解决和价值

把散乱的面谈纪要转成结构化归因，主动识别核心人才流失信号。

传统做法

逐条读纪要 → 凭经验归因 → 只对提离职的人做挽留 → 无统计无对策 · 一整天起步，口径不一，核心人才流失滞后。

WorkBuddy 做法

访谈纪要+人员信息一键导入 → AI 10分钟完成六类归因（主因/次因/置信度）→ 可挽留性评估 → 原因分布统计+红黄绿流失预警（建议动作+期限）。

三个核心价值
01拆话术看真相，主因客观可解释

六类关键词最长优先去重计数，员工说"个人原因"但原话里全是"调薪没结果、薪资倒挂"，照样归到薪酬福利；置信度高/中/低让归因有可信度。

02核心人才流失提前拦截

可挽留性=核心岗位×绩效≥B×主因属组织可控（薪酬/管理/发展），红黄绿分级直接给出动作和期限，挽留资源只投给值得留的人。

03数据沉淀闭环，问题定位到组织

六大类占比统计让"个案"和"系统问题"分得清：3条红警2条在研发且同因薪酬，不是个案，是薪酬体系问题，对策直指倒挂校核。

方案定位

不是替HR做挽留决定，而是把"逐条猜"变成"关键词归因+可挽留评估+分级动作清单"，把一整天的归因工作压缩到10分钟。

解决方案的工作流程

从散乱纪要到流失预警，共5步。

01数据导入

导入访谈记录与人员信息（司龄/绩效/核心岗位）。

02关键词归类

六类离职原因关键词匹配，最长优先去重计数，输出主因/次因/置信度。

03可挽留评估

核心岗位×绩效等级×主因属性组合判定可挽留性高/中/低。

04原因分布

统计六大类占比，区分个案与系统性组织问题，给出对策建议。

05流失预警

输出红黄绿预警清单，附建议动作和处理期限。

提示词
TRAINING PROMPT · 复制即用
帮我做本季度离职面谈分析，数据已上传（访谈记录 / 人员信息 / 归类规则）。

请帮我处理，要求：
1. 按六类离职原因关键词归类：薪酬福利 / 职业发展 / 管理风格 / 工作强度 / 家庭个人 / 企业文化
2. 关键词按最长优先去重计数（"晋升通道"优先于"晋升"），主因=命中最多，次因=第二，仅一类命中时次因填"—"
3. 置信度：主因命中≥3词=高 / 2词=中 / 1词=低
4. 可挽留性：家庭个人/企业文化 或 绩效C → 低；核心岗位+绩效AB+主因∈{薪酬福利,管理风格,职业发展} → 高；其余 → 中
5. 流失预警：高→🔴红 / 中→🟡黄 / 低→🟢绿
6. 输出：面谈台账 + 原因分布（占比+对策建议）+ 流失预警（建议动作+期限）

注意：无关键词命中标"未归类"提示人工复核；缺失字段标"需补充"。
