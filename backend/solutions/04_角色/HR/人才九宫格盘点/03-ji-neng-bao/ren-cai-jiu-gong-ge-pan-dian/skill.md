# 人才九宫格盘点 Skill

## 适用场景
年度/半年度人才盘点,基于绩效等级(横轴)与潜力评分(纵轴),将每位员工定位到九宫格,输出六类人才策略与关键岗位继任计划建议。

## 输入契约

| 字段 | 必填 | 说明 |
|---|---|---|
| 绩效评估表 | ✅ | 人员/部门/岗位/绩效等级(A/B/C/D) |
| 潜力评估表 | ✅ | 人员/潜力评分(1-5)/潜力说明 |
| 盘点规则 | 可选 | 绩效与潜力映射(默认见下文) |

**输入格式**：Excel(.xlsx 多 Sheet)直接读取;也可粘贴表格文本。

## 计算规则(写死,不可自行变更)

**1. 双维映射**：
```
绩效轴:A/B/C/D → 高/中/中低/低
潜力轴:评分 4-5 高 / 3 中 / 1-2 低
```

**2. 九宫格定位(六类)**：
| 绩效\潜力 | 高 | 中 | 低 |
|---|---|---|---|
| 高 | ⭐ 明星员工 | 🟢 骨干力量 | 🟢 骨干(保留观察) |
| 中 | 💎 潜力股 | 🟡 稳定贡献 | 🟠 边缘观察 |
| 中低 | 💎 潜力股 | 🟡 稳定贡献 | 🟠 边缘观察 |
| 低 | 🟠 待发展 | 🟠 待发展 | 🔴 风险 |

**3. 人才策略**：
- ⭐ 明星:差异化激励 + 关键岗继任者
- 💎 潜力股:培训资源重点倾斜(衔接 H4.1/H4.2)
- 🟢 骨干:保留 + 中层后备
- 🟡 稳定贡献:维持现状
- 🟠 边缘/待发展:改进窗口 + 半年复评
- 🔴 风险:衔接 H2.3 汰换评估

**4. 继任计划**：明星→部门负责人继任者;潜力股→关键岗后备;骨干→中层后备

## 执行步骤(内部流程)

1. **双维对齐**：以人员为 key 合并绩效/潜力表,缺失标"需补充"
2. **九宫格定位**：逐人按映射落格
3. **策略匹配**：按定位给人才策略与动作
4. **继任计划**：从明星/潜力股中筛选关键岗继任者
5. **输出**：九宫格分布 + 六类策略表 + 继任计划

**特殊规则**：
- 潜力评分缺失 → 按 3(中)处理并标注
- 绩效等级缺失 → 不参与定位,标"需补充"
- 同一人可同时是"潜力股"与某岗位后备

## 输出契约

最终输出为 Excel 文件 `人才九宫格盘点·交付物.xlsx`,三个 Sheet(与页面案例数据一致:12 人,⭐3/💎2/🟢1/🟡2/🟠3/🔴1):

**Sheet1「九宫格定位」**：人员/部门/岗位/绩效等级/潜力评分/潜力等级/九宫格定位/人才策略

**Sheet2「分布统计」**：人才类别/人数/人员名单/策略要点

**Sheet3「继任计划」**：关键岗位/继任者/当前定位/准备度/培养建议

**交付 Excel**：当用户需要 .xlsx 文件时,用 Python openpyxl 生成:
- 文件名：`人才九宫格盘点·交付物.xlsx`
- 表头深蓝底白字、⭐行绿色、🔴行红色、🟠行黄色
- 生成方式：`openpyxl` 创建工作簿 → 写入表头与数据行 → 保存到输出目录 → 在回复中告知文件路径(参考 `` 中的同名样例)

**默认输出**：Markdown 九宫格分布 + 策略表 + 继任计划,直接在对话中展示;用户要求 Excel 时再生成文件。
