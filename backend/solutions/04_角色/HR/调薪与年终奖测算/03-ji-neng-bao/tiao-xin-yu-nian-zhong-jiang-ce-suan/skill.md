# 调薪 / 年终奖测算 Skill

## 适用场景
年度调薪窗口,基于绩效等级(来自 H3.2 校准)、当前薪资、岗位市场对标(P50/P75)与调薪预算,测算每人调薪幅度与调薪后月薪,并测算年终奖、输出预算敏感性分析。

## 输入契约

| 字段 | 必填 | 说明 |
|---|---|---|
| 薪资档案表 | ✅ | 人员/部门/岗位/当前月薪/绩效等级 |
| 绩效结果表 | ✅ | 人员/绩效等级/综合分(来自 H3.2 校准) |
| 市场对标表 | ✅ | 岗位/市场 P50/P75(薪酬报告数据) |
| 预算与规则 | ✅ | 调薪预算比例/绩效基准涨幅/市场修正规则/年终奖系数/敏感性档位 |

**输入格式**：Excel(.xlsx 多 Sheet)直接读取;也可粘贴表格文本。

## 计算规则(写死,不可自行变更)

**1. 绩效基准涨幅**：A=12% / B=8% / C=4% / D=0%

**2. 市场倒挂修正**(±1 个百分点)：
```
当前月薪 < 岗位P50×0.9 → +1pp(低于市场,防流失)
当前月薪 > 岗位P75×1.1 → −1pp(高于市场,控冗余)
其余 → 0
基准涨幅 = 绩效基准 + 市场修正
```

**3. 预算约束(全局压缩)**：
```
预算池     = 总月薪 × 预算比例(默认 5%)
基准总成本 = Σ(每人 当前月薪 × 基准涨幅)
压缩因子   = 预算池 ÷ 基准总成本
若 基准总成本 ≤ 预算池 → 压缩因子 = 1(不压缩)
实际调薪额 = 每人基准调薪额 × 压缩因子
实际涨幅   = 实际调薪额 ÷ 当前月薪
```

**4. 年终奖**：`年终奖 = 当前月薪 × 系数`(A=2.5 / B=2.0 / C=1.5 / D=1.0 个月)

**5. 敏感性分析**：按预算档位(默认 3%/4%/5%/6%)重算压缩因子,输出每档的平均涨幅、A 档实际涨幅、C 档实际涨幅、覆盖人数

## 执行步骤(内部流程)

1. **数据对齐**：以人员姓名为 key 合并薪资档案/绩效结果/市场对标三表,缺失标"需补充"
2. **基准涨幅**：逐人计算绩效基准 + 市场修正
3. **预算压缩**：计算基准总成本 → 压缩因子 → 逐人实际调薪额
4. **年终奖测算**：逐人按系数计算,汇总年终奖池
5. **敏感性分析**：按预算档位重算,输出四档对比
6. **校验**：实际调薪总额 ≤ 预算池(舍入差 ≤1 元),超了检查压缩因子

**特殊规则**：
- 绩效 D 涨幅为 0(不调薪),但仍需保留在方案中标注"不调薪"
- 任一数据缺失 → 标"需补充",不默认估值
- 市场对标缺失的岗位 → 该岗位市场修正为 0,标注"无对标数据"
- 压缩后涨幅保留 2 位小数

## 输出契约

最终输出为 Excel 文件 `调薪与年终奖测算·交付物.xlsx`,三个 Sheet(与页面案例数据一致:12 人,预算 ¥14,300,年终奖池 ¥572,500):

**Sheet1「调薪方案」**：人员/部门/岗位/当前月薪/绩效等级/基准涨幅/市场修正/调薪幅度/调薪额/调薪后月薪 —— 含合计行(总成本 ¥14,301)

**Sheet2「年终奖测算」**：人员/基础月薪/绩效等级/系数(月)/年终奖 —— 含合计行(¥572,500)

**Sheet3「敏感性分析」**：预算档位/调薪池/平均涨幅/A档实际涨幅/C档实际涨幅/覆盖人数(3%/4%/5%/6% 四行)

**交付 Excel**：当用户需要 .xlsx 文件时,用 Python openpyxl 生成:
- 文件名：`调薪与年终奖测算·交付物.xlsx`
- 表头深蓝底白字、金额右对齐、A 档行绿色、D 档行红色、市场修正列标 🟡
- 生成方式：`openpyxl` 创建工作簿 → 写入表头与数据行 → 保存到输出目录 → 在回复中告知文件路径(参考 `` 中的同名样例)

**默认输出**：Markdown 调薪方案 + 年终奖表 + 敏感性四档对比,直接在对话中展示;用户要求 Excel 时再生成文件。
