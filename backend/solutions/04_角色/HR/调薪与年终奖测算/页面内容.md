现状与痛点

每年调薪窗口，HR 逐人手工试算总成本，超预算就拍脑袋砍，说不清凭什么砍他不砍他。

年度调薪手工试算，Excel 累到吐

每年调薪窗口，HR 要按绩效等级给每人定涨幅，再一个个调 Excel 看总成本有没有超预算，调一个人动一列，改 12 人就是半天，全公司几百人改一周。

耗时
超预算就"拍脑袋压"

试算完发现总涨幅超了预算，没有科学方法，要么整体砍一刀，要么挑几个人砍，凭什么砍他不砍他，说不清楚。

高风险
市场对标缺失，薪酬倒挂看不见

只按绩效定涨幅，不看这个人薪资跟市场比是高了还是低了：低薪高绩效的人不加就流失，高薪低绩效的人加了就是养冗余。

易遗漏
年终奖系数拍脑袋

谁拿几个月年终奖，凭感觉定，没有跟绩效等级挂钩的统一系数，员工觉得不公平。

高风险

预算从 5% 降到 4% 会怎样？"——领导一问，HR 只能现场编，没有一个四档对比表直接摆出来。

WorkBuddy 的解决和价值

四份数据一键导入，10分钟完成基准涨幅、市场修正、预算压缩、年终奖测算与敏感性分析。

传统做法

HR 逐人定涨幅 → 手动 Excel 试算总成本 → 超预算拍脑袋压 → 薪酬倒挂看不见 → 敏感性靠猜，一周起步，方案说不清。

WorkBuddy 做法

绩效+薪资+市场+预算一键导入 → AI 10分钟完成：绩效基准涨幅 → 市场倒挂修正 → 预算约束全局压缩 → 年终奖测算 → 3%/4%/5%/6% 四档敏感性分析 → 一套方案直接上会。

三个核心价值
01预算约束自动压缩，方案可解释

基准涨幅算出后，超出预算自动按全局压缩因子等比例收窄，每个人"为什么从 12% 变 7.75%"有明确计算过程，不靠拍脑袋。

02市场对标修正，薪酬倒挂自动识别

低于市场 P50 的绩效人才自动 +1pp 提薪，高于市场 P75 的自动 −1pp 压缩，钱花在刀刃上。

03敏感性四档对比，领导一问就有答案

预算 3%/4%/5%/6% 四档的平均涨幅、A 档实际涨幅、C 档实际涨幅一次算清，预算调整的代价一目了然。

方案定位

不是替 HR 拍板，而是把"逐人试算+拍脑袋压缩"变成"规则化涨幅+可解释压缩因子"，把一周的测算工作压缩到 10 分钟。

解决方案的工作流程

从四表导入到完整调薪方案，共5步。

01数据导入

薪资档案、绩效结果、市场对标、预算与规则四表按人员对齐。

02基准涨幅

按绩效等级给出基准涨幅：A=12%/B=8%/C=4%/D=0%。

03市场修正

低于市场P50×0.9自动+1pp，高于P75×1.1自动−1pp。

04预算压缩

超出预算池的部分，按全局压缩因子等比例收窄至预算内。

05敏感性分析

按3%/4%/5%/6%四档预算重算，输出平均涨幅与A/C档对比。

TRAINING PROMPT · 复制即用
帮我做年度调薪和年终奖测算，四份数据已上传（薪资档案 / 绩效结果 / 市场对标 / 预算规则）。

请帮我测算，要求：
1. 绩效基准涨幅：A=12% / B=8% / C=4% / D=0%
2. 市场修正：当前月薪 < 岗位P50×0.9 → +1pp；> P75×1.1 → −1pp
3. 预算约束：基准总成本超预算 → 全局压缩因子等比例收窄，每人实调额=基准×压缩因子
4. 年终奖 = 当前月薪 × 系数（A2.5/B2.0/C1.5/D1.0 个月）
5. 敏感性分析：预算 3% / 4% / 5% / 6% 四档对比（平均涨幅/A档实调/C档实调）
6. 输出：调薪方案 + 年终奖表 + 敏感性四档对比

注意：绩效 D 涨幅 0 但要保留标注；数据缺失标"需补充"；压缩后总额不得超过预算。
