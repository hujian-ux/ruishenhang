# 主提示词 · 课件 / SOP 生成

## 操作步骤
1. 上传  下的《课件与SOP生成·原始数据.docx》（含培训目标/课程大纲/SOP/考核要求）
2. 复制下方提示词发送

## 提示词
```
帮我生成培训课件和考核题库，培训资料已上传（Excel 数据分析实战）。

请帮我处理，要求：
1. 课件四段式：培训目标(3条可量化) + 课程模块(4个×3知识点) + 实操案例(1个) + 考核要求
2. SOP 分解：从模块操作要点抽取 5-8 步可执行流程，每步带校验要点
3. 考核题库：10 题（5 单选 + 5 判断），每题含答案与知识点标签（对应培训目标）
4. 输出：课件 docx + 考核题 xlsx

注意：资料缺目标时按知识点反向生成；知识点不足 12 个按实际数量；SOP 步骤必须动词开头可执行。
```

## 输出格式
- 默认：Markdown 课件结构预览 + 题库预览，直接在对话展示
- 需要文件：追加一句「生成课件和考核题文件」，得到 `Excel数据分析实战_课件.docx` + `课件与SOP生成·交付物.xlsx`（与 outputs/ 样例一致）
