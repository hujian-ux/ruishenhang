# Skill · 招聘漏斗分析

## 一句话定位

**输入分渠道 / 分岗位的招聘转化数据，输出漏斗诊断（各环节转化率、瓶颈环节）+ 渠道 ROI 卡片 + 优化建议。**

不是"画一张漏斗图"，是回答招聘负责人最关心的三个问题：**钱花在哪最值、人卡在哪一环、下周怎么调**。

---

## 触发条件

当用户表达以下意图时召唤本 Skill：
- "这个月的招聘漏斗帮我分析下"
- "哪个渠道性价比最高？" / "钱花在哪最划算？"
- "投了这么多简历为什么没入职的？"
- 关键词：**漏斗、转化率、渠道、ROI、招聘数据、复盘、招不到人**

---

## 输入契约

| 字段 | 必填 | 说明 |
|---|---|---|
| funnel_data | ✅ | 转化数据（渠道 × 岗位：投递 / 初筛 / 面试 / Offer / 入职），CSV/表格 |
| cost_data | 可选 | 渠道成本（用于 ROI 计算；内推成本为 0） |
| hc | 可选 | 各岗位 HC（用于评估是否达标） |
| period | 可选 | 分析周期（默认当月） |
| context | 可选 | 情境（月度复盘 / 渠道调优 / 加预算申请） |

---

## 执行步骤（内部流程）

1. **清洗数据**：按渠道 × 岗位聚合，补齐转化环节
2. **算转化率**：每环节转化率 = 下一环节数 / 本环节数（初筛通过率 / 面试率 / Offer 率 / 入职率）
3. **算渠道 ROI**：单位入职成本 = 渠道成本 / 入职数；渠道贡献度 = 入职数 / 总入职数
4. **瓶颈定位**：对比各环节转化率与行业基准（初筛→面试 30%+ / 面试→Offer 25%+ / Offer→入职 80%+），标出异常环节
5. **三色诊断**：
   - 🟢 健康：转化率 ≥ 基准
   - 🟡 关注：低于基准 30% 以内
   - 🔴 瓶颈：低于基准 30% 以上
6. **渠道分级**：高性价比（入职多 + 成本低）优先加投；低效渠道（成本高 + 入职少）建议缩减
7. **输出**：漏斗诊断 + 渠道 ROI 卡片 + 优化建议（含预算再分配方案）

## 输出格式说明（Excel 交付）

**对话内默认输出**：Markdown 表格/结构化结果，直接在对话中展示。

**交付 Excel**：当用户需要 .xlsx 文件（对应 demo 中的参考输出）时，用 Python openpyxl 生成：
- 文件名：`招聘漏斗分析·交付物.xlsx`
- Sheet「招聘漏斗原始数据」：渠道/岗位/投递数/初筛通过/进入面试/Offer数/入职数/成本(元)/HC
- Sheet「漏斗汇总」：环节/数量/环节转化率/行业基准/三色状态，含瓶颈标注（Offer→入职、结构工程师Offer全流失）
- Sheet「渠道对比」：渠道/各环节数量/转化率/渠道成本/单位入职成本/渠道建议
- 生成方式：调用 `openpyxl` 创建工作簿 → 写入表头与数据行 → 保存到输出目录 → 在回复中告知文件路径（参考 `` 中的同名样例）

**输入格式**：CSV / Excel 转化数据直接用 read_file + 表格解析读取，无需转换。

## 依赖工具（底层 MCP / 能力）

- `read_file` / 表格解析（CSV/Excel）
- `aggregate_funnel`（数据清洗与聚合）
- `calc_conversion`（转化率计算）
- `calc_channel_roi`（渠道 ROI 计算）
- 后置：可输出 HTML 漏斗图 / 周会汇报摘要

## 适用场景清单

| 岗位 | 场景 | 复用点 |
|---|---|---|
| **招聘 TA** | 招聘漏斗周/月复盘 | 主用（本包场景三） |
| **招聘 TA** | 渠道预算分配 | 每季度用 ROI 卡片决定预算流向 |
| **HRBP** | 部门招聘健康度汇报 | 给业务负责人看部门漏斗 + 缺口 |
| **管理层** | 招聘成本管控 | 只看渠道 ROI 汇总 + 优化建议 |
| **薪酬绩效** | 招聘成本分摊（可选） | 复用成本数据结构 |

**至少 4-5 个场景可复用同一 Skill**。

## 一句话结论

**招聘漏斗分析 = 招聘的"经营驾驶舱"**。它把"感觉招不到人"变成"卡在哪个环节、哪个渠道最划算"的可量化结论——有了这个 Skill，招聘负责人可以像看销售漏斗一样看招聘，每次复盘都从"凭感觉"变成"看数据、做决策"。
