# ES.1 入离职手续办理 Skill

## 适用场景
HR服务台处理批量入职/离职事务，按流程规则自动生成：手续清单（办理环节+负责方+所需材料+时限）、材料闭环（逐条 ✅/⚠️/❌ 核验）、离职交接清单、风险项标注。

## 输入契约
| 字段 | 必填 | 说明 |
|---|---|---|
| 案例登记 | ✅ | 员工/部门/岗位/类型(入职/离职)/特殊情况/日期 |
| 材料清单 | ✅ | 材料类别/材料项/是否必须/适用类型/合规提示 |
| 流程规则 | ✅ | 办理环节/负责方/标准时限/校验要点 |

## 计算规则(写死)
- 入职必查四件套：身份证+学历学位+体检报告+离职证明(缺任何一项标红)
- 竞业限制/背调为特殊审查项(触发多一个流程环节)
- 销售岗离职必查：客户名单+应收账款状态
- 研发岗离职必查：代码归档+设备归还+权限回收

## 执行步骤
1. 读入案例登记+材料清单+流程规则三份数据
2. 为每个案例匹配流程步骤(按员工类型：标准/竞业/应届/销售/研发)
3. 逐材料核验状态(✅已完成/⚠️进行中/❌缺失)
4. 标注风险项(竞业审查→入职挂起、应收逾期→离职财务暂缓)
5. 输出 3 Sheet Excel

## 输出契约
默认 Markdown 输出。用户要求 Excel 时 openpyxl 生成：
- Sheet1「手续清单」：案例编号/员工/类型/办理环节/负责方/材料/时限/状态
- Sheet2「材料闭环」：案例编号/材料项/是否必须/当前状态/缺失提示
- Sheet3「离职交接清单」：编号/员工/交接类型/交接事项/接收人/确认状态/备注（竞业审查、应收逾期等风险项以状态标注形式高亮）

## 输出 Excel
`ES.1 入离职手续办理.xlsx` (3 Sheet: 手续清单+材料闭环+离职交接清单)
