# 面试评估汇总 · 案例素材包

> 本素材包基于真实业务场景整理，可直接作为落地模板套用。

## 目录
- `03_技能包/面试评估汇总/SKILL.md` — Skill 定义
- `主提示词.md` — 主提示词与说明
- 原始数据源（见下节）
- 预期交付物（见下节）

## 原始数据源
- `面试评估汇总·原始数据.xlsx`（结构化反馈）：各面试官按表格填写的评分和评语，作为主要评估输入
- `面试面评记录.docx`（自由文本反馈）：面试官的详细文字评价，供观点抽取和矛盾检测使用
- `README.md`（场景说明）：介绍本场景的使用方式和验证对照

## 预期交付物
- `面试评估汇总·交付物.xlsx`：4位候选人的完整五维度评分表，含三色决策、矛盾清单和下一轮建议。

## 验证对照
用「主提示词」处理原始数据，应得到：4位高级硬件工程师候选人面试反馈，5分钟内输出五维度评分+三色决策+矛盾清单+下一轮建议。
