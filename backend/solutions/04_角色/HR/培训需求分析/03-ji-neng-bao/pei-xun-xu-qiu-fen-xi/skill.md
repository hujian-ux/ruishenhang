# 培训需求分析 Skill

## 适用场景
年度/季度培训计划制定前,将各部门培训需求调研问卷与绩效短板数据交叉分析,按"人数权重+紧急度+绩效短板匹配"三因子评分,输出需求优先级(P0/P1/P2)与课程规划建议。

## 输入契约

| 字段 | 必填 | 说明 |
|---|---|---|
| 调研问卷汇总表 | ✅ | 部门/培训主题/需求人数/部门人数/紧急度/培训类型/需求描述 |
| 绩效短板表 | ✅ | 部门/低分维度/短板人数/说明 |
| 分析规则 | 可选 | 评分权重(默认见下文) |

**输入格式**：Excel(.xlsx 多 Sheet)直接读取;也可粘贴表格文本。

## 计算规则(写死,不可自行变更)

**1. 三因子评分**：
```
需求评分 = 人数权重×40% + 紧急度×30% + 绩效短板匹配×30%
人数权重 = 需求人数 ÷ 部门人数 × 100(保留 1 位小数)
紧急度   = 高=100 / 中=70 / 低=40
短板匹配 = 匹配=100 / 部分=70 / 不匹配=40
```

**2. 优先级**：评分 ≥80 → P0 / 60-79 → P1 / <60 → P2

**3. 课程规划**：每个 P0/P1 需求给出课程建议(课程名称/时长/形式/对象/预算档位),P2 建议低成本覆盖(线上课)或并入下季度

## 执行步骤(内部流程)

1. **数据对齐**：以部门为 key 合并调研问卷/绩效短板,缺失标"需补充"
2. **评分计算**：逐条需求按三因子加权评分
3. **优先级排序**：按评分降序落 P0/P1/P2,输出优先级清单
4. **课程规划**：P0/P1 配课程建议,P2 配低成本方案
5. **汇总**：优先级分布统计、P0 培训预算占比建议

**特殊规则**：
- 部门人数缺失 → 人数权重按 50 计,标注"需补充"
- 紧急度缺失 → 按"中"处理
- 同分需求 → 需求人数多者优先

## 输出契约

最终输出为 Excel 文件 `培训需求分析·交付物.xlsx`,三个 Sheet(与页面案例数据一致:6 条需求,P0×3/P1×1/P2×2):

**Sheet1「需求清单」**：部门/培训主题/需求人数/部门人数/人数权重/紧急度/短板匹配/需求评分/优先级

**Sheet2「优先级排序」**：优先级/部门/培训主题/需求评分/排序说明(按评分降序分组 P0/P1/P2)

**Sheet3「课程规划」**：优先级/课程名称/培训类型/时长/形式/对象/预算建议

**交付 Excel**：当用户需要 .xlsx 文件时,用 Python openpyxl 生成:
- 文件名：`培训需求分析·交付物.xlsx`
- 表头深蓝底白字、金额右对齐、P0 行红色、P1 行黄色、P2 行绿色
- 生成方式：`openpyxl` 创建工作簿 → 写入表头与数据行 → 保存到输出目录 → 在回复中告知文件路径(参考 `` 中的同名样例)

**默认输出**：Markdown 需求清单 + 优先级 + 课程规划,直接在对话中展示;用户要求 Excel 时再生成文件。
