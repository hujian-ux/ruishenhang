# 主提示词 · 培训需求分析

## 操作步骤
1. 上传  下的《培训需求分析·原始数据.xlsx》（Sheet1 调研问卷汇总 / Sheet2 绩效短板 / Sheet3 分析规则）
2. 复制下方提示词发送

## 提示词
```
帮我做年度培训需求分析，两份数据已上传（调研问卷汇总 / 绩效短板）。

请帮我处理，要求：
1. 需求评分 = 人数权重×40% + 紧急度×30% + 绩效短板匹配×30%
2. 人数权重 = 需求人数 ÷ 部门人数 × 100；紧急度 高100/中70/低40；短板匹配 匹配100/部分70/不匹配40
3. 优先级：评分≥80 P0 / 60-79 P1 / <60 P2
4. 课程规划：P0/P1 配课程建议（名称/时长/形式/对象/预算），P2 低成本覆盖
5. 输出：需求清单 + 优先级排序 + 课程规划

注意：部门人数缺失按 50 计并标注；紧急度缺失按"中"；同分需求人数多者优先。
```

## 输出格式
- 默认：Markdown 需求清单 + 优先级 + 课程规划，直接在对话展示
- 需要 Excel：追加一句「把结果输出成 Excel 文件」，得到 `培训需求分析·交付物.xlsx`（Sheet1 需求清单 + Sheet2 优先级排序 + Sheet3 课程规划）
