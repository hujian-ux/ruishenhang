# ES.2 员工证明开具 Skill

## 适用场景
HR服务台处理员工各类证明开具需求(在职证明/收入证明/离职证明/中英文双语证明)，自动匹配模板、填入员工数据、输出完整可打印正文，附带合规校验(收入金额校验/身份匹配/中英文一致性等)。

## 输入契约
| 字段 | 必填 | 说明 |
|---|---|---|
| 证明申请 | ✅ | 员工/部门/证明类型/申请事由/审批人 |
| 证明模板 | ✅ | 证明类型/模板骨架(含占位符)/合规要点 |
| 员工数据 | ✅ | 脱敏员工档案(身份证/岗位/入职/收入/社保) |

## 计算规则(写死)
- 四类模板：在职证明/收入证明/离职证明/工龄证明
- 合规自检：金额校验(是否低于岗位P50)、日期合法性、身份匹配
- 外包员工开"服务证明"而非"在职证明"
- 收入证明建议添加"仅限XX用途"水印+有效期

## 输出契约
默认 Markdown 输出。用户要求 Excel 时 openpyxl 生成：
- Sheet1「证明台账」：申请编号/员工/类型/用途/审批状态/合规自检
- Sheet2「证明正文」：完整可打印证明文本(含合规标注)
- Sheet3「模板匹配」：4 类模板+字段映射+合规规则

## 输出 Excel
`ES.2 员工证明开具.xlsx` (3 Sheet: 台账+明细+追踪)
