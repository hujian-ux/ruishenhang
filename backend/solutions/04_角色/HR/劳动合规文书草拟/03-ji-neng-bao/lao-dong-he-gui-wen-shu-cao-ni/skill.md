# 合规文书草拟 Skill

## 适用场景
HR 处理劳动合规事件时,根据案例类型自动匹配文书模板（警告通知书/解除劳动合同通知书/协商解除协议/调岗通知书/试用期解除通知）,补全必填要件、引用对应法条、输出完整可复制文书正文,并生成合规自检清单逐项核验,避免遗漏要件或法条引用错误。

## 输入契约

| 字段 | 必填 | 说明 |
|---|---|---|
| 案例登记 | ✅ | 案例编号/员工姓名/部门/岗位/文书类型/事实简述/引用法条 |
| 模板规则 | ✅ | 文书类型/模板骨架（关键段落+占位符）/必填要件/法条引用 |
| 合规自检清单 | ✅ | 文书类型/要件编号/检查项/法律依据 |

**输入格式**：Excel(.xlsx 多 Sheet)直接读取。

## 计算规则(写死,不可自行变更)

**1. 文书模板匹配**：按案例登记中的"文书类型"自动匹配模板骨架,占位符([日期]/[违纪行为]/[制度条款]等)替换为案例事实

**2. 五种文书类型及法条**：
- 警告通知书 → 《劳动合同法》第39条（轻微违纪）
- 解除劳动合同通知书 → 第39条（严重违纪,需精确到款项）
- 协商解除协议 → 第36条+第46条+第47条（协商一致+补偿标准）
- 调岗通知书 → 第40条第2项（不胜任工作）
- 试用期解除通知 → 第39条第1项（不符合录用条件）

**3. 合规自检**：每份文书按对应类型逐项核验,标注"✅ 通过"/"⚠️ 需确认"/"❌ 缺失"

## 执行步骤

1. **案例匹配**：读取案例登记,按文书类型匹配模板骨架
2. **占位符替换**：将模板中的占位符替换为案例事实（日期/行为/制度条款）
3. **法条校验**：确认引用法条与文书类型匹配,款项精确
4. **合规自检**：逐项检查要件完整性
5. **输出**：台账 + 文书正文 + 自检清单

## 输出契约

最终输出为 Excel 文件 `劳动合规文书草拟·交付物.xlsx`,三个 Sheet(与页面案例数据一致:5 个案例,5 种文书类型,10 项自检通过):

**Sheet1「文书台账」**：案例编号/员工姓名/部门/岗位/文书类型/事实简述/引用法条

**Sheet2「文书正文」**：案例编号/员工姓名/文书类型/完整文书正文(可直接复制使用)

**Sheet3「合规自检」**：案例编号/文书类型/要件检查项/状态/法律依据

**交付 Excel**：当用户需要 .xlsx 文件时,用 Python openpyxl 生成,表头深蓝底白字,状态列 ✅/⚠️/❌。
