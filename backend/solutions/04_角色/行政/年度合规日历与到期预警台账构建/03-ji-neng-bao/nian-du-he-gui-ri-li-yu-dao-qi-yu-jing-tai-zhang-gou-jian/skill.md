# 年度合规日历与到期预警台账构建 · SKILL

## 适用场景
证照合规与制度治理 · 真实业务触发 工商年报快截止了、消防年检通知来了、或者某个资质突然发现已经过期 —— 这时候才想起来去翻那份不知道谁在维护的证照台账

## 输入
- 年度合规日历与到期预警台账构建·原始数据.xlsx

## 工作流程（5 步）
1. 信息抽取：从扫描件里把日期抽出来 证照名称、编号、发证机关、有效期起止；识别不清的标注需人工核对原件
2. 台账重建：五区结构一次建好 基础信息 / 时效管控 / 年检维护 / 实物保管 / 责任关联
3. 倒推应启动日：不是到期日 应启动办理日 = 截止日 − 准备周期（换证按 3 个月，租约优先续租按合同约定通知期）
4. 罚则标价：每项写清逾期后果 逾期列入经营异常名录 / 责令停用 / 罚款区间 —— 附法条出处
5. 缺口识别：哪些证照根本没找到 对照典型证照清单，列出应该有但没找到的，标为待客户确认

## 产出
- 年度合规日历与到期预警台账构建·交付物.xlsx

## 不承诺
本场景基于真实业务叙事整理；最终结论与提交由人确认。
