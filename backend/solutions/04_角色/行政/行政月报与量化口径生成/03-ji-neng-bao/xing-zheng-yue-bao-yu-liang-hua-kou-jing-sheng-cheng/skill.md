# 行政月报与量化口径生成 · SKILL

## 适用场景
会议与文书管理 · 真实业务触发 每月 28 日前要交行政月报

## 输入
- 行政月报与量化口径生成·原始数据.xlsx

## 工作流程（5 步）
1. 数据归集：把散的数据拼起来 按五表结构归集；来源不同的同类数据标注口径差异
2. 量化成型：变成可写进月报的句式 「事务类型 + 数量 + 效率/质量说明」，每项标注数据来源
3. 指标计算：算出 KPI 口径 工单及时率、资产差异率、采购按时到货率等 —— 分母是什么写清
4. 缺口标注：哪些算不出来 没有记录的指标明确写「本月无记录，建议自 X 月起建立」
5. 根因分析：问题栏不写「加强沟通」 每个问题写清发生时间、涉及环节、根本原因、临时措施、长期方案、责任人、完成时间

## 产出
- 行政月报与量化口径生成·交付物.xlsx

## 不承诺
本场景基于真实业务叙事整理；最终结论与提交由人确认。
