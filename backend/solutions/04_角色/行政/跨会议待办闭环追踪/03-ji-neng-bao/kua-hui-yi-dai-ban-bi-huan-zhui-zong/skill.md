# 跨会议待办闭环追踪 · SKILL

## 适用场景
会议与文书管理 · 真实业务触发 季度经营会前，老板问「上季度定的那几件事做了没有」

## 输入
- 跨会议待办闭环追踪·原始数据.xlsx

## 工作流程（5 步）
1. 纪要归一：先把格式不同的纪要拉平 抽出会议名称、日期、参会人、议题、决议；微信文本按语义切分
2. 事项抽取：抽出所有承诺型表述 「XX 部门在 X 月前完成 YY」；模糊表述（如「尽快推进」）单独标注为不可追踪
3. 跨会串联：同一件事在几次会里的轨迹 按事项语义聚类，串出「第一次提出 → 后续几次是否提及 → 最后一次状态」
4. 静默检测：找出说过就再没提过的 首次出现后连续 N 次会议未被提及的，标为「静默事项」—— 这是最有价值的发现
5. 逾期计算：算清逾期多久 按约定时限与当前日期算逾期天数；超期三天以上按模板要求标注逾期

## 产出
- 跨会议待办闭环追踪·交付物.xlsx

## 不承诺
本场景基于真实业务叙事整理；最终结论与提交由人确认。
