# 盘点差异归因与盘点报告生成 · SKILL

## 适用场景
资产与空间管理 · 真实业务触发 盘点表交上来了，账实对不上

## 输入
- 盘点差异归因与盘点报告生成·原始数据.xlsx

## 工作流程（5 步）
1. 差异计算：先算清差多少 逐条算账面 vs 实盘、数量差与金额差；分盘盈/盘亏/账实不符三类
2. 跨源回查：一条差异查四处 对每条差异分别去采购、报废、调拨、离职记录里找对应线索
3. 原因归类：归到可追的类目 入库流程不规范 / 调拨未备案 / 报废销账滞后 / 实物已灭失 / 台账错误 五类，各算占比
4. 佐证标注：每条写清依据哪张单 「调拨单 DB-2026-017 显示该资产已于 3 月调至市场部，台账未更新」
5. 无线索项单列：敢说这个查不到 四处都查不到线索的单独列出，明确写「需现场复盘或责任部门书面说明」

## 产出
- 盘点差异归因与盘点报告生成·交付物.xlsx

## 不承诺
本场景基于真实业务叙事整理；最终结论与提交由人确认。
