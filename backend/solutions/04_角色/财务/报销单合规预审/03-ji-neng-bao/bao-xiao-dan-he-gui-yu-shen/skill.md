# Skill · 报销单合规预审

> 本文件为「财务岗位场景库」课程配套 Skill 定义。

## 适用场景
每周员工提交报销，财务按「十看法」逐张审：发票真伪、抬头税号、品名一致、大小写、连号。审出问题要退单，但退单理由缺少书面依据易引发摩擦。

## 输入
- 费用报销单（OA 或 Excel）
- 发票照片/PDF（抬头/税号/品名/金额）
- 公司报销制度与费用标准

## 工作流程
1. **要素校验**：报销单、发票、附件张数是否对得上；缺附件先标出。
2. **十看法逐项审**：抬头税号、品名与实际、大小写、连号、发票真伪初筛。
3. **标准比对**：差旅/招待标准、报销上限、预算科目是否超。
4. **退单理由生成**：每条退单理由写成「依据公司报销制度第X条」的口径。
5. **留证**：预审结论 + 待复核项 + 退单话术一次生成。

## 输出
- 报销合规预审清单（逐张结论 + 退单理由挂条款）
- 待复核发票清单（需走官方查验平台的发票）
- 退单话术模板（附制度出处）

## 边界（不承诺什么）
- 不做发票真伪最终判定（以官方查验平台为准）。
- 不做报销最终批准（签字权在人）。
