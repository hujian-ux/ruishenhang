# 凭证全量稽核扫描 · SKILL

## 适用场景
制度要求凭证要有稽核人签章、实际从没抽过 · 不是抽 5%，是全部扫一遍。

## 输入
- 记账凭证数据.xlsx
- 科目余额表.xlsx

## 工作流程（5 步）
1. 全量扫描：逐张凭证借贷是否相等，不平的揪出来。
2. 科目异常：科目挂错、方向反了、余额方向异常。
3. 附件摘要：附件张数缺失、摘要乱填或为空。
4. 断号检测：凭证号是否连续，断号的揪出来。
5. 稽核清单：异常项分类，附处理建议。

## 产出
- 凭证稽核清单.xlsx
- 借贷不平明细.xlsx

## 不承诺
本场景基于真实业务叙事整理；最终结论与提交由人确认。
