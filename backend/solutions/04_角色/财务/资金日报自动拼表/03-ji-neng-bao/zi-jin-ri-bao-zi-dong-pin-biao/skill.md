# Skill · 资金日报自动拼表

> 本文件为「财务岗位场景库」课程配套 Skill 定义。

## 适用场景
老板每天早上要看「今天账上还有多少钱、昨天收了哪些大额、这周要付哪些」。出纳从三家网银+微信截图+审批单现凑，口径软件默认不出。

## 输入
- 三家银行对账单/余额截图
- 微信收款截图、收据照片
- 待付款审批单

## 工作流程
1. **账户余额汇总**：工行/招行/建行余额各自多少、合计多少。
2. **在途收款归集**：微信收款截图逐条识别入表。
3. **待付款汇总**：本周待付金额按付款日排序。
4. **拼表**：可用资金 = 余额 + 在途收款 − 待付款，一张表讲清。

## 输出
- 资金日报（可用资金口径 + 收款 Top + 待付清单）
- 在途收款明细（逐条 + 待确认项标注）

## 边界（不承诺什么）
- 不做资金预测（预测不准会误导决策）。
- 不做自动付款（对外付款必须人审批）。
