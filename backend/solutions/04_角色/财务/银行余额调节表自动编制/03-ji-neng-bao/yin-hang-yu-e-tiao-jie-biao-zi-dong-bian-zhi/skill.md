# Skill · 银行余额调节表自动编制

> 本文件为「财务岗位场景库」课程配套 Skill 定义，企业落地时按自身制度与账户信息替换即可。

## 适用场景
资金与收付岗每月底结账前，需把多家银行对账单与企业日记账逐笔勾对、编制银行余额调节表。规则确定但动作脏、耗时，常被月底 deadline 挤掉。

## 输入
- 银行对账单（多家银行格式各异，摘要模糊）
- 现金/银行日记账
- 历史未达账项台账

## 工作流程
1. **要素校验**：对账单与日记账的日期区间、币种、账户是否对得上；缺期先标出。
2. **逐笔勾对**：日期+金额+对方三要素匹配，容忍 ±1 元；摘要模糊做二次语义对齐。
3. **未达账项分类**：企业已收银行未收 / 企业已付银行未付 / 银行已收企业未收 / 银行已付企业未付 四类清单。
4. **历史未达追踪**：上月遗留未达项逐条核对，超 3 个月未清标红。
5. **左右闭合**：调节后余额必须相等，否则回退重扫。

## 输出
- 银行余额调节表（左右两栏 + 编制人/审核人签章栏）
- 未达账项清单（每条带出处与超期天数）
- 历史未达清账跟踪表

## 边界（不承诺什么）
- 不做「自动生成凭证」：差异只出清单和建议，不直接写进日记账。
- 不做资金挪用定性判断：只列出可疑未达账项，最终结论由人下。
