# 应收账款账龄分析与逾期预警 · SKILL

## 适用场景
账上躺着 300 万应收、老板以为都是钱 · 逾期超 1 年核销概率高达 80%。

## 输入
- 应收账款明细账.xlsx
- 销售开票记录.xlsx
- 银行回款流水.xlsx

## 工作流程（5 步）
1. 口径对齐：销售订单量口径 vs 财务收入确认口径，差异逐笔标注。
2. 回款核销：回款流水逐笔匹配到发票，算出未收金额。
3. 账龄分级：A正常 / B 1-30天 / C 31-90天 / D 91天以上 四档。
4. 坏账计提：按账龄计提比例测算坏账准备。
5. 逾期清单：逾期客户按金额×天数排序，生成催收清单。

## 产出
- 应收账款账龄分析表.xlsx
- 逾期催收清单.xlsx
- 回款核销差异清单.xlsx

## 不承诺
本场景基于真实业务叙事整理；最终结论与提交由人确认。
