# 广告—库存—利润联动预警 · Skill 定义

## 1. 能力定位
把"广告看 ROAS、供应链看库存、没人一起看"的盲区，变成"库存三态 × 补货时间线 × 三方案总账"的联动预警线，让放量决策先过库存这关。

## 2. 输入
- `FBA库存三态表.csv`：SKU / 可售 / 预留 / 在途 / 日均销量 / 覆盖天数 / 单价
- `工厂排产表.csv`：SKU / 系统发货日 / 工厂排产发货日 / 偏差 / 海运到仓 / 实际断货天数

## 3. 输出
- `库存利润联动预警.md`：断货 / 超储 / 亏损广告三类预警规则 + 处置 + 三方案总账

## 4. 工作流（5 步）
1. 库存三态拆分：可售/预留/在途分开，不混算
2. 覆盖天数：按近 30 天日均销量算还能卖几天
3. 补货时间线：生产+物流到仓日 vs 库存耗尽日，算断货窗口
4. 方案对比：空运/降档/硬断三案总账，人拍板
5. 预警输出：三类预警规则与处置

## 5. 关键规则
- 可售 ≠ 账面库存：必须扣预留、区分在途。
- 交期信系统更要信工厂排产表，偏差天数放大断货窗口（本例 7→11 天）。
- 放量决策前必做库存联动；库存将断时加预算 = 花钱买断货。
- 三方案总账对比后再拍板；发货日未与工厂书面确认前不做空运决定。
- 空运/运费审批、广告预算调整、工厂交期确认一律人工终审。
