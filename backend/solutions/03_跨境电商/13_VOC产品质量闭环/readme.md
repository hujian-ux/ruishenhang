## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入 `03_技能包/VOC产品质量闭环/`（或直接上传本场景 Skill 包 zip），并在「已安装」列表启用。
2. 上传 4 份素材：`差评明细.csv`、`FBA退货报告.csv`、`客服工单.csv`、`产品与Listing档案.md`。
3. 复制 `主提示词.md` 第一节的主提示词并发送。
4. 按「结果核对清单」逐项核对聚类算平、金额乘法、星标证据 ID。
5. 导出 CAPA 表，交质量月会签字；产品根因认定、Listing 修改确认、供应商索赔决定必须人工审批。

## 四、数字复算对照（与场景素材逐项对齐）

| 素材原文 | 本素材包中的可复算依据 | 复算结果 |
| --- | --- | --- |
| 差评 214 条 / 退货 163 单 / 工单 96 件 | 三个 CSV 的实际行数 | 214 / 163 / 96，合计 VOC 473 条 |
| 尺寸误解 61% / 噪音 19% / 漏水 11% / 其他 9%（算平） | 主题条数 288 / 90 / 52 / 43 | 60.9% / 19.0% / 11.0% / 9.1%，条数合计 = 473，占比合计 100.0% |
| 61% 的退货备注写 too small / not as expected | 尺寸类退货 99 单 ÷ 163 单 | 60.7%（≈61%），备注见 `customer_comment` |
| 仓库 Disposition 也标 Defective | `warehouse_disposition` 计数 | Defective 共 122 单（74.8%），其中**尺寸类 71 单**，`warehouse_note` 写「通电正常/功能测试通过/无渗漏」 |
| **尺寸类退货 99 单 × 18.4 USD = 1,821.6 USD/月** | 交付物首行 `退货单数 × 单均损失USD` | 99 × 18.4 = **1,821.60 USD**（四类合计 3,078.90 USD，尺寸类占 59.2%） |
| 拐点：尺寸类差评集中在 Listing v2.3 改图后两周 | v2.3 上线 2026-01-18，切分尺寸类差评 130 条 | 01-18~01-31 共 **66 条**，日均 4.71；其余 76 天 64 条，日均 0.84 → **约 5.6 倍** |
| 结论：尺寸图修改未上线前不做「已解决」结论；方案一先改描述文字（零成本） | 交付物 CAPA A1（改描述文字，2026-03-18）先于 A2（改图，2026-03-27）；合计行验收标准写明「尺寸图上线前不得判定已解决」 | 通过 |
| 双路径归因：为什么发生 + 为什么没被拦住，CAPA 到部门 | 交付物两列 `发生原因_为什么发生` / `流出原因_为什么没被拦住` + `责任岗位` 到岗位名 | 12 条 CAPA 全覆盖 |

**单均损失口径**：尺寸 18.4 / 噪音 19.6 / 漏水 21.3 / 其他 17.5 USD（含退货运费 + 二次包装 + 不可再售残值损失）。
`FBA退货报告.csv` 中每单 `unit_loss_usd` 有真实波动，但按主题求和后恰好等于 `单数 × 单均`，可逐主题复核。
