# 场景说明 · Amazon及多平台商品批量上架与发布（op-04）

> 跨境电商 · 平台运营与合规 · 角色簇
> 案例：海拓生活科技 · 美国站 HT-K09 / HT-L10 共 6 个变体 SKU 批量上架
> 数据：脱敏构造，逻辑可核验；高风险动作一律人工审批

## 场景一句话
ERP 批量刊登首轮回执报出 42 个字段错误，根子在旧 ERP 映射表把颜色变体建成独立 SKU，与新父子体规则冲突。WorkBuddy 主数据先校验、错误三类归因、分批发布（先发 3 无争议 + 重试 3 争议），全程留痕。
