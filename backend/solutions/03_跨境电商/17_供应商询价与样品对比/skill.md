# 供应商询价与样品对比 · Skill

## 适用时机
- 收到三家及以上供应商报价，需要选厂定点。
- 比价目前只比单价，落地成本没人算。
- 样品问题停留在微信/照片里，没进正式比价表。
- 供应商历史延期/退货记录没人翻，每次像第一次合作。
- 老板问「为什么选贵的这家」，答不上来、谈判没弹药。

## 输入（inputs）
1. 多源报价原始记录：供应商、单价（含税）、模具费、MOQ、交期、账期、良率。
2. 样品测试记录：跌落/密封/老化等测试报告（含不合格项与次数）。
3. 供应商历史绩效：过往延期天数、退货批次、质量事故。

## 工作流（workflow）
1. **归一化**：把单价、模具费（按 MOQ 摊销到每台）、运费、账期资金占用统一折算成同一口径。模具费摊销 = 模具费 ÷ 首单量。
2. **落地成本**：单价之外每一项都折算成钱，得「归一化落地成本 = 单价USD + 模具摊销 + 单位运费 + 账期资金成本」。
3. **交叉验证**：样品测试记录 + 历史绩效逐项交叉，样品不合格或历史延期/退货单独列否决项，与报价放同一张表。
4. **定点与谈判**：输出推荐（定点首选）+ 备选 + 双源备选，并生成谈判点清单（每项该压什么、压多少、依据是什么）。

## 输出（outputs）
- `供应商对比表.csv`：每家供应商的报价 / 起订量 / 交期 / 良率 / 样品结论 / 历史绩效 / 归一化落地成本 / 综合推荐。
- 谈判点清单（在提示词回复中给出）：单价、模具费、账期、MOQ 各自可压空间与依据。

## 关键规则
- **比价必须比落地成本，不比单价**：单价最低的中山若模具费高、运费高、账期长，落地可能最贵。
- **样品记录与报价同表**：微信里的跌落测试照片必须转成正式记录并参与评分；样品不合格即否决项。
- **历史绩效进当次决策**：延期、退货、色差等记录逐项调取，作为定点与谈判依据。
- **定点留证据**：推荐/备选/双源都要写依据；双源备选需算额外成本（模具费 + 小单运费溢价）。
- **人工边界**：样品质量现场判断、供应商定点与合同签署、双源策略最终决定一律人工。本 Skill 只出对比与建议，不构成定点授权。
- **不写效率百分比或效果承诺**。
