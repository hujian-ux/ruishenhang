
## 四、真实性等级与边界

- **T3**：采购比价方法论来自实务；**构造**：成本参数为脱敏构造且可复算。
- **升 T1 还缺**：客户真实报价单与样品记录。
- **人工边界**：样品质量现场判断、供应商定点与合同签署、双源策略最终决定一律人工。
