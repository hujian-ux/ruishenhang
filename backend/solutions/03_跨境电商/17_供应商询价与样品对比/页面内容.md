现状与痛点

三家报价截图发群里，按单价选一个——这是中小企业采购最贵的习惯。HT-K09 的单价中山最低，可没人把模具费、运费、账期、MOQ 和那份跌落测试记录放进同一张表。

比价只比单价，落地成本没人算

模具费、运费、账期、MOQ、返工率都不在报价单同一页上。中山单价低 7 块，但模具费 8,000、交期多 9 天，折算落地反而最贵。按单价选厂是隐性亏损。

高频真实
样品问题躺在微信里

样品缺陷记录在业务员微信的语音和照片里，正式比价表上永远「样品合格」。量产后同一缺陷变成批量事故，止损窗口早已关闭。

隐蔽风险
历史绩效从不进当次决策

这家上次延期 12 天、那家批次色差被退过——这些记录没人翻，每次定点都像第一次合作，踩过的坑反复踩。

组织失忆
定点理由说不清，谈判没弹药

老板问「为什么选贵的这家」，答「感觉靠谱」。没有逐项折算表，议价时也不知道该压哪一项、能压多少。

协同痛点

你们样品测试的记录，比价的时候会从微信里翻出来一起看吗？

WorkBuddy 的解决与价值

差别不在快，在于有人把散在多处的东西拼到了一起——报价、样品、绩效进同一张表，且每一项都可折算成钱。

传统做法

三家报价截图发群里，按单价选一个 → 样品「看着还行」就算通过 → 定点理由口头说，谈判凭感觉压价 → 出问题时才发现这家厂早有前科。单价最低的中山被选中，落地成本与样品风险全在后知后觉里。

WorkBuddy 做法

归一化：含税/模具/运费/账期/MOQ 全部折算成落地成本 → 样品测试记录与历史绩效交叉进评分 → 星标素材：中山厂两次跌落开裂记录改变定点 → 输出谈判点清单：每项该压什么、压多少、依据是什么。

三个核心价值
01把「单价」变成可复算的「落地成本」

落地成本 = 单价 + 模具摊销 + 运费 + 账期资金占用。中山单价低 7 块，但模具费 8,000、运费最高、账期最长，落地 14.6 美元反超顺德 13.8。谁便宜一眼见底。

02让样品与绩效从微信走进比价表

跌落测试记录、历史延期/退货逐项并入对比表，样品不合格即否决项。中山两次跌落开裂直接改变定点，不再等量产变事故。

03定点有证据，谈判有弹药

推荐/备选/双源都写依据；谈判点清单逐项列可压空间（账期、MOQ、运费）与依据。老板再问「为什么选贵的」，拿折算表说话。

方案定位

不是替你决定用哪家厂，而是把散在报价截图、微信语音、历史台账里的东西拼成一张每行可复算、每个否决都带证据的对比表。样品质量现场判断、供应商定点与合同签署、双源策略最终决定一律人工——本表不构成定点授权。

解决方案的工作流程

从三份素材到一张对比表 + 一份谈判清单，共 5 步，每步都有正式产出。

01归一化

三家口径统一：含税、模具费（按 MOQ 摊销）、运费、账期、MOQ 全部折算成同一单位 USD/台。

02落地成本

单价之外的每一项都折算成钱：落地成本 = 单价 + 模具摊销 + 运费 + 账期资金成本。

03交叉验证

样品测试记录 + 历史绩效逐项并入，样品不合格 / 历史延期退货单独列否决或风险项。

04定点与谈判

推荐（定点首选）+ 备选 + 双源备选，并生成谈判点清单：每项该压什么、压多少、依据是什么。

05留证据

定点结论写清依据；双源备选算额外成本；样品风险未闭环前标注待复测，决策全程留痕。

脱敏案例：海拓生活科技 · HT-K09 供应商定点

三家报价归一化后：顺德 13.8 / 宁波 14.2 / 中山 14.6 USD/台——单价最便宜的中山落地反而最贵，主因模具费 8,000、运费最高、账期最长。星标素材：中山厂样品两次 1.2m 跌落外壳开裂，判定不合格，直接改变定点。最终定点顺德，首单 2,000 台 × ¥68（与 PD-02 立项决议一致）；双源备选顺德 70% + 中山 30%，预付模具费 ¥8,000（≈1,103 USD）+ 小单运费溢价，合计约多花 1,400 USD 换供应韧性。结论：中山开裂原因（材料批次还是结构）未确认前不排除它，待 8D 复测。

提示词
TRAINING PROMPT · 复制即用
请基于我上传的三份素材，为「海拓生活科技 · HT-K09 智能保温杯」做供应商询价与样品对比，输出一张归一化落地成本对比表与一份谈判点清单。

【输入 1 · 三家报价原始记录】三家报价原始记录.csv
- 含供应商、区域、单价CNY、模具费CNY、MOQ、交期天、账期天、良率%、样品状态(业务反馈)
- 原始记录里样品状态只是群内口头反馈，不是正式测试结论

【输入 2 · 样品跌落测试记录】样品跌落测试记录.md（星标素材）
- 中山厂 HT-K09 样品两次 1.2m 跌落外壳开裂，判定不合格
- 开裂原因待定（材料批次 or 结构），需供应商 8D 报告

【输入 3 · 供应商历史绩效】供应商历史绩效.md
- 顺德厂近 3 批无延期无退货；宁波厂一批次色差被退 1 次；中山厂上次延期 12 天

【执行要求】
1. 归一化：把单价(÷7.25)、模具费(÷7.25÷MOQ 摊销到每台)、单位运费、账期资金成本统一折算成 USD/台。
2. 落地成本：归一化落地成本 = 单价USD + 模具摊销USD/台 + 单位运费USD + 账期资金成本USD（保留 1 位小数）。
3. 交叉验证：把样品跌落记录与历史绩效逐项并入对比表，样品不合格 / 历史延期退货单独标为否决或风险项。
4. 定点与谈判：给出定点首选 + 备选 + 双源备选（顺德 70% + 中山 30%），计算双源额外成本（中山模具费 ¥8,000≈1,103 USD + 小单运费溢价，合计约 1,400 USD）。
5. 谈判点清单：对定点首选列可压项（账期、MOQ、运费），每项写可压空间与依据。

【输出格式】CSV：供应商, 区域, 单价CNY, 单价USD, 模具费CNY, 模具摊销USD每台, MOQ, 交期天, 账期天, 良率%, 单位运费USD, 账期资金成本USD, 归一化落地成本USD, 样品结论, 历史绩效, 综合推荐

【硬性约束】
- 比价比「归一化落地成本」，不比单价；单价最低不等于落地最便宜。
- 样品不合格必须作为否决/风险项，与报价同表展示。
- 历史绩效必须进当次决策，逐项调取。
- 中山开裂原因未确认前不排除它，可作为双源备选待复测。
- 定点只出建议，不构成授权；现场判断与合同签署人工。
- 不写任何效率百分比或效果承诺。

【生成后自检，逐条回答】
1. 三家归一化落地成本是否 = 顺德 13.8 / 宁波 14.2 / 中山 14.6 USD/台？
2. 单价最低的中山是否落地最贵？原因是否写清（模具费 + 运费 + 账期）？
3. 中山样品是否标为不合格且改变定点？
4. 定点首选是否 = 顺德，首单是否 = 2,000 台 × ¥68（与 PD-02 一致）？
5. 双源备选（顺德 70% + 中山 30%）额外成本是否 ≈ 1,400 USD？
6. 是否无任何「可定点授权」字样？
自检全过再输出 CSV。
