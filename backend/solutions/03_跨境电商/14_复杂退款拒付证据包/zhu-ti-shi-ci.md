## 一、主提示词（复制即用）

```
请按「复杂退款、拒付证据包」技能，处理以下拒付案件，产出一份可直接提交的《拒付证据包.md》。

【案件基本信息】
- 争议编号 dp_1QmT9xHT0428；订单 HT-SP-10428；收款流水 ch_3QkR7uHT0428
- 平台：Shopify 独立站，收款通道 Stripe
- 争议金额 386.00 USD；争议手续费 15.00 USD（败诉不退）
- 原因码 13.1 · Merchandise/Services Not Received（商品未收到）
- 受理时间 2026-03-11 03:02 UTC；证据截止 2026-03-16 23:59 UTC（5 天）
- 编制启动 2026-03-12 09:00 UTC（剩余 4 天）；负责人 苏婷 · 客服售后与用户体验
- 本月成交 1,264 笔 / 拒付 11 笔（含本案）= 0.87%；1.00% 触发支付通道保证金上调

【输入 1 · 订单支付物流时间线.csv】21 行
字段：序号, 时间_UTC, 来源系统, 事件, 关键字段与取值, 证据编号, 证明力
覆盖：下单 → 付款（AVS=Y / CVC=M）→ 拣货 → 出库 → 干线 → 派送 → 签收(POD) → 客服往来 → 承运商回函 → 拒付通知

【输入 2 · 物流与POD记录.csv】13 行
字段：记录编号, 运单号, 节点时间_本地, 节点类型, 节点位置, 字段名, 字段取值, 可否作为拒付证据
星标字段：pod_photo_1 / pod_photo_2 / pod_gps(39.158341, -75.524372) / pod_signature_name(R. Alvarez)
        / house_number_legibility(门牌第 3 位被快递袋遮挡) / geo_deviation(与订单地址偏差 8 米)

【输入 3 · 客服沟通记录.csv】11 行
字段：记录编号, 时间_UTC, 方向, 渠道, 主题, 原文摘录, 抗辩用途
关键原文：客户 2026-03-07 "Nobody at home signed for it, maybe it was left at the door and taken."

【输入 4 · 拒付规则与时效.md】
含：原因码 ↔ 必交证据类型对照、5 天时限与倒排规则、拒付率阈值与后果、
   证据来源系统对照（哪份材料在哪个后台）、历史败诉复盘（DP-2025-1187 因漏附沟通记录败诉）

【输出要求 · 一份 MD，十节】
1. 案件摘要：金额 / 原因码 / 受理与截止时间 / 剩余时长 / 我方结论 / 拒付率背景
2. 时效 SLA：T0–T7 倒排到小时，提交节点必须留 12 小时缓冲，标注责任人与状态
3. 争议点 ↔ 证据链逐条映射：把对方主张拆成 C1…Cn（含预判的关联主张：非本人授权、发错地址、
   商家未提供救济），每条给「我方反驳要点 / 支撑证据编号 / 证据类型 / 证明力 / 缺口补强」
4. 证据清单：EV-01…EV-14，写明名称、来源系统、获取方式、对应主张；标出哪些在承运商后台
5. 排除性结论：地址错误 / 未出库 / 未提供救济逐一排除并附第三方依据；不可排除项如实写明
6. 抗辩陈述：英文提交正文（事实—证据编号—结论 三段式）+ 中文对照要点
7. 双策略与金额：A 直接提交 vs B 协商部分退款 120 USD 撤诉，各给确定金额与拒付率影响
8. 人工审批点：对外陈述措辞 / 退款协商决定 / 提交执行
9. 待补缺口与流程整改：G1…Gn，含责任岗位与截止
10. 复算索引：每个数字给计算式

【硬规则】
- 按指控逐条对应，任一主张证据为空不许提交；客服沟通记录必须全量附上，不得节选
- POD 影像 + GPS + 签收人是 13.1 类争议的必交项，「轨迹显示签收」一句话不算证据
- 时间统一 UTC；金额保留两位小数并给出计算式
- 抗辩陈述只写事实与证据编号，不含情绪化表达、不预判胜负、不承诺胜率百分比
- 弱项（门牌遮挡、签收人关系不明）必须写进「待补缺口」，不许粉饰
- 提交申诉 or 协商撤诉不由 AI 决定，标注为「需人工审批」

生成后自检：主张全覆盖了吗？沟通记录是全量吗？POD 与 GPS 引用了吗？
每个金额有计算式吗？提交是否留了 12 小时缓冲？
```

## 二、追问提示词（按需使用）

**追问 1 · 给主管的一页决策纸**
```
把双策略压缩成一页决策纸：两行金额（最坏值 vs 确定值）、两行拒付率（本月 vs 撤诉后）、
一行证据强度（最强项与最弱项）、一行建议签字时点。不要再复述案情。
```

**追问 2 · 承运商 POD 调取函**
```
起草一封给 MetroLast Mile 客服的 POD 补充调取函：说明 case ML-CLM-55831，
请求补充「签收人 R. Alvarez 的身份记录」与「门牌清晰版照片（若有第三张）」，
写明我方证据截止时间与所需回函格式。
```

**追问 3 · 拒付预防 SOP**
```
基于本案的 5 个缺口，输出一份拒付预防 SOP：客服话术模板要点、POD 自动归档方案、
拒付率预警阈值（0.85% 提醒 / 0.95% 管控）、以及每项的责任岗位与上线截止。
```
