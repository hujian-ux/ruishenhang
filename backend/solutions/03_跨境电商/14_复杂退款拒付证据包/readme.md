## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入 `03_技能包/复杂退款、拒付证据包/`（或直接上传本场景 Skill 包 zip），并在「已安装」列表启用。
2. 上传 4 份素材：`订单支付物流时间线.csv`、`物流与POD记录.csv`、`客服沟通记录.csv`、`拒付规则与时效.md`。
3. 复制 `主提示词.md` 第一节的主提示词并发送。
4. 按「结果核对清单」逐项核对时限、主张覆盖、POD 引用、金额与拒付率复算。
5. 抗辩陈述最终措辞、策略选择、提交执行三项必须人工审批后再操作通道后台。
