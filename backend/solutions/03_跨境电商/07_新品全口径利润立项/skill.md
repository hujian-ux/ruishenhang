# 新品全口径利润立项

## 一、这个 Skill 解决什么

中小卖家的立项表通常只有三行：售价、采购价、毛利率。看着都超 35%，于是全部通过。

漏掉的六项成本会在量产后的第一个月逐个现身：

| 漏项 | 什么时候现身 | 后果 |
| --- | --- | --- |
| 头程 | 发货后 | 体积重超标的品，头程吃掉 10% 售价 |
| 平台佣金 + FBA 配送费 | 第一笔结算 | 家居类合计常达售价的 28%–30% |
| 广告 | 上线第一周 | 新品期广告占比 18%，是所有参数里最敏感的一项 |
| 退货 | 第一个月末 | 采购 + 头程 + FBA 三项均不可回收 |
| 认证摊销 | 认证发票到账 | 6,800 EUR 按首单 1,000 台摊销 = 7.34/台，可以把利润摊成负数 |
| 现金占用 | 付款那天 | MOQ 5,000 锁掉 42,500 USD，正好撞上 Q4 付款高峰 |

**再加一项从来没进过立项表的：退出成本。** 卖不掉怎么办？清仓折价、移仓费、长期仓储费、销毁费。只看上行不测下行的立项，本质是用公司的钱买彩票。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 立项会前要出一份可复核的测算 | 主用场景 |
| 打样候选已定，要决定哪几个下单 | 承接 PD-01 的「打样」队列 |
| 老板问「毛利 35% 为什么还亏」 | 用全口径模型逐项拆给他看 |
| 需要否决一个品且必须给出理由 | 输出门槛编号 + 实测值 + 重评条件 |

**不适用**：候选品筛选（→ PD-01）；供应商比价与落地成本归一化（→ PD-03）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `打样候选清单.csv` | 必需 | 候选编号、售价、采购价、体积重、FBA配送费、退货率、认证项与费用、MOQ、首单量、基准月销、归一化落地成本、PD-01 结论与移交事项 |

| 3 | `Q4现金流预测.csv` | 必需 | 月度老品补货货款、新品首单落地付款、广告预算、固定支出、流出合计、预计回款 |

## 四、输出（outputs）

唯一交付物：`全口径利润立项表.xlsx`，固定 9 个工作表：

| # | 工作表 | 内容 |
| --- | --- | --- |
| 1 | 立项汇总 | 每候选一行：三情景贡献率、现金占用两口径、回本周期、决议与门槛编号 |
| 2 | 全口径成本模型 | 8 项成本逐列展开，并列出「传统口径毛利」做对照 |
| 3 | 三情景测算 | 5 候选 × 3 情景 = 15 行，含广告/退货/售价/销量假设与回本周期 |
| 4 | 敏感性分析 | 5 候选 × 5 扰动项，按对贡献率的负向影响排序 |
| 5 | 首单方案与现金占用 | 首单量对照（如 2,000 台 vs 3,000 台）、采购货款与落地现金两口径 |
| 6 | Q4现金流预测 | 月度流出/回款/净现金，标出付款高峰月 |
| 7 | 退出成本测算 | 滞销 30% 下的清仓折价 + 移仓 + 仓储 + 销毁 |
| 8 | 立项决议 | 通过 / 否决 / 附条件通过，含门槛编号、实测值、证据来源、重评条件 |
| 9 | 口径说明 | 全部公式与门槛，保证任一格数字可复算 |

## 五、工作流程（workflow）

### STEP 1 · 统一口径：毛利 ≠ 贡献利润

先把 8 项成本全部写进模型，**且在输出里保留一列「传统口径毛利」做对照**——让看表的人自己看出漏了多少。

```
贡献利润/台 = 售价 − 采购价 − 头程 − 平台佣金 − FBA配送费 − 广告 − 退货损失 − 认证摊销
贡献率      = 贡献利润 ÷ 售价
```

关键子口径（不可自行更改）：

```
头程单件     = 体积重(kg) × 1.35 USD/kg
平台佣金     = 售价 × 15%
退货损失/台  = 退货率 × (采购 + 头程 + FBA配送费)     ← 佣金退货可退回，不计入
认证摊销/台  = 认证费(EUR) × 1.08 ÷ 首单量            ← 按首单量摊销，保守口径
```

### STEP 2 · 三情景测算

| 情景 | 广告占比 | 退货率 | 售价 | 销量 |
| --- | --- | --- | --- | --- |
| 保守 | 18% | 参考值 × 1.5 | × 0.95（促销让价） | × 0.7 |
| 基准 | 12% | 参考值 | 不变 | 基准 |
| 乐观 | 8% | 参考值 × 0.8 | 不变 | × 1.3 |

每个情景都要算贡献利润、贡献率与回本周期：

```
首单采购货款   = 首单量 × 采购价USD          ← 首笔现金支出，G1 判定口径
首单落地现金   = 首单量 × 归一化落地成本      ← 含头程关税，到港后 4-6 周付
回本周期(月)   = 首单落地现金 ÷ (月销量 × 单位贡献利润)
```

> **两个现金口径不可混用。** G1 门槛判的是采购货款（T/T 那笔钱），回本周期算的是落地现金。

### STEP 3 · 敏感项排序

对每个候选逐项做单点扰动，按对贡献率的负向影响从大到小排序：

| 扰动项 | 扰动幅度 |
| --- | --- |
| 广告占比 | +6pp（基准 12% → 保守 18%） |
| 售价 | −5% |
| 认证费 | +1,000 EUR |
| 退货率 | +2pp |
| 采购价 | +5% |

广告占比按售价百分比计，因此对贡献率是 **1:1 线性影响**——它几乎必然排在前两位。这一条决定了立项决议的措辞（见 STEP 5）。

### STEP 4 · 退出成本（必填，不允许留空）

```
退出成本 = 清仓折价损失 + 移仓费 + 长期仓储费 + 销毁费
清仓折价损失 = 滞销量 × max(落地成本 − 清仓净得, 0)
滞销量 = 首单量 × 30%（保守情景假设）
清仓净得 = 售价 × 35%（折价后扣平台费）
移仓费 0.62/台 · 长期仓储费 1.45/台（半年）· 销毁费 0.28/台
```

### STEP 5 · 立项决议

按五道门槛逐条判定，**命中任一即否决**：

| 门槛 | 阈值 |
| --- | --- |
| G1 | 首单采购货款 ≤ 38,000 USD |
| G2 | 单品认证费 ≤ 3,000 EUR |
| G3 | 基准情景贡献率 ≥ 22% |
| G4 | 基准情景回本周期 ≤ 8 个月 |
| G5 | 保守情景贡献率 ≥ 0% |

决议只能是三种之一：

- **通过**：G1–G5 全过
- **通过（附条件）**：全过但有未完成的验证项（如散热/噪音测试），须写明放行前置条件
- **否决**：写明门槛编号 + 实测值 + **重评条件**（「MOQ 降到多少可以重提」）

**并且：只要广告占比排在敏感项第一或第二位、且广告假设未用真实 CPC 校准，决议措辞必须限定为「只批打样 + 小批量，不批量产」。**

### STEP 6 · 自检

输出前逐项自检，任一不过则不得输出：

1. 每个候选的 8 项成本是否都有数（不允许空格或 0 占位）？
2. 「传统口径毛利」列是否保留，用于对照？
3. 三情景是否都算了回本周期？
4. 否决项是否都写了门槛编号 + 实测值 + 重评条件？
5. 退出成本页是否每个候选都有数？
6. 现金占用两个口径是否分列，没有混用？
7. 立项决议是否包含「不批量产」的限定（当广告假设未校准时）？

## 六、关键规则（不可协商）

1. **毛利不是贡献利润。** 输出里必须同时给出两个数并让差额可见，否则这个 Skill 没意义。
2. **认证的费用与周期分开判。** 周期超上市窗口是 PD-01 的硬红线；费用超预算是 PD-02 的 G2。
3. **两个现金口径分列。** 采购货款判 G1，落地现金算回本，不许混用。
4. **退出成本必填。** 「卖不掉怎么办」那一栏留空即视为立项表不合格。
5. **广告假设不能当结论。** 未用真实 CPC 校准的广告占比只能支撑「打样 + 小批量」，不能支撑量产。
6. **否决必须给重评条件。** 只写「否决」不写「怎样才能重提」等于把供应商谈判空间也一起否掉了。
7. **本表不构成量产授权。** 资金审批与立项签字由人完成。
