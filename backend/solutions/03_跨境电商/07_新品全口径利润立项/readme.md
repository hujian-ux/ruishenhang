## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `打样候选清单.csv`、`平台费率与成本参数.md`、`Q4现金流预测.csv`。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末 6 条关键追问逐一质询，再按验收清单核对。
5. 通过立项的候选转 PD-03 询价打样；小批量试销后用真实 CPC 回填广告假设再议量产。

### 可复算口径（口径说明页同步收录）

```
头程单件     = 体积重(kg) × 1.35
平台佣金     = 售价 × 15%
退货损失/台  = 退货率 × (采购 + 头程 + FBA配送费)
认证摊销/台  = 认证费(EUR) × 1.08 ÷ 首单量
贡献利润/台  = 售价 − 采购 − 头程 − 佣金 − FBA − 广告 − 退货损失 − 认证摊销
贡献率       = 贡献利润 ÷ 售价
首单采购货款 = 首单量 × 采购价USD                    （G1 判定）
首单落地现金 = 首单量 × 归一化落地成本                （回本周期）
回本周期(月) = 首单落地现金 ÷ (月销量 × 单位贡献利润)
退出成本     = 清仓折价损失 + 移仓费 + 长期仓储费 + 销毁费
```

### 复算示例（HT-P11 认证摊销把利润吃光）

```
认证摊销 = 6,800 EUR × 1.08 ÷ 1,000 台 = 7.34 USD/台   （占售价 34.90 的 21.0%）
贡献利润 = 34.90 − 11.17 − 1.73 − 5.24 − 4.95 − 4.19 − 1.09 − 7.34 = −0.81 USD/台
贡献率   = −0.81 ÷ 34.90 = −2.3%
→ 命中 G2（认证费 6,800 > 3,000 EUR）+ G3（贡献率 < 22%）+ G5（保守情景亏损）
```

## 五、真实性等级与边界

- **T2**：平台费率与成本结构来自官方文档。
- **T3**：立项实务痛点来自 JD 与社区。
- **构造**：数字为脱敏构造且可复算（口径说明页给出全部公式）。
- **升 T1 还缺**：客户真实立项表与一次失败新品的财务复盘。
- **人工边界**：市场假设确认、打样与量产资金审批、立项最终签字一律人工。**本表不构成量产授权。**
