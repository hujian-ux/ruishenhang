# PD-02 主提示词 · 新品全口径利润立项

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/新品全口径利润立项/SKILL.md`）。
2. 上传三个附件：`打样候选清单.csv`、`平台费率与成本参数.md`、`Q4现金流预测.csv`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `全口径利润立项表.xlsx` 后，按文末「验收清单」逐项核对。

## 主提示词（复制即用）

```
请基于我上传的三份素材，为「海拓生活科技 · 秋冬新品季」5 个打样候选做全口径利润立项测算，输出一份 9 个工作表的立项表。今晚开立项会，需要能直接上会的版本。

【输入 1 · 打样候选清单】打样候选清单.csv（5 行，承接 PD-01 打样队列）
- HT-K09 / HT-L10 / HT-M12 / HT-P11 / HT-S15
- 含售价、采购价、体积重、FBA配送费、退货率、认证项与费用、MOQ、首单量、基准月销、归一化落地成本、PD-01 移交事项

【输入 2 · 平台费率与成本参数】平台费率与成本参数.md
- 汇率 CNY→USD 7.25 / EUR→USD 1.08；平台佣金 售价×15%；头程 体积重×1.35 USD/kg
- 三情景：保守(广告18%/退货×1.5/售价×0.95/销量×0.7)、基准(12%/×1.0/不变/基准)、乐观(8%/×0.8/不变/×1.3)
- 立项门槛：G1 首单采购货款 ≤38,000 USD / G2 认证费 ≤3,000 EUR / G3 基准贡献率 ≥22% / G4 回本 ≤8 个月 / G5 保守情景贡献率 ≥0%

【输入 3 · Q4现金流预测】Q4现金流预测.csv
- 9-12 月老品补货货款、新品首单落地付款、广告预算、固定支出、流出合计、预计回款

【执行要求】
1. 统一口径，毛利 ≠ 贡献利润：
   贡献利润/台 = 售价 − 采购价 − 头程 − 平台佣金 − FBA配送费 − 广告 − 退货损失 − 认证摊销
   退货损失/台 = 退货率 × (采购 + 头程 + FBA配送费)   ← 佣金退货可退回，不计入
   认证摊销/台 = 认证费(EUR) × 1.08 ÷ 首单量           ← 按首单量摊销，保守口径
   **必须额外保留一列「传统口径毛利 = 售价 − 采购价」做对照**，让漏算的 6 项成本可见。
2. 三情景测算：每个候选每个情景都算贡献利润、贡献率、月贡献利润与回本周期。
   首单采购货款 = 首单量 × 采购价USD（G1 判定口径，首笔 T/T）
   首单落地现金 = 首单量 × 归一化落地成本（含头程关税，回本周期口径）
   回本周期(月) = 首单落地现金 ÷ (月销量 × 单位贡献利润)
   **两个现金口径必须分列，不许混用。**
3. 敏感性分析：对每个候选做单点扰动并按对贡献率的负向影响排序——
   广告占比 +6pp / 售价 −5% / 认证费 +1,000 EUR / 退货率 +2pp / 采购价 +5%
4. 退出成本（必填，不允许留空）：
   退出成本 = 清仓折价损失 + 移仓费 + 长期仓储费 + 销毁费
   滞销量 = 首单量 × 30%；清仓净得 = 售价 × 35%；移仓 0.62/台；长期仓储 1.45/台；销毁 0.28/台
5. 首单方案对照：对 HT-K09 同时测算 2,000 台与 3,000 台两个方案（3,000 台单位落地成本降 0.40/台），并结合 Q4 付款高峰说明选哪个。
6. 立项决议：按 G1-G5 逐条判定，命中任一即否决。决议只能是「通过 / 通过（附条件）/ 否决」三种，且必须写明门槛编号 + 实测值 + 重评条件（否决项要写「怎样才能重提」）。

【输出格式】xlsx，固定 9 个工作表，表名与顺序：
立项汇总 / 全口径成本模型 / 三情景测算 / 敏感性分析 / 首单方案与现金占用 / Q4现金流预测 / 退出成本测算 / 立项决议 / 口径说明

【硬性约束】
- 8 项成本每项都要有数，不允许空格或 0 占位（真为 0 的写 0.00 并在口径说明注明原因）。
- 否决项不允许写「综合考虑」，必须是门槛编号 + 实测值。
- 「口径说明」页必须让任一格数字可以从「打样候选清单.csv」复算出来。
- **只要广告占比排在敏感项第一或第二位、且广告假设未用真实 CPC 校准，立项决议措辞必须限定为「只批打样 + 小批量，不批量产」。**
- 本表不构成量产授权：资金审批与立项签字由人完成，请在立项决议页注明。
- 不写任何效率百分比或效果承诺。

【生成后自检，逐条回答】
1. 每个候选的 8 项成本是否都有数？
2. 「传统口径毛利」列是否保留做对照？
3. 三情景是否都算了回本周期？
4. 否决项是否都写了门槛编号 + 实测值 + 重评条件？
5. 退出成本页是否每个候选都有数？
6. 现金占用两个口径是否分列，没有混用？
7. 立项决议是否包含「不批量产」的限定？
自检全过再输出 xlsx。
```

## 本案例的关键追问（拿到结果后必须问）

1. **五个候选毛利率都超 35%，为什么只有 3 个通过？** 期望回答：毛利是（售价−采购价），漏了头程、佣金、FBA、广告、退货、认证 6 项；换成贡献率后 HT-P11 是 −2.3%、HT-S15 是 13.6%。
2. **HT-P11 认证费 6,800 EUR 到底怎么把利润吃掉的？** 期望回答：6,800 × 1.08 ÷ 首单 1,000 台 = **7.34 USD/台**，占售价 34.90 的 21%，直接把贡献率打到负数；同时命中 G2（>3,000 EUR）。
3. **HT-S15 贡献率 13.6% 还有正利润，为什么否决？** 期望回答：MOQ 5,000 不可拆，首单采购货款 = 5,000 × 8.50 = **42,500 > 38,000** 上限（G1），叠加 10-11 月付款高峰无腾挪空间；同时 G3 贡献率 13.6% < 22%。
4. **HT-K09 为什么选 2,000 台不选 3,000 台？** 期望回答：3,000 台单位落地成本降 0.40/台，但落地现金从 **27,600 升到 40,200**（多占 12,600；若单价不降按 13.80 估算则多占 13,800），撞上 10-11 月货款与头程付款高峰 86,400 级别，Q4 现金流承载不了。
5. **为什么通过了还不能量产？** 期望回答：敏感性分析显示广告占比是第一敏感项（1:1 线性影响贡献率），而 12% 是假设、未用真实 CPC 校准——所以只批「打样 + 小批量」，等试销拿到真实 CPC 再议量产。
6. **HT-M12 为什么是「通过（附条件）」？** 期望回答：G1–G5 全过（贡献率 25.0%、回本 7.7 个月），但退货率 7.4% 偏高且散热与噪音测试未完成，测试通过是放行前置条件。

## 验收清单

- [ ] xlsx 含 9 个工作表，表名与顺序一致
- [ ] HT-K09 基准贡献率 = 32.0%；HT-L10 = 36.1%
- [ ] HT-P11 认证摊销 = 7.34 USD/台，基准贡献率为负 → 否决（G2 + G3 + G5）
- [ ] HT-S15 首单采购货款 = 42,500 USD → 否决（G1，上限 38,000）
- [ ] HT-M12 = 通过（附条件），散热与噪音测试为放行前置条件
- [ ] HT-K09 首单 2,000 台落地现金 = 27,600；3,000 台 = 40,200
- [ ] Q4 10-11 月货款与头程付款高峰 = 86,400 USD 级别
- [ ] 敏感性分析中广告占比排第一或第二
- [ ] 立项决议含「只批打样 + 小批量，不批量产」
- [ ] 退出成本页 5 个候选全部有数
