# 平台费率与成本参数（立项测算口径）

> 本文件是立项模型的参数底稿。所有参数一旦写入，测算过程不得再临时改动；
> 如需修改，必须重跑全部候选并留版本记录。

## 一、汇率与费率

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| 汇率 CNY→USD | 7.25 | 采购价折算 |
| 汇率 EUR→USD | 1.08 | 认证费折算 |
| 平台佣金 | 售价 × 15% | Amazon 家居厨具类目参考费率 |
| FBA 配送费 | 按体积重分档，逐品给定 | 见「打样候选清单.csv」FBA配送费列 |
| 头程单件 | 体积重(kg) × 1.35 USD/kg | 空派 + 到仓派送 |
| 关税与清关 | 已含在归一化落地成本内 | 落地成本口径见 PD-03 |

## 二、广告占比（三情景假设）

| 情景 | 广告占售价比 | 说明 |
| --- | --- | --- |
| 保守 | 18% | 新品期竞价高、转化未起量 |
| 基准 | 12% | 成熟期目标广告占比 |
| 乐观 | 8% | 自然流量占比提升后 |

> **重要**：广告占比是**假设**，不是实测。本季尚未用真实 CPC 校准，
> 因此立项决议不得基于广告假设直接批量产（见立项决议页结论）。

## 三、退货损失口径

```
退货损失/台 = 退货率 × (采购价 + 头程 + FBA配送费)
```

理由：退货发生时，采购成本、头程成本、FBA 配送费均不可回收；平台佣金可退回。

| 情景 | 退货率取值 |
| --- | --- |
| 保守 | 参考值 × 1.5 |
| 基准 | 参考值 |
| 乐观 | 参考值 × 0.8 |

## 四、认证费摊销口径

```
认证摊销/台 = 认证费(EUR) × 1.08 ÷ 首单量
```

按**首单量**摊销（而非首年预估销量），属保守口径——避免用乐观销量预测把认证成本摊薄。

## 五、贡献利润与贡献率

```
贡献利润/台 = 售价 − 采购价 − 头程 − 平台佣金 − FBA配送费 − 广告 − 退货损失 − 认证摊销
贡献率     = 贡献利润 ÷ 售价
```

**注意：贡献利润 ≠ 毛利。** 传统立项表的「毛利 = 售价 − 采购价」会漏掉 6 项成本。

## 六、立项门槛（财务给定）

| 门槛 | 阈值 | 命中处理 |
| --- | --- | --- |
| G1 首单采购货款 | ≤ 38,000 USD | 超出即否决（货款是首笔现金支出，头程与关税在到港后 4-6 周才付） |
| G2 单品认证费预算 | ≤ 3,000 EUR | 超出即否决 |
| G3 基准情景贡献率 | ≥ 22% | 低于即否决 |
| G4 基准情景回本周期 | ≤ 8 个月 | 超出需补充验证 |
| G5 保守情景贡献率 | ≥ 0% | 保守情景亏损即否决 |

## 七、回本周期口径

```
回本周期(月) = 首单落地现金占用 ÷ (月销量 × 单位贡献利润)
首单落地现金占用 = 首单量 × 归一化落地成本
```

## 八、退出成本（下行测算，必填项）

卖不掉时的退出成本必须进立项表，不允许留空：

```
退出成本 = 清仓折价损失 + 移仓费 + 长期仓储费 + 销毁费
清仓折价损失 = 滞销量 × (落地成本 − 清仓售价净得)
```

滞销假设：保守情景下按首单量 30% 滞销测算。
