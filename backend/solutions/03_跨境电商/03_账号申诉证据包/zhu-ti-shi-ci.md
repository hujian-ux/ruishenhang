# 主提示词 · 账号申诉证据包（op-02）

## 一、使用方式

1. 先在 WorkBuddy 中导入并启用本场景 Skill 包（`03_技能包/账号申诉证据包/SKILL.md`）。
2. 上传三份素材：`平台绩效通知与Case往来.md`、`证据文件台账.csv`、`账号绩效指标.csv`。
3. 复制下方【主提示词】原文发送。
4. 拿到 `账号申诉证据包.md` 后，按第三节自检项逐条核对，再交法务复核、负责人签字，最后由人工点击平台提交按钮。

---

## 二、主提示词（复制即用）

```
请以「平台运营与合规」岗位视角，为以下 Listing 下架案件生成完整的《账号申诉证据包》。

【案件背景】
- 主体：深圳海拓生活科技有限公司
- SKU / 商品：HT-H03 · Hightop 超声波恒温加湿器 4.5L
- ASIN / 站点：B0DE7H03QM · Amazon.de（德国站）
- 下架时间：2026-08-24 09:12 (CEST)，原因「安全隐患投诉」
- 平台要求：72 小时内提交 POA，截止 2026-08-27 09:12 (CEST)
- 商业影响：近 30 天销售额 13,800 USD；FBA 在仓 540 件，到仓单价 24.00 USD
- 历史：2025-11-08 上一轮申诉被驳回，理由「证据与主张不对应」

【输入 1 · 平台绩效通知与 Case 往来】（见 平台绩效通知与Case往来.md）
- 平台三项指控：A1 近 90 天 3 起过热/异味安全投诉；A2 详情页安全与认证表述误导；A3 在档合规文件不完整
- 含事件时间线（含投诉、页面改动、下架通知）、上轮驳回记录、页面表述现状对照

【输入 2 · 证据文件台账】（见 证据文件台账.csv，20 行）
- 字段：证据编号, 文件名, 证据类型, 出具方, 签发日期, 有效期至, 关联SKU, 关联型号,
        持有人, 所在系统, 文件状态, 可24小时内取得, 对应指控编号, 星标

【输入 3 · 账号绩效指标】（见 账号绩效指标.csv，12 行）
- 字段：指标代码, 指标名称, 统计口径, 平台阈值, 当前值, 单位, 是否超标, 统计窗口, 数据来源

【输出要求 · 严格按 10 段】
1. 案件基本信息与商业影响：必须算出「停售日损失 = 13,800 ÷ 30」与「库存货值 = 540 × 24.00」
2. 事件时间线还原：按时间排序，把自相矛盾处单独标为「矛盾点」
3. 平台指控拆解：A1/A2/A3 逐项写「平台指控 / 我方定性 / 需要证明的事」，不许合并回答
4. 指控—证据映射表：每条指控挂到具体证据编号，判定证明力（直接 / 间接·型号不同需限定表述 /
   缺口·不可引用）；单列「星标素材」并说明它如何改变申诉口径
5. 证据缺口清单：把「未取得 / 待导出 / 待供应商提供」的证据明写，含责任人、取得方式、
   目标时点、预计费用
6. 账号绩效指标核对：列出全部指标与超标项，并说明每个超标项由 POA 的哪一条承接
7. 申诉陈述 · POA 三段式：根因 / 纠正 / 预防，每条编号（R1、C1、P1…）并括注支撑证据编号；
   附「表述红线自检」表
8. 时限 SLA：以收到通知为 T+0 的 72 小时倒排表（节点 / 时间 / 动作 / 责任人 / 状态）
9. 两个提交方案与代价对比：窄口径申诉 vs 完整申诉，各带外部支出、停售天数、停售损失、
   合计代价、提交时点、风险，并给出建议
10. 人工审批边界：逐环节写清 AI 负责什么、人负责什么

【硬性约束】
- 一条主张 = 一条证据编号。没有证据编号支撑的主张，不许写进 POA。
- 认证主体不得外扩：元件级 UL 认证只能支撑「所用元件持第三方认证」，
  不得推导「整机安全无隐患」。整机认证未确认前，全文禁止出现「产品合规」「整机安全」表述。
- 根因不许写成纠正（「我们已修改页面」属纠正）；预防必须是可验证动作
  （SOP 编号、审批留痕、培训签到人数），禁止「加强管理」「提高意识」。
- 全文禁用：良心卖家、恶意投诉、我们很委屈、客户不讲理、绝对安全、百分百安全、加强管理。
- 无法在 72 小时内取得的证据，不得作为本轮提交的前置条件。

生成后自检并在文末声明：① 每条主张是否都有证据编号？② 时间线是否与 Case 记录顺序一致？
③ 是否出现禁用表述？④ 是否有任何主张超出证据范围？确认无误再输出。
```

## 三、拿到结果后的人工自检项

| 序号 | 自检项 | 通过标准 |
| --- | --- | --- |
| 1 | 主张—证据一一对应 | POA 中每条 R/C/P 后都有证据编号 |
| 2 | 时间线无矛盾 | 与平台 Case 记录日期顺序完全一致 |
| 3 | 认证主体未外扩 | 全文不出现「整机安全」「产品合规」 |
| 4 | 缺口已明写 | 3 项缺口均含责任人、取得方式、目标时点 |
| 5 | 禁用表述为零 | 红线自检表全部「未出现」 |
| 6 | 金额可复算 | 460.00 USD/日、12,960.00 USD 货值、方案代价可用四则运算复核 |
| 7 | 法务已复核 | 承诺与法律责任表述经法务确认 |
| 8 | 提交为人工 | 平台提交按钮由负责人本人点击 |
