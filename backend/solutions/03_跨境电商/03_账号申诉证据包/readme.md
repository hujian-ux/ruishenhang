## 四、Skill 包使用

1. 在 WorkBuddy 左侧「专家·技能·连接器」点击「添加技能 → 上传技能」，导入 `03_技能包/账号申诉证据包/SKILL.md` 所在文件夹，或直接上传 `平台运营与合规-账号申诉证据包.zip`。
2. 在「已安装」列表中启用该技能。
3. 上传三份原始数据源，发送 `主提示词.md` 中的主提示词原文。
4. 按 `主提示词.md` 第三节 8 项自检表核对结果。

## 五、遗留与真实性声明

- 真实性等级 T2+T3：POA 结构与平台申诉流程来自卖家实务与社区案例，事件与文件为脱敏构造。
- 升 T1 还缺：客户真实绩效通知、真实证据文件与一次完整申诉往来记录。
- 高风险动作一律人工审批：事实陈述最终确认、法律责任与承诺表述（法务）、检测费用审批、平台最终提交按钮。
