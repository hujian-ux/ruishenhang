## 四、Skill 包使用

1. 在 WorkBuddy 左侧「专家·技能·连接器」点击「添加技能 → 上传技能」，导入 `03_技能包/商品合规材料包/SKILL.md` 所在文件夹，或直接上传 `平台运营与合规-商品合规材料包.zip`。
2. 在「已安装」列表中启用该技能。
3. 上传四份原始数据源，发送 `主提示词.md` 中的主提示词原文。
4. 按 `主提示词.md` 第三节 8 项自检表核对结果。

## 五、遗留与真实性声明

- 真实性等级 T2+T3：GPSR 义务来自欧盟官方，认证实务痛点来自公开案例，文件与数据为脱敏构造。
- 升 T1 还缺：客户真实证书台账与一次驳回/抽查实例。
- 高风险动作一律人工审批：法规适用性最终判断（合规/法务）、检测与认证费用审批、最终提交与上市放行。
- 台账维护提醒：`满足要求编号` 必须填写，否则该文件在核验中等同不存在。
