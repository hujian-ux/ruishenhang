# 内容—达人—广告—退款后净ROI · Skill 定义

## 1. 能力定位
把"平台 GMV 好看"还原成"扣完所有成本后的净贡献"，用四链匹配挤掉重复归因的水分，让达人/素材按净利润而非播放量排座次。

## 2. 输入
- `达人合作结算单.csv`：达人ID / 视频数 / GMV / 佣金 / 样品 / 券补 / 授权到期日
- `广告报表.csv`：视频ID / 广告费 / 播放量 / 类型 / 订单 / 重复归因标记
- 订单/退款数据：GMV、退款额

## 3. 输出
- `净ROI核算表.xlsx`：视频明细（31 条）+ 达人层（20 位）+ 净ROI汇总 + 规则与结论

## 4. 工作流（4 步）
1. 四链匹配：达人-视频-广告-订单对齐，重复归因单列
2. 净贡献：五类成本全扣，算真利润
3. 分层：素材与达人按净 ROI 分层，不按播放量
4. 续投决策：续约/切换/停投，授权到期先处理

## 5. 关键规则
- 净贡献 = GMV − 退款 − 佣金(15%) − 样品 − 券补 − 广告费。
- 重复归因必须单列，不计入净贡献。
- 播放量第 1 的素材往往净 ROI 垫底；按净利润分层。
- 授权到期提前预警，未续约前不得投流。
- 续约谈判、佣金审批、授权法律确认一律人工负责。
