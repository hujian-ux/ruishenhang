## 二、交付物验证结果
- `净ROI核算表.xlsx` 存在：✅  size>0，4 个工作表（净ROI汇总/视频明细/达人层/规则与结论）
- `视频明细` 行数 = 31（含表头 32）；`达人层` 20 位 + 合计行 ✅
- 列和校验（对齐素材）：GMV 41,600 / 广告费 9,800 / 样品 1,860 / 券补 2,100 / 退款 3,400 / 佣金 6,240 / 重复归因 2,860 / 净贡献 18,200 ✅（全部精确匹配）
- 冠军：21 万播放测评视频净 ROI 第 1（2.95）；86 万播放素材净 ROI 垫底（第 31），印证"高播放≠高净ROI"

## 四、关键案例数字（对齐素材 /tmp/cb_GR-03.txt）
- 20 达人、31 视频、总 GMV 41,600 USD
- 重复归因 12 笔 / 2,860 USD
- 净贡献 = 41,600 − 3,400 − 6,240 − 1,860 − 2,100 − 9,800 = 18,200
- 播放量第 1（86 万）净 ROI 垫底；冠军是 21 万播放测评视频
- 3 条高贡献素材授权 14 天内到期；续约 680/月 vs 切换损失 4,200/月
- 演示第一句话："你们的达人佣金结算单，投手算 ROI 的时候见过吗？"
