## 业务背景
Amazon 7 月月账单 **2,400 行**费用明细，抽查时撞见一笔重复扣费。全量审计发现：重复扣费 3 笔 486、费率偏差 2 笔 590、广告费跨期漏记 233，合计异常 **1,309 USD**（算平）。
排除性结论：FBA 配送费与仓储费主体部分费率正确，异常集中在 5 笔。申诉策略：先提证据最硬的 3 笔重复扣费（486，成功率最高）；费率偏差 2 笔因类目调整未确认前不提交申诉；跨期漏记走内部调账。
