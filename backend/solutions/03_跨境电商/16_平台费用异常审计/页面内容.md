现状与痛点

平台月账单动辄两三千行费用明细，财务每月只能抽查几十行。费率政策 PDF 发了没人打开，重复扣费混在海量行里，没人逐行对。

费率调整没人同步改账单

平台费率每年调整，部分类目按旧费率多收并不少见——费率政策 PDF 公开发布，但逐行核对的成本让人放弃。

高频真实
重复扣费单笔小、笔数隐蔽

几十到几百美元一笔的重复扣费混在 2,400 行里，抽查命中率低，平台不会主动提醒你多扣了。

隐蔽出血
广告费跨期漏记让利润失真

点击在 7 月、扣费入账在 8 月，利润表上 7 月虚高、8 月虚低——跨期漏记不纠正，经营分析全是错位的。

口径陷阱
审计靠抽查，覆盖率靠运气

2,400 行明细全量人工核对要两三天，财务只能抽查——没抽到的那几笔，就成了平台的。

工作量

费率政策 PDF 上一次打开是什么时候？——没打开过，才是大多数重复扣费和费率偏差没被追回的原因。

WorkBuddy 的解决与价值

WorkBuddy 把费用审计做成一条"标准生产线"：费项标准化但保留原始名，按政策逐行重算，重复/偏差/漏记三类识别，逐笔定位订单与凭证，申诉清单按证据强度排序。

传统做法

账单导出来总数对得上就过，抽查几十行撞到问题算运气，费率政策公告收藏了从没打开过，发现异常也不知道去哪申诉。

WorkBuddy 做法

费项标准化但保留原始名，按政策逐行重算；重复/偏差/漏记三类识别，逐笔定位订单与凭证；星标素材费率政策 PDF 关键页；申诉清单按证据强度排序，先提最硬的 3 笔。

三个核心价值
01全量而非抽查

2,400 行一次扫完，不靠运气覆盖率——隐蔽的重复扣费和跨期漏记无处藏身。

02政策逐行对照

费率政策 PDF 关键页变成可执行基准，旧费率多收、类目错配自动现形。

03申诉有优先级

按证据强度排序，先提最硬的 3 笔重复扣费（成功率最高），人只做确认与提交。

方案定位

差别不在快，在于有人把散在多处的东西拼到了一起——费率政策与账单逐行对齐，让每一笔异常都有铁证。

解决方案的工作流程

整个流程完全自动，财务只在最后做费率解释确认、申诉提交与会计调整审批，共 5 步。

01费项标准化

原始费项保留，映射统一字典（FBA配送费/仓储费/佣金/广告费…）。

02按政策重算

费率政策逐行核对应收应付，得出基准金额与异常幅度。

03异常识别

重复/偏差/漏记三类，逐笔定位订单与凭证。

04申诉与调整

按证据强度排序，内部责任归口；重复优先申诉。

05输出证据包

导出审计表 + 申诉清单，凭证归档，可复核可提交。

脱敏案例：海拓生活科技 · 财务与经营分析

【输入 1 · 平台费用账单】（节选自 平台费用账单.csv）
- 字段：费用项 / 订单_ASIN / 金额USD / 账期 / 备注
- 覆盖 FBA配送费、仓储费、佣金、广告费、退货处理费等，含 ORD-A1001~A1003、ORD-B2001~B2002、CAM-C3001

【输入 2 · 费率政策摘要】（星标素材，节选自 费率政策摘要.md）
- FBA 配送费类目 B 基准 2.47 USD/件（旧费率 5.42）
- 仓储费 / 佣金 / 广告费跨期口径

【输出要求】
1. 费项标准化：原始费项保留，映射统一字典
2. 按政策重算：逐行核对基准金额，得出异常幅度
3. 三类异常识别：重复 / 偏差 / 漏记，逐笔定位订单与凭证
4. 排除性结论：FBA 配送费与仓储费主体费率正确，异常集中在少数几笔
5. 审计表 + 申诉清单：导出「平台费用审计表.csv」，按证据强度排序（先提最硬的 3 笔重复扣费）

【约束】
- 费率偏差若因类目调整未书面确认，不提交该笔申诉
- 跨期漏记走内部调账，不向平台申诉
- 高风险动作（费率解释确认、申诉提交、会计调整）一律人工审批
- 生成后自检：异常合计能否复算（重复486+偏差590+漏记233=1309）？每笔是否都有证据强度与申诉优先级？
