# 主提示词 · 平台费用异常审计

> 学员在 WorkBuddy 中实际发送的主提示词。配合本场景 Skill 包使用，复制下方内容并附上两份数据源即可。

---

请基于以下两份素材，为「海拓生活科技 · 财务与经营分析」完成 7 月 Amazon 月账单（2,400 行）的全量费用异常审计，严格按 5 段输出。

【输入 1 · 平台费用账单】（节选自 平台费用账单.csv）
- 字段：费用项 / 订单_ASIN / 金额USD / 账期 / 备注
- 覆盖 FBA配送费、仓储费、佣金、广告费、退货处理费等，含异常批次 ORD-A1001~A1003、ORD-B2001~B2002、CAM-C3001

【输入 2 · 费率政策摘要】（星标素材，节选自 费率政策摘要.md）
- FBA 配送费类目 B 基准 2.47 USD/件（旧费率 5.42）
- 仓储费 / 佣金 / 广告费跨期口径

【输出要求】
1. 费项标准化：原始费项保留，映射统一字典
2. 按政策重算：逐行核对基准金额，得出异常幅度
3. 三类异常识别：重复 / 偏差 / 漏记，逐笔定位订单与凭证
4. 排除性结论：FBA 配送费与仓储费主体费率正确，异常集中在少数几笔
5. 审计表 + 申诉清单：导出「平台费用审计表.csv」，按证据强度排序（先提最硬的 3 笔重复扣费）

【约束】
- 费率偏差若因类目调整未书面确认，不提交该笔申诉
- 跨期漏记走内部调账，不向平台申诉
- 高风险动作（费率解释确认、申诉提交、会计调整）一律人工审批
- 生成后自检：异常合计能否复算（重复486+偏差590+漏记233=1309）？每笔是否都有证据强度与申诉优先级？
