# 平台费用异常审计

## 适用时机
- 平台月账单 2,000+ 行费用明细，全量人工核对要两三天，财务只能抽查。
- 平台费率每年调整，部分类目按旧费率多收，费率政策 PDF 发了却没人逐行对。
- 几十到几百美元一笔的重复扣费混在海量行里，平台不会主动提醒多扣。
- 广告点击与扣费跨月，利润表错位，经营分析失真。

## 输入（inputs）
- `平台费用账单.csv`：费用项、订单/ASIN、金额、账期、备注（2,400 行样本）。
- `费率政策摘要.md`（星标素材）：FBA 配送费 / 仓储费 / 佣金等基准费率，旧费率多收的铁证。
- 申诉历史与类目费率调整确认单（可选，用于判断是否提交费率偏差申诉）。

## 输出（outputs）
- `平台费用审计表.csv`：费用项、订单/ASIN、账单金额、政策基准金额、异常幅度、异常类型（重复/偏差/漏记/正常）、审计结论、证据强度、申诉优先级。
  - 异常类型仅限三类：重复 / 偏差 / 漏记；其余为「正常」。
  - 申诉按证据强度排序：先提证据最硬的 3 笔重复扣费。

## 工作流（workflow）
1. **费项标准化**：保留原始费项名，映射统一字典（FBA配送费 / 仓储费 / 佣金 / 广告费…）。
2. **按政策重算**：以费率政策逐行核对应收应付，得出政策基准金额与异常幅度。
3. **异常识别**：重复（同 ASIN 同账期多笔）、偏差（费率错配）、漏记（应计未计）三类，逐笔定位订单与凭证。
4. **申诉排序**：按证据强度排序，内部责任归口；重复扣费优先申诉。
5. **输出证据包**：导出审计表 + 申诉清单（含金额与证据强度），归档可复核。

## 关键规则
- 排除性原则：FBA 配送费与仓储费主体部分费率正确，异常集中在少数几笔（样例 5 笔）。
- 费率偏差若因类目调整未书面确认，**不提交该笔申诉**，待确认后再提。
- 跨期漏记走内部调账，不向平台申诉。
- 高风险动作（费率解释确认、申诉提交、会计调整审批）一律人工，AI 只生成清单与金额。
- 数字必须可复算：重复 486 + 偏差 590 + 漏记 233 = 1,309（样例异常合计）。
