# 经营利润异常会诊与行动审批（MG-01）

## 适用时机
- 月结发现「销售额涨了、利润反而降了」，各部门归因不一致（运营怪广告、广告怪退款、财务怪汇率）。
- 需要从多源数据（平台结算单、ERP、银行流水、费用科目映射表）会诊利润异常，给出可复算的分项金额。
- 需要输出带「人工审批点」的行动清单（调价、停投、清库存等经营动作不得 AI 代决）。

## 输入（inputs）
- `三渠道销售利润明细.csv`：渠道 / 7月销售额USD / 环比% / 上月贡献利润USD / 本月贡献利润USD。
- `利润桥接分项.csv`：项目 / 方向(增益|拖累) / 金额USD / 说明。
- `财务费用科目映射表.csv`：科目编码 / 科目名称 / 费用类型 / 关联事件 / 计入科目 / 金额USD / 备注（用于重复计费检测）。

## 工作流程（workflow）
1. **口径校验**：确认三渠道的数据期间、币种、退款确认时点一致，不能比的不硬比，提示不可比项。
2. **利润桥接**：毛利增量 + 五项拖累，分项金额相加必须等于利润净变动（96,400 + 10,400 − 21,400 = 85,400）。
3. **归因排序**：按金额绝对值从大到小排列，每一项标注来源表与字段，杜绝「大概是被广告吃的」式口头归因。
4. **重复计费检测**：扫描费用科目映射表，同一科目编码+名称+金额出现在两个计入科目即为重复计费（如秒杀费 3,200 同时计入广告费与促销费）。
5. **行动审批**：调价、停投、清库存只给建议，标注需老板/财务负责人签字的人工审批点；汇率口径由财务负责人最终确认前，月报不得发出。

## 输出（outputs）
- 利润桥接表（可复算，合计算平）。
- 归因排序表（含来源表/字段）。
- 行动建议清单（按金额排序 + 人工审批标注）。
- 重大异常会诊报告 `.md`（见 `经营利润异常会诊报告.md`）。

## 关键规则 / 提示词要点
- 所有金额必须来自输入表，禁止凭空编造；桥接合计必须算平，否则报错。
- 重复计费用「同一科目编码+名称+金额出现在两个计入科目」判定。
- 高风险经营动作一律标注人工审批，AI 仅给建议不代决。
- 不承诺任何效率百分比；真实性为脱敏构造、可从素材复算。
