- `三渠道销售利润明细.csv` 行数 = 3（断言：销售额=412,600、上月利润=96,400、本月利润=85,400）
- `利润桥接分项.csv` 行数 = 6（断言：毛利增量=10,400、五项拖累=−21,400、净变动=−11,000）
- `财务费用科目映射表.csv` 行数 = 7（断言：检出重复计费 3,200，共 1 笔）
- `经营利润异常会诊报告.md` size > 0，含关键数字 85,400 / 21,400 / 3,200
- 复算：96,400 + 10,400 − 21,400 = 85,400 ✓

## 使用方式
1. 在 WorkBuddy 左侧「专家·技能·连接器」导入本场景 Skill 包并在「已安装」启用。
2. 将三份 CSV 作为素材发送主提示词。
3. 核对利润桥接表是否算平、重复计费是否被检出、高风险动作是否标注人工审批。
4. 汇率口径由财务负责人最终确认后，再发月报。
