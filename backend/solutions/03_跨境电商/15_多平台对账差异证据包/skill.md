# 多平台对账差异证据包

## 适用时机
- 每月月结，Amazon / Shopify / TikTok 三方结算单、ERP、银行流水对不上。
- 差异被「标黄挂账」，下月又被新差异盖住，年底变成无人能解释的总额。
- 差异解释依赖某位老员工经验，其休假或离职即对账停摆。
- 需要向平台发起费用追回（漏返）或做会计调账，但缺乏逐笔凭证。

## 输入（inputs）
- `平台结算单.csv`：各平台结算批次、结算日期、结算金额、币种。
- `ERP明细.csv`：凭证号、批次、确认金额、确认日期。
- `银行流水.csv`：到账日期、渠道、到账金额、对应批次。
- `收款服务商手续费明细.csv`（星标素材）：Payoneer / WorldFirst / LianLian 等手续费，补齐平台结算单缺的那块。
- `汇率取值记录`（可选）：EUR 等外币的取数日与汇率。

## 输出（outputs）
- `多平台对账差异表.csv`：订单号/批次、平台、币种、平台结算金额、ERP 确认金额、银行到账金额、差额、差异类别、证据索引、责任归属、处置建议。
  - 差异类别仅限五类：跨期 / 漏返 / 汇率 / 退款 / 补贴；其余为「无差异」。
  - 每笔差异必须带证据索引（政策截图 / 工单号 / 流水日期），并给责任归属与处置建议。

## 工作流（workflow）
1. **口径统一**：对齐主键（订单号/结算批次）、币种、时间轴（结算周期 / payout / 账期 / 到账日）。
2. **三方匹配**：平台结算 × ERP × 银行逐笔匹配，标记差额。
3. **五类归口**：将每笔差额定性为跨期 / 漏返 / 汇率 / 退款 / 补贴，禁止模糊写「大概是跨期」。
4. **审批处置**：调账与追款分开；漏返属可追回、跨期属时间差需下月核销；调账/追款走审批并留痕。
5. **输出证据包**：导出差异表与凭证索引，归档可复核。

## 关键规则
- 排除性原则：先确认银行侧有无差错（通常无），差异归属平台费项与时间口径。
- 外币（如 EUR）汇率取值日未确认前，**不得出调账单**。
- 高风险动作（会计调账最终确认、向平台追款沟通、汇率口径政策确认）一律人工审批，AI 只生成清单与凭证索引。
- 数字必须可复算：跨期 1,940 + 漏返 1,120 + 汇率 860 + 退款 620 + 补贴 347 = 4,887（样例总额）。
