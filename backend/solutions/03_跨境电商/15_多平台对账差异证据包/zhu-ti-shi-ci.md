# 主提示词 · 多平台对账差异证据包

> 学员在 WorkBuddy 中实际发送的主提示词。配合本场景 Skill 包使用，复制下方内容并附上四份数据源即可。

---

请基于以下四份素材，为「海拓生活科技 · 财务与经营分析」完成 7 月多平台月结对账，严格按 5 段输出。

【输入 1 · 平台结算单】（节选自 平台结算单.csv）
- 字段：平台 / 结算批次 / 结算日期 / 结算金额USD / 币种
- 覆盖 Amazon、Shopify、TikTok 三方，含样本批次 AMZ-JUL-0042、SHOP-JUL-0177、TIK-JUL-0091 等

【输入 2 · ERP明细】（节选自 ERP明细.csv）
- 字段：凭证号 / 批次 / 确认金额USD / 确认日期 / 币种

【输入 3 · 银行流水】（节选自 银行流水.csv）
- 字段：到账日期 / 渠道 / 到账金额USD / 对应批次 / 币种
- 关键：银行侧需先确认有无差错（本例银行侧无差错）

【输入 4 · 收款服务商手续费明细】（星标素材，节选自 收款服务商手续费明细.csv）
- Payoneer / WorldFirst / LianLian 手续费，补齐平台结算单缺的那块

【输出要求】
1. 口径统一说明：主键（订单号/结算批次）、币种、时间轴（结算周期/payout/账期/到账日）如何对齐
2. 三方逐笔匹配：平台结算 × ERP × 银行，标记差额
3. 五类归口表：跨期 / 漏返 / 汇率 / 退款 / 补贴，每笔定性 + 证据索引 + 责任归属 + 处置建议
4. 排除性结论：先确认银行侧有无差错；差异全在平台费项与时间口径
5. 差异证据包：导出「多平台对账差异表.csv」，并给出调账/追款清单（区分可追回与待核销）

【约束】
- 外币（EUR）汇率取值日未确认前，不得出调账单
- 高风险动作（会计调账最终确认、向平台追款、汇率口径确认）一律人工审批
- 生成后自检：五类归口金额能否复算到总额？每笔差异是否都有证据索引？
