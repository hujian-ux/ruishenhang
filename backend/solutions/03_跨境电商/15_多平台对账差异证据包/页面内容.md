现状与痛点

跨境电商财务每月最头疼的事之一：多平台月结。Amazon 按结算周期、Shopify 按 payout、TikTok 按自己账期、银行按到账日——四方四个时间轴，硬对必差。

平台周期与会计期间错位

Amazon 结算周期、Shopify payout、TikTok 账期、银行到账日，四个时间轴永远对不齐，结构性差异甩不掉。

结构性差异
费项漏返是沉默的出血

平台承诺返还的促销补贴、运费补贴实际未到账，金额小、笔数多，不逐笔核就发现不了。

高频真实
差异解释靠老师傅经验

「这笔大概是跨期」——判断依据在老员工脑子里，她休假时对账就停摆，新人接手要从零学。

人走技失
挂账越滚越大

当月对不上的挂「待查」，下月新差异盖上来——年底审计时一年的「待查」变成谁都解释不清的总额。

风险累积

「这笔大概是跨期」——判断依据在何静怡脑子里，她休假时对账就停摆，新人接手要从零学。

WorkBuddy 的解决与价值

WorkBuddy 把三方对账做成一条"标准生产线"：先统一口径主键，再三方逐笔匹配，差异按五类归口定性，每笔带凭证索引，调账追款走审批。

传统做法

每月花一星期 Excel 里 VLOOKUP 三方数据，对不上的标黄挂账下月再说，跨期、漏返、汇率混在一起凭感觉解释，调账没有审批链、改了没有留痕。

WorkBuddy 做法

主键与口径先统一（订单号/结算批次/币种）；三方逐笔匹配，差异按五类归口；收款服务商手续费明细补上平台结算单缺的那块；每笔差异带凭证索引，调账/追款走审批。

三个核心价值
01把散点拼成整体

平台结算、ERP、银行、收款商手续费四来源先统一主键与口径，原本散在多处的东西第一次拼到一张表上。

02差异可解释

跨期/漏返/汇率/退款/补贴五类归口，每笔差定量定性，不再是"大概是跨期"的口头判断。

03调账可追溯

每笔差异带证据索引，调账与追款分开、走审批留痕，新人也能照着做、老人休假不断档。

方案定位

差别不在快，在于有人把散在多处的东西拼到了一起——并让每一笔差异都有出处、有责任人、有处置。

解决方案的工作流程

整个流程完全自动，财务只在最后做业务确认与审批，共 5 步。

01口径统一

主键、批次、币种、时间轴先对齐，四方数据落到同一把"钥匙"上。

02三方匹配

平台结算 × ERP × 银行逐笔对，标记每一笔差额。

03五类归口

跨期/漏返/汇率/退款/补贴，每笔定性并给证据索引。

04审批处置

调账与追款分开，凭证索引完整，走审批留痕。

05输出证据包

导出差异证据包，可复核、可追溯、可对外追款。

脱敏案例：海拓生活科技 · 财务与经营分析

提示词
TRAINING PROMPT · 复制即用
请基于以下四份素材，为「海拓生活科技 · 财务与经营分析」完成 7 月多平台月结对账，严格按 5 段输出。

【输入 1 · 平台结算单】（节选自 平台结算单.csv）
- 字段：平台 / 结算批次 / 结算日期 / 结算金额USD / 币种
- 覆盖 Amazon、Shopify、TikTok 三方，含 AMZ-JUL-0042、SHOP-JUL-0177、TIK-JUL-0091 等

【输入 2 · ERP明细】（节选自 ERP明细.csv）
- 字段：凭证号 / 批次 / 确认金额USD / 确认日期 / 币种

【输入 3 · 银行流水】（节选自 银行流水.csv）
- 字段：到账日期 / 渠道 / 到账金额USD / 对应批次 / 币种
- 关键：先确认银行侧有无差错（本例银行侧无差错）

【输入 4 · 收款服务商手续费明细】（星标素材）
- Payoneer / WorldFirst / LianLian 手续费，补齐平台结算单缺的那块

【输出要求】
1. 口径统一说明：主键（订单号/结算批次）、币种、时间轴如何对齐
2. 三方逐笔匹配：平台结算 × ERP × 银行，标记差额
3. 五类归口表：跨期 / 漏返 / 汇率 / 退款 / 补贴，每笔定性 + 证据索引 + 责任归属 + 处置建议
4. 排除性结论：银行侧有无差错；差异全在平台费项与时间口径
5. 差异证据包：导出「多平台对账差异表.csv」，给出调账/追款清单

【约束】
- 外币（EUR）汇率取值日未确认前，不得出调账单
- 高风险动作（会计调账确认、向平台追款、汇率口径确认）一律人工审批
- 生成后自检：五类归口金额能否复算到总额？每笔差异是否都有证据索引？
