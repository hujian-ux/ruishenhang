# 主提示词 · PPC 搜索词与真实利润诊断

> 学员实际发送给 AI 的主提示词（可直接复制）。输入 Search Term Report + SKU 贡献率表，输出按真实利润分群的搜索词诊断表。

---

请基于以下两份素材，为「海拓生活科技 · HT-JC01」做 **PPC 搜索词与真实利润诊断**，严格按 5 步输出。

【输入 1 · 搜索词报告】（节选自 搜索词报告.csv，共 18 个搜索词）
- 字段：搜索词 / 类型(品牌词·竞品词·长尾词·通用词) / 曝光 / 点击 / CTR / 订单 / CVR / CPC / 花费 / 销售额 / ACoS
- 已知：HT-JC01 整体 ACoS 41%，但 CVR 从 12.4% 跌到 8.1%

【输入 2 · SKU 成本与贡献率表】（星标素材）
- 广告前贡献率 = 34% → 盈亏平衡 ACoS = 34%（广告后台永远看不到这张表）
- 根因线索：Listing 被跟卖压价 15%，CVR 下跌推高 ACoS

【诊断 5 步】
1. **口径校验**：归因窗口、数据粒度、日期范围先对齐，避免报表偏差
2. **漏斗定位**：曝光/CTR/CVR/CPC 逐环看哪环变了（重点：CVR 12.4%→8.1% 是主因，不是流量问题）
3. **利润化**：真实利润 = 销售额×34% − 花费；不靠 ACoS 一刀切
4. **四类分群**：扩量(<34%) / 观察(≈持平) / 降价(>34%) / 否词(无转化)，每条带金额化动作
5. **动作与复盘**：每条给去留建议 + 复盘窗口；品牌词误投先降竞价观察勿直接否（丢自然关联流量约 2,600 USD/月）；跟卖处置未定前不否词

【输出要求】
- 输出可直接落库的「搜索词利润诊断表.csv」结构：搜索词 / 类型 / 曝光 / 点击 / CTR / 订单 / CVR / CPC / 花费 / 销售额 / ACoS / 广告前贡献(34%) / 真实利润 / 分群 / 去留建议
- 合计行：整体 ACoS、整体真实利润、否词 3 词周省金额（应≈1,140 USD）、占已识别浪费比例

生成后自检：是否按真实利润而非 ACoS 分群？品牌词是否谨慎处理？跟卖处置前是否保留否词？确认无误再输出。
