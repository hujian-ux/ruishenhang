# PPC 搜索词与真实利润诊断 · Skill 定义

## 1. 能力定位
把"ACoS 高就停词"的条件反射，升级为"校口径 → 定位漏斗 → 利润化 → 分群 → 动作复盘"的标准诊断线。核心判断依据是**真实利润**（销售额×广告前贡献率 − 花费），而不是广告后台那个没有成本的 ACoS。

## 2. 输入
- `搜索词报告.csv`：搜索词 / 类型 / 曝光 / 点击 / CTR / 订单 / CVR / CPC / 花费 / 销售额 / ACoS
- `SKU成本与贡献率表`（案例星标素材）：给出广告前贡献率 = 盈亏平衡 ACoS，本例 **34%**

## 3. 输出
- `搜索词利润诊断表.csv`：搜索词 × 花费 × 真实利润 × 分群 × 去留建议 × 复盘窗口（18 词 + 合计行）

## 4. 工作流（5 步）
1. 口径校验：归因窗口、数据粒度、日期范围先对齐
2. 漏斗定位：曝光-点击-转化-成本逐环看哪环变了（本例 CVR 12.4%→8.1% 是主因，非流量问题）
3. 利润化：真实利润 = 销售额×34% − 花费
4. 四类分群：扩量（<34%）/ 观察（≈持平）/ 降价（>34%）/ 否词（无转化），每条带金额与复盘窗口
5. 动作与复盘：否词、调价、预算变更由人最终执行；跟卖处置未定前不否词

## 5. 关键规则
- 盈亏平衡 ACoS = 广告前贡献率（本例 34%），是唯一基准。
- ACoS 是结果不是原因：CVR 跌 / CPC 涨 / 客单价被压 / 归因错位都会推高它。
- 品牌词误投先降竞价观察，勿直接否定匹配（每月丢约 2,600 USD 自然关联流量）。
- Listing 被跟卖压价 15% → CVR 下跌 → ACoS 上升，需运营与广告对到一起。
- 高风险动作（否词、调价、预算变更、Listing 修改、跟卖处置）一律人工审批。
