# PD-01 · AI选品机会发现与多维验证 —— 场景使用说明

- **行业**：跨境电商
- **角色**：商品开发与供应链（赵晴）
- **场景编号**：PD-01
- **案例主体**：海拓生活科技（脱敏构造，与本场景库 PD-02 / PD-03 / PD-04 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/AI选品机会发现与多维验证/SKILL.md` | Skill 定义 | 六维评分口径、差评机会/伪需求判定规则、三档队列与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `经营约束.md` | 原始输入 | 5 条硬红线（R1–R5）、软约束移交规则、Q4 现金流上限、六维权重 |
| `候选商品池.csv` | 原始输入 | 180 行候选商品明细（关键词工具 + 竞品监控 + 询价 + 认证清单归一后） |
| `竞品差评样本300条.csv` | 原始输入 | 300 条竞品差评原文，已打抱怨聚类与映射机会点 |
| `选品机会验证表.csv` | **交付物** | 21 行选品证据卡：候选 × 六维评分 × 机会信号 × 风险 × 验证结论 |
| `商品开发与供应链-AI选品机会发现与多维验证.zip` | Skill 包 | 上表全部内容打包，可直接导入 WorkBuddy |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `经营约束.md`、`候选商品池.csv`、`竞品差评样本300条.csv` 三份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 「打样」候选转 PD-03 询价打样；软约束标注项转 PD-02 立项裁决。

### 可复算口径

- `采购价USD = 采购价CNY ÷ 7.25`
- `首单采购现金USD = MOQ × 采购价USD`
- `头程单件USD = 体积重kg × 1.35`
- `六维加权分 = 需求×0.25 + 竞争×0.20 + 利润×0.20 + 供应链×0.15 + 合规×0.10 + 退货×0.10`

## 五、真实性等级与边界

- **T2**：选品方法论与平台机会工具能力来自官方文档。
- **T3**：岗位痛点来自 JD 与社区。
- **构造**：候选数据与差评样本为脱敏构造，口径可复算。
- **升 T1 还缺**：客户真实选品表与一次成功/失败新品复盘。
- **人工边界**：专利/商标核查、认证可行性判断、打样与立项决定一律人工；本场景全部输出中**不出现「可立项」结论**。
