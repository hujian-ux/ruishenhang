# 商品详情图与A+内容批量生成 · Skill 定义

## 1. 能力定位
把"AI 一键出图"升级为"事实锁定 → 脚本生成 → 双检 → 选版留痕"的可控生产线，确保每张图既不失真、又不违规。

## 2. 输入
- `产品工程尺寸图.md`：SKU / 产品 / 颜色 / 结构锁定项（接口位置、卡扣方向、尺寸等不可变事实）
- `卖点证据表.csv`：SKU / 卖点 / 宣称证据 / 合规状态

## 3. 输出
- `详情图A+内容清单.csv`：6 SKU × 4 类图 × 3 方向 = 72 行（文生图 Prompt + 文案 + 结构锁定项 + 宣称证据 + 双检结果）

## 4. 工作流（4 步）
1. 事实锁定：产品不可变项清单，生成前冻结
2. 脚本生成：卖点-画面-模块一一对应，每条宣称绑定证据
3. 双检：结构一致性 + 宣称证据逐项核
4. 选版输出：人工选版，批次与上传对应关系留痕

## 5. 关键规则
- 先锁定不可变事实，生成图逐张对照工程尺寸图。
- 每条宣称必须绑定证据；无测试报告的（如「10秒速热」）改写为有依据表述（如「实测 500ml 容量刻度」）。
- 结构一致性 + 宣称证据双检，任一不符即退回。
- 最终选版与上传由人负责，需留痕；变形图与无据宣称清完前一张都不上传。
