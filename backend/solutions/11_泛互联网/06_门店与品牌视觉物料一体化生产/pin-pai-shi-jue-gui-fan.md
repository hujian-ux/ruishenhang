# 品牌视觉规范 · 某跨境母婴电商企业

> 适用范围：门店促销、门店陈列、品牌节令、品牌活动四类视觉物料的模板化生产与规格校验，由视觉运营岗统一维护口径。

## 一、品牌要素层级

- **主题色**：深海蓝 `#0052D9`（唯一主色，延展只用同色系色阶）
- **标识**：品牌标识固定标识层右上，最小留白为标识高度的二分之一
- **字体**：思源黑体家族（标题 Bold / 正文 Regular / 数字 Tabular）
- **摄影风格**：真实亲子场景，暖调滤镜仅用于照片本身，不覆盖版面

## 三、四层图层结构（先结构后风格）

所有物料按「背景层 → 主图层 → 文案层 → 标识层」四层组织：

- **背景层**：主题色 / 色带 / 延展色阶
- **主图层**：实拍图 / 插画 / 影像 / 动画元素
- **文案层**：信息三级层级（主标题 / 副标题 / 行动引导）
- **标识层**：品牌标识 / 话题标识

分层的目的：**局部替换不动全局**——改排布不改内容，改内容不改排布。

## 四、规格校验规则

1. **规格三要素** = 尺寸 + 色彩模式 + 分辨率；缺项物料先补齐标注再复检。
2. **印刷物料**：CMYK · 300dpi · 出血 3mm，交付含出血版。
3. **屏显物料**：RGB · 72dpi 及以上，按投放端适配。
4. 校验结果只有两种：**通过** / **修正后通过**（写明补齐项）——不允许「带病交付」。

## 五、产出文件口径

- **印刷物料**每项 3 件：分层源文件（.psd）+ 印刷成品（.jpg）+ 出血版（.pdf）
- **屏显物料**每项 2 件：分层源文件（.psd）+ 投放成品（.png）

## 六、硬性规则

- **R1 主题色唯一**：深海蓝 #0052D9 为唯一主色，禁引入红绿橙等对比暖色。
- **R2 内容与排布分离**：改排布不改内容，改内容不改排布。
- **R3 模板先行**：任何物料先映射模板再生产，无模板不生产。
- **R4 缺项复检**：规格三要素缺项的物料，补齐后复检通过才可定型。
- **R5 修正不重排**：多轮修正只针对被指出的图层，其余图层保持不变。
- **R6 定型需人工验收**：AI 产出全部标记「待人工验收」，不直接进投放与印刷。
