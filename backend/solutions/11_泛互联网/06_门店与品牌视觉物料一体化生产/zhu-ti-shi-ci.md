## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某跨境母婴电商企业 · 视觉物料一体化生产」按品牌规范批量生产门店与品牌视觉物料，输出一张可复核的视觉物料生产表。

【输入 1 · 视觉物料需求清单】视觉物料需求清单.csv（15 行）
- 含需求板块、物料用途、使用场景、物料类型、规格要求、品牌要素、交付形态，覆盖门店促销 / 门店陈列 / 品牌节令 / 品牌活动四类
- 规格三要素 = 尺寸 + 色彩模式 + 分辨率，缺项物料须补齐标注后复检

【输入 2 · 品牌视觉规范】品牌视觉规范.md
- 主题色深海蓝 #0052D9，五套模板库，四层图层结构（背景 / 主图 / 文案 / 标识），内容与排布分离
- 印刷 CMYK · 300dpi · 出血 3mm 交付 3 件，屏显 RGB · 72dpi 交付 2 件

【输出】视觉物料生产表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「门店与品牌视觉物料一体化生产」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **15 项需求怎么映射模板的？** 期望回答：五套模板全覆盖——T01 促销海报 3 项（主视觉 / 折扣 / 节令海报）、T02 促销卡片 3 项（跳跳卡 / 立牌 / 贺卡）、T03 陈列物料 3 项（头卡 / 围挡 / 腰封）、T04 社交图 5 项（banner / 社交图 / 头图 / 封面 / 长图）、T05 动态分镜 1 项（分镜稿）。
2. **为什么 V02 / V10 / V13 是「修正后通过」？** 期望回答：三项的规格要求缺色彩模式与分辨率标注，按 R4 补齐（印刷 CMYK · 300dpi、屏显 RGB · 72dpi）后复检通过——不允许带病交付。
3. **改配色会不会牵动内容？** 期望回答：不会。四层图层结构下，主题色只动背景层，文案层与标识层保持不变——改排布不改内容，改内容不改排布。
4. **一共产出多少个文件？** 期望回答：38 件——印刷物料 8 项 × 3 件（分层源文件 + 印刷成品 + 出血版），屏显物料 7 项 × 2 件（分层源文件 + 投放成品）。
5. **为什么全是「待人工验收」？** 期望回答：R6 规定 AI 产出不直接进投放与印刷，最终视觉验收与下印决定属于人。
