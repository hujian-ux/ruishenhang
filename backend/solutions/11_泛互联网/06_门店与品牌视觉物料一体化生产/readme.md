## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `视觉物料需求清单.csv`、`品牌视觉规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 人工验收通过后下印 / 投放；分镜稿转三维动画效果生成环节。

### 可复算口径

- `映射模板` = 按物料类型关键词匹配（分镜 / 头卡·围挡·腰封 / banner·媒体图·头图·封面·长图 / 海报 / 卡·立牌）
- `规格校验` = 尺寸 + 色彩模式 + 分辨率三要素齐备即通过；缺项补齐（印刷 CMYK · 300dpi / 屏显 RGB · 72dpi）后复检通过
- `产出文件数` = 印刷 3 件 / 项 + 屏显 2 件 / 项（本例 8×3 + 7×2 = 38）

## 五、真实性等级与边界

- **T2**：图像生成与分层生产能力来自官方文档。
- **T3**：门店与品牌物料痛点来自案例素材。
- **构造**：需求清单与生产表口径可复算。
- **升 T1 还缺**：客户真实品牌规范手册与一轮门店物料下印回执。
- **人工边界**：品牌规范修订、最终视觉验收、投放与下印决定一律人工；AI 只出模板映射、校验结果与产出清单。
