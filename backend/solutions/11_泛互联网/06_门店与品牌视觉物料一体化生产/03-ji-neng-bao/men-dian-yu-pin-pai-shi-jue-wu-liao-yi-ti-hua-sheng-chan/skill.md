# 门店与品牌视觉物料一体化生产

## 一、这个 Skill 解决什么

门店与品牌物料的真实困难不是「不会设计」，而是**设计与文案分头走、改版要排期**：

- 门店海报找设计、活动文案找策划，往返沟通多，一轮改版重新排期
- 内容与排布绑死在一起，改个配色带动整版重做
- 促销、陈列、节令、活动四类物料各做各的，品牌规范靠口头传达
- 印刷件缺出血、屏显件色彩模式错，问题到交付前才发现

本 Skill 的核心动作：**先结构后风格**——所有物料先映射模板、拆四层，再按品牌规范填充，改排布不改内容，改内容不改排布。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 门店开业 / 周年庆 / 大促需要一批物料 | 主用场景：四类需求一次进清单，批量产出 |
| 节令 / 活动视觉要贴品牌规范 | 主题色、标识、字体按规范强制套用 |
| 改版频繁、内容排布反复调 | 四层结构局部替换，修正不重排 |
| 印刷与屏显双形态交付 | 按各自口径校验规格并输出对应成品清单 |

**不适用**：完全脱离品牌模板的定制艺术创作；需要专业三维渲染成片的视频制作（本场景只产出分镜稿与封面）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `视觉物料需求清单.csv` | 必需 | 序号、需求板块、物料用途、使用场景、物料类型、规格要求、品牌要素、交付形态 |
| 2 | `品牌视觉规范.md` | 必需 | 品牌要素层级、五套模板库、四层图层结构、规格校验规则、产出文件口径、R1-R6 硬性规则 |

> 缺 2（品牌视觉规范）时，本 Skill **必须拒绝生产**——没有模板与主题色约束的批量出图，等于批量产出废稿。这是本 Skill 最重要的一条硬规则。

## 四、输出（outputs）

唯一交付物：`视觉物料生产表.csv`，字段固定为 12 列：

```
序号, 需求板块, 物料用途, 使用场景, 物料类型, 映射模板, 规格校验结果,
图层结构, 品牌要素应用, 产出文件清单, 生产方式, 交付状态
```

- `映射模板` ∈ {T01 促销海报模板, T02 促销卡片模板, T03 陈列物料模板, T04 社交图模板, T05 动态分镜模板}
- `规格校验结果` 只有两种：通过 / 修正后通过（写明补齐项），不允许「带病交付」
- `交付状态` 全部含「待人工验收」——AI 不直接定型

## 五、工作流程（workflow）

### STEP 1 · 模板映射（R3 模板先行）

按物料类型关键词把每项需求映射到五套模板之一。**无模板不生产**——映射失败的物料先补模板或调整类型。

### STEP 2 · 四层结构拆解

按「背景层 → 主图层 → 文案层 → 标识层」拆解物料：主题色与色带归背景层，实拍 / 插画 / 影像 / 动画元素归主图层，信息层级归文案层，品牌标识归标识层。

### STEP 3 · 规格三要素校验（R4 缺项复检）

尺寸 + 色彩模式 + 分辨率逐项核对：印刷件 CMYK · 300dpi · 出血 3mm；屏显件 RGB · 72dpi 及以上。缺项物料补齐标注后复检，结果只有「通过 / 修正后通过」两种。

### STEP 4 · 产出文件清单生成

印刷物料每项 3 件（分层源文件 .psd + 印刷成品 .jpg + 出血版 .pdf）；屏显物料每项 2 件（分层源文件 .psd + 投放成品 .png）。

### STEP 5 · 自检与人工边界声明

输出前逐项自检（见附录），任一不过则不得输出；全部产出标记「待人工验收」。

## 六、关键规则（不可协商）

1. **主题色唯一。** 深海蓝 #0052D9 为唯一主色，禁引入红绿橙等对比暖色。
2. **内容与排布分离。** 改排布不改内容，改内容不改排布——四层结构是这条规则的落地形态。
3. **模板先行。** 先映射模板再生产；无模板的物料先补模板，不裸做。
4. **缺项复检。** 规格三要素缺项必须补齐后复检通过才可定型，不允许「带病交付」。
5. **修正不重排。** 多轮修正只针对被指出的图层，其余图层保持不变。
6. **定型需人工验收。** AI 产出全部标记「待人工验收」，不直接进投放与印刷；不承诺效率百分比。

## 七、人工边界

| AI 负责 | 人负责 |
| --- | --- |
| 模板映射与四层结构拆解 | 品牌规范的修订与定稿 |
| 规格校验与缺项复检 | 最终视觉验收与投放 / 下印决定 |
| 产出文件清单生成 | 多轮修正意见的提出与范围指定 |

## 八、下游衔接

- 「待人工验收」物料 → 人工验收后下印 / 投放
- 分镜稿 → 三维动画效果生成环节
- 复盘与汇报 → 汇报展示材料（统一主题色）输出


## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读规范再生产：把五套模板映射规则与规格校验规则写成显式判定表，不要边做边定标准。
2. 模板映射：按物料类型关键词（分镜 / 头卡·围挡·腰封 / banner·媒体图·头图·封面·长图 / 海报 / 卡·立牌）将 15 项需求逐一映射到 T01-T05 模板，映射失败的先补模板。
3. 四层拆解：品牌要素按关键词归入背景层（主题色 / 色带）、主图层（实拍 / 插画 / 影像 / 动画）、文案层（文案 / 层级 / 短语 / 背书）、标识层（标识），逐要素写明归属。
4. 规格校验：核对规格三要素（尺寸 + 色彩模式 + 分辨率）；缺项物料补齐印刷 CMYK · 300dpi 或屏显 RGB · 72dpi 后复检，结果写明补齐项。
5. 产出清单：印刷物料每项 3 件（分层源文件 + 印刷成品 + 出血版），屏显物料每项 2 件（分层源文件 + 投放成品），逐项列出文件名。

### 硬性约束

【硬性约束】
- 主题色唯一：深海蓝 #0052D9 为唯一主色，全表禁出现红绿橙等对比暖色描述。
- 内容与排布分离：修正只针对被指出的图层，其余图层保持不变。
- 无模板不生产；规格三要素缺项必须补齐复检，不允许「带病交付」。
- 交付状态全部含「待人工验收」，AI 不直接定型进投放与印刷。
- 不写绝对化表述与效率百分比。

### 生成后自检

【生成后自检，逐条回答】
1. 交付物是否 15 行、12 列，与需求清单逐行对应？
2. 模板映射是否 5 套全覆盖（T01=3 / T02=3 / T03=3 / T04=5 / T05=1）？
3. 规格校验是否 15/15 通过（直接 12 + 修正后 3，修正项为 V02 / V10 / V13）？
4. 产出文件是否 = 印刷 8×3 + 屏显 7×2 = 38 件，逐行列出文件名？
5. 是否全表无红绿橙描述、交付状态全部「待人工验收」？
自检全过再输出 CSV。

【输出格式】CSV，12 列，列名与顺序固定：
序号, 需求板块, 物料用途, 使用场景, 物料类型, 映射模板, 规格校验结果, 图层结构, 品牌要素应用, 产出文件清单, 生产方式, 交付状态
