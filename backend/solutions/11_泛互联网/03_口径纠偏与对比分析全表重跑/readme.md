## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `口径规则版本记录.csv`、`报表数据样本.csv`、`重跑机制.md` 三份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 高影响 5 项推送战区复核，确认差异可解释后按 INT-01 机制刷新看板（登记台账、不覆盖历史）。

### 断言项

| 断言 | 结果 |
| --- | --- |
| 三个文件存在且数据行 = 15 / 20 / 20 | 通过 |

### 可复算口径

- `差异额 = 新口径值 − 旧口径值`（保留位数随单位：万元 / 百分比 1 位小数，个 / 元取整）
- `差异率 =（新口径值 − 旧口径值）÷ 旧口径值`（1 位小数，带符号）
- 影响等级：|差异率| ≥8% 高 / 3%–8% 中 / >0% 且 <3% 低 / =0% 无变化

## 五、真实性等级与边界

- **素材来源**：即时零售连锁企业的口径纠偏实践——采购成本新口径公式落地、门店状态去重规则变更、底表来源指定、规则一变全表重跑。
- **构造**：规则与样本数据为可复算口径，全部差异量化由脚本从输入行计算。
- **人工边界**：对照表只呈现变更差异与影响等级，不判定口径对错；高影响行的业务解释与处置由战区负责人与口径提出方复核决定。
