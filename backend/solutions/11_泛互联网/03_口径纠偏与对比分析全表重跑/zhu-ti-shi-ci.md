# INT-03 主提示词 · 口径纠偏与对比分析全表重跑

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/口径纠偏与对比分析全表重跑/SKILL.md`）。
2. 上传三个附件：`口径规则版本记录.csv`、`报表数据样本.csv`、`重跑机制.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `口径纠偏重跑对照表.csv` 后，按文末「验收清单」逐项核对。

## 主提示词（复制即用）

```
请基于我上传的三份素材，为「某即时零售企业 · 口径纠偏与全表重跑」做变更差异量化，输出一张可复核的口径纠偏重跑对照表。

【输入 1 · 口径规则版本记录】口径规则版本记录.csv（15 行）
- 每条规则含旧口径、新口径、生效日期与变更原因，是重跑的规则基准
- 样本中的涉及规则编号必须能在此表中找到对应行

【输入 2 · 报表数据样本】报表数据样本.csv（20 行）
- 每行为某门店某指标的旧口径值与新口径值，附涉及规则编号
- 归属类调整（如新店爬坡期单独列示）数值可能不变，按「无变化」处理

【输入 3 · 重跑机制】重跑机制.md
- 差异率 =（新值−旧值）÷ 旧值；影响等级：|差异率| ≥8% 高 / 3%–8% 中 / <3% 低 / 0% 无变化
- 规则一变即全表重跑，禁止局部修补；重跑动作只取机制中的四个固定值

【输出】口径纠偏重跑对照表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「口径纠偏与对比分析全表重跑」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **影响最大的差异是哪一项，为什么？** 期望回答：月泉店呆滞库存SKU数 +33.3%（96 → 128）——R14 把判定阈值从 60 天收紧到 45 天，原「正常」库存中有 32 个 SKU 被重新判为呆滞，属上调型高影响。
2. **为什么有 18 项下调、只有 1 项上调？** 期望回答：本轮规则多指向挤水分——R01 剔除平台补贴、R12 配送费移出毛利、R05 剔除已下架商品，多数新口径都比旧口径「更瘦」；只有 R14 的收紧型规则产生了上调。
3. **银杏店月销售额差异率 0.0%，为什么还在表里？** 期望回答：它涉及 R11「新店爬坡期单独列示」——归属类调整数值不变、列示位置变，按「无变化」等级处理，动作是「归属调整 · 保留单列标注」。
4. **高影响的 5 项分别为什么高？** 期望回答：|差异率| ≥ 8%——朝晖店月销售额 -9.3%（R01）、翠湖店月毛利 -11.0%（R12）、石桥店月销售额 -9.0%（R01）、月泉店呆滞库存SKU +33.3%（R14）、兰亭店促销费用分摊 -23.7%（R07）。
5. **15 条规则为什么只有 10 条出现在对照表里？** 期望回答：规则版本记录是完整规则库，本轮 20 行样本只覆盖其中 10 条；其余 5 条（如 R03 门店状态去重、R09 门店在册口径）的数据源不在本样本底表中。

## 验收清单

- [ ] 输出为 20 行、14 列，行序按门店编号升序
- [ ] 影响等级分布 = 高 5 / 中 12 / 低 2 / 无变化 1
- [ ] 差异方向 = 下调 18 / 上调 1 / 无变化 1（仅月泉店呆滞库存SKU +33.3% 为上调）
- [ ] 每行差异率 =（新值 − 旧值）÷ 旧值，保留 1 位小数并带符号
- [ ] 高影响 5 项均挂「全表重跑 · 推送战区复核」；银杏店月销售额挂「归属调整 · 保留单列标注」
- [ ] 全表无口径对错判定（如「新口径更合理」）、无经营结论、无效率承诺
