# INT-04 主提示词 · 工作日志定时自驱生成

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/工作日志定时自驱生成/SKILL.md`）。
2. 上传两个附件：`工作记录流水.csv`、`日志模板规范.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `工作日志生成表.csv` 后，按文末「验收清单」逐项核对。

---

## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某跨境母婴电商企业 · 工作日志定时自驱生成」汇总各岗位碎片工作记录，输出一张可复核的工作日志生成表。

【输入 1 · 工作记录流水】工作记录流水.csv（25 行）
- 含日期、岗位、姓名、事项、所属项目、完成状态、耗时分钟，覆盖 4 个岗位 × 5 个工作日
- 同一人同一天可有多条记录，汇总时须合并；完成状态只认「已完成 / 进行中」两类

【输入 2 · 日志模板规范】日志模板规范.md
- 板块固定为已完成 / 进行中 / 明日计划，明日计划只能由当日进行中事项滚动推导
- 每日 17:30 定时自驱生成草稿，人工确认后提交，全表状态为「草稿待人工确认」

【输出】工作日志生成表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「工作日志定时自驱生成」技能执行（技能附录含本案例完整执行细则）。
```

---

## 本案例的关键追问（拿到结果后必须问）

1. **25 条流水怎么变成 26 行的？** 期望回答：按人×日合并出 20 份人日日报（4 人 × 5 个工作日，每天必有记录），加 6 个项目归集行（保税仓大促备货 7 / 婴幼儿益生菌上新 5 / 门店周年庆 5 / 店铺日常维护 3 / 转奶期奶粉专题 3 / 高端纸尿裤种草 2）。
2. **耗时合计怎么核？** 期望回答：流水 25 条耗时之和 = 人日行合计 = 项目行合计 = 1,930 分钟（约 32.2 小时），三本账必须相等。
3. **明日计划是编的吗？** 期望回答：不是。7 条进行中事项（R005 / R007 / R011 / R014 / R019 / R022 / R025）全部原样滚动为对应日志的「继续推进」项，无一条虚构。
4. **为什么全是草稿状态？** 期望回答：规范要求「提交前确认」——先生成草稿供人工检查，确认后才提交，AI 不代提交。
5. **周报怎么处理？** 期望回答：项目归集视角只做周报板块补录，不重新生成整份周报；日期记项目记录的最早日至最迟日。

## 验收清单

- [ ] 26 行输出 = 按人按日 20 + 项目归集 6
- [ ] 耗时三本账相等：流水 1,930 = 人日合计 1,930 = 项目合计 1,930
- [ ] 进行中 7 条（R005 / R007 / R011 / R014 / R019 / R022 / R025）全部滚动进明日计划
- [ ] 项目归集条数分布 = 大促备货 7 / 益生菌上新 5 / 门店周年庆 5 / 日常维护 3 / 转奶专题 3 / 纸尿裤种草 2
- [ ] 全表提交状态 = 草稿待人工确认，无一行「已提交」
