# INT-04 · 工作日志定时自驱生成 —— 场景使用说明

- **行业**：泛互联网
- **角色**：运营支持岗（姜芸）
- **场景编号**：INT-04
- **案例主体**：某跨境母婴电商企业（与本场景库 INT-05 / INT-06 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/工作日志定时自驱生成/SKILL.md` | Skill 定义 | 双视角汇总口径、板块结构、R1-R6 硬性规则、定时自驱与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `工作记录流水.csv` | 原始输入 | 25 行碎片记录：4 岗位 × 5 个工作日 × 6 个项目 |
| `日志模板规范.md` | 原始输入 | 板块结构、双视角汇总口径、R1-R6 硬性规则、17:30 定时触发 |
| `工作日志生成表.csv` | **交付物** | 26 行：20 份人日日报 + 6 个项目归集行 |
| `运营支持岗-工作日志定时自驱生成.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `工作记录流水.csv`、`日志模板规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 人工确认草稿后提交；项目归集行补进周报对应板块。

### 可复算口径

- `事项条数` = 该视角下流水行数
- `耗时合计分钟` = 该视角下「耗时分钟」之和
- `明日计划` = 「继续推进：」+ 当日进行中事项合并；无则记「无进行中事项，按排期接续」

## 四、与案例链的数字对齐

| 数字 | 出处 | 在本场景的落点 |
| --- | --- | --- |
| 25 条流水 → 20 份日报 + 6 个项目归集 | 案例钩子 | 交付物 26 行结构 |
| 定时触发、无需人工提醒 | 素材模式一 | 生成方式列「定时自驱（每日17:30触发）」 |
| 周报补录而非重写 | 素材案例一 | 项目归集行「周报板块补录」口径 |
| 口径纠偏（日报/周报混称） | 素材案例一 | 规范 R6 + 日志颗粒度条款 |
| 提交前确认、避免误报 | 素材案例一 | 全表「草稿待人工确认」 |
| 进行中事项滚动 | 素材「明日/本月归类」 | 明日计划列推导规则 |

## 五、真实性等级与边界

- **T2**：定时自驱与技能封装能力来自官方文档。
- **T3**：岗位痛点来自案例素材。
- **构造**：流水与交付物口径可复算。
- **升 T1 还缺**：客户真实日志系统导出与一次完整周期回放。
- **人工边界**：事项取舍判断、明日计划合理性确认、最终提交与补录一律人工；AI 只输出草稿。
