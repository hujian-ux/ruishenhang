# 商品内容按卖点批量生产与收敛

## 一、这个 Skill 解决什么

母婴内容投放的真实困难不是「写不出」，而是**产能与口径两头受挤**：

- 同一款产品要从肠道呵护、脑部发育、转奶衔接等不同角度反复输出，一篇一篇写产能受限
- 纯 AI 一次性生成容易千篇一律，换个角度写卖点就丢了
- 返工往往要整篇重写，前面已经合格的内容跟着陪葬
- 哪篇能上、哪篇该毙，评审时说不清依据，靠嗓门定

本 Skill 的核心动作：把「生产」与「收敛」拆成两个独立动作交给流程——**效率来自批量，质量来自收敛**，每一步的判定都有成文规则。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 一款商品要多角度铺一批种草内容 | 主用场景：一次批量出稿，多角度覆盖 |
| 改写过程中卖点总被写丢 | 核心卖点硬约束，三版逐条校验 |
| 评审说不清哪篇能上 | 按淘汰 / 备选 / 上线三级口径收敛，依据成文 |
| 只想改某一段不想整篇重写 | V3 定点收敛，其余段落保持原文 |

**不适用**：门店活动的满减、赠品、适用期限等规则化描述（另行补充，不进本表）；一次性单篇的深度测评长文。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `商品卖点素材清单.csv` | 必需 | 序号、商品名称、目标人群、卖点角度、核心卖点、辅助要素、投放渠道、内容形式 |
| 2 | `内容生产与收敛规范.md` | 必需 | 三版演化规则、收敛判定优先级、R1-R6 硬性规则 |

> 缺「核心卖点」列时，本 Skill **必须拒绝批量生成**——没有硬约束的批量出稿，只会产出 18 篇不达标的废稿。这是本 Skill 最重要的一条硬规则。

## 四、输出（outputs）

唯一交付物：`商品内容生产收敛表.csv`，字段固定为 13 列：

```
序号, 商品名称, 目标人群, 卖点角度, V1初稿要点, V2换角度重写要点, V3定点收敛稿要点,
核心卖点保留校验, 收敛结论, 收敛依据, 上线标记, 投放渠道, 内容形式
```

- `核心卖点保留校验` 逐条回答三版是否均含卖点原文
- `收敛结论` ∈ {上线, 备选, 淘汰}，`上线标记` 对应为 {是, 备选, 否}
- `收敛依据` 必须引用成文规则（要素计数 / 一渠一文），**不允许写「综合判断」**

## 五、工作流程（workflow）

### STEP 1 · 定卖点，先立硬约束

从素材清单提取每条素材的核心卖点原文，写成显式校验表。**任何一轮改写的第一检验都是它**。

### STEP 2 · 批量出稿（V1 → V2 → V3）

每条素材固定三版：V1 按素材要素直接成稿；V2 换视角重新切入、卖点移位强化；V3 只对指定段落定点收敛，其余保持 V2 原文。**一次覆盖全部素材，不逐条发起**。

### STEP 3 · 卖点校验

逐条核对三版要点是否均含核心卖点原文——换角度是换切入视角，不是换卖点。未通过者不得进入收敛。

### STEP 4 · 三级收敛（按优先级）

| 结论 | 判定条件 | 依据 |
| --- | --- | --- |
| 淘汰 | 辅助要素不足 2 项 | 卖点支撑不足，改写补不出来 |
| 备选 | 同商品同渠道已有上线条目 | 一渠一文，第二条等排期 |
| 上线 | 卖点三版保留 + 要素 ≥2 项 + 渠道无冲突 | 进入投放 |

### STEP 5 · 自检与人工边界声明

输出前逐项自检（见附录），任一不过则不得输出；最终投放决定与渠道排期属于人。

## 六、关键规则（不可协商）

1. **卖点不丢。** 核心卖点原文贯穿 V1/V2/V3 三版，校验列逐条回答。
2. **批量与收敛分开。** 批量出稿阶段不做质量判断，收敛阶段单独逐轮执行——两个动作混在一起，比一次性要求高质量更不可控。
3. **定点返工。** V3 只改指定段落，前面版本合格内容保持不变，不整篇重写。
4. **一渠一文。** 同商品同渠道只保留首条上线，其余转备选库。
5. **淘汰留依据。** 每条淘汰 / 备选都要写明规则依据，不允许「综合判断」。
6. **用语边界。** 不写绝对化功效表述，母婴品类用语遵守广告法边界；不承诺效率百分比。

## 七、人工边界

| AI 负责 | 人负责 |
| --- | --- |
| 三版批量生产与卖点校验 | 核心卖点的最终确认 |
| 三级收敛与依据成文 | 投放渠道与排期决定 |
| 一渠一文冲突识别 | 备选库启用与返工范围指定 |

## 八、下游衔接

- 「上线」条目 → 按投放渠道格式输出，进入投放
- 「备选」条目 → 备选库等排期空位，或换渠道后重评
- 本场景素材清单的要素字段 → 上游由选品与卖点拆分环节维护


## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读规范再出稿：把三版演化规则与收敛判定优先级写成显式判定表，不要边写边定标准。
2. 批量出稿：每条素材固定走 V1 初稿 → V2 换角度重写 → V3 定点收敛三个版本，一次覆盖全部 18 条素材，不逐条发起。
3. 卖点校验：逐条核对三版要点是否均含「核心卖点」原文，未通过者不得进入收敛。
4. 三级收敛按优先级执行：辅助要素不足 2 项判淘汰 → 同商品同渠道已有上线条目按一渠一文转备选 → 其余判上线。
5. 收敛依据必须引用成文规则（要素计数 / 一渠一文），写明要素项数或冲突条目。

### 硬性约束

【硬性约束】
- 核心卖点原文贯穿三版，任何一轮改写不得丢失，校验列逐条回答。
- V3 只做定点收敛，指定段落之前的合格内容保持不变，不整篇重写。
- 辅助要素按「、」分隔计数，不足 2 项判淘汰。
- 同商品同渠道只保留首条上线，其余转备选。
- 不写绝对化功效表述与效率百分比，母婴品类用语遵守广告法边界。

### 生成后自检

【生成后自检，逐条回答】
1. 交付物是否 18 行、13 列，与素材清单逐行对应？
2. 收敛分布是否 = 上线 12 / 备选 3 / 淘汰 3？
3. 淘汰 3 条（S03 / S06 / S18）是否均因辅助要素仅 1 项？
4. 备选 3 条（S08 / S14 / S17）是否均为同商品同渠道冲突，且无同渠道双上线？
5. 18 条的三版要点是否均含核心卖点原文，校验列全部「通过」？
自检全过再输出 CSV。

### 输出格式

【输出格式】CSV，13 列，列名与顺序固定：
序号, 商品名称, 目标人群, 卖点角度, V1初稿要点, V2换角度重写要点, V3定点收敛稿要点, 核心卖点保留校验, 收敛结论, 收敛依据, 上线标记, 投放渠道, 内容形式
