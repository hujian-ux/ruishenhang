# INT-05 · 商品内容按卖点批量生产与收敛 —— 场景使用说明

- **行业**：泛互联网
- **角色**：商品内容岗（纪云舒）
- **场景编号**：INT-05
- **案例主体**：某跨境母婴电商企业（与本场景库 INT-04 / INT-06 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/商品内容按卖点批量生产与收敛/SKILL.md` | Skill 定义 | 三版演化规则、三级收敛口径、卖点硬约束、一渠一文与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `商品卖点素材清单.csv` | 原始输入 | 18 行素材：6 款商品 × 3 个卖点角度，含核心卖点与辅助要素 |
| `内容生产与收敛规范.md` | 原始输入 | 三版演化规则、收敛判定优先级、R1-R6 硬性规则 |
| `商品内容生产收敛表.csv` | **交付物** | 18 行：V1/V2/V3 三版要点 + 卖点校验 + 收敛结论与上线标记 |
| `商品内容岗-商品内容按卖点批量生产与收敛.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `商品卖点素材清单.csv`、`内容生产与收敛规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 「上线」条目按渠道格式投放；「备选」条目入库等排期空位。

### 断言项

| 断言 | 结果 |
| --- | --- |
| 两个文件存在且 size > 0 | 通过 |

| 备选 3 条（S08 / S14 / S17）均因同商品同渠道冲突，无同渠道双上线 | 通过 |

| 6 款商品每款至少 1 条上线 | 通过 |

### 可复算口径

- `版本数` = 素材条数 × 3（本例 18 × 3 = 54 版）
- `辅助要素项数` = 辅助要素列按「、」分隔计数，<2 项判淘汰
- `一渠一文` = 同商品同渠道按序号顺序只保留首条上线
- `上线标记` = 上线→是 / 备选→备选 / 淘汰→否

## 五、真实性等级与边界

- **T2**：批量内容生产与技能封装能力来自官方文档。
- **T3**：岗位痛点与角度切换需求来自案例素材。
- **构造**：素材清单与收敛结果口径可复算。
- **升 T1 还缺**：客户真实内容评审记录与一轮投放数据回流。
- **人工边界**：核心卖点最终确认、投放渠道与排期决定、备选库启用一律人工；AI 只出三版要点与收敛依据。
