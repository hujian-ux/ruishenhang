# INT-05 主提示词 · 商品内容按卖点批量生产与收敛

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/商品内容按卖点批量生产与收敛/SKILL.md`）。
2. 上传两个附件：`商品卖点素材清单.csv`、`内容生产与收敛规范.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `商品内容生产收敛表.csv` 后，按文末「验收清单」逐项核对。

## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某跨境母婴电商企业 · 商品内容批量生产」按卖点角度批量生产并收敛内容，输出一张可复核的商品内容生产收敛表。

【输入 1 · 商品卖点素材清单】商品卖点素材清单.csv（18 行）
- 含商品名称、目标人群、卖点角度、核心卖点、辅助要素、投放渠道、内容形式，6 款商品 × 3 个卖点角度
- 核心卖点为硬约束，任何一轮改写都不得丢失原文

【输入 2 · 内容生产与收敛规范】内容生产与收敛规范.md
- 每条素材固定走 V1 初稿 → V2 换角度重写 → V3 定点收敛 三个版本
- 收敛按优先级判定：辅助要素不足 2 项淘汰 → 同商品同渠道一渠一文转备选 → 其余上线

【输出】商品内容生产收敛表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「商品内容按卖点批量生产与收敛」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **18 条素材一共出了几版内容？** 期望回答：54 版——每条固定 V1 初稿 / V2 换角度重写 / V3 定点收敛三版，批量一次覆盖。
2. **为什么 S03 / S06 / S18 被淘汰？** 期望回答：三条的辅助要素都只有 1 项（独立包装便携 / 饱腹感更持久 / 旅行装便携），卖点支撑不足，改写补不出来，按规则判淘汰。
3. **为什么 S08 / S14 / S17 只能备选？** 期望回答：三条各自与同商品的另一条撞在同一投放渠道（S08 与 S07 同为种草笔记、S14 与 S13 同为种草笔记、S17 与 S16 同为详情页），按一渠一文规则第二条转备选库。
4. **换角度重写时卖点怎么保证不丢？** 期望回答：核心卖点作为硬约束写进规范 R1，三版要点逐条校验，18/18 全部通过——换角度是换切入视角，不是换卖点。
5. **返工为什么要整篇重写？** 期望回答：不需要。V3 只做定点收敛，指定段落之前的合格内容保持 V2 原文不变。

## 验收清单

- [ ] 18 行输出，收敛分布 = 上线 12 / 备选 3 / 淘汰 3
- [ ] 淘汰 3 条 = S03 / S06 / S18，均因辅助要素仅 1 项
- [ ] 备选 3 条 = S08 / S14 / S17，均因同商品同渠道一渠一文，且无同渠道双上线
- [ ] 核心卖点保留校验 18/18 通过，三版要点均含卖点原文
- [ ] 6 款商品每款至少 1 条上线，收敛依据均引用成文规则
