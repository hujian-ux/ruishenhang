# INT-02 · 跨仓跨期跨平台批量报表与自动化 —— 场景使用说明

- **行业**：泛互联网（即时零售）
- **角色**：数据运营岗
- **场景编号**：INT-02
- **案例主体**：某即时零售企业（与本场景库 INT-01 / INT-03 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/跨仓跨期跨平台批量报表与自动化/SKILL.md` | Skill 定义 | 汇总口径、环比公式与标记阈值、无人值守自动化机制与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |

| `跨仓跨期汇总报表.csv` | **交付物** | 15 行（仓库 × 平台）：两期 GMV / 订单量并列 + 环比 + 标记 + 推送提示 |
| `数据运营岗-跨仓跨期跨平台批量报表与自动化.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `多仓多平台数据.csv`、`批量报表规则.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 把成表动作挂到每日 08:30 的无人值守定时任务，推送业务群；回落组合转仓储与战区负责人复核。

### 断言项

| 断言 | 结果 |
| --- | --- |
| 两个文件存在且数据行 = 30 / 15 | 通过 |
| 环比标记分布 = 增长 8 / 持平 4 / 回落 3 | 通过 |
| 回落组合 = WH03×外卖平台A / WH03×外卖平台B / WH04×外卖平台B，均 ≤ -5% | 通过 |
| 15 行 GMV 环比逐行复算（（本期 − 上期）÷ 上期）一致 | 通过 |
| 15 行本期客单价 × 订单量与 GMV 一致（±取整误差内） | 通过 |
| 推送提示与标记一一匹配（回落→置顶，其余→常规） | 通过 |
| 推送提示全部来自规则文件两个固定值 | 通过 |

### 可复算口径

- `GMV 环比 =（本期 GMV − 上期 GMV）÷ 上期 GMV`；`订单量环比 =（本期订单量 − 上期订单量）÷ 上期订单量`
- `本期客单价 = 本期 GMV ÷ 本期订单量`（1 位小数）
- 期间口径：上期 = 2026-08 全月；本期 = 2026-09 截至昨日（T-1，9 月 15 日）

## 五、真实性等级与边界

- **素材来源**：即时零售连锁企业的定时任务实践——跨仓要货金额汇总、无人值守无头运行、报表群推送、异常重跑与看板刷新。
- **构造**：仓 / 平台 / 期间数据为可复算口径，全部环比与客单价由脚本从输入行计算。
- **人工边界**：报表只呈现环比事实与推送提示；回落组合的处置由仓储与战区负责人复核决定，AI 不下补货 / 调仓结论。
