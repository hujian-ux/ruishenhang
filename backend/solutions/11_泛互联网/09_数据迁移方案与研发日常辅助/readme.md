## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `数据迁移清单.csv`、`迁移与辅助规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 「重建映射」2 张表转映射模型评审（工程师确认后方可执行）；「双轨并行」2 张表转割接方案，明确并行窗口与撤轨条件。

### 可复算口径

- `字段对齐率 = 可直连字段数 ÷ 字段总数`；直连 ≥90% / 转换 60%-89% / 重建 <60%
- `清洗动作`：按关键词优先级归类（权限重挂 > 去重与结构归并 > 编码归一 > 格式标准化 > 补默认值）
- `迁移策略`：在途业务表（源表名或目标平台表名含在途/待办）→ 双轨并行；风险提示含体量大/量大 → 分批增量；其余 → 停机窗口
- `研发辅助`：待确认 → 文档补全 > 重建 → 评审清单 > 转换 → 映射初稿 > 直连 → 校验脚本

## 五、真实性等级与边界

- **T2**：数据迁移方法论（映射三档 / 双轨并行 / 分批增量）来自政企系统切换交付实践。
- **T3**：迁移清单按协同办公领域常见表结构构造，口径可复算。
- **升 T1 还缺**：客户真实迁移清单与割接复盘记录。
- **人工边界**：重建表映射模型确认、每批迁移放行裁决、割接窗口与回滚决策一律人工；AI 只出初稿、脚本、清单与留痕。
