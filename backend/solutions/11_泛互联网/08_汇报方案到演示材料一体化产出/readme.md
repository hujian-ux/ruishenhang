# INT-08 · 汇报方案到演示材料一体化产出 —— 场景使用说明

- **行业**：泛互联网
- **角色**：方案咨询岗（沈屹）
- **场景编号**：INT-08
- **案例主体**：某协同办公软件企业（与本场景库 INT-07 / INT-09 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/汇报方案到演示材料一体化产出/SKILL.md` | Skill 定义 | 版式规范、演示环节规则、时长分配、讲稿口径与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `方案素材要点.csv` | 原始输入 | 15 行方案素材（章节/痛点/方案能力/案例引用），对应 15 页材料 |
| `演示材料框架.md` | 原始输入 | 五类版式规范、3 处演示环节规则、40 分钟时长表、讲稿撰写规范 |
| `汇报与演示材料表.csv` | **交付物** | 15 页材料：PPT 章节标题 × 版式 × 演示步骤 × 讲稿要点 × 时长 |
| `gen_INT-08.py` | 生成脚本 | 从两份输入按框架规则计算生成交付物，含断言 |
| `方案咨询岗-汇报方案到演示材料一体化产出.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `方案素材要点.csv`、`演示材料框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 「内容页·演示型」3 页转现场演示准备（环境、账号、脱敏数据核查）；材料表作为 PPT 制作与讲稿定稿底稿。

## 三、交付物验证记录

生成脚本以 Python 标准库 `csv` 实际写出文件，并在脚本内做断言验证。执行结果：

```

总时长 40 分钟；演示型 3 页合计 12 分钟
```

### 断言项

| 断言 | 结果 |
| --- | --- |
| 输入 15 行、输出 15 行 7 列 | 通过 |
| 版式分布 = 封面 1 / 目录 1 / 章节页 3 / 演示型 3 / 讲解型 6 / 结尾 1 | 通过 |
| 总时长 = 40 分钟（2+1+1×3+4×3+2.5×6+7） | 通过 |
| 演示型 3 页合计 = 12 分钟 | 通过 |
| 演示环节定位 = S-06 统一门户 / S-07 公文管理 / S-09 流程审批 | 通过 |
| 章节页定位 = 第一篇现状与挑战 / 第二篇核心方案 / 第三篇实施与保障 | 通过 |
| 每页讲稿要点 2-4 条 | 通过 |

### 可复算口径

- `时长分配 = 封面 2 + 目录 1 + 章节页 1×3 + 演示型内容页 4×3 + 讲解型内容页 2.5×6 + 结尾页 7 = 40 分钟`
- `版式定位`：封面 S-01 / 目录 S-02 / 章节页 S-03、S-05、S-12 / 结尾页 S-15，其余为内容页；S-06、S-07、S-09 为演示型

## 四、与案例链的数字对齐

| 数字 | 出处 | 在本场景的落点 |
| --- | --- | --- |
| 15 页汇报材料 | `方案素材要点.csv` | 交付物 15 行逐一对应 |
| 版式分布 1/1/3/9/1 | 框架版式规则 | 交付物「版式类型」列 |
| 总时长 40 分钟、演示 12 分钟 | 框架时长表 | 交付物「时长分配分钟」列 |
| 3 处演示环节 | 框架演示规则 | S-06 / S-07 / S-09 三段式脚本 |
| 移动审批响应 ≤3 秒 | INT-07 规格 REQ-09 | 讲稿口径与方案文档一致（风险提示列） |

## 五、真实性等级与边界

- **T2**：演示材料结构化方法（版式规范 / 时长分配 / 讲稿口径）来自售前汇报实践。
- **T3**：汇报章节与素材按政企协同办公客户汇报常见结构构造，口径可复算。
- **升 T1 还缺**：客户真实汇报材料与汇报效果复盘记录。
- **人工边界**：汇报策略与章节取舍、演示环境准备、临场承诺口径、与方案文档差异的最终裁定一律人工；演示界面数据须脱敏。
