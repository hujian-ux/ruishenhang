# 汇报方案到演示材料一体化产出

## 一、这个 Skill 解决什么

客户汇报材料准备的真实困难，不是「写不出内容」，而是**「写内容」和「排版面」被切成两段**：

- 先写完汇报稿，再交排版；换一次模板，重新手工排一次
- 演示 Demo 环节靠现场即兴，没有脚本，讲到哪算哪
- 讲稿口径正式度依赖个人经验，过于直白的表述临场才被发现
- 涉及工期、性能的数字与方案文档不一致，被客户当场质询

本 Skill 的核心动作，是把两段工作合并到一张表里：以既定模板统一风格，每页同时产出章节标题、版式、演示步骤、讲稿要点与时长分配——「边写边成型」，排版等待被消除。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 售前客户汇报前，要把汇报方案转成演示材料 | 主用场景：PPT 大纲 + 演示脚本 + 讲稿要点一体化产出 |
| 已有方案大纲，要求沿用公司或项目既定视觉模板 | 指定模板后按首页风格全局统一 |
| 汇报含现场演示环节，需要 Demo 脚本 | 三段式演示步骤：进入界面 → 操作 → 指出要点 |
| 成稿后需要口径纠偏与表述正式化调整 | 逐页定点修改，不重排全篇 |

**不适用**：从零起草无既有材料的汇报（本 Skill 以既有方案素材为输入）；投标报价文件（→ 售前应标类场景）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `方案素材要点.csv` | 必需 | 章节编号、汇报章节、客户痛点、方案能力说明、案例引用 |
| 2 | `演示材料框架.md` | 必需 | 五类版式规范、演示环节规则、40 分钟时长分配、讲稿撰写规范 |

> 缺 2（演示材料框架）时，本 Skill **必须拒绝输出**——没有版式与时长规则的材料表只是章节清单，无法进入汇报排练。这是本 Skill 最重要的一条硬规则。

## 四、输出（outputs）

唯一交付物：`汇报与演示材料表.csv`，字段固定为 7 列：

```
页码序号, PPT章节标题, 版式类型, 演示步骤, 讲稿要点, 时长分配分钟, 口径与风险提示
```

- `版式类型` ∈ {封面页, 目录页, 章节页, 内容页·演示型, 内容页·讲解型, 结尾页}
- `演示步骤`：演示型页按「进入界面 → 操作 → 指出要点」三段式；讲解型页写明翻页与指图动作
- `讲稿要点`：每页 2-4 条，每条不超过 40 字

## 五、工作流程（workflow）

### STEP 1 · 给母本，先套模板

读入方案素材要点与演示材料框架，明确既定视觉模板——标题层级、色板与页眉页脚按模板首页风格全局统一应用。**内容与版式在同一轮对话内推进**，先统一风格再补章节。

### STEP 2 · 版式定位

按框架规则给每页定版式：封面（S-01）、目录（S-02）、每篇起始章节页、内容页、结尾页（S-15）。

### STEP 3 · 演示环节定位

现场演示共 3 处（统一门户 / 公文管理 / 流程审批），演示页写三段式 Demo 脚本；非演示页写「讲解为主」加翻页与指图动作。

### STEP 4 · 时长分配

按框架时长表逐页分配：封面 2 / 目录 1 / 章节页 1×3 / 演示型内容页 4×3 / 讲解型内容页 2.5×6 / 结尾页含答疑 7，合计 40 分钟。

### STEP 5 · 讲稿与口径撰写

每页 2-4 条讲稿要点；口径正式度、案例匿名化、数字与方案文档一致——逐页写入口径与风险提示列。

### STEP 6 · 自检与人工边界声明

输出前逐项自检，任一不过则不得输出。

## 六、关键规则（不可协商）

1. **以既有材料为输入。** 母本（方案素材）先行，AI 做增量补全与格式转换，不凭空起草。
2. **模板统一在先。** 版式、色板与标题层级按既定模板全局应用，禁止每页自成风格。
3. **演示必须有脚本。** 现场演示环节逐页写三段式步骤，禁止「现场即兴」。
4. **口径一致是硬要求。** 工期、性能数字与方案文档一致，不得现场加码；案例引用匿名化，不出现可识别的客户名称。
5. **多形态输出同源。** 同一内容可输出文档版、演示版或网页版说明页，口径以本表讲稿要点为准。
6. **不承诺效率百分比。** 输出中不写「提升 X%」这类无法核验的表述。

## 七、人工边界

| AI 负责 | 人负责（方案咨询岗 / 售前负责人） |
| --- | --- |
| 版式定位、时长分配与材料表生成 | 汇报策略与重点章节取舍 |
| 演示脚本与讲稿要点初稿 | 演示环境与账号准备、彩排确认 |
| 口径一致性提示 | 与方案文档差异的最终裁定 |
| 多形态格式转换 | 对客户的临场承诺口径 |

## 八、下游衔接

- 材料表「内容页·演示型」行 → 转现场演示准备（环境、账号、脱敏数据核查）
- 材料表全部行 → 作为 PPT 制作与讲稿定稿的逐页底稿

## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读 `演示材料框架.md`：确认五类版式规范（封面 S-01 / 目录 S-02 / 章节页 S-03、S-05、S-12 / 内容页 9 页 / 结尾页 S-15）、演示环节规则与 40 分钟时长表，不要边写边定规则。
2. 读入 `方案素材要点.csv` 15 行，确认字段齐全：章节编号 / 汇报章节 / 客户痛点 / 方案能力说明 / 案例引用。
3. 版式定位：封面页 1 / 目录页 1 / 章节页 3 / 内容页 9（演示型 3：S-06 统一门户、S-07 公文管理、S-09 流程审批；讲解型 6）/ 结尾页 1。
4. 时长分配：封面 2 + 目录 1 + 章节页 1×3 + 演示型 4×3 + 讲解型 2.5×6 + 结尾页 7 = 40 分钟。
5. 演示步骤：演示型页按「进入界面 → 操作 → 指出要点」三段式；讲解型页写「讲解为主」+ 翻页与指图动作。
6. 讲稿要点每页 2-4 条、每条不超过 40 字；口径与风险提示逐页写明正式度、匿名化与数字一致性要求。

### 硬性约束

【硬性约束】
- 以既有素材为母本做增量，不凭空起草；模板统一在先。
- 案例引用一律匿名化为同行业同类案例，不得出现可识别的客户名称。
- 工期、性能数字与方案文档一致，不得现场加码；对未签约事项不使用承诺性措辞。
- 演示型页面必须有三段式脚本，禁止留空或写「现场即兴」。
- 不写任何效率百分比或效果承诺。

### 生成后自检

【生成后自检，逐条回答】
1. 输出是否为 15 行、7 列，列名与顺序固定？
2. 版式分布是否为：封面 1 / 目录 1 / 章节页 3 / 演示型 3 / 讲解型 6 / 结尾 1？
3. 总时长是否 = 40 分钟？演示型 3 页合计是否 = 12 分钟？
4. 演示环节是否定位在统一门户（S-06）、公文管理（S-07）、流程审批（S-09）？
5. 每页讲稿要点是否为 2-4 条、每条不超过 40 字？是否无承诺性措辞与可识别客户名称？
自检全过再输出 CSV。

### 输出格式

【输出格式】CSV，7 列，列名与顺序固定：
页码序号, PPT章节标题, 版式类型, 演示步骤, 讲稿要点, 时长分配分钟, 口径与风险提示
