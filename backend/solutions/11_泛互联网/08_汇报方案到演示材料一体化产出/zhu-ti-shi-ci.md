# INT-08 主提示词 · 汇报方案到演示材料一体化产出

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/汇报方案到演示材料一体化产出/SKILL.md`）。
2. 上传两个附件：`方案素材要点.csv`、`演示材料框架.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `汇报与演示材料表.csv` 后，按文末「验收清单」逐项核对。

---

## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某协同办公软件企业 · 政务协同平台客户汇报」把汇报方案一体化转成演示材料（PPT 大纲 + 演示 Demo 脚本 + 讲稿要点），输出一张可排练复核的汇报与演示材料表。

【输入 1 · 方案素材要点】方案素材要点.csv（15 行）
- 含章节编号、汇报章节、客户痛点、方案能力说明、案例引用
- 15 行对应 15 页材料：开场、目录、三篇章节（现状与挑战 / 核心方案 / 实施与保障）、结尾展望

【输入 2 · 演示材料框架】演示材料框架.md
- 五类版式规范（封面 / 目录 / 章节页 / 内容页 / 结尾页）、3 处现场演示环节定位规则
- 40 分钟时长分配表（封面 2 / 目录 1 / 章节页 1×3 / 演示型 4×3 / 讲解型 2.5×6 / 结尾 7）
- 讲稿撰写规范：每页 2-4 条、案例匿名化、数字与方案文档一致

【输出】汇报与演示材料表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「汇报方案到演示材料一体化产出」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **演示环节安排在哪三页？** 期望回答：S-06 统一门户与消息、S-07 公文管理方案、S-09 流程审批方案——演示型内容页各 4 分钟，合计 12 分钟。
2. **40 分钟怎么拆？** 期望回答：封面 2 + 目录 1 + 章节页 1×3 + 演示型 4×3 + 讲解型 2.5×6 + 结尾页（含答疑引导）7 = 40 分钟。
3. **为什么内容与版式要一体化推进？** 期望回答：传统模式「先写完再排版」往返成本高；指定模板后按首页风格全局统一，单页可定点修改，不重排全篇。
4. **演示脚本是三段式吗？** 期望回答：是——「进入界面 → 操作 → 指出要点」，如公文页「打开发文流程 → 逐级流转至签批 → 指出全流程轨迹留痕与版式套红」。
5. **口径风险提示怎么控制？** 期望回答：每页逐条写明——性能口径与方案文档一致（如移动审批 ≤3 秒）、案例匿名化、未签约事项不作承诺性表述。
