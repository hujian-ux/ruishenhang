# INT-01 · 经营看板持续维护与线上分享 —— 场景使用说明

- **行业**：泛互联网（即时零售）
- **角色**：经营数据岗
- **场景编号**：INT-01
- **案例主体**：某即时零售企业（与本场景库 INT-02 / INT-03 同一案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/经营看板持续维护与线上分享/SKILL.md` | Skill 定义 | 看板口径、同比阈值、维护动作优先级、持续维护机制与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `门店经营日数据.csv` | 原始输入 | 75 行（15 门店 × 5 个工作日）门店日经营明细，含去年同期对照列 |
| `看板口径与维护机制.md` | 原始输入 | 指标口径与保留位数、同比标记阈值、看板维护动作优先级表、持续维护机制 |
| `经营看板数据表.csv` | **交付物** | 15 行看板数据：门店汇总 × 指标 × 同比标记 × 看板维护动作 |
| `经营数据岗-经营看板持续维护与线上分享.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `门店经营日数据.csv`、`看板口径与维护机制.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 回落 / 预警门店推送所属战区负责人复核；口径变更场景转 INT-03。

### 可复算口径

- `客单价 = 本期销售额 ÷ 本期订单数`（1 位小数）
- `毛利率 = 本期毛利 ÷ 本期销售额`（1 位小数百分比）
- `日均动销SKU数 = 期间各日动销SKU数算术平均（取整）`；`动销SKU占比 = 日均动销SKU数 ÷ 在售SKU数`
- `销售额同比 =（本期销售额 − 去年同期销售额）÷ 去年同期销售额`；毛利额同比同口径

| 数字 | 出处 | 在本场景的落点 |

## 五、真实性等级与边界

- **素材来源**：即时零售连锁企业的看板化实践——从临时取数到持续维护、可分享的线上产品（看板版本迭代、链接补发、版式调整不覆盖历史）。
- **构造**：门店明细数据为可复算口径，全部汇总值由脚本从日数据计算。
- **人工边界**：看板只呈现事实与标记，回落 / 预警门店的处置由战区负责人复核决定；口径迭代转 INT-03。
