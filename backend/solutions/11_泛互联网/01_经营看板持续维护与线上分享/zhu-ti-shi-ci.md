## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某即时零售企业 · 门店经营看板」做看板口径的汇总计算与同比标记，输出一张可复核的经营看板数据表。

【输入 1 · 门店经营日数据】门店经营日数据.csv（75 行，15 门店 × 5 个工作日）
- 每行含当日销售额、订单数、毛利、动销SKU数，及去年同期销售额、去年同期毛利对照列
- 在售SKU数按门店固定，用于动销占比计算

【输入 2 · 看板口径与维护机制】看板口径与维护机制.md
- 客单价、毛利率、动销占比的口径与保留位数；同比标记阈值：≥+5% 增长 / ≤-5% 回落
- 看板维护动作按「回落置顶 → 毛利率<20% 预警 → 增长且毛利率≥28% 标杆行 → 常规刷新」优先级挂接

【输出】经营看板数据表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「经营看板持续维护与线上分享」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **哪三家门店被标了「回落」，依据是什么？** 期望回答：月泉店 -7.1%、星海店 -6.2%、银杏店 -9.3%，均为销售额同比 ≤ -5% 触发阈值。
2. **云谷店毛利率只有 19.0%，为什么动作不是「置顶关注」？** 期望回答：它的同比标记是「持平」（+3.0%），回落置顶不命中；按第二优先级挂「新增毛利率预警标注」。
3. **银杏店毛利率 19.1% 也低于 20%，为什么动作是「置顶关注」？** 期望回答：优先级命中即停——它同时命中回落（-9.3%），置顶优先于毛利率预警。
4. **平均客单价 41.2 元怎么复算？** 期望回答：合计销售额 3,183,218 元 ÷ 合计订单 77,207 单 = 41.2 元（各门店行客单价 = 本门店销售额 ÷ 订单数）。
5. **整体同比 +7.8% 但有 3 家回落，矛盾吗？** 期望回答：不矛盾——8 家增长（最高兰亭店 +18.8%）拉动整体，回落门店由看板置顶提示战区复核，看板不下经营结论。

## 验收清单

- [ ] 输出为 15 行、16 列，每门店一行，行序按门店编号升序
- [ ] 同比标记分布 = 增长 8 / 持平 4 / 回落 3
- [ ] 回落门店 = 月泉店 / 星海店 / 银杏店，动作均为「置顶关注 · 推送所属战区负责人」
- [ ] 云谷店动作 = 「新增毛利率预警标注 · 保留展示」（毛利率 19.0%）
- [ ] 标杆行 = 翠湖店 / 望江店 / 竹韵店 / 兰亭店（增长且毛利率 ≥ 28%）
- [ ] 15 门店 5 天合计销售额 3,183,218 元、订单 77,207 单，可从 75 行日数据逐行复算
- [ ] 全表无经营结论（如「应关店」「需降价」）、无效率承诺
