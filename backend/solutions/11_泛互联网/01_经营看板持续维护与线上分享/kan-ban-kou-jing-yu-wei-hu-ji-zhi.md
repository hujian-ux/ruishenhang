# 门店经营看板 · 口径与维护机制

> 适用范围：某即时零售企业 15 家直营与加盟门店的经营看板（销售 / 毛利 / 动销）。看板定位为持续维护、可分享链接的线上产品，而非一次性报表。

## 一、指标口径（看板列定义）

| 指标 | 口径 | 保留位数 |
| --- | --- | --- |
| 本期销售额 | 门店收银 + 各平台线上订单实收（不含平台补贴），期间为 2026-09-07 至 2026-09-11 共 5 天合计 | 元，整数 |
| 本期订单数 | 收银小票数 + 平台成交订单数，同期合计 | 单，整数 |
| 客单价 | 本期销售额 ÷ 本期订单数 | 元，1 位小数 |
| 本期毛利 | 销售额 − 商品销售成本 − 即时配送履约成本 | 元，整数 |
| 毛利率 | 本期毛利 ÷ 本期销售额 | 百分比，1 位小数 |
| 日均动销SKU数 | 期间各日动销SKU数的算术平均 | 个，四舍五入取整 |
| 动销SKU占比 | 日均动销SKU数 ÷ 门店在售SKU数 | 百分比，1 位小数 |

## 二、同比口径与标记规则

- 销售额同比 =（本期销售额 − 去年同期销售额）÷ 去年同期销售额；毛利额同比同口径（本期毛利对比去年同期毛利）。
- 去年同期取 2025-09-08 至 2025-09-12（对应工作日）。
- 同比标记只看销售额同比：≥ +5% 记「增长」；≤ −5% 记「回落」；其间记「持平」。

## 三、看板维护动作（按标记与预警挂接，优先级从上到下，命中即停）

| 条件 | 看板维护动作 |
| --- | --- |
| 同比标记 = 回落 | 置顶关注 · 推送所属战区负责人 |
| 毛利率 < 20% | 新增毛利率预警标注 · 保留展示 |
| 同比标记 = 增长 且 毛利率 ≥ 28% | 纳入标杆行 · 保持展示 |
| 其余门店 | 常规刷新 |

## 四、持续维护机制

1. **版本与不覆盖**：指标行的增删、排版密度调整须在看板台账登记变更项与日期，历史内容一律不覆盖。
2. **链接管理**：看板以分享链接在团队内流转，链接失效须在 24 小时内重新生成并补发，新链接沿用原口径。
3. **刷新节奏**：每个工作日 09:30 刷新至 T-1 数据；口径调整后先重跑再刷新。
4. **权限**：战区负责人仅可见本战区门店行；全量视图限经营数据岗。
5. **人工边界**：看板只呈现事实与标记，不自动下经营结论；「回落」「预警」门店由战区负责人复核后再定动作。
