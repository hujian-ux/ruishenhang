## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `销售明细数据.csv`、`分析口径说明.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 8 个量升价跌单元的应对动作提交管理层决策后落地执行。

### 可复算口径

- `销售额同比 = 当期合计 ÷ 去年同期合计 − 1`（如检验试剂线：3480 ÷ 3680 − 1 = −5.4%）
- `均价（元）= 销售额（万元）× 10000 ÷ 销量`（如介入耗材×华中当期：1050 × 10000 ÷ 2600 = 4038.5）
- `量升价跌 = 集采标记=是 AND 销量同比>0 AND 均价同比<0`
- `A1 = 量升价跌且均价降幅 ≥ 25%；A2 = 量升价跌且降幅 < 25%；A3/A4 以非集采单元销售额同比 0 为界`

## 五、真实性等级与边界

- **T2**：双维拆解与集采量升价跌分析方法论来自行业通行做法。
- **构造**：某医疗器械流通企业及其 4 条产品线、5 个省区的数据为构造数据，口径可复算。
- **人工边界**：品类替换、渠道调整等经营决策一律人工；AI 只输出判定依据与建议动作。
