# MED-10 · 产品内容目录与视觉方案批量加工 —— 场景使用说明

- **行业**：医疗健康
- **角色**：产品与内容岗（沈攸宁）
- **场景编号**：MED-10
- **案例主体**：某医疗防护制品企业

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/产品内容目录与视觉方案批量加工/SKILL.md` | Skill 定义 | C1–C4 章节规则、S1–S4 卖点规则、F1–F4 图位规则、L1–L5 语言版本规则、一致性校验 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `产品参数表.csv` | 原始输入 | 25 行产品明细（防护手套 10 / 康复辅具 6 / 康复护具 5 / 医用敷料耗材 4） |
| `目录与视觉规范.md` | 原始输入 | 章节分配、卖点提炼、图位规划、语言版本规则与版式品牌一致性校验 |
| `产品目录与视觉方案表.csv` | **交付物** | 25 行方案表：产品 × 章节 × 卖点 × 图位 × 语言版本 |
| `产品与内容岗-产品内容目录与视觉方案批量加工.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `产品参数表.csv`、`目录与视觉规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 按方案表批量产出目录页；专业译文交母语审校后发布。

### 可复算口径

- `目录页章节 = 按产品类别映射（C1–C4）`
- `卖点提炼 = {认证} · {类别价值短语（S1–S4）} · {核心参数}`，认证与参数照抄参数表原文
- `图位数量 = 类别映射（F1：4 / F2：5 / F3：3 / F4：3），合计 = Σ(类别产品数 × 类别图位数)`
- `语言版本 = 目标市场语言列（L1–L5），每产品 1 版`

## 五、真实性等级与边界

- **T3**：产品目录与多语言加工痛点来自出口制造企业内容岗实践归纳。
- **构造**：产品参数、认证与语言分布为构造数据，加工口径可复算。
- **人工边界**：参数与认证真实性、品类规则修订、专业译文母语审校一律人工；本场景全部输出中**不补充参数表之外的规格**。
