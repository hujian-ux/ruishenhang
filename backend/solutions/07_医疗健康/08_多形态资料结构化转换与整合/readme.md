# MED-13 · 多形态资料结构化转换与整合 —— 场景使用说明

- **行业**：医疗健康
- **角色**：知识管理岗（温若清）
- **场景编号**：MED-13
- **案例主体**：某创新药企业

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/多形态资料结构化转换与整合/SKILL.md` | Skill 定义 | 条目字段、主题枚举、转换动作映射、去重与冲突双保留规则、人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `多形态资料清单.csv` | 原始输入 | 20 份资料：形态、来源、关键内容摘要、涉及主题、原始与重复条目数 |
| `知识条目Schema.md` | 原始输入 | 条目字段定义、11 个主题枚举、转换动作映射、去重规则、冲突处理规则 |
| `结构化转换与整合清单.csv` | **交付物** | 20 行整合清单：资料 × 转换动作 × 入库条目数 × 去重标记 × 冲突标记 |
| `知识管理岗-多形态资料结构化转换与整合.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `多形态资料清单.csv`、`知识条目Schema.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 5 处冲突条目移交知识管理委员会裁决，裁决前不参与下游引用。

### 可复算口径

- `入库条目数` = 原始条目数 − 去重条目数（逐份）
- `X 条知识条目` = 全部资料入库条目数合计 = **86 条**（104 − 18）
- `Y 处冲突` = 冲突标记 ≠ 无冲突的资料数 = **5 处**，每处写明对方资料编号与冲突数据要素
- `去重标记` = 重复条目数 > 0 的资料写明去重条数，共 10 份、18 条

## 四、与案例链的数字对齐

| 数字 | 出处 | 在本场景的落点 |
| --- | --- | --- |
| 20 份多形态资料 | `多形态资料清单.csv` 20 行 | 交付物 20 行逐行对应 |
| 104 条原始条目 | 输入「原始条目数」列合计 | 交付物「原始条目数」列 |
| 18 条去重 | 输入「其中重复条目数」列合计 | 交付物「去重标记」列（10 份资料） |
| 86 条知识条目 | 104 − 18 | 交付物「入库条目数」列合计 |
| 5 处冲突 | Schema 冲突规则（D06/D07/D09/D17/D20） | 交付物「冲突标记」列 |
| 5 种形态 / 11 个主题 | 输入「形态」「涉及主题」列 | 交付物对应列与断言 |

## 五、真实性等级与边界

- **T2**：多形态资料处理与结构化整合方法论来自案例素材（形态识别 → 结构转换 → 字段补全 → 合并分析）。
- **T3**：知识管理岗痛点来自素材中的传统/WorkBuddy 模式对比列。
- **构造**：资料与条目数据为构造数据，口径可复算。
- **人工边界**：Schema 与主题枚举维护、冲突数值裁决、知识底座发布与权限管理一律人工；AI 只出转换、去重、标记与移交清单。
