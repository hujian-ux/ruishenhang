# 知识条目 Schema（多形态资料结构化转换与整合 · MED-13）

某创新药企业知识管理条线的多形态资料结构化转换与整合规则。本文件是生成与校验 `结构化转换与整合清单.csv` 的唯一规则来源。

## 一、知识条目字段定义

| 字段 | 说明 |
| --- | --- |
| 条目ID | K-主题代码-流水号，全局唯一 |
| 标题 | 条目核心论断（名词化短句） |
| 主题 | 主题枚举值之一（见第二节） |
| 来源资料编号 | 指回 D01–D20 的资料编号，可溯源 |
| 原始形态 | PDF报告 / 会议记录 / 表格 / 图片扫描件 / 邮件长文本 |
| 要点摘要 | 一至两句话的结构化要点 |
| 数据要素 | 条目含的具体数值/口径（如中位OS、入组数），无则留空 |
| 入库时间 | ISO 日期 |
| 状态 | 已入库 / 已入库（冲突待裁决） |

## 二、主题枚举（11 个）

临床疗效 / 领域格局 / 竞品动态 / 专家意见 / 注册策略 / 安全管理 / 项目协同 / 文献管理 / 术语规范 / 培训档案 / 流程规范

## 三、转换动作映射（按形态）

| 形态 | 转换动作 |
| --- | --- |
| PDF报告 | PDF 解析与条目抽取 |
| 会议记录 | 长文本提炼与结构化 |
| 表格 | 字段校对与格式归一 |
| 图片扫描件 | OCR 识别与结构化 |
| 邮件长文本 | 要点提炼与主题归类 |

## 四、去重规则

- 同一来源或同主题下要点重复的条目合并，保留信息最全的一条；
- `入库条目数 = 原始条目数 − 去重条目数`；
- 涉及去重的资料在交付物「去重标记」列写明去重条数。

## 五、冲突处理规则

- 同一数据要素在不同来源数值不一致（如中位OS、入组数、事件计数）时，**双来源条目均保留入库**，后入库一方标记「冲突待裁决」；
- 冲突条目提交知识管理委员会人工裁决，裁决前不参与下游引用；
- 冲突不计为去重，也不得静默丢弃任何一方。

## 六、交付物口径

- 交付物 `结构化转换与整合清单.csv`：每份资料一行，共 20 行；
- 「X 条知识条目」= 全部资料入库条目数合计（20 份资料共 104 条原始条目，去重 18 条后入库 86 条）；
- 「Y 处冲突」= 标记冲突待裁决的资料数（应为 5 处：D06/D07/D09/D17/D20，分别与 D05/D01/D14/D01/D13 的数值不一致）；
- 形态 5 种（PDF报告 5 / 会议记录 5 / 表格 6 / 图片扫描件 2 / 邮件长文本 2），主题 11 个。
