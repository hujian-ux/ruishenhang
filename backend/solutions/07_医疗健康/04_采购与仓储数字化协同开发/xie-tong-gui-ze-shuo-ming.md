# 协同规则说明 · 采购与仓储数字化协同开发

## 一、目标

把采购需求与仓储库存数据打通：仓储侧的消耗与库存驱动采购侧的补货动作，采购侧的在途数量反哺仓储侧的可用库存判断，两类异常（效期、滞销）在同一张协同表里预警。

## 二、核心公式

- **可用库存** = 当前库存 + 在途数量（采购在途计入可用，避免重复下单）
- **补货点** = 月均消耗 × 1.5（采购提前期 2 周 + 需求波动余量 0.5 个月用量）
- **需补货判定**：可用库存 < 补货点
- **建议补货量** = 2 × 月均消耗 − 可用库存（补至两个月用量，覆盖一个采购周期内的消耗与波动）
- **效期预警判定**：最近批次效期剩余天数 < 180 天（6 个月，覆盖一个季度用量加周转余量）
- **滞销预警判定**：当前库存 > 6 × 月均消耗（按当前消耗速度半年以上用不完）

## 三、预警类型优先级

同一物料可能同时命中多条规则，按以下优先级取唯一预警类型：

```
需补货 > 效期预警 > 滞销预警 > 正常
```

理由：缺货直接影响医院临床供应，优先级最高；效期风险在补货时会叠加（近效期批次应先消耗再补货），由依据列说明；滞销只涉及资金占用。

## 四、输出口径

- 每个物料一行，共 35 行，与输入一一对应；
- `建议补货量` 仅在预警类型 = 需补货时非 0，其余为 0；
- `依据` 必须写明触发规则与实测值（如「可用库存 400 < 补货点 525（月均消耗 350×1.5）」）；
- 协同看板按「采购在途 / 仓储现状 / 消耗速度」三列组织，异常物料置顶。

## 五、协同机制

1. 仓储侧每日更新当前库存与效期批次，采购侧更新在途数量；
2. 协同表每日重算，需补货物料自动生成采购建议，效期与滞销物料推送处置动作；
3. 医院消耗速度（月均消耗）按近 3 个月滚动平均，每月刷新一次。
