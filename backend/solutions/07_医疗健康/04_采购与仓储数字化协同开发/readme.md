## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `仓储与采购数据.csv`、`协同规则说明.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 需补货清单交采购下单，效期与滞销预警推送处置动作。

### 可复算口径

- `可用库存 = 当前库存 + 在途数量`（如采样管：15,000 + 20,000 = 35,000）
- `补货点 = 月均消耗 × 1.5`（如采样管：30,000 × 1.5 = 45,000）
- `建议补货量 = 2 × 月均消耗 − 可用库存`（如采样管：60,000 − 35,000 = 25,000）
- `效期预警 = 最近批次效期剩余天数 < 180`（如校准品：100 天）
- `滞销预警 = 当前库存 > 6 × 月均消耗`（如影像胶片：15,000 > 12,000）
