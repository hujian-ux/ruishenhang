# 知识体系框架 · 售后工程师知识体系与服务系统自建

## 一、为什么要三级分类

厂家维修手册篇幅长、专业度高，现场故障与解决方案长期散落在工程师个人经验里。把每张工单按「故障现象 → 最可能原因 → 标准处置」三级归档，新工程师按现象检索即可独立处置大部分常见故障，老工程师的经验变成可检索的组织资产。

## 二、三级分类规则

- **L1 故障现象**：接单时可直接观察到的外在表现（如「样本针堵塞」），是检索入口。
- **L2 最可能原因**：该现象在历史工单中的首位原因（如「血样纤维蛋白挂壁结晶」）。
- **L3 标准处置**：对应原因的标准处置动作（如「拆卸针组件超声清洗后重新校准定位」），是派单与新工程师执行的依据。

每张工单必须归入一个 L1 类目；处置动作与 L3 不一致时，先按 L3 复核工单记录，确认后再决定是否新增类目。

## 三、L1 类目映射表（8 类）

| L1 故障现象 | L2 最可能原因 | L3 标准处置 |
| --- | --- | --- |
| 样本针堵塞 | 血样纤维蛋白挂壁结晶 | 拆卸针组件超声清洗后重新校准定位 |
| 试剂冷藏舱温度异常 | 压缩机启动继电器老化 | 更换启动继电器并复测温度曲线 |
| 光度计读数漂移 | 光源灯衰减未做空白校准 | 更换光源灯后执行空白校准 |
| 软件报错通讯中断 | 通讯板卡接触不良 | 重新插拔通讯板卡并升级固件 |
| 开机无反应 | 电源模块保险丝熔断 | 更换保险丝并检测电源模块 |
| 探针液面感应失灵 | 感应电极污染结垢 | 清洁感应电极并重做液面标定 |
| 废液排空不畅 | 废液管路弯折异物 | 疏通废液管路并检查单向阀 |
| 打印报告无输出 | 打印模块排线松动 | 重新插拔打印排线并测试自检页 |

## 四、频次分级与派单规则

| 分级 | 判定条件 | 派单规则 |
| --- | --- | --- |
| 高频重点 | 出现次数 ≥ 6 | 优先派资深工程师，并纳入月度预防性维护清单 |
| 中频常规 | 出现次数 3 ~ 5 | 按标准流程派单，处置按 L3 执行 |
| 低频备案 | 出现次数 ≤ 2 | 接单后先检索知识库按 L3 处置，处置完沉淀记录 |

## 五、覆盖率判定

- 高频故障覆盖率 = 前 N 类故障出现次数合计 ÷ 工单总数（用于回答「掌握哪几类就能应付大部分现场」）。
- 平均耗时 = 该类工单维修耗时合计 ÷ 出现次数（用于派单排期与备件准备）。
- 每月复盘一次：新增现象判断是否入库、频次分级是否变化、平均耗时是否异常。
