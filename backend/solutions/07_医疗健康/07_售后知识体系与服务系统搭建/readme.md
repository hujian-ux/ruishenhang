- **行业**：医疗健康
- **角色**：售后服务管理岗（陆一鸣）
- **场景编号**：MED-05
- **案例主体**：某医疗器械流通企业

## 一、文件清单

| 文件 | 类型 | 作用 |

| `03_技能包/售后工程师知识体系与服务系统自建/SKILL.md` | Skill 定义 | 三级分类规则、频次分级与派单规则、人工边界 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `维修工单记录.csv`、`知识体系框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 知识表作为自建服务系统（报单、派单、知识检索）的数据底表落地使用。

### 可复算口径

- `出现次数` = 该 L1 类目下工单数（如样本针堵塞：RL-2604-01/02/03/04/05/06/07 共 7 张）
- `工单占比` = 出现次数 ÷ 30（如 7 ÷ 30 = 23.3%）
- `平均耗时` = 该类耗时合计 ÷ 出现次数（如样本针堵塞 (1.5+1.8+1.2+2.0+1.6+1.4+1.7) ÷ 7 = 11.2 ÷ 7 = 1.6）
- `前 4 类覆盖率` = (7+6+5+4) ÷ 30 = 73.3%
- `派单优先级` = 次数 ≥6 高频重点 / 3~5 中频常规 / ≤2 低频备案
