# 区域经营复盘与一线讲话材料

## 一、这个 Skill 解决什么

区域复盘的真实困难不是「没有数据」，而是**复盘结果与讲话场景脱节**：

- 经营报表给全量数据，不给「哪个区域该被点名、为什么」
- 汇报稿按阅读习惯写，念到一半一线就走神
- 成绩讲不透（只报数不归因），问题不敢点明（怕伤士气），行动落不了地（没有时限与责任人）
- 同一个区域这个月说好、下个月说差，判定口径每期都在变

本 Skill 的核心动作，是**先把判定规则立起来，再让同一套数据同时服务「看」和「讲」两种场景**：评级表供管理层核对，讲话稿供一线动员，两者数字严格一致。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 月度经营复盘，手里有各实验室的经营数据 | 主用场景：口径计算 → 评级 → 行动指引 → 讲话材料 |
| 一线动员会前需要一份 8 分钟讲话稿 | 按讲话结构成文，成绩/问题/行动三段式 |
| 老板问「哪个区域好、好在哪」 | 评级表逐区域给出亮点信号与数据出处 |
| 需要跨期对比判定口径是否稳定 | 规则写死在框架说明里，每期复算口径一致 |

**不适用**：年度战略规划与预算编制（口径与颗粒度不同）；单个医院的客户经营分析（→ 客户维度场景）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `区域月度经营数据.csv` | 必需 | 区域编号、区域名称、标本量万份、去年同期标本量万份、营收万元、去年同期营收万元、特检收入万元、报告时效达标率 |
| 2 | `复盘框架说明.md` | 必需 | 计算口径、短板信号 S1-S3、亮点信号 H1-H3、评级规则、行动指引映射、讲话材料结构 |

> 缺 2（框架说明）时，本 Skill **必须拒绝输出评级**——判定规则不是 AI 临场发明的，是机构复盘机制的正式口径。

## 四、输出（outputs）

唯一交付物：`区域复盘与行动指引表.csv`，字段固定为 6 列：

```
区域, 评级, 亮点, 短板, 行动指引, 讲话要点
```

- `区域` 与输入的区域名称一致，10 行
- `评级` ∈ {A, B, C, D}，按框架说明第四节的规则判定
- `亮点` / `短板` 必须写具体数据与信号编号（如「营收同比+18.0%（H1）；特检占比32.5%（H2）」），**不允许只写「表现好/表现差」**
- `行动指引` 按框架说明第五节的映射逐区域给出，带时限
- `讲话要点` 为一句话口径，直接可嵌入讲话稿的对应段落

## 五、工作流程（workflow）

### STEP 1 · 读框架，先立规矩再看数

从 `复盘框架说明.md` 读入口径、信号与评级规则，写成显式判定表。**顺序不可颠倒**——先看数据再定规则，等于给结论找理由。

### STEP 2 · 口径计算

对每个区域计算：营收同比、标本量同比、特检占比，并读入报告时效达标率。所有结果保留 1 位小数，任何人可用原始字段复算。

### STEP 3 · 信号判定与评级

逐区域判定 S1-S3（短板）与 H1-H3（亮点），按「短板 0 且亮点≥2 → A；短板 0 → B；短板 1 → C；短板≥2 → D」定级。

### STEP 4 · 行动指引映射

按命中的短板信号（或亮点/稳态组合）映射到框架说明第五节的行动指引，逐区域给出带时限的动作。

### STEP 5 · 讲话材料成文

按框架说明第六节的五段式结构（开场定调 → 成绩讲透 → 问题点明 → 行动具体 → 收尾）组织讲话稿：成绩区点名 A 级区域，问题区点名 D 级区域，行动区覆盖 C 级区域，总时长 8 分钟口径。讲话稿中的每个数字都来自评级表或其派生口径。

### STEP 6 · 自检

输出前逐项自检，任一不过则不得输出：

1. 每行亮点/短板是否都含具体数据与信号编号？
2. 评级分布是否与信号判定逐一吻合？
3. 行动指引是否逐区域给出且带时限？
4. 讲话要点是否与评级表数字完全一致？

## 六、关键规则（不可协商）

1. **AI 不改判定规则。** 短板/亮点阈值与评级规则来自机构复盘机制，AI 只按规则执行；对规则本身的修改属人工决策。
2. **数字必须有出处。** 讲话稿与评级表里出现的每一个数字，必须能在 `区域月度经营数据.csv` 或其派生口径中复算得出。
3. **讲话稿不是培训材料。** 不写培训练习、不写考核细则，只写「讲什么、怎么讲、讲完要什么动作」。
4. **问题点名只说事实。** D 级区域报差距值与信号编号，不做人身化评价、不贴标签。
5. **不承诺效率百分比。** 输出中不写「提升 X%」这类无法核验的表述。

## 七、人工边界

| AI 负责 | 人负责（区域经营岗 / 管理层） |
| --- | --- |
| 口径计算与信号判定 | 判定规则与阈值的制定与修订 |
| 评级与行动指引初稿 | 行动项的资源与责任人裁定 |
| 讲话材料成文 | 讲话场合、语气与最终定稿 |
| 数字与口径的一致性检查 | 一线反馈的收集与下期规则迭代 |

## 八、下游衔接

- 评级表 C/D 级区域的短板信号 → 纳入下月区域经营重点跟踪清单
- 行动指引的落地情况 → 作为下月复盘「上期行动回头看」的输入


## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读框架再看数：把口径、信号、评级规则写成显式判定表，不要先看数据再定标准。
2. 口径计算：对 10 个区域逐个计算营收同比、特检占比（保留 1 位小数），与报告时效达标率一起进入信号判定。
3. 逐区域评级：按短板/亮点信号计数定级，并统计整体盘面（标本量合计、营收合计、整体同比、特检收入合计与占比、时效达标实验室数）。
4. 行动指引：按框架第五节映射逐区域给出带时限的动作；讲话要点写成一句话口径。
5. 讲话材料：按五段式结构给出成文口径——成绩区点名 A 级区域并讲透数据与归因，问题区点名 D 级区域并报差距值，行动区覆盖 C 级区域，收尾给下月目标口径。

### 硬性约束

【硬性约束】
- 亮点/短板必须写具体数据与信号编号，不允许只写「表现好/表现差」。
- 讲话稿中出现的每一个数字，必须能在区域月度经营数据.csv 或其派生口径中复算得出。
- 成绩区只点名 A 级区域，问题区点名 D 级区域，C 级区域进行动区，不混用。
- 讲话稿是讲话材料不是培训材料：不写培训练习、不写考核细则。
- 不写任何效率百分比或效果承诺。

### 生成后自检

【生成后自检，逐条回答】
1. 每行亮点/短板是否都含具体数据与信号编号？
2. 评级分布是否与信号判定逐一吻合？（本期应为 A 2 / B 3 / C 3 / D 2）
3. 整体盘面是否为：标本量合计 253.8 万份、营收合计 17,705 万元、整体同比 +6.2%、特检占比 25.7%、时效达标实验室 7/10？
4. 行动指引是否逐区域给出且带时限？
5. 讲话材料是否为五段式且总时长控制在 8 分钟口径内？
自检全过再输出 CSV。

### 输出格式

【输出格式】CSV，6 列，列名与顺序固定：
区域, 评级, 亮点, 短板, 行动指引, 讲话要点
另附讲话材料成文口径（五段式，每个数字标注来自哪个区域的哪个口径）。
