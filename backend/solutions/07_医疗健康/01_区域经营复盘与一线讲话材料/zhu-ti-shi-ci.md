## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某第三方医学检验机构 · 9 月区域经营月度复盘」做评级与行动指引，并按讲话材料结构给出成文口径。

【输入 1 · 区域月度经营数据】区域月度经营数据.csv（10 行）
- 含区域编号、区域名称、标本量万份、去年同期标本量万份、营收万元、去年同期营收万元、特检收入万元、报告时效达标率
【输入 2 · 复盘框架】复盘框架说明.md
- 计算口径：营收同比 = (本月营收−去年同期营收)÷去年同期营收；特检占比 = 特检收入÷营收
- 短板信号：S1 营收同比<0 / S2 报告时效达标率<92% / S3 特检占比<20%
- 亮点信号：H1 营收同比≥10% / H2 特检占比≥30% / H3 报告时效达标率≥96%
- 评级规则：A=短板0且亮点≥2 / B=短板0且亮点≤1 / C=短板1 / D=短板≥2
- 讲话材料结构：开场定调→成绩讲透→问题点明→行动具体→收尾，总时长 8 分钟约 1,900 字

【输出】区域复盘与行动指引表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「区域经营复盘与一线讲话材料」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **杭州实验室为什么是 A 级？** 期望回答：营收同比 +18.0%（H1）、特检占比 32.5%（H2）、时效 97.2%（H3），三项亮点全中且无短板。
2. **郑州实验室和西安实验室为什么都是 D 级？** 期望回答：郑州营收同比 −5.0%（S1）、时效 89.8%（S2）、特检占比 16.5%（S3）三项短板；西安营收同比 −4.3%（S1）、时效 90.6%（S2）、特检占比 16.4%（S3）三项短板。
3. **宁波实验室营收是正增长为什么只评 C？** 期望回答：营收同比 +2.6% 不触发 S1，特检占比 20.5% 不触发 S3，但时效 91.5% < 92% 触发 S2，短板 1 项 → C。
4. **整体特检占比 25.7% 怎么算出来的？** 期望回答：特检收入合计 4,551 万元 ÷ 营收合计 17,705 万元 = 25.7%。
5. **讲话稿成绩区为什么只讲杭州武汉？** 期望回答：A 级区域只有 2 个（杭州、武汉），框架规定成绩区只点名 A 级区域。
