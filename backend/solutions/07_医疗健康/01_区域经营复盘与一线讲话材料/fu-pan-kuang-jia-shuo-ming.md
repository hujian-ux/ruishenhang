# 复盘框架说明（某第三方医学检验机构 · 区域月度经营复盘）

本说明定义区域月度复盘的判定规则与讲话材料结构。所有判定只使用 `区域月度经营数据.csv` 中的原始字段，先算口径、再判信号、后定评级，任何人按本说明都能复算出同一张评级表。

## 一、计算口径

| 指标 | 口径 |
| --- | --- |
| 营收同比 | (本月营收 − 去年同期营收) ÷ 去年同期营收 × 100% |
| 标本量同比 | (本月标本量 − 去年同期标本量) ÷ 去年同期标本量 × 100% |
| 特检占比 | 特检收入 ÷ 营收 × 100%（特检指基因、质谱、病理等高附加值项目） |
| 报告时效达标率 | 约定时限内出具报告的标本数 ÷ 标本总数 × 100%（取自实验室月报口径） |

## 二、短板信号（任一命中记 1 项短板）

| 编号 | 判定条件 |
| --- | --- |
| S1 | 营收同比 < 0%（负增长） |
| S2 | 报告时效达标率 < 92% |
| S3 | 特检占比 < 20% |

## 三、亮点信号（任一命中记 1 项亮点）

| 编号 | 判定条件 |
| --- | --- |
| H1 | 营收同比 ≥ 10% |
| H2 | 特检占比 ≥ 30% |
| H3 | 报告时效达标率 ≥ 96% |

## 四、区域评级规则（先数短板，再数亮点）

| 评级 | 判定条件 |
| --- | --- |
| A | 短板 0 项 且 亮点 ≥ 2 项 |
| B | 短板 0 项 且 亮点 ≤ 1 项 |
| C | 短板 1 项 |
| D | 短板 ≥ 2 项 |

## 五、行动指引映射（按信号组合生成，逐区域给出）

| 命中信号 | 行动指引 |
| --- | --- |
| S1 营收同比<0 | 两周内完成送检客户流失排查，锁定流失机构名单并制定回访计划 |
| S2 时效<92% | 一周内排查标本前处理与冷链交接环节，出时效改进清单并落实到组 |
| S3 特检占比<20% | 组织特检项目宣讲，向重点医院推广高附加值项目组合 |
| 无短板且有亮点 | 把特检推广与时效管理做法整理成标准动作，向同类区域输出 |
| 无短板无亮点 | 稳住基本盘，选定 1 个特检重点客户群做专项突破 |

## 六、讲话材料结构（面向一线团队，不是培训材料）

总时长 8 分钟，全文约 1,900 字，五个部分按序展开：

1. **开场定调（约 1 分钟）**：报整体盘面——标本量合计、营收合计、整体同比，让一线先看到全貌。
2. **成绩讲透（约 2 分钟）**：点名 A 级区域，逐个说清数据（同比多少、特检占比多少、时效多少）与打法归因，讲「为什么能涨」。
3. **问题点明（约 2 分钟）**：点名 D 级区域与短板信号，报出具体差距值，只说事实不贴标签，讲「差在哪里」。
4. **行动具体（约 2 分钟）**：按行动指引逐区域讲动作，每条动作带时限与责任岗位，讲「下一步做什么」。
5. **收尾（约 1 分钟）**：给出下月整体目标口径（如整体同比、时效达标实验室数量），一句话收束。

## 七、口径硬约束

- 讲话稿中出现的每一个数字，必须能在 `区域月度经营数据.csv` 或其派生口径中复算得出，不允许出现无出处的数字。
- 成绩区只点名 A 级区域，问题区点名 D 级区域，C 级区域进行动区，不混用。
- 讲话稿是讲话材料不是培训材料：不写培训练习、不写考核细则，只写「讲什么、怎么讲、讲完要什么动作」。
