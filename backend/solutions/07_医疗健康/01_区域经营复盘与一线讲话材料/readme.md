# MED-01 · 区域经营复盘与一线讲话材料 —— 场景使用说明

- **行业**：医疗健康
- **角色**：区域经营岗（陆知远）
- **场景编号**：MED-01
- **案例主体**：某第三方医学检验机构

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/区域经营复盘与一线讲话材料/SKILL.md` | Skill 定义 | 口径计算、S1-S3/H1-H3 信号判定、A-D 评级规则、行动指引映射与讲话材料结构 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `区域月度经营数据.csv` | 原始输入 | 10 个区域实验室 × 8 字段：标本量、去年同期标本量、营收、去年同期营收、特检收入、报告时效达标率 |
| `复盘框架说明.md` | 原始输入 | 计算口径、短板/亮点判定规则、评级规则、行动指引映射、讲话材料五段式结构 |
| `区域复盘与行动指引表.csv` | **交付物** | 10 行：区域 × 评级 × 亮点 × 短板 × 行动指引 × 讲话要点 |
| `区域经营岗-区域经营复盘与一线讲话材料.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `区域月度经营数据.csv`、`复盘框架说明.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 评级表供管理层核对，讲话材料按五段式口径成文后用于一线动员。

| 断言 | 结果 |
| --- | --- |
| `区域月度经营数据.csv` 数据行 = 10 | 通过 |
| `区域复盘与行动指引表.csv` 数据行 = 10，6 列表头一致 | 通过 |
| 评级分布 = A 2 / B 3 / C 3 / D 2 | 通过 |

| 营收合计 = 17,705 万元，去年同期合计 = 16,675 万元 | 通过 |
| 整体同比 = (17705 − 16675) ÷ 16675 = +6.2% | 通过 |
| 特检收入合计 = 4,551 万元，特检占比 = 4551 ÷ 17705 = 25.7% | 通过 |

### 可复算口径

- `营收同比 = (营收 − 去年同期营收) ÷ 去年同期营收 × 100%`
- `特检占比 = 特检收入 ÷ 营收 × 100%`
- `评级 = 短板 0 且亮点 ≥2 → A；短板 0 → B；短板 1 → C；短板 ≥2 → D`
- 短板信号：S1 营收同比 <0 / S2 时效 <92% / S3 特检占比 <20%
- 亮点信号：H1 营收同比 ≥10% / H2 特检占比 ≥30% / H3 时效 ≥96%

### 关键数字溯源

| 数字 | 出处与算法 |
| --- | --- |
| 10 个区域实验室 | `区域月度经营数据.csv` 数据行数 |
| 253.8 万份标本 | 10 行标本量字段求和 |
| 17,705 万元营收 / +6.2% 同比 | 10 行营收求和；(17705 − 16675) ÷ 16675 |
| 特检占比 25.7% | 特检收入合计 4,551 ÷ 营收合计 17,705 |
| 杭州 A 级：同比 +18.0%、特检 32.5%、时效 97.2% | R01 行原始字段直接计算 |
| 郑州 D 级：同比 −5.0%、时效 89.8%、特检 16.5% | R09 行原始字段直接计算 |
| 宁波 C 级（时效 91.5% 触发 S2） | R08 行时效字段 < 92 |
