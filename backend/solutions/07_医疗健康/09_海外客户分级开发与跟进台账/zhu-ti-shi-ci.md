## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某医疗防护制品企业 · 海外销售团队」生成统一的客户分级与跟进台账，输出一张可复核的 CSV。

【输入 1 · 客户往来记录】海外客户往来记录.csv（30 行）
- 含客户编号、客户名称、区域、最近订单日期、年采购额USD、沟通渠道、跟进事项
- 跟进事项列同时是历史触达核查底稿：有在手事项的客户，跟进动作必须从待办续起
【输入 2 · 分级与跟进规则】分级与跟进规则.md
- 基准日 2026-06-30；间隔天数 = 基准日 − 最近订单日期（自然日）
- 分级规则（判定顺序 GA1→GB1→GB2→GC1，命中即定级）：
  · GA1：年采购额 ≥200,000 USD 且间隔 ≤90 天 → A 级
  · GB1：年采购额 ≥200,000 USD 且间隔 >90 天 → B 级
  · GB2：60,000 ≤ 年采购额 <200,000 USD 且间隔 ≤180 天 → B 级
  · GC1：其余 → C 级
- 跟进节奏：A 级每 14 天（下次跟进日期 = 基准日 + 14 天）、B 级每 30 天（+30 天）、C 级每 90 天（+90 天）

【输出】客户分级与跟进台账.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「海外客户分级开发与跟进台账」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **半年未下单的 TH-C02（年采购额 215,000 USD）为什么是 B 级而不是 C 级？** 期望回答：GB1 规则——金额 ≥200,000 但间隔 166 天 >90 天，命中 B 级；金额达标保住了等级，但需在跟进事项里关注竞品替代风险。
2. **TH-C20（年采购额 56,000 USD）如果下个季度涨到 62,000 USD 会升级吗？** 期望回答：不一定——GB2 还要求间隔 ≤180 天，若订单间隔仍超 180 天，依旧 GC1 判 C 级；金额与活跃度缺一不可。
3. **A 级 8 家的金额占比是多少？** 期望回答：2,923,000 / 5,042,000 = 58.0%，8 家客户（27% 的客户数）贡献过半采购额，这是重点维护的直接依据。
4. **为什么 A 级统一 2026-07-14 跟进？** 期望回答：下次跟进日期 = 基准日 2026-06-30 + 14 天节奏，与单个客户的最近沟通日期无关，保证同等级节奏一致。
5. **哪些客户触达前必须先查历史？** 期望回答：TH-C14、TH-C20、TH-C25 的跟进事项均标注历史触达记录待核查，重复触达风险最高。

## 验收清单

- [ ] 30 行输出，与输入客户编号逐行对应
- [ ] 分级分布 = A 8 家 / B 12 家 / C 10 家
- [ ] A 级年采购额合计 2,923,000 USD，占 30 家合计 5,042,000 USD 的 58.0%
- [ ] 每行判定依据含规则编号（GA1/GB1/GB2/GC1）+ 金额实测值 + 间隔实测值
- [ ] 下次跟进日期 = 2026-07-14（A）/ 2026-07-30（B）/ 2026-09-28（C）
- [ ] 建议动作按等级映射，跟进事项已有待办的客户保留原待办表述
