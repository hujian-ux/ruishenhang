# MED-08 · 海外客户分级开发与跟进台账 —— 场景使用说明

- **行业**：医疗健康
- **角色**：海外销售岗（林澜）
- **场景编号**：MED-08
- **案例主体**：某医疗防护制品企业

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/海外客户分级开发与跟进台账/SKILL.md` | Skill 定义 | 四条分级规则（GA1/GB1/GB2/GC1）、三级跟进节奏、判定依据书写规范与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `海外客户往来记录.csv` | 原始输入 | 30 行客户往来明细（邮件、聊天工具与个人备忘归集后） |
| `分级与跟进规则.md` | 原始输入 | 基准日 2026-06-30、分级规则、跟进节奏与建议动作映射 |
| `客户分级与跟进台账.csv` | **交付物** | 30 行分级台账：客户 × 等级 × 判定依据 × 下次跟进日期 × 建议动作 |
| `海外销售岗-海外客户分级开发与跟进台账.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `海外客户往来记录.csv`、`分级与跟进规则.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 台账导入团队协作表统一维护；客户降级与淘汰由销售主管人工决定。

### 可复算口径

- `间隔天数 = 基准日 2026-06-30 − 最近订单日期`（自然日）
- `等级 = GA1（≥200,000 且 ≤90 天）→ GB1（≥200,000 且 >90 天）→ GB2（60,000–200,000 且 ≤180 天）→ GC1（其余）`，命中即定级
- `下次跟进日期 = 基准日 + 节奏天数（A 14 / B 30 / C 90）`
- `A 级金额占比 = A 级年采购额合计 ÷ 30 家合计 × 100%`

## 五、真实性等级与边界

- **T3**：海外销售岗位痛点来自外贸业务实践归纳。
- **构造**：客户名单、金额与日期为构造数据，分级口径可复算。
- **人工边界**：客户深度背调、分级规则修订、让价谈判与客户淘汰的最终决定一律人工；本场景全部输出中**不出现客户淘汰结论**。
