# 日报与汇报模板（某医疗防护制品企业 · 国际业务支持）

本文件是「工作日报与出差汇报规范化生产」场景的模板与归类规则输入。**结构先定、素材后归**：每一条素材流入哪份文档、落到哪个章节、要不要双语，都由本文件的规则决定，不由写的人临时发挥。

## 一、文档结构模板

### 1. 工作日报（每个工作日一份，当日产出）

| 章节 | 内容要求 |
| --- | --- |
| 今日要事 | 当日客户拜访与沟通要点，按「事项—进展—结果」三段式扩写成段 |
| 订单进展 | 当日订单推进条目，写明客户、当前节点与下一步 |
| 行政事务 | 当日内部事务与面向客户的行政动作，一句话交代即可 |

日报标题格式：`工作日报 YYYY-MM-DD · 海外业务支持`

### 2. 出差汇报（一次出差一份，返程后 1 个工作日内产出）

| 章节 | 内容要求 |
| --- | --- |
| 行程概览 | 出差区间、城市与交通住宿安排、拜访对象清单 |
| 客户拜访纪要 | 按客户逐家记录：拜访对象、议题、达成的共识 |
| 结论与待办 | 出差期间的订单进展、结论决定与带回的待办事项 |

出差汇报标题格式：`出差汇报 YYYY-MM-DD至YYYY-MM-DD · 区域`

## 二、素材归类规则

| 规则编号 | 条件 | 归入文档 | 章节位置 |
| --- | --- | --- | --- |
| R1 | 日期在出差区间（2026-06-08 至 2026-06-10）且类型=行政 | 东南亚出差汇报（2026-06-08至06-10） | 行程概览 |
| R2 | 日期在出差区间且类型=拜访 | 东南亚出差汇报（2026-06-08至06-10） | 客户拜访纪要 |
| R3 | 日期在出差区间且类型=订单 | 东南亚出差汇报（2026-06-08至06-10） | 结论与待办 |
| R4 | 日期不在出差区间且类型=拜访 | 工作日报（当日） | 今日要事 |
| R5 | 日期不在出差区间且类型=订单 | 工作日报（当日） | 订单进展 |
| R6 | 日期不在出差区间且类型=行政 | 工作日报（当日） | 行政事务 |

判定顺序：先判日期是否在出差区间，再按类型映射章节。素材归类列写「出差汇报素材」或「日报素材」。

## 三、双语转换规则

| 规则编号 | 条件 | 双语转换状态 |
| --- | --- | --- |
| L1 | 归入出差汇报（整篇要求中英双语版本，同步海外区域团队） | 中英已转换 |
| L2 | 归入日报且关联客户 ≠ 内部（面向海外客户的条目附英文摘要） | 中英已转换 |
| L3 | 归入日报且关联客户 = 内部 | 仅中文（内部事务） |

## 四、扩写与一致性规范

1. 每条素材扩写为完整段落时保持「事项—进展—结果」三段式，语气客观、不夸大；
2. 同类素材在不同批次间的版式、章节顺序与语气保持一致，不允许同一场景出现两种格式；
3. 素材流水 20 条 = 产出表 20 行，逐条对应，不允许合并、拆分或遗漏；
4. 出差汇报的「结论与待办」章节中，每条待办必须写明责任人归属（本人 / 转内部核价 / 待客户回复）。

## 五、硬性约束

1. 归类结论只能引用 R1–R6 规则编号，不得新增规则或凭感觉归章；
2. 双语状态只能按 L1–L3 判定，不按个人判断增减；
3. 不允许出现「综合整理」「其他事项」这类无法溯源的兜底章节；
4. 日报与汇报中的事实只能来自素材流水，不允许补充未经记录的业绩数字。
