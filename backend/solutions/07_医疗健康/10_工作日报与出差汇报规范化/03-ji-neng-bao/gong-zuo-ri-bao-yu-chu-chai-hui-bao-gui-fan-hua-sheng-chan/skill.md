# 工作日报与出差汇报规范化生产

## 一、这个 Skill 解决什么

日常汇报密度高的岗位，真实困难不是「没东西可写」，而是**每天从零开始回忆、每次格式都不一样**：

- 素材碎片散在聊天记录、日历和脑子里，写日报前先花半小时回忆
- 同一个人这周写的日报和上周结构不一样，跨人更没法比
- 出差回来一堆待办，汇报另起炉灶，格式又变一套
- 面向海外团队需要中英双语，哪条要转英文、哪条只用中文，全凭当次判断

本 Skill 的核心动作，是让「结构先定、素材后归」——每条素材流入哪份文档、落到哪个章节、要不要双语，全部由规则决定，跨批次稳定复现。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 工作日结束，需要按固定结构产出当日日报 | 主用场景：素材归集 + 章节归类 + 扩写成文 |
| 出差返程，需要 1 个工作日内交出结构化汇报 | 行程、客户纪要、结论与待办三段式产出 |
| 汇报需要同步海外区域团队，要求中英双语 | 双语规则自动判定哪些条目要转换 |
| 不同批次汇报需要格式完全一致 | 结构与规则固化，跨会话稳定输出 |

**不适用**：需要深度分析的经营复盘报告（本 Skill 只做素材的规范化生产）；季度绩效考核材料（数据口径不同）。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `日报素材流水.csv` | 必需 | 日期、类型（拜访/订单/行政）、事项、关联客户、结果 |
| 2 | `日报与汇报模板.md` | 必需 | 日报三章节结构、出差汇报三章节结构、R1–R6 归类规则、L1–L3 双语规则、扩写与一致性规范 |

> 缺 2（模板文件）时，本 Skill **必须拒绝输出**——没有先定的结构，汇报生产就退化成每次自由发挥。这是本 Skill 最重要的一条硬规则。

## 四、输出（outputs）

唯一交付物：`规范日报与汇报产出表.csv`，字段固定为 8 列：

```
序号, 日期, 类型, 事项, 素材归类, 归入文档, 章节位置, 双语转换状态
```

- `素材归类` ∈ {日报素材, 出差汇报素材}
- `归入文档`：日报格式为 `工作日报 YYYY-MM-DD · 海外业务支持`；出差汇报格式为 `东南亚出差汇报（2026-06-08至06-10）`
- `章节位置`：日报 ∈ {今日要事, 订单进展, 行政事务}；出差汇报 ∈ {行程概览, 客户拜访纪要, 结论与待办}
- `双语转换状态` ∈ {中英已转换, 仅中文（内部事务）}
- 行数 = 输入行数（20 行），逐条对应，不允许合并、拆分或遗漏

## 五、工作流程（workflow）

### STEP 1 · 归集素材流水

把当日沟通记录、日程与工作痕迹整理为 `日报素材流水.csv`，每条一行：日期、类型、事项、关联客户、结果五字段齐全才算归集完成。

### STEP 2 · 先定结构再动笔

从 `日报与汇报模板.md` 读入文档结构与归类规则，写成显式判定表。**顺序不可颠倒**——先看素材再定结构，格式就会漂移。

```
R1  出差区间 + 行政   → 出差汇报 · 行程概览
R2  出差区间 + 拜访   → 出差汇报 · 客户拜访纪要
R3  出差区间 + 订单   → 出差汇报 · 结论与待办
R4  非出差区间 + 拜访 → 当日日报 · 今日要事
R5  非出差区间 + 订单 → 当日日报 · 订单进展
R6  非出差区间 + 行政 → 当日日报 · 行政事务
```

### STEP 3 · 逐条归类与双语判定

先判日期是否在出差区间（本批为 2026-06-08 至 2026-06-10），再按类型映射章节；双语按 L1（出差汇报整篇双语）/ L2（日报中面向客户的条目）/ L3（内部条目仅中文）判定。

### STEP 4 · 三段式扩写成文

每条素材按「事项—进展—结果」三段式扩写为完整段落，落入对应章节。事实只能来自素材流水，不允许补充未经记录的业绩数字。

### STEP 5 · 一致性校准

核对批次间版式、章节顺序与语气是否一致；同类素材不允许出现两种格式。历次输出的格式要求保持统一，跨会话生效。

### STEP 6 · 自检与人工边界声明

输出前逐项自检，任一不过则不得输出：

1. 产出表行数是否 = 素材流水行数（20 行）？
2. 每条素材的归类是否引用 R1–R6 规则、双语状态是否引用 L1–L3 规则？
3. 归入文档数量是否可复算（本批：5 份日报 + 1 份出差汇报）？
4. 双语分布是否可复算（本批：中英已转换 17 条、仅中文 3 条）？
5. 是否没有任何一条出现「综合整理」「其他事项」兜底章节？

## 六、关键规则（不可协商）

1. **结构先定、素材后归。** 归类结论只能引用 R1–R6，不得临时新增规则或凭感觉归章。
2. **双语状态不按个人判断。** L1–L3 写在模板里，面向海外客户的条目必须附英文摘要，内部条目只出中文。
3. **事实不外溢。** 扩写只重组素材流水里的信息，不允许补充未经记录的数字与业绩。
4. **格式一致性是验收标准。** 不是一次性生成就结束，历次输出格式必须统一，跨会话生效。
5. **每条待办写明责任人归属。** 出差汇报「结论与待办」章节中，待办必须标注本人 / 转内部 / 待客户回复。
6. **不承诺效率百分比。** 输出中不写「节省 X 小时」这类无法核验的表述。

## 七、人工边界

| AI 负责 | 人负责（国际业务支持岗） |
| --- | --- |
| 素材归集与五字段格式校验 | 素材的真实性与完整性确认 |
| 按规则归类与双语状态判定 | 模板结构的制定与修订 |
| 三段式扩写与格式一致性 | 汇报中的主观判断与结论措辞 |
| 批次间一致性校准 | 汇报的最终签发与抄送范围 |

## 八、下游衔接

- 出差汇报「结论与待办」中的意向与询价 → 海外客户分级开发与跟进台账（MED-08）的跟进事项列
- 待客户回复的英文目录与报价需求 → 产品内容目录与视觉方案批量加工（MED-10）
- 日报「订单进展」章节 → 跟单交付与单证加工场景


## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读模板再归类：把 R1-R6 与 L1-L3 写成显式判定表，不要先看素材再定结构。
2. 逐条归类：对 20 条素材逐条判定归入文档与章节位置，归入文档格式：日报为「工作日报 YYYY-MM-DD · 海外业务支持」，出差汇报为「东南亚出差汇报（2026-06-08至06-10）」。
3. 双语标注：按 L1-L3 判定每条的双语转换状态，出差汇报素材一律「中英已转换」。
4. 三段式扩写：按「事项—进展—结果」结构把每条素材扩写为完整段落，事实只能来自素材流水。
5. 统计汇总：给出归入文档数量（日报份数 + 出差汇报份数）、章节分布、双语转换分布。

### 硬性约束

【硬性约束】
- 归类结论只引用 R1-R6 规则，双语状态只按 L1-L3 判定，不得新增规则或凭感觉归章。
- 不允许出现「综合整理」「其他事项」这类无法溯源的兜底章节。
- 扩写不补充素材流水之外的业绩数字。
- 不写任何效率百分比或时间节省承诺。

### 生成后自检

【生成后自检，逐条回答】
1. 产出表行数是否 = 20，与输入逐条对应？
2. 是否产出 5 份日报（6月1日3条/6月2日3条/6月3日3条/6月4日2条/6月5日2条）+ 1 份出差汇报（7 条）？
3. 章节分布是否为：今日要事3 / 订单进展6 / 行政事务4 / 行程概览2 / 客户拜访纪要3 / 结论与待办2？
4. 双语分布是否为：中英已转换 17 条、仅中文（内部事务）3 条？
5. 每条素材是否都能按规则编号复算出同一归类？
自检全过再输出 CSV。

### 输出格式

【输出格式】CSV，8 列，列名与顺序固定：
序号, 日期, 类型, 事项, 素材归类, 归入文档, 章节位置, 双语转换状态
共 20 行，与输入逐条对应，不合并、不拆分、不遗漏。
