# MED-09 · 工作日报与出差汇报规范化生产 —— 场景使用说明

- **行业**：医疗健康
- **角色**：国际业务支持岗（周砚）
- **场景编号**：MED-09
- **案例主体**：某医疗防护制品企业

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/工作日报与出差汇报规范化生产/SKILL.md` | Skill 定义 | 日报与出差汇报六章节结构、R1–R6 归类规则、L1–L3 双语判定、三段式扩写规范 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `日报素材流水.csv`、`日报与汇报模板.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 产出表确认后交给 AI 三段式扩写成文，中英版本分别归档。

### 可复算口径

- `归类 = 先判日期 ∈ [2026-06-08, 2026-06-10]，再按类型映射章节（R1–R6）`
- `双语状态 = L1（出差汇报整篇双语）/ L2（日报且关联客户≠内部）/ L3（日报且关联客户=内部）`
- `归入文档 = 日期去重计数（在岗 5 个工作日 → 5 份日报；出差区间 → 1 份汇报）`

## 五、真实性等级与边界

- **T3**：汇报规范化痛点来自外贸业务支持岗实践归纳。
- **构造**：素材流水为客户名与事项的构造数据，归类口径可复算。
- **人工边界**：素材真实性确认、模板结构修订与汇报最终签发一律人工；本场景全部输出中**不补充素材之外的业绩数字**。
