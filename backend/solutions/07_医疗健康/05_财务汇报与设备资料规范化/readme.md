- **案例主体**：某医疗器械流通企业

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `财务专题数据.csv`、`设备资料清单.csv`、`汇报框架.md` 三份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 方案表交财务与质量负责人确认催收安排与补办时限后执行。

### 断言项

| 断言 | 结果 |
| --- | --- |
| `财务专题数据.csv` 数据行 = 20，`设备资料清单.csv` 数据行 = 15 | 通过 |
| `专题汇报与资料规范化方案表.csv` 数据行 = 35（20 + 15） | 通过 |
| 应收总额 = 9,530 万元（20 户求和） | 通过 |
| 分级分布 = 高 3 / 中 8 / 正常 9；高 2,305 万（24.2%）、中 3,815 万（40.0%） | 通过 |
| 高风险名单 = 桐岭县人民医院（106 天）/ 江城中心医院（85 天）/ 平川县人民医院（62 天） | 通过 |
| 资料分布 = 缺失 4 / 不全 5 / 已归档 6，合规率 40.0% | 通过 |

### 可复算口径

- `逾期天数 = 账龄天数 − 合同账期`（如桐岭县人民医院：196 − 90 = 106 天）
- `分级 = 逾期 >60 高 / 0<x≤60 中 / ≤0 正常`
- `高风险金额占比 = 2305 ÷ 9530 = 24.2%`；`中风险 = 3815 ÷ 9530 = 40.0%`
- `资料合规率 = 已归档 6 ÷ 15 = 40.0%`
