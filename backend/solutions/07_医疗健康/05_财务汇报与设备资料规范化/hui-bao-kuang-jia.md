# 汇报框架 · 财务专题汇报与设备资料规范化

## 一、汇报定位

面向管理层的双专题汇报：应收账款风险 + 设备资料合规。汇报时长 15 分钟，每个专题一页结论、一页明细，所有数字可回指底表。

## 二、专题一：应收账款结构与风险分级

### 风险分级规则

- 逾期天数 = 账龄天数 − 合同账期（天）
- **高风险**：逾期天数 > 60 天 → 建议动作：专项催收，发对账函并锁定后续发货额度
- **中风险**：0 < 逾期天数 ≤ 60 天 → 建议动作：例行跟进，电话催收并更新回款计划
- **正常**：逾期天数 ≤ 0 → 建议动作：正常账期管理，按合同账期跟踪

### 汇报结构（按此顺序成稿）

1. 总量：应收合计金额、覆盖客户数
2. 结构：高 / 中 / 正常三级金额与占比
3. 重点户：逾期最长、金额最大的前三个客户逐一说明
4. 动作：分级催收安排与发货额度管控

## 三、专题二：设备资料规范化

### 规范化动作规则

- **缺失** → 30 天内补办并归档
- **不全** → 60 天内更新补齐
- **已归档** → 年度复核确认

### 汇报结构

1. 总量：设备资料项数、覆盖设备数
2. 结构：缺失 / 不全 / 已归档分布与合规率（已归档 ÷ 总项数）
3. 动作：补办与更新清单、责任人与时限

## 四、成稿口径

- 金额单位统一为万元，保留整数；占比保留 1 位小数
- 每个结论必须回指「财务专题数据.csv / 设备资料清单.csv」的具体行与字段
- 两个专题的交付动作合并在一张方案表里，板块列区分
- 汇报正文控制在一页纸结构内，明细以附表形式随附
