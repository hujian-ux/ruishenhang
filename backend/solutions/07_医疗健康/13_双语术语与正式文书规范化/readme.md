# MED-12 · 双语术语与正式文书规范化加工 —— 场景使用说明

- **行业**：医疗健康
- **角色**：注册与医学写作岗（顾承砚）
- **场景编号**：MED-12
- **案例主体**：某创新药企业

## 一、文件清单

| 文件 | 类型 | 作用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `双语术语对照表.csv`、`正式文书模板.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 错译类术语（T19/T21）转医学事务确认后回写术语库；多形态往来资料转 MED-13 入库。

### 可复算口径

- `不统一类型`：按《正式文书模板.md》第二节规则——casefold 相同 → 大小写；去连字符压缩空格后相同 → 连字符；再忽略词尾 s 相同 → 单复数；其余 → 译法不统一
- `X 处译法不统一被纠正` = 不统一类型 ≠ 一致的行数 = **11 处**；其中 T19、T21 涉及医学语义，**2 处待确认**、9 处已定稿
- `影响文书分布` = 25 行「影响文书」列按分号拆分后计数（同一术语可影响多类文书）

## 五、真实性等级与边界

- **T2**：术语统一与文书加工方法论来自案例素材（术语确认 → 语气调整 → 规范统一 → 副本输出）。
- **T3**：岗位痛点来自素材中的传统/WorkBuddy 模式对比列。
- **构造**：术语数据（现行/标准译法对）为构造数据，判定口径可复算。
- **人工边界**：标准译法库裁决、错译类术语医学确认、对外交付签字一律人工；AI 只出判定、动作与校对状态。
