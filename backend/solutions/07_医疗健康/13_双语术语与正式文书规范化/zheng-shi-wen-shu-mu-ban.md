# 正式文书模板（双语术语与正式文书规范化加工 · MED-12）

某创新药企业注册与医学写作条线的双语术语统一与正式文书加工规范。本文件是生成与校验 `术语规范化与文书加工表.csv` 的唯一规则来源。

## 一、术语统一原则

1. **一词一译**：每个中文术语唯一对应一个标准英文译法，写进可复用配置，后续材料自动继承。
2. **缩写规范**：缩写首次出现给全称（如 overall survival, OS）；正文术语小写，专有名词与固定缩写除外。
3. **标题大小写**：英文标题用 Title Case；正文语境一律小写。同一术语在标题与正文中的写法差异属正常现象，不判为不统一。

## 二、不统一类型判定规则（按优先级自上而下）

1. 现行译法 = 标准译法 → **一致**
2. 仅大小写不同（casefold 后相同）→ **大小写不统一**
3. 仅连字符/空格书写形式不同（去连字符、压缩空格、casefold 后相同）→ **连字符不统一**
4. 仅单复数不同（在 3 的基础上再忽略词尾 s）→ **单复数不统一**
5. 其余 → **译法不统一**

## 三、规范化动作（按不统一类型）

| 不统一类型 | 规范化动作 |
| --- | --- |
| 一致 | 维持现行译法，写入可复用配置 |
| 大小写不统一 | 统一为标准写法（正文小写 / 标题 Title Case） |
| 连字符不统一 | 统一连字符书写形式 |
| 单复数不统一 | 统一为标准单复数形式 |
| 译法不统一 | 以标准译法替换现行译法 |

## 四、正式文书类型与结构

| 文书类型 | 结构 | 语气规范 |
| --- | --- | --- |
| 注册申请函 | 收件方 → 事由 → 申请内容 → 附件清单 → 落款 | 正式、克制，无口语化 |
| 说明信 | 背景说明 → 数据口径 → 结论 → 附件清单 | 客观、准确，不使用模糊量词 |
| 月度汇报标题 | 主题词 + 周期 + 关键结论词 | 简洁、名词化，英文标题用 Title Case |

## 五、加工与校对流程

1. **术语确认**：就关键表述的译法先行比对与确认，一词一译，缩写规范。
2. **语气调整**：按沟通对象调整措辞，使其通顺得体。
3. **规范统一**：统一标题大小写、标点与专有名词写法。
4. **副本输出**：一律生成新副本交付，原始文件保持只读不被覆盖。
5. **一致性全检**：交付前对全部术语 × 全部文书做一致性全检，出具逐条校对状态。

## 六、交付物口径

- 交付物 `术语规范化与文书加工表.csv`：每条术语一行，共 25 行；
- 「X 处译法不统一被纠正」= 不统一类型 ≠ 一致的行数（应为 11 处），其中 T19、T21 两处需医学事务确认后方可定稿；
- 影响文书分布按「影响文书」列分号拆分统计（注册申请函 13 条 / 说明信 10 条 / 月度汇报标题 3 条，同一术语可影响多类文书）。
