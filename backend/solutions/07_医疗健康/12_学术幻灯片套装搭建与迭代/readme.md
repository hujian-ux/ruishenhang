# MED-11 · 学术幻灯片套装搭建与迭代 —— 场景使用说明

- **行业**：医疗健康
- **角色**：医学事务岗（林知遥）
- **场景编号**：MED-11
- **案例主体**：某创新药企业（在研创新药 HD-2102）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/学术幻灯片套装搭建与迭代/SKILL.md` | Skill 定义 | 套装结构、图表类型映射、引用格式（按证据等级）、R1–R3 迭代规则与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `文献证据清单.csv` | 原始输入 | 20 行文献证据：研究、终点结果、证据等级、拟引用幻灯片位 |
| `幻灯片套装规范.md` | 原始输入 | 套装 12 页结构、页面类型定义、图表映射、引用格式、迭代规则 |
| `幻灯片套装与迭代计划表.csv` | **交付物** | 20 行套装与迭代计划：证据 × 目标页面 × 图表类型 × 引用格式 × 迭代轨迹 × 校验结果 |
| `医学事务岗-学术幻灯片套装搭建与迭代.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用|

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `文献证据清单.csv`、`幻灯片套装规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 套装定稿后按规范归档；双语表述与术语问题转 MED-12。

生成脚本 `gen_MED-11.py`（未随 zip 分发）以 Python 标准库 `csv` 实际写出文件，并在脚本内做断言验证。执行结果：


| 参考文献页切分：P11 = E01–E10，P12 = E11–E20 | 通过 |

### 可复算口径

- `套装页数` = 内容页（拟引用幻灯片位去重，10）+ 参考文献页（固定 2）= **12 页**
- `R2 更新页` = 审阅意见指定页集合 {P01, P07, P08, P09} = **4 页**；涉及证据行 = 落在这 4 页的证据数 = **11 处**（E05–E09、E12–E16、E19）
- `R3 术语统一` = 术语基线不一致的 3 处引用 = **3 处**（E02/E03/E04）
- `引用校验处数` = 交付物行数 = **20 处**，R3 全部通过

## 四、与案例链的数字对齐

| 数字 | 出处 | 在本场景的落点 |
| --- | --- | --- |
| 20 条文献证据 | `文献证据清单.csv` 20 行 | 交付物 20 行逐行对应 |
| 12 页套装 | `幻灯片套装规范.md` 套装结构 | 内容页去重 10 + 参考文献页 2 |
| R2 只改 4 个指定页、11 处引用 | 规范迭代规则 + 输入拟引用位 | 交付物「迭代轮次 = R1+R2」行 |
| R3 统一 3 处术语 | 规范术语基线 | 交付物 E02/E03/E04 行 |
| 引用格式按证据等级 A=14 / B=5 / C=1 | 输入「证据等级」列 | 交付物「引用格式」列逐档对应 |

## 五、真实性等级与边界

- **T2**：学术幻灯片套装方法论与迭代模式来自案例素材。
- **T3**：医学事务岗痛点来自素材中的传统/WorkBuddy 模式对比列。
- **构造**：文献证据数据（研究代码、终点数值）口径可复算。
- **人工边界**：套装整体口径、审阅意见裁决、对外使用前的合规与医学审查签字一律人工；AI 只出结构、计划与校验结论。
