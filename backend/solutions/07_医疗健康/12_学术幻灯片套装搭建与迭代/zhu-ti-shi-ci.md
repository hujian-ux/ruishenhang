# MED-11 主提示词 · 学术幻灯片套装搭建与迭代

## 使用说明

1. 先在 WorkBuddy 中启用本场景 Skill 包（`03_技能包/学术幻灯片套装搭建与迭代/SKILL.md`）。
2. 上传两个附件：`文献证据清单.csv`、`幻灯片套装规范.md`。
3. 复制下方「主提示词」原文发送。
4. 拿到 `幻灯片套装与迭代计划表.csv` 后，按文末「验收清单」逐项核对。

---

## 主提示词（复制即用）

```
请基于我上传的两份素材，为「某创新药企业 · 医学事务条线」搭建学术幻灯片套装并完成逐轮迭代计划，输出一张可复核的幻灯片套装与迭代计划表。

【输入 1 · 文献证据】文献证据清单.csv（20 行）
- 含证据编号、研究名称、研究类型、主要终点、终点结果、证据等级（A/B/C）、拟引用幻灯片位
【输入 2 · 套装规范】幻灯片套装规范.md
- 套装 12 页结构（P01–P12）、页面类型定义、图表类型映射规则、按证据等级的引用格式（A 完整引注 / B 编号引注 / C 脚注引注）
- 迭代规则：R1 全量搭建 / R2 只改审阅意见指定页（时间轴前置为首页、补充亚组分析、补充次要结局、新增同类研究对比页）/ R3 术语与引用一致性校验

【输出】幻灯片套装与迭代计划表.csv——列名与格式按技能输出定义执行。

执行步骤、判定规则、硬性约束与生成后自检，一律按已启用的「学术幻灯片套装搭建与迭代」技能执行（技能附录含本案例完整执行细则）。
```

## 本案例的关键追问（拿到结果后必须问）

1. **为什么时间轴页要从 P05 位置前置到 P01？** 期望回答：R2 审阅意见第一条要求把研究时间轴前置为首页，只动该页位置与内容，不触发其他页重做。
2. **E09 为什么用脚注引注？** 期望回答：E09 为学术会议摘要（PRO 分析），证据等级 C，按规范用脚注引注格式。
3. **E12–E16 都落在对比页，为什么？** 期望回答：同类药物 A/B 的 III 期 OS/PFS 数据与真实世界研究中位 OS，都是 R2 新增同类研究对比页（P09）的对比素材。
4. **R2 没动的页会不会被误改？** 期望回答：迭代规则限定 R2 只改 P01/P07/P08/P09 四个指定页，其余页保持 R1 状态不动。
5. **参考文献页怎么分？** 期望回答：P11 收录 E01–E10、P12 收录 E11–E20，各 10 条，合计 20 处引用全部入册。

## 验收清单

- [ ] 交付物 20 行，与文献证据清单逐行对应
- [ ] 内容页 10 页 + 参考文献页 2 页 = 12 页套装
- [ ] R2 更新 4 页（P01/P07/P08/P09）、涉及 11 处引用
- [ ] R3 术语统一 3 处（E02/E03/E04）
- [ ] 图表类型与映射规则一致；引用格式与证据等级 A=14 / B=5 / C=1 对应
- [ ] 20 处引用校验全部通过，数值与来源逐字一致
