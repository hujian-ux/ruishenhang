# ENG-08 · 流程月报与汇报材料一体化生成 —— 场景使用说明

- **行业**：制造与能源
- **角色**：流程管理岗（沈悦）
- **场景编号**：ENG-08
- **案例主体**：某消费电子制造企业（智能电视等整机研发制造，自动化测试团队、流程管理团队与终端软件团队协作）

## 一、文件清单

| 文件 | 类型 | 作用 |

| `03_技能包/流程月报与汇报材料一体化生成/SKILL.md` | Skill 定义 | 三级判定口径、卡点归因口径、汇报要点格式与人工边界 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `流程执行月度数据.csv`、`月报模板.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 改进项（F09 / F10）转专项治理，明确责任人与节点后更新材料分发。

### 断言项

| 断言 | 结果 |
| --- | --- |
| `流程执行月度数据.csv` 数据行 = 18 | 通过 |
| 交付物数据行 = 18，与流程清单一一对应 | 通过 |
| 总发起 / 总完成 = 1669 / 1592，整体完成率 95.4% | 通过 |
| 综合判定分布 = 达标 12 / 关注 4 / 改进 2 | 通过 |
| 关注 = F02 / F05 / F08 / F15；改进 = F09 / F10 | 通过 |
| F02 完成率 95.6% 但时长 52h 超 48h → 关注 | 通过 |
| F10 完成率 71.4% <80% → 改进 | 通过 |
| 卡点归因分布 = 跨部门 7 / 资源工具 4 / 审批 3 / 标准 3 / 无 1 | 通过 |
| F17 OTA灰度发布完成率 100%，无明显卡点 | 通过 |

### 可复算口径

- `完成率 = 本月完成量 ÷ 本月发起量（保留 1 位小数）`
- `达标 = 完成率 ≥90% 且 时长 ≤ 目标；关注 = 完成率 ≥80% 且 时长 ≤ 目标 × 1.2；改进 = 其余`
- `目标时长按流程域查表：研发 48 / 质量 24 / 变更 72 / 供应 96 / 发布 12（小时）`
- `卡点归因按关键词：无明显卡点 → 审批流转 → 资源与工具 → 标准与口径 → 跨部门协同（默认）`

## 五、真实性等级与边界

- **T2**：三级判定口径与月报结构方法论来自研发效能度量通用实践。
- **T3**：流程卡点口径来自岗位实践。
- **构造**：月度数据与判定结果口径可复算。
- **升 T1 还缺**：客户真实月报终稿与一次管理层汇报的反馈记录。
- **人工边界**：目标时长与阈值修订、改进项责任人与节点确定、材料最终签发一律人工。
