# 流程月报模板

适用范围：研发效能与流程团队的月度流程执行汇报。输入本月流程执行数据，按本模板完成汇总、达标判定、汇报要点整理与配套演示稿大纲产出。

## 1. 月报结构（五段式）

```
一、本月总览：流程条数、总发起量、总完成量、整体完成率、达标分布
二、分域明细：按流程域逐条列出各流程的完成率与时长对比目标
三、运行亮点：达标且完成率最高的流程及其可复制做法
四、问题清单：未达标流程逐条列出问题与卡点，不做归类堆叠
五、下月行动：逐条写明行动、责任人与完成节点
```

## 2. 达标判定规则（三级口径）

先查目标时长表，再按以下顺序判定（命中即停）：

| 判定 | 条件 |
| --- | --- |
| 达标 | 完成率 ≥90% 且 平均处理时长 ≤ 目标时长 |
| 关注 | 完成率 ≥80% 且 平均处理时长 ≤ 目标时长 × 1.2 |
| 改进 | 其余情形 |

```
完成率 = 本月完成量 ÷ 本月发起量（保留 1 位小数，百分数呈现）
```

## 3. 目标时长表（按流程域）

| 流程域 | 目标时长（小时） |
| --- | --- |
| 研发域 | 48 |
| 质量域 | 24 |
| 变更域 | 72 |
| 供应域 | 96 |
| 发布域 | 12 |

## 4. 卡点归因口径（按关键词判定）

| 归因类别 | 关键词 |
| --- | --- |
| 无明显卡点 | 卡点描述含「无明显卡点」 |
| 审批流转 | 档期 / 签批 / 影响面评估 |
| 资源与工具 | 工具 / 环境 / 排队 / 超时 |
| 标准与口径 | 标准 / 定级 / 模板 |
| 跨部门协同 | 其余情形（默认归入） |

## 5. 汇报要点生成规则

每条流程的汇报要点固定格式：`流程名称：完成率 X%（完成/发起），判定为「XX」；卡点：XX`。

面向管理层的演示稿大纲固定三条：

1. **整体口径**：18 条流程，总发起量与总完成量、整体完成率、达标 / 关注 / 改进分布；
2. **最大卡点归因**：占比最高的归因类别及条数，点名对应流程；
3. **改进项清单**：判定为「改进」的流程逐条列出卡点、责任人与节点。

## 6. 表述与分发纪律

- 通俗化表达：面向管理层时不使用内部缩写，问题逐条列出而非归类堆叠；
- 换受众只调整详略与措辞，数据口径不得变动；
- 材料更新后重新生成，按收件对象定向分发，演示稿、可打印文档、网页版数据同源。

## 7. 人工边界

数据汇总、达标判定、要点整理与格式转换由 AI 承担；目标时长与判定阈值的修订、改进项责任人与节点的确定、材料的最终签发，属于流程管理团队。
