## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `大宗原料采购与消耗表.csv`、`分析口径说明.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 带标记的月份（库存偏高/偏低、价格上行/回落、采购收缩）结合市场行情做归因，形成例会结论——原始表始终保持只读。

### 可复算口径

- `不含税采购额 = 含税采购额 ÷ 1.13`（含税行），采购额万元 = 不含税额 ÷ 10000（2 位）
- `平均采购单价 = 不含税采购额 ÷ 采购量`（元/吨，2 位）
- `环比 =（本期 − 上期）÷ 上期 × 100`（1 位，首月「—」）
- `库存天数 = 期末库存 ÷（当月消耗 ÷ 当月自然天数）`（2 位；1-5 月天数 31/28/31/30/31）
- 标记阈值：库存 >45 天偏高 / <15 天偏低 / 单价环比 ≥+5% 上行 / ≤−5% 回落 / 采购量环比 ≤−10% 收缩

## 五、真实性等级与边界

- **T2**：只读分析、双主字段汇总方法论来自案例素材的实际使用行为归纳。
- **T3**：采购分析岗痛点来自行业通用管理实践。
- **构造**：采购与消耗数据、折算与标记结果口径可复算（gen_ENG-03.py 复跑一致）。
- **升 T1 还缺**：客户真实多基地采购台账与一轮真实经营例会结论。
- **人工边界**：口径说明制定、不平衡数据核实、标记的市场归因与采购节奏决策一律人工；AI 只做只读提取、口径统一、计算与标记。
