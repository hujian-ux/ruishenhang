# ENG-07 · 整机自动化验证脚本编写与维护 —— 场景使用说明

- **行业**：制造与能源
- **角色**：自动化测试岗（周启）
- **场景编号**：ENG-07
- **案例主体**：某消费电子制造企业（智能电视等整机研发制造，自动化测试团队、流程管理团队与终端软件团队协作）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/整机自动化验证脚本编写与维护/SKILL.md` | Skill 定义 | 脚本命名与五段式结构约束、前置动作规则、维护状态口径与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `整机测试项清单.csv` | 原始输入 | 20 行整机测试项明细（信号 / 接口 / 显示 / 音频 / 网络 / 系统） |
| `脚本规范.md` | 原始输入 | 命名规范、五段式结构、前置动作表、预期输出口径、维护状态判定 |
| `自动化脚本覆盖表.csv` | **交付物** | 20 行脚本覆盖台账：脚本名 × 前置动作 × 步骤数 × 预期输出 × 维护状态 |
| `gen_ENG-07.py` | 生成脚本 | 从原始输入计算生成交付物并断言验证 |
| `自动化测试岗-整机自动化验证脚本编写与维护.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `整机测试项清单.csv`、`脚本规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 待回归脚本修复单跑通过后进整机回归序列；人工保留项按评审记录表执行。

### 可复算口径

- `执行步骤数 = 验证要点条数（按「；」切分） + 前置步数（接口类/网络类 2，其余 1）`
- `脚本名 = AUTO_类型码_测试项编号_测试项名称去括号.py`
- `日志回收文件 = LOG_脚本名去扩展名.log`
- `维护状态 = 按上轮回归结果查表（通过/异常/未执行/不适用）`

## 五、真实性等级与边界

- **T2**：脚本规范与五段式结构方法论来自企业自动化测试通用实践。
- **T3**：测试项与回归状态口径来自岗位实践。
- **构造**：测试项清单与覆盖台账口径可复算。
- **升 T1 还缺**：客户真实脚本仓库与一轮完整回归的执行日志。
- **人工边界**：判定标准与阈值制定、主观画质与音质评定、回归通过与否的最终裁决一律人工。
