# 集团财务与数据多口径分析

## 一、这个 Skill 解决什么

多元化集团最棘手的问题之一是口径统一，**同一批业务数据在不同口径下答案不同**：

- 各事业部原报口径不一：有的按管理口径、有的按合并口径、有的按法人口径上报
- 换一个维度（组织 / 科目 / 股份）就要重做一遍透视与排版
- 口径规则靠口头或临时说明传递，结果不可复现
- 两套口径的差异数说不清构成，追溯不到明细

结果是：**同一笔业务，三个版本的收入**，管理层会上各说各的数。本 Skill 的核心动作，是先把散在各口径里的原报数据归一到管理口径基准，再按书面规则重述出合并与法人两种口径，差异逐行留构成。

## 二、什么时候用（适用时机）

| 触发情形 | 说明 |
| --- | --- |
| 各事业部台账口径不一，要汇总成集团口径 | 主用场景：归一 + 三口径重述 |
| 管理层要同一批数据的组织 / 合并 / 法人多维呈现 | 换维度以规则下达，一次生效 |
| 两套口径的差异数需要解释构成 | 差异说明写明金额、月数、方向 |
| 月度 / 季度例行多口径对照分析 | 口径即规则、规则可复用 |

**不适用**：事业部内部的现场成本核算（→ ENG-04 生产现场台账与成本数据结构化处理）；单法人主体的账务处理。

## 三、输入（inputs）

| # | 输入文件 | 必需 | 关键字段 |
| --- | --- | --- | --- |
| 1 | `事业部财务数据.csv` | 必需 | 事业部、期间、营业收入万元、营业成本万元、原报口径 |
| 2 | `多口径规则.md` | 必需 | 口径定义、原报归一规则、调整参数表、输出要求 |

> 缺 2（规则文件）时，本 Skill **必须拒绝输出**——没有书面规则的多口径汇总不可复现，这是本 Skill 最重要的一条硬规则。

## 四、输出（outputs）

唯一交付物：`多口径对照分析表.csv`，字段固定为 8 列：

```
事业部, 统计口径, 营业收入万元, 营业成本万元, 毛利万元, 毛利率, 与管理口径收入差异万元, 差异说明
```

- `统计口径` ∈ {管理口径, 合并口径, 法人口径}
- `毛利率` = 毛利 ÷ 营业收入，保留 2 位小数百分比
- `与管理口径收入差异万元` = 该口径收入 − 管理口径收入（基准行恒为 0.00）
- `差异说明` 必须写明调整构成（金额、月数、方向），**不允许写「综合调整」**

## 五、工作流程（workflow）

### STEP 1 · 读规则，先立口径再看数据

从 `多口径规则.md` 读入口径定义、归一规则与调整参数表，写成显式换算表。**顺序不可颠倒**——先看数据再定口径，等于给结果找口径。

### STEP 2 · 原报归一到管理口径

逐行按原报口径还原：管理原报直接用；合并原报加回内部交易抵销额；法人原报减去法人归属调整额。归一后各事业部应得 5 个月管理口径月度数。

### STEP 3 · 三口径汇总

管理口径 = 各月加总（基准）；合并口径 = 管理口径 − 5 × 内部交易抵销；法人口径 = 管理口径 + 5 × 法人归属调整。收入与成本分别换算，再派生毛利与毛利率。

### STEP 4 · 差异说明逐行留构成

每行差异写明金额、月数与方向（如「抵销内部交易收入 1,600 万元（5 个月 × 320）」）；集团合计行写明合计构成与明细。

### STEP 5 · 自检与人工边界声明

输出前逐项自检（见附录），任一不过则不得输出。对外披露口径的选择与最终确认属于集团财务部。

## 六、关键规则（不可协商）

1. **管理口径是基准。** 一切换算先归一到管理口径再重述；跳过归一直接汇总不同口径的行，是本 Skill 定义下的错误结果。
2. **规则先于数据。** 调整参数以书面规则文件为准；参数变更须财务部书面确认并同步文件，不得在分析层面临时调整。
3. **差异必须留构成。** 金额、月数、方向三要素齐全；「综合调整」「口径不同」不是合格的差异说明。
4. **每行可回溯。** 输出任意一行的任意数字，都能用原报行按参数表复算得出。
5. **抵销完整性不臆断。** 是否存在漏抵的内部交易由财务部按交易明细复核，AI 只按参数表执行。
6. **不承诺效率百分比。** 输出中不写「提升 X%」这类无法核验的表述。

## 七、人工边界

| AI 负责 | 人负责（集团财务岗 / 财务部） |
| --- | --- |
| 原报归一与三口径重述汇总 | 口径规则与调整参数的书面确认 |
| 差异计算与构成说明 | 内部交易抵销完整性的明细复核 |
| 毛利与毛利率派生 | 对外披露口径的选择与确认 |
| 对照表结构与数字整理 | 差异异常原因的业务解释 |

## 附 · 执行细则（本案例主提示词约束并入）

以下细则来自本场景案例的主提示词，与上文「关键规则」同等效力，执行时一并遵守。

### 执行要求

【执行要求】
1. 先读规则再看数据：把口径定义、原报归一规则与调整参数表写成显式换算表。
2. 原报归一：管理原报直接用；合并原报 + 内部交易抵销（收入 320/45/60/130，成本 281.60/38.25/54/117，按事业部）；法人原报 − 法人归属调整（收入 +85/−60/−40/+25，成本 +76.50/−51/−34/+21.25）。
3. 三口径汇总：管理口径 = 归一后 5 个月加总；合并口径 = 管理口径 − 5×抵销；法人口径 = 管理口径 + 5×调整。收入、成本分别换算后派生毛利与毛利率（2 位小数百分比）。
4. 输出 15 行：有色材料/教育服务/产业金融/数字科技各 3 行 + 集团合计 3 行；差异说明逐行写明金额、月数与方向，集团合计行附明细。

### 硬性约束

【硬性约束】
- 不得跳过归一：不同原报口径的行不得直接加总。
- 差异说明不允许写「综合调整」，必须含金额、月数、方向三要素。
- 全表 15 行，每个事业部恰好 3 行（管理/合并/法人），不得增删。
- 保留位数严格按规则文件执行；毛利率 2 位小数百分比。
- 不写任何效率百分比或效果承诺。

### 生成后自检

【生成后自检，逐条回答】
1. 输出是否为 15 行（4 事业部 × 3 口径 + 集团合计 × 3 口径）？
2. 每个事业部管理口径收入是否 = 原报行按口径还原后加总？
3. 合并口径差异是否 = −5×内部交易抵销（集团合计 −2,775 万元）？
4. 法人口径差异是否 = +5×法人归属调整（集团合计 +50 万元）？
5. 是否没有任何一行差异说明缺构成或缺少方向要素？
自检全过再输出 CSV。

### 输出格式

【输出格式】CSV，8 列，列名与顺序固定：
事业部, 统计口径, 营业收入万元, 营业成本万元, 毛利万元, 毛利率, 与管理口径收入差异万元, 差异说明
