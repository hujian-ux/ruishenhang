# ENG-06 · 集团财务与数据多口径分析 —— 场景使用说明

- **行业**：制造与能源
- **角色**：集团财务岗
- **场景编号**：ENG-06
- **案例主体**：某多元产业制造集团（4 个事业部）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/集团财务与数据多口径分析/SKILL.md` | Skill 定义 | 口径定义、归一规则、调整参数与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `事业部财务数据.csv` | 原始输入 | 20 行事业部月度财务数据（4 事业部 × 5 个月），原报口径不一 |
| `多口径规则.md` | 原始输入 | 口径定义、原报归一规则、调整参数表、输出要求 |
| `多口径对照分析表.csv` | **交付物** | 15 行对照表：事业部 × 3 口径汇总 + 差异说明 |
| `gen_ENG-06.py` | 生成脚本 | 从原始输入真实计算生成交付物，内置断言，可复跑 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `事业部财务数据.csv`、`多口径规则.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 对外披露口径的选择与差异异常的业务解释，由集团财务部复核确认。

### 可复算口径

- `管理口径 = 原报归一（合并原报 + 抵销额；法人原报 − 调整额）后 5 个月加总`
- `合并口径 = 管理口径 − 5 × 内部交易抵销（收入/成本分别抵销）`
- `法人口径 = 管理口径 + 5 × 法人归属调整（收入/成本分别调整）`
- `毛利 = 营业收入 − 营业成本；毛利率 = 毛利 ÷ 营业收入（2 位小数百分比）`

## 五、真实性等级与边界

- **T2**：多口径归一与重述方法来自客户应用模式归纳。
- **T3**：集团多口径痛点来自多元化集团的通用财务工作场景。
- **构造**：20 行原报与 15 行对照全部可由 `gen_ENG-06.py` 复跑复算。
- **升 T1 还缺**：客户真实多口径台账与一次管理层口径争议的完整复盘。
- **人工边界**：口径规则与调整参数变更、内部交易抵销完整性复核、对外披露口径选择一律人工；AI 只做归一、重述与差异构成说明。
