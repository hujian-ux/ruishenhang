- **行业**：制造与能源
- **角色**：内部数字化岗
- **场景编号**：ENG-12
- **案例主体**：某算力设备制造企业（服务器与算力基础设施制造商）

| 文件 | 类型 | 作用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `内部系统与智能体需求清单.csv`、`提效实践框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 每个任务的授权确认、上线与切换决定、跨系统变更审批由人执行——AI 只提供定位、实现、文档与评审追问。

## 五、真实性等级与边界

- **T2**：确认门协作模式、对抗式评审与技能沉淀方法论来自客户应用案例素材。
- **T3**：岗位痛点来自素材中的业务特征描述（范围杂、交接多、文档重）。
- **构造**：需求清单与量化记录按素材场景构造，口径可由 gen 脚本复算。
- **升 T1 还缺**：客户真实需求台账与一次完整项目的确认门记录。
- **人工边界**：任务授权确认、上线与切换决定、跨系统变更审批一律人工；AI 只提供定位、实现、文档与评审追问，不替人放行。
