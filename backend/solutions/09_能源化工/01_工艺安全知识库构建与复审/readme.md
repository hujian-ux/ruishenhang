# ENG-01 · 化工工艺安全风险知识库构建与复审 —— 场景使用说明

- **行业**：制造与能源
- **角色**：工艺安全岗
- **场景编号**：ENG-01
- **案例主体**：某重化工与能源集团（与 ENG-02 / ENG-03 同一集团案例链）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/化工工艺安全风险知识库构建与复审/SKILL.md` | Skill 定义 | 分级规则 R1-R3、高危词×工程控制双词表、对抗式复审与收口机制 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `工艺安全风险点清单.csv`、`知识库条目框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 重大/高级条目交装置技术负责人补漏后，再发起一轮收口终审。

### 可复算口径

- `条目编号 = 环节代码（反应FY/储运CY/操作CZ）+ 两位流水号`
- `风险等级`：现有措施 =「暂无」→ 重大（R1）；高危词命中且措施未命中工程控制词 → 高（R2）；其他 → 中（R3）；R1 优先于 R2，命中即止
- 高危词表：超温、超压、泄漏、爆炸、火灾、中毒、窒息；工程控制词表：报警、联锁、检测、监测、通风、呼吸器、火炬

## 五、真实性等级与边界

- **T2**：对抗式复审、多身份评审方法论来自案例素材的实际使用行为归纳。
- **T3**：工艺安全岗痛点来自行业通用管理实践。
- **构造**：风险点清单与分级结果口径可复算（gen_ENG-01.py 复跑一致）。
- **升 T1 还缺**：客户真实知识库条目与一轮真实复审记录。
- **人工边界**：补漏措施的工程设计与选型、风险等级的最终确认与签字定稿一律人工；AI 只做结构化、分级判定与对抗式追问。
