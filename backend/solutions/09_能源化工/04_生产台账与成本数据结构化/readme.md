# ENG-04 · 生产现场台账与成本数据结构化处理 —— 场景使用说明

- **行业**：制造与能源
- **角色**：现场管理岗
- **场景编号**：ENG-04
- **案例主体**：某多元产业制造集团（有色材料制造板块 4 个车间）

## 一、文件清单

| 文件 | 类型 | 作用 |
| --- | --- | --- |
| `03_技能包/生产现场台账与成本数据结构化处理/SKILL.md` | Skill 定义 | 统一 schema、成本口径、异常阈值与人工边界 |
| `主提示词.md` | 提示词 | 学员实际发送的主提示词 + 关键追问 + 验收清单 |
| `车间台账原始记录.csv` | 原始输入 | 24 行现场台账转录记录：4 车间 × 6 天的产量/电耗/辅料/人工 |
| `结构化与成本口径.md` | 原始输入 | 统一 schema 定义、电价 0.68 元/kWh、成本公式与各车间异常阈值 |
| `台账结构化与单位成本表.csv` | **交付物** | 24 行结构化台账：成本要素汇总 + 单位电耗 + 单位成本 + 异常标注 |
| `gen_ENG-04.py` | 生成脚本 | 从原始输入真实计算生成交付物，内置断言，可复跑 |
| `现场管理岗-生产现场台账与成本数据结构化处理.zip` | Skill 包 | 仅含 SKILL.md 的技能定义，可直接导入 WorkBuddy 启用 |

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `车间台账原始记录.csv`、`结构化与成本口径.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 异常行的原因经现场核实后补记，确认后的结果再写入共享台账。

## 三、交付物验证记录

生成脚本 `gen_ENG-04.py` 以 Python 标准库 `csv` 写出原始输入并从原始输入真实计算交付物，脚本内做断言验证。执行结果：

```
OK 车间台账原始记录.csv 写出 24 data rows
OK 台账结构化与单位成本表.csv 写出 24 data rows
异常 3 行：熔铸 09-10 单位电耗 485.7>470 且单位成本 768.7>740；盘拉 09-09 单位成本 721.1>580；退火 09-12 单位电耗 243.5>240 且单位成本 539.5>400
全厂 6 天：产量 1846 吨，合计成本 1017483.60 元，综合单位成本 551.2 元/吨
电力成本合计 277283.60 元，占合计成本 27.3%
ALL ENG-04 ASSERTIONS PASSED
```

### 断言项

| 断言 | 结果 |
| --- | --- |
| 原始输入与交付物均存在且 size > 0 | 通过 |
| `车间台账原始记录.csv` 数据行 = 24（4 车间 × 6 天） | 通过 |
| `台账结构化与单位成本表.csv` 数据行 = 24，与原始记录一一对应 | 通过 |
| 异常行 = 3（熔铸 09-10 / 盘拉 09-09 / 退火 09-12） | 通过 |
| 熔铸 09-10 单位电耗 = 485.7 kWh/吨（>470）、单位成本 = 768.7 元/吨（>740） | 通过 |
| 盘拉 09-09 单位成本 = 721.1 元/吨（>580） | 通过 |
| 退火 09-12 单位电耗 = 243.5 kWh/吨（>240）、单位成本 = 539.5 元/吨（>400） | 通过 |
| 全部正常行（21 行）低于本车间阈值/基准 | 通过 |
| 每行合计成本元 = 电力成本元 + 辅料成本元 + 人工成本元（误差 ≤0.01 元） | 通过 |
| 全厂 6 天产量合计 = 1,846 吨，合计成本 = 1,017,483.60 元 | 通过 |

### 可复算口径

- `电力成本元 = 电耗kWh × 0.68`
- `合计成本元 = 电力成本元 + 辅料成本元 + 人工成本元`
- `单位电耗kWh每吨 = 电耗kWh ÷ 产量吨`（1 位小数）
- `单位成本元每吨 = 合计成本元 ÷ 产量吨`（1 位小数）
- `综合单位成本 = 1,017,483.60 ÷ 1,846 = 551.2 元/吨`

## 五、真实性等级与边界

- **T2**：台账结构化方法与成本口径来自客户应用模式归纳。
- **T3**：现场痛点来自过程型制造的通用工作场景。
- **构造**：24 行数据与异常判定全部可由 `gen_ENG-04.py` 复跑复算。
- **升 T1 还缺**：客户真实台账原件与一次完整的异常处置复盘。
- **人工边界**：纸质原件逐行确认、异常原因现场核实、确认后写入共享台账一律人工；AI 只做转录归一、成本计算与规则判定。
