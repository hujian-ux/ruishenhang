# ENG-09 · 终端系统问题定位与修复 —— 场景使用说明

- **行业**：制造与能源
- **角色**：终端软件岗（顾岩）
- **场景编号**：ENG-09
- **案例主体**：某消费电子制造企业（智能电视等整机研发制造，自动化测试团队、流程管理团队与终端软件团队协作）

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `终端问题记录.csv`、`定位方法框架.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 待复测与复测中项（I03/I09/I11/I14/I17）进入下一轮验证循环，闭环后更新回归标记。

### 可复算口径

- `根因分类 = 按优先级扫描日志摘要关键词，命中即停（内存→线程→驱动→网络→配置→电源）`
- `验证结论：轮次 0 → 待复测；0 < 轮次 < 所需（P0=2，P1=P2=1）→ 复测中；达到 → 复测通过`
- `回归标记：复测通过且 P0/P1 → 已入回归；复测通过且 P2 → 待入回归；未闭环 → 待闭环后入回归`
- `影响面评估 = 按严重级别查表（P0 全量阻断 / P1 高频可复现 / P2 特定条件偶发）`

## 五、真实性等级与边界

- **T2**：六类根因与定位路径方法论来自终端系统问题治理通用实践。
- **T3**：问题现象与日志特征口径来自岗位实践。
- **构造**：问题清单与归因结果口径可复算。
- **升 T1 还缺**：客户真实问题单系统导出与一次完整修复闭环的复测记录。
- **人工边界**：根因最终裁决、修复方案评审与合入、发布与全量推送决定一律人工；六类不命中的日志不强归类，标「待人工归因」。
