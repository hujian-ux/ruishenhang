- **案例主体**：某重化工与能源集团（与 ENG-01 / ENG-03 同一集团案例链）

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `环保监测原始数据.csv`、`入库Schema与判定规则.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 「超标标记·待环保复核」的 6 条记录转环保管理岗做数据有效性确认与处置跟踪。

### 可复算口径

- `记录编号 = EP- + 两位流水号`
- `判定结果`：实测值 > 执行限值 → 超标；否则达标（相等视为达标）
- `超标幅度% = （实测值 − 限值）÷ 限值 × 100`，保留 1 位小数
- 标准限值列为国标与地方/行业标准取严后的执行限值

## 五、真实性等级与边界

- **T2**：取严判定、超标标记方法论来自案例素材的实际使用行为归纳。
- **T3**：环保管理岗痛点来自行业通用管理实践。
- **构造**：监测数据与判定结果口径可复算（gen_ENG-02.py 复跑一致）。
- **升 T1 还缺**：客户真实监测台账与一轮真实超标处置闭环记录。
- **人工边界**：超标数据有效性确认、原因分析与整改措施制定一律人工；AI 只做结构化、判定、标记与统计。
