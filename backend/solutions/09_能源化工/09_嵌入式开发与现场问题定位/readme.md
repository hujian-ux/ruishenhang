- **行业**：制造与能源
- **角色**：嵌入式研发岗
- **场景编号**：ENG-10
- **案例主体**：某算力设备制造企业（服务器与算力基础设施制造商）

## 二、使用步骤

1. 在 WorkBuddy 左侧「专家·技能·连接器」→「添加技能 → 上传技能」，导入本 Skill 包并在「已安装」中启用。
2. 上传 `嵌入式模块与现场问题清单.csv`、`开发与定位规范.md` 两份素材。
3. 复制 `主提示词.md` 中的主提示词发送。
4. 按 `主提示词.md` 文末「验收清单」核对输出。
5. 现场问题中硬件事实（引脚连接、辅路归属、传感器好坏）逐项人工复核；待确认项由现场工程师裁决后闭环。

### 可复算口径

- 需求行状态 = 单元测试 + 代码走查通过且经确认门放行 → 已完成
- 问题行状态 = f(定位路径)：配置回退 → 已回退待确认；补日志验证 → 已闭环；日志归因 → 已闭环（ISS-01/08）或已定位待修复（ISS-02/04/06）

## 五、真实性等级与边界

- **T2**：嵌入式开发与日志定位方法论来自客户应用案例素材（协作模式、工作方式对比）。
- **T3**：岗位痛点来自素材中的业务特征描述。
- **构造**：清单条目与根因结论按素材场景构造，口径可由 gen 脚本复算。
- **升 T1 还缺**：客户真实批次清单与一次现场问题复盘记录。
- **人工边界**：硬件事实判断（引脚连接、辅路归属、传感器好坏）与变更放行一律人工；AI 只建因果链、生成验证代码、整理回退清单。
