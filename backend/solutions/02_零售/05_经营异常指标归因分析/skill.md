# 异常指标归因分析（客户策划 · 零售业）

## 适用时机
- 客户核心指标突然异常（如试驾预约、GMV、转化率暴跌）
- 需要向 CMO / 品牌方汇报"为什么跌了"，而非只给一个数字
- 多因素交织，人工难以判断主因与共振，容易因果错认
- 想知道"表面异常之下"是否藏着更深层的结构/链路问题

## 输入（inputs）
1. 核心指标_YYYYMMDD.csv（字段：指标, W30值, 前4周均值, 环比变化, 说明）
2. 漏斗数据_YYYYMMDD.csv（字段：漏斗阶段, 前4周均值, W30值, 变化, 解读）
3. 归因因素.csv（字段：#, 归因因素, 可信度, 影响估算(单), 影响估算(pp), 数据支撑）
4. 交叉验证.csv（字段：假设, 若假设成立应同时观察到, 反例排除（实测）, 结论）
5. 补救行动.csv（字段：阶段, 动作, 负责人, 时效/指标, 预期回捞）

## 输出（outputs）
1. 异常指标归因报告.md（Part A-F：归因链路 / 三层因果 / 交叉验证 / 三阶段行动 / CMO结论 / 延伸洞察）

## workflow（7 步）
1. **异常量化**：汇总异常指标与基线，量化异常幅度（环比/同比）。
2. **因素可信度**：列出候选归因因素，按"数据支撑强度"给每个因素可信度%与影响估算。
3. **归因链路**：按可信度降序排出归因链路，提示"合计解释度"与因素间共振/抵扣。
4. **三层因果**：表象层（直接原因）→ 机制层（中间原因）→ 结构层（根本原因，如组织协同/数据基建）。
5. **交叉验证**：为每个主因假设设计"应同时观察到"的反例排除，标注✅印证/⚠️部分证伪。
6. **三阶段行动**：紧急止血 / 短期回升 / 长期防复发，每条带负责人+时效+预期回捞。
7. **结论 + 延伸**：一句话 CMO 结论 + 延伸洞察（异常之下是否藏着隐性链路问题）。

## 关键规则 / 提示
- 可信度必须配数据支撑，禁止"感觉是XX导致"
- 区分相关与因果，用证伪设计避免因果错认
- 必须挖到结构层（组织/数据基建）根本原因，不止于表象
- 行动分三阶段，紧急动作先止血、长期动作补基建
- 主动提示"显性异常 vs 隐性阴跌"，避免被分母掩盖的深层劣化
