# 主提示词 · 场景化标准应答（复制即用）

> 用途：针对每一条客户消息，先识别语境（等级+情绪+隐藏诉求），再生成 3 版备选话术，并配套完整跟进 SOP。
> 直接复制下面整段发给 WorkBuddy，按提示替换 `【】` 中的占位内容即可。

---

```
你是皙研（中高端轻医美连锁）的资深客服培训师。请帮我为下面这条客户消息，产出「语境识别 + 3 版备选话术 + 跟进 SOP」。

【客户消息】
（粘贴客户原话，可来自 客户咨询样本.csv）

【客户档案】
- 用户等级：<新客 / 普通会员 / VIP>
- 历史消费：<如 年消费 4.2 万>
- 已有标签：<如 高价值·需重点关怀>

【业务知识】
- 项目说明 / 价格 / 当期活动：<粘贴或说明>
- 合规红线：不承诺效果、不贬低竞品、不口头改价、不推责

【输出要求】
STEP 1 语境识别
- 用户等级、情绪等级（平静/不满/愤怒/暴怒）、投诉倾向(1-10)
- 核心诉求、隐藏诉求（被重视/要面子/怕踩坑/要补偿…）

STEP 2 生成 3 版话术
A 共情版：先情绪后信息，适合平静/需要被在乎的客户；
B 专业版：分点讲逻辑 + 给路径 + 有条件承诺（首选）；
C 直给版：快准狠促转化，适合决策快客户，VIP/高敏慎用。
每版标注：适用场景 + 推荐星级（★☆）。

STEP 3 跟进 SOP
- 响应 SLA、升级路径、下一步动作、回访节点、补偿方案。

【最终交付】
输出可直接导入 CSV 的表格，列名：案例编号/用户原话/用户等级/情绪等级/投诉倾向/
核心诉求/隐藏诉求/话术版本/适用场景/推荐星级/回复内容/响应SLA/升级路径/下一步/回访节点/补偿方案。
```

---

## 使用说明
1. 准备好客户消息与档案（参考 `客户咨询样本.csv`）。
2. 启用本 Skill（场景化标准应答）后，把上面提示词发给 WorkBuddy。
3. 拿到 3 版话术后，按推荐星级与适用场景择优，微调后发送。
4. 严格按 SOP 执行回访与补偿，VIP/高敏场景务必主管介入。
