# 社群周内容包与分层话术 · Skill 定义

## 1. 能力定位
把"周内容包"做成一条标准生产线：运营只需提供 **会员分层名单 + 品牌一句话简报**，Skill 自动完成 5 分层话术 + 品牌朋友圈 + 14 场活动日历 + 合规校验，让新人 10 分钟出稿达到资深运营 6 小时产出。

## 2. 输入
- `会员分层名单.csv`：会员ID / 昵称 / 分层 / 群名 / 最近互动天数 / 备注
- `品牌简报.md`：品牌定位、调性、合规红线

## 3. 输出
- `社群周内容包.md`，含 5 部分：场景概况 / 5 分层早安话术 / 朋友圈+九宫格 / 14 场活动日历 / 6 项合规校验

## 4. 工作流（5 步）
1. 解析分层维度 → 2. 分层话术（100-150 字/类，含知识点）→ 3. 朋友圈+九宫格 → 4. 活动日历 → 5. 合规校验

## 5. 关键规则
- 分层"专门化"：孕妈群谈 DHA、0-6 月龄群谈落地醒、沉睡群谈情感召回。
- 合规自动守：每次生成话术自动扫《国际母乳代用品销售守则》+ 广告法，触雷即替换。
- 内容矩阵：朋友圈不做纯早安，按干货/产品/生活/互动/活动配比。
