# 主提示词 · RFM会员分层与差异化触达

> 学员实际发送给 AI 的主提示词（可直接复制）。输入一份订单 CSV，输出分段结果 + 每段触达 SOP。

---

请基于「订单样本.csv」，为素研（中高端功能性护肤）做 **RFM 会员分层与差异化触达**，分 4 步输出。

【输入 · 订单样本】（节选自 订单样本.csv）
字段：客户ID、订单日期、订单金额(净额¥)（仅需这 3 个字段，衍生 R/F/M）

【输出要求】
1. **清洗与打分**：过滤测试单/批发单；按复购周期中位数 45 天定 R/F/M 阈值；逐客打 1-5 分
2. **分段与验证**：映射到 8 段命名人群——冠军 / 忠诚 / 潜力 / 新客户 / 需关注 / 有流失风险 / 高价值流失中 / 冬眠；校验分段健康度（案例：冠军占比 18.8%、贡献 GMV 61.3%）
3. **每段占比与 GMV 占比**：会员占比 + GMV 占比；标注"高价值流失中 7.8%（¥17K GMV）60+ 天未回，需定向大额挽回"
4. **触达 SOP**：每段独立的话术口吻 / 优惠力度 / 触达频次 / 推荐渠道（冠军不打折、冬眠自动化轻触）

【案例数字锚点】
- 62 会员 → 8 段
- 冠军占比 18.8% / 冠军贡献 GMV 61.3%
- 高价值流失中 7.8%（¥17K GMV）
- 平均客单 ¥380 / 复购周期中位数 45 天

输出结构参考「RFM会员分层结果.xlsx」：Sheet1 分段结果（段名/会员占比/GMV占比/平均R/F/M/触达SOP），Sheet2 会员明细（客户ID/R/F/M/分段）。
