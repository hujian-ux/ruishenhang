# RFM会员分层与差异化触达 · Skill 定义

## 1. 能力定位
把 RFM 做成"傻瓜化生产线"：丢一份订单 CSV 进去，2 分钟出完整分层 + 每段触达 SOP + ROI 预估，全 Agency 用同一套逻辑跑出同一份结果。

## 2. 输入
- `订单样本.csv`：客户ID / 订单日期 / 订单金额(净额¥)

## 3. 输出
- `RFM会员分层结果.xlsx`：分段结果（8 段 + 占比/GMV占比/触达SOP）+ 会员明细（62 样本 R/F/M/分段）

## 4. 工作流（4 步）
1. 导入订单 CSV → 2. 清洗与打分（R/F/M 五分位）→ 3. 分段与验证（8-11 段）→ 4. 触达计划

## 5. 关键规则
- 冠军不打折；高价值流失中大额挽回；冬眠自动化轻触。
- 每 30 天重跑，追踪迁移；头部 20/80 效应明显。
- 案例：62 会员→8 段，冠军占比 18.8% / GMV 61.3%，高价值流失中 7.8%（¥17K）。
