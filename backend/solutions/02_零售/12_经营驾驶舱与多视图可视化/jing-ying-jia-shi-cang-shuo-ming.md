# 经营驾驶舱说明 · 经营驾驶舱与多视图可视化（r4-3）

> 跨行业通用（美妆 / 家清 / 母婴 / 餐饮 / 零售……）。把一份「日期 + 指标名 + 指标值」三列长表 CSV，一键生成 **7 页（5 主视图 + 老板大屏 + 客户方自助）20+ 图表** 的经营驾驶舱，含桑基 / 词云 / 雷达 / 玫瑰 / 面积等高级图表、自动异常告警与独立自助访问链接。
> 案例：**清舍 · 天然家居清洁**（家清品类，客单低、复购高、渠道分散：有赞商城 / 抖店 / 线下门店），30 天监控。

## 一、核心结论（三个人满意，三张 PPT 消失）
- 运营团队：5 页 20+ 图表经营驾驶舱（SKU 排行、渠道 ROI 对比、会员来源桑基图、反馈词云）。
- 老板：深色大屏 4 大数字（营收 / 订单 / 活跃会员 / 复购率）。
- 品牌方甲方：绿色成果视图（4 项业务成果 + 会员增长面积图，**不含 Agency 成本 ROI**）。

## 二、工作流（指标口径只定义一次，之后每天自动跑）
1. **导入长表 CSV**：仅 3 列 `date + metric_name + metric_value`，所有 BI/后台一句 SQL 可出。
2. **定义指标口径**："活跃会员"= 30 天内有购买或登录；"复购率"= 周期内第 2 次及以上购买订单 / 总订单。一次定义，全公司一致。
3. **生成驾驶舱**：5 主视图 + 2 角色视图，20+ 图表自动配色，移动端自适应。
4. **告警 + 分享**：异常自动推送企微；客户方拿到独立自助访问链接。

## 四、双角色专属视图说明
- **老板大屏（深色）**：只放 4 大数字 + 趋势，信息极简，出差路上手机也能一眼看懂。
- **客户方自助（绿色成果）**：4 项业务成果 + 会员增长面积图，独立自助链接，可随时拉数据——这是"信任基础设施"，意味着 Agency 不怕客户随时查。

## 五、自动告警（让运营从"事后救火"变"事前预警"）
| 告警 | 触发规则 | 通道 |
| --- | --- | --- |
| 客单价下滑 | 客单价日环比下跌 ≥ 10% | 企微推送 @运营负责人 |
| 客诉超线 | 客诉率 > 警戒线（如 > 3%） | 企微推送 + 工单派单 |
| 词云聚集 | 投诉词云出现"包装漏液"聚集 | 自动飘红 + 推送品控 |

## 六、原始数据对照（本场景 CSV）
- 文件：`经营数据长表.csv`，3 列 `date,metric_name,metric_value`，覆盖 30 天 × 20 项指标（GMV/订单数/活跃会员/客单价/复购率/三渠道 GMV 与 ROI/SKU TOP3/会员来源/客诉率/包装漏液投诉数/好评率 等），可直接驱动上述 21 个图表。
- 口径示例：`活跃会员 = 30 天内有购买或登录`；`复购率 = 周期内第 2 次及以上购买订单 / 总订单`。
