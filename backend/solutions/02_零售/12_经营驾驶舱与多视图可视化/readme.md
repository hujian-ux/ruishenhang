# 场景使用说明 · 经营驾驶舱与多视图可视化（r4-3）

## 场景简介
把一份「日期 + 指标名 + 指标值」三列长表 CSV，一键生成 7 页（5 主视图 + 老板大屏 + 客户方自助）20+ 图表的经营驾驶舱，含桑基/词云/雷达/玫瑰/面积等高级图表、自动异常告警与独立自助访问链接。案例：清舍 · 天然家居清洁（30 天监控）。

## 文件清单与验证
| 文件 | 角色 | 验证 |
| --- | --- | --- |
| `03_技能包/经营驾驶舱与多视图可视化/SKILL.md` | Skill 定义 | 存在 / 非空 |
| `主提示词.md` | 学员主提示词 | 存在 / 非空 |
| `经营数据长表.csv` | 原始输入 | 存在 / **600 行**（30 天 × 20 项指标） |
| `经营驾驶舱说明.md` | **预期交付物** | 存在 / 5284 字节 / 含 7 页 + 21 图表 + 双角色视图 + 告警 |
| `videos/README.md` | 演示视频占位 | 存在 |
| `scene-r4-3.zip` | 完整 Skill 包 | 存在 |

## 验证方式
- 交付物与数据源均由 `python3 _gen_r4_3.py` 生成，脚本断言：CSV/MD 文件存在且 size>0，且 MD 包含 `桑基图`、`词云`、`雷达图`、`玫瑰图`、`面积图`、`老板深色大屏`、`客户方自助`、`21 个图表`、`包装漏液`、`复购率` 等关键字。

## 数字对齐
- 7 页驾驶舱：5 主视图 + 老板深色大屏 + 客户方绿色成果视图。
- **21 个图表**，覆盖柱/饼/环/雷达/桑基/词云/玫瑰/面积/漏斗/热力。
- 3 条自动告警：客单价跌 10% / 客诉率超线 / 投诉词云"包装漏液"聚集。
- 客户方视图**不含 Agency 成本 ROI**。
