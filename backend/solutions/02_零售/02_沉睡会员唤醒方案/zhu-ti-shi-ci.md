# 主提示词 · 沉睡会员识别与唤醒

> 学员实际发送给 AI 的主提示词（可直接复制）。输入会员行为明细，输出 3 级分层唤醒方案 + 可审计 GMV 模型。

---

请基于「会员行为样本.csv」，为食光（进口天然宠粮）生成**沉睡会员识别与唤醒方案**，分 5 步输出。

【输入 · 会员行为样本】（节选自 会员行为样本.csv）
字段：会员ID、宠物昵称、距上次下单天数、加购未支付、领券未核销、APP30天打开、种草页浏览、积分签到、客服工单类型、分层判定

【三维分层规则】
- 浅度：距上次下单 30-60 天 + 意愿信号≥1（APP打开/种草浏览/积分签到/咨询工单）；排除"暂停订购/宠物离世"
- 中度：60-90 天 + 加购未支付/领券未核销≥2 + APP30天打开1-3次 + 咨询换粮/软便
- 深度：90天+ + 近90天0加购0券 + APP未打开/种草0浏览/积分未动(三项全0)；历史消费≥¥2,000 的"高价值深沉"约1,800人单列走人工回访

【输出要求】
1. **3 级分层规模与规则**：浅度 12,000 / 中度 10,500 / 深度 7,500（合计 30,000，占会员 35%）
2. **每级 4 版差异化话术**：情感 / 利益 / 悬念 / 关切，统一说{宠物昵称}>粮种>时间戳
3. **触达节奏 × 渠道矩阵**：最优时段 / 主渠道 / 备渠道 / 频次上限 / 单次长度 / 跨渠道熔断（7天≥4次熔断）
4. **可挽回 GMV 预估模型**：唤醒GMV=Σ(人数×挽回率×AOV×M)，M 浅度2.4/中度1.9/深度1.4；挽回率 25%/15%/6%；AOV ¥420/¥400/¥550
5. **财务审计口径**：毛GMV ¥4,567,500 − 3减项(券补¥438k+自然回流¥540k+履约¥165k) = 净GMV ¥3,424,500 ≈ ¥342万，综合 ROI ≈ 5.68

输出为可直接落库的「沉睡会员分层方案.csv」结构（3 级 + 合计行）。
