# 沉睡会员识别与唤醒 · Skill 定义

## 1. 能力定位
把"沉睡会员"从单维时间切分升级为"时间 × 意愿"三维分层，输出可落地的差异化唤醒方案与可审计 GMV 模型。

## 2. 输入
- `会员行为样本.csv`：会员ID / 宠物昵称 / 距上次下单天数 / 加购未支付 / 领券未核销 / APP30天打开 / 种草页浏览 / 积分签到 / 客服工单类型

## 3. 输出
- `沉睡会员分层方案.csv`：3 级分层 + 每级 4 版话术 + 触达节奏 × 渠道矩阵 + 可挽回 GMV 预估 + 合计行

## 4. 工作流（5 步）
1. 清洗排除无效标签 → 2. 三维分层（浅/中/深 + 高价值深沉单列）→ 3. 每层 4 版话术 → 4. 触达节奏×渠道 → 5. GMV 模型测算净 GMV 与 ROI

## 5. 关键规则
- 浅度 12,000/25%、中度 10,500/15%、深度 7,500/6%；高价值深沉≈1,800 走人工。
- 话术说宠物昵称 > 粮种 > 时间戳。
- 跨渠道 7 天累计≥4 次商业触达即熔断。
