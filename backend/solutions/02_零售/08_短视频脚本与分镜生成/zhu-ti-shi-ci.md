# 主提示词 · 短视频脚本与分镜

> 为下面这款新品，产出可拍 / 可喂 AI 生成的短视频分镜脚本，含 15s 与 30s 双版本、3 版钩子、4 变体 CTA 与数据预测。

## 产品与人群
- 品牌：眠可（脱敏 · 智能睡眠品牌）
- 新品：智能睡眠头带，¥899
- 目标平台：抖音 + 视频号 + 小红书
- 核心人群：长期失眠、靠咖啡/褪黑素续命的都市年轻人
- 核心卖点：医疗级脑电监测，AI 识别脑波主动引导入睡；实测 19 分钟入睡、深睡 +47%

## 双版本结构
- 15s（抖音信息流）：痛点炸开 → 产品出场 → 效果对比 → 价格钩子 → CTA
- 30s（视频号 + 小红书）：一夜失眠铺垫 → 白天疲惫 → 产品登场 → 功能可视化 → 睡眠延时 → 数据报告 → 价格保障 → 品牌落版

## 分镜字段要求
每一镜必须包含：画面描述 / 字幕 / 运镜 / 音效，并额外输出 1 条英文文生视频 Prompt（带镜头语言，兼容即梦/剪映/可灵/Runway）。

## 钩子与 CTA 变体
- 3 版开头钩子：A 痛点共鸣 / B 好奇悬念 / C 反常识（标注历史 CTR 排序，C 通常高 30%+）
- 4 变体 CTA：限时型 / 利益型 / 情感型 / 悬念型

## 数据预测输出
结合行业均值（抖音完播 22% / 视频号 18%，CTR 2%），给出 15s / 30s 的完播率、3s 留存、CTR、互动率预期区间，并给"前 1.5s 人脸情绪冲突""字幕描边放大""钩子 A/B 跑量"等提升建议。
