现状与痛点

新品上市节奏快，短视频脚本产能却卡在"一个人写、一条投、Prompt 复用难"三道坎上。

脚本产能跟不上

一支能打的短视频从脚本到分镜要 2-3 天，多平台同时上新时根本排不过来。

高频
一条素材投到底

没有 A/B 钩子，同一支视频反复投，跑不出量也不知道该优化开头还是 CTA。

高风险
Prompt 难复用

分镜写给人看，喂给即梦/可灵还要二次改写镜头语言，团队间无法沉淀资产。

耗时
数据凭感觉

完播率、CTR 全靠事后看后台，上线前没有预期区间，预算浪费在试错上。

成本浪费

脚本写了三天，投了三天，最后发现——开头那 1.5 秒，才是决定生死的地方。

WorkBuddy 的解决和价值

把短视频脚本产能从"一人一稿"升级为"结构化批量产出 + 可复用 AI Prompt + 数据前置预测"。

传统做法

编导写脚本 → 美术拆解分镜 → 拍摄/外包 → 一条素材投多平台 → 凭感觉看数据，2-3 天一稿。

WorkBuddy 做法

输入产品+人群 → 自动出 15s/30s 双分镜 + 13 条 AI Prompt + 3 版钩子/4 CTA → 前置给出完播率/CTR 预测，分钟级多稿。

三个核心价值
01完整分镜设计

15s + 30s 双版本，每镜给足画面 / 字幕 / 运镜 / 音效，可直接拍，也可直接喂 AI 生成。

02可执行 AI Prompt

13 条英文 Prompt 带镜头语言，兼容即梦 / 剪映 / 可灵 / Runway，团队可沉淀复用。

03数据预测前置

结合行业均值给出完播率、3s 留存、CTR 预期区间，上线前就知道往哪优化。

方案定位

不是替编导想创意，而是把"产品→多版本分镜→可复用 Prompt→数据预测"工程化，让一支脚本的产能放大数倍。

解决方案的工作流程

从产品资料到可投放分镜，共 5 步。

01锁定产品人群

明确新品卖点、价格、目标平台与核心人群痛点。

02设计双版本结构

15s 走痛点炸开五段式；30s 加叙事铺垫与数据沉淀。

03拆解分镜

每镜给画面 / 字幕 / 运镜 / 音效 + 英文 Prompt（带镜头语言）。

04产出钩子与CTA

3 版开头钩子 + 4 变体 CTA，标注历史 CTR 排序。

05数据预测与打法

完播率 / CTR 预期 + "前 1.5s 人脸情绪冲突"等提升建议。

提示词
TRAINING PROMPT · 复制即用
为下面这款新品，产出可拍 / 可喂 AI 生成的短视频分镜脚本，含 15s 与 30s 双版本、3 版钩子、4 变体 CTA 与数据预测。

【产品与人群】
品牌：眠可｜新品：智能睡眠头带 ¥899
平台：抖音 + 视频号 + 小红书
人群：长期失眠、靠咖啡/褪黑素续命的都市年轻人
卖点：医疗级脑电监测，AI 识别脑波主动引导入睡；实测 19 分钟入睡、深睡 +47%

【双版本结构】
15s（抖音）：痛点炸开→产品出场→效果对比→价格钩子→CTA
30s（视频号/小红书）：一夜失眠→白天疲惫→产品登场→功能可视化→睡眠延时→数据报告→价格保障→品牌落版

【分镜字段要求】
每镜必须含：画面描述 / 字幕 / 运镜 / 音效，并额外输出 1 条英文文生视频 Prompt（带镜头语言，兼容即梦/剪映/可灵/Runway）。

【钩子与 CTA】
3 版开头钩子：A 痛点共鸣 / B 好奇悬念 / C 反常识（标注历史 CTR 排序）
4 变体 CTA：限时型 / 利益型 / 情感型 / 悬念型

【数据预测输出】
结合行业均值（抖音完播 22%、CTR 2%），给出 15s/30s 的完播率、3s 留存、CTR、互动率预期区间，并给提升建议。
