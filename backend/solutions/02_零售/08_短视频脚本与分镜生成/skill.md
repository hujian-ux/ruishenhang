# Skill · 短视频脚本与分镜

## 适用时机
- 新品上市要在抖音 / 视频号 / 小红书投放短视频，但脚本产能跟不上。
- 需要多版本钩子做 A/B 跑量，而非一条素材投到底。
- 团队想用即梦 / 剪映 / 可灵 / Runway 直接按分镜生成视频。

## 核心能力
1. **完整分镜设计**：15s + 30s 双版本，每镜给足画面 / 字幕 / 运镜 / 音效。
2. **可执行 Prompt**：13 条文生视频英文 Prompt，兼容即梦 / 剪映 / 可灵 / Runway。
3. **A/B 钩子 3 版**：痛点 / 悬念 / 反常识三种角度，配 CTR 预测排序。
4. **CTA 4 变体**：限时 / 利益 / 情感 / 悬念，覆盖不同人群与阶段。
5. **数据预测**：结合行业均值给出完播率、3s 留存、CTR、互动率预期区间。

## Workflow（5 步）
- **STEP 01 · 锁定产品与人群**：明确新品卖点、价格、目标平台与核心人群痛点。
- **STEP 02 · 设计双版本结构**：15s 走"痛点炸开→产品出场→效果对比→价格钩子→CTA"；30s 加叙事铺垫与数据沉淀。
- **STEP 03 · 拆解分镜**：每镜给画面 / 字幕 / 运镜 / 音效 + 英文 Prompt（带镜头语言）。
- **STEP 04 · 产出钩子与 CTA**：3 版开头钩子 + 4 变体 CTA，标注历史 CTR 排序。
- **STEP 05 · 给数据预测与优化打法**：完播率/CTR 预期 + "前 1.5s 人脸情绪冲突""字幕描边放大"等提升建议。

## 钩子 A/B 三版（以眠可睡眠头带为例）
- A 痛点共鸣："你也是一到晚上就清醒吗？"
- B 好奇悬念："戴上这个，能 19 分钟入睡？"
- C 反常识（历史 CTR 最高）："我把褪黑素戒了，靠它"

## CTA 四变体
- 限时型：前 100 名下单立减 ¥200，仅剩今晚
- 利益型：30 天睡不好，全额退，连头带一起送你
- 情感型：你已经太久没睡好了，是时候对自己好一点
- 悬念型：评论区扣"1"，告诉你它到底是怎么让人 19 分钟睡着的

## Inputs
- 产品资料：名称、价格、核心卖点、目标平台。
- 人群洞察：核心痛点、真实使用场景。

## Outputs
- `短视频分镜脚本.md`：15s/30s 双分镜 + 3 版钩子 + 13 条 AI Prompt + CTA + 数据预测。

## 关键规则
- 前 1.5s 必须有"人脸情绪冲突"（瞪眼/皱眉/烦躁），远比产品特写更能留人。
- 关键数字（如"19 分钟""¥899"）字幕加粗描边 + 放大 2 倍，静音也能接收信息。
- 13 条 Prompt 须带明确镜头语言（top-down / orbit / split-screen / time-lapse），无需二次改写。

## 提示词（主提示词见 主提示词.md）
主提示词结构：产品与人群 → 平台与时长 → 双版本结构 → 分镜字段要求（画面/字幕/运镜/音效+英文Prompt）→ 钩子/CTA 变体 → 数据预测输出。
