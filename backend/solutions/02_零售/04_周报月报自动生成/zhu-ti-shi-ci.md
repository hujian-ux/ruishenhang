> 复制下方内容，把 3 张 CSV 路径替换为本周期实际文件，直接发送即可。
> 配套 Skill 包：`03_技能包/周报月报自动化/SKILL.md`

---

## 主提示词（复制即用）

```
你现在是我的「周报月报自动化」助手。请基于我上传的 3 张 CSV，生成本周客户周报。

【数据输入】
1. 每日KPI_W30.csv —— 字段：日期, GMV, 订单数, UV, 新客数, 老客活跃数
2. 品类拆分_W30.csv —— 字段：品类, W29_GMV, W30_GMV, W29_订单, W30_订单, 备注
3. 本周事件_W30.csv —— 字段：日期, 类型, 事件, 关联指标
4. W29基线.csv —— 用于环比对比的上周基准

【固定口径（必须严格遵守，跨周一致）】
- 新客 = 统计窗口内首购用户
- 老客活跃 = 30 日内有互动的老会员
- AOV = GMV / 订单数
- GMV 为实付成交金额（剔除退款）

【输出要求】
1. 计算 W30 周聚合：GMV / 订单数 / AOV / UV / 新客 / 老客活跃，并与 W29 做环比（带 % 与箭头）。
2. 品类维度归因：逐品类给出 GMV 环比、订单环比，标注"涨的是量还是价"。
3. 生成深度洞察三栏：
   ✅ 亮点（数据支撑）
   ⚠️ 下滑（数据支撑）
   🔍 隐性风险（重点：当总盘涨但 AOV 跌 / 老客活跃降时，必须抛"促销依赖 / 量增价跌"类结构问题）
4. 输出 6 条 W31 行动清单，每条带：优先级(P0/P1/P2) + 行动项 + 负责人 + 截止时间 + 可量化目标。
5. 按六段式周报骨架（封面结论 / 指标卡 / 多维归因 / 深度洞察 / 行动清单 / 附录数据）组织，可直接进 PPT。

【硬规则】
- 洞察不能只是"环比上升"的翻译，必须给"所以呢 + 该做什么"。
- 禁止空泛行动项（如"加强老客运营"），必须可落地、可分派。
- 口径若有冲突，先标注待确认，不擅自改定义。
```

## 使用说明

1. 先导入并启用本场景 Skill 包（`03_技能包/周报月报自动化/SKILL.md` 所在文件夹或 `assets/scene-r2-1.zip`）。
2. 把本周期 3 张 CSV 与上周基线 CSV 准备好（可参考本目录示例样本）。
3. 复制上方主提示词，替换文件名后发送给 WorkBuddy。
4. 核对产出的 `周报大纲.md`，微调措辞即可交付客户。
