# 周报月报自动化（客户策划 · 零售业）

## 适用时机
- 每周/每月需要向品牌方客户交付经营周报、月报
- 周报常陷入"数字堆砌没结论""只报增长不报隐忧""行动项空泛无法分派"
- 数据口径每周漂移、跨周 KPI 无法追踪
- 想让每份周报都能过挑剔客户（CMO/品牌方）的挑战

## 输入（inputs）
1. 每日KPI_YYYYMMDD.csv（字段：日期, GMV, 订单数, UV, 新客数, 老客活跃数）
2. 品类拆分_YYYYMMDD.csv（字段：品类, W29_GMV, W30_GMV, W29_订单, W30_订单, 备注）
3. 本周事件_YYYYMMDD.csv（字段：日期, 类型, 事件, 关联指标）
4. W29基线.csv（字段：指标, W29值, 说明）——用于环比对比

## 输出（outputs）
1. 周报大纲.md（六段式结构 + 核心指标表 + 品类归因 + 深度洞察 + 6条行动清单）
2. 可直接导入 PPT / 微信长图 / HTML 可视化的结构化内容

## workflow（7 步）
1. **口径校验**：校验 3 张 CSV 字段与口径，固化数据定义（如"新客=30天内首购"），跨周零漂移。
2. **指标聚合**：聚合每日KPI为周指标，与W29基线做环比/同比，计算 GMV/订单/AOV/UV/新客/老客活跃。
3. **多维交叉**：总盘 vs 品类 vs 渠道，定位"涨的是量还是价"。
4. **事件关联**：把本周事件映射到对应指标波动，区分相关与因果。
5. **深度洞察**：生成 ✅亮点 / ⚠️下滑 / 🔍隐性风险，每条带数据支撑，主动抛"表面涨底层跌"类结构问题。
6. **行动清单**：输出 6 条带优先级(P0/P1/P2)+负责人+截止时间的行动清单，可直接分派。
7. **周报组装**：组装客户级 PPT 周报六段式骨架（封面/指标卡/归因/洞察/行动/附录）。

## 关键规则 / 提示
- 口径固化：所有"新客/老客/GMV"定义写入配置，周与周一致，禁止靠人记忆
- 洞察非复读：禁止"本周GMV环比上升"式翻译，必须给"所以呢/该做什么"
- 隐忧优先：当总盘涨但 AOV 跌、老客活跃降时，必须作为 P0 风险抛出
- 行动可落地：每条行动必须有负责人+截止+可量化目标，禁止"加强运营"式空话
- 数据可追溯：PPT 附录附原始数据表与口径说明，让挑剔客户可复核
