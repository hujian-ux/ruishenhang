# 主提示词 · 活动落地页与 H5（r4-1）

> 学员在 WorkBuddy 中实际发送的主提示词。把运营的自然语言需求替换到【需求】处即可。

---

## 提示词正文（复制即用）

```
你是资深前端 + 增长活动开发工程师。帮我把下面这条运营需求，做成一个真实可本地预览的 H5 活动落地页。

【品牌】
劲能（中高端健身房连锁）· 北京朝阳店新店开业

【运营需求（一句话）】
做个新店开业活动页，能预约体验课、拉好友组队送次卡、地图能导航到店。

【输出要求】
1. 先输出「页面模块清单」：模块 / 功能 / 交互逻辑 三列，覆盖 Hero、预约体验课、拉好友组队、地图导航、门店信息、数据回流、分享传播 共 7 个模块。
2. 再输出一份**单文件自包含 HTML**（内联 CSS+JS），包含：
   - Hero 主视觉，顶部 100vh，主 CTA 锚点滚到预约区；
   - 预约体验课表单：手机号实时正则校验（^1[3-9]\d{9}$） + 数字键盘 + 提交按钮禁用态联动 + 定位门店距离（Haversine）；
   - 拉好友组队：URL 携带 ?inviter= 感知邀请上下文，Web Share API 分享 + 剪贴板降级；
   - 地图导航：兼容微信 wx.openLocation / 高德 / 百度 URI Scheme，3 秒未跳走降级网页版；
   - 门店信息：营业时间、设施、点击拨号；
   - 数据回流：sendBeacon 上报 13 个关键事件，手机号 sha256 脱敏，beforeunload 不丢包；
   - 分享传播：系统分享 + 剪贴板降级。
3. 品牌 VI 用 CSS Variables 变量化（主色 #c8ff00 荧光黄绿 + 深黑底），按 375 / 768 / 1024 三断点响应式。
4. 最后给出 EdgeOne 生产部署命令级流程（打包 / 上传 / 缓存 / A-B 灰度 / 校验）。

要求：HTML 必须合法、能本地直接双击打开预览，不依赖任何外部付费服务。
```

---

## 使用说明

- 此提示词直接发送给已启用「活动落地页与 H5 生成」Skill 的 WorkBuddy。
- 第 1 步产出《需求-代码对照》中的"模块清单"，第 2 步产出 `活动落地页.html`，第 4 步对应部署章节。
- 若品牌 VI 不同，替换【品牌】与 CSS Variables 中的主色/辅助色即可。
