WorkBuddy 的解决和价值

把一句话需求，转成真实可跑的 H5，并内建埋点与一键部署能力。

传统做法

需求一句话 → 产品出原型 → 设计出图 → 前端开发 → 联调 → 部署，3-5 天串行，埋点常漏、渠道常错。

WorkBuddy 做法

自然语言需求 → AI 解构 7 模块 → 生成自包含可跑 HTML → 内建埋点 → 一键部署公网链接，20 分钟闭环。

三个核心价值
01自然语言→可跑代码

运营说人话，AI 产出能本地双击预览的单文件 HTML，含表单校验、组队分享、三方地图等真实组件。

02数据埋点内建

13 关键事件随页面一并产出，sendBeacon 保证 beforeunload 不丢包，手机号 sha256 脱敏上报。

03一键部署

CloudStudio 沙箱直出公网域名，EdgeOne 生产命令级流程（缓存策略/A-B 灰度/校验）开箱即用。

方案定位

不是替运营写代码，而是把"一句话需求→上线"这条 3-5 天的长链路，压缩成 20 分钟的可跑闭环，让活动跟上热点。

解决方案的工作流程

从一句自然语言需求到可访问链接，共 4 层。

01需求解构

解析自然语言需求，拆出 Hero、预约、组队、地图、门店、数据、分享 7 个模块清单。

02品牌变量化

沉淀品牌 VI 为 CSS Variables，按 375/768/1024 三断点写响应式。

03关键组件编码

生成表单实时校验、组队分享降级、三方地图导航与埋点上报代码。

04部署上线

CloudStudio 沙箱直出公网链接，或 EdgeOne 生产部署并配置缓存与灰度。

05数据回流

13 关键事件回传 CDP，运营实时看到预约/组队/导航转化。

你是资深前端 + 增长活动开发工程师。帮我把下面这条运营需求，做成一个真实可本地预览的 H5 活动落地页。

【品牌】劲能（中高端健身房连锁）· 北京朝阳店新店开业
【运营需求（一句话）】做个新店开业活动页，能预约体验课、拉好友组队送次卡、地图能导航到店。

【输出要求】
1. 先输出「页面模块清单」：模块 / 功能 / 交互逻辑 三列，覆盖 Hero、预约、组队、地图、门店、数据、分享 共 7 个模块。
2. 再输出一份单文件自包含 HTML（内联 CSS+JS），含：手机号实时正则校验、组队 Web Share 降级、三方地图导航降级、sendBeacon 13 事件埋点。
3. 品牌 VI 用 CSS Variables 变量化，按 375/768/1024 三断点响应式。
4. 最后给出 EdgeOne 生产部署命令级流程。

要求：HTML 必须合法、能本地直接双击打开预览，不依赖外部付费服务。
