# 活动落地页与H5生成（技术开发 · 零售业）

## 适用时机
- 品牌/门店需要快速上线营销活动页（开业、大促、拉新、会员日等）
- 运营只给得出一两句话需求，但要求 1 天内甚至 20 分钟内拿到可访问链接
- 需要把"需求 → 可跑代码 → 公网链接"全程压缩，避免产品-设计-前端-联调-部署的长链路

## 输入（inputs）
1. 运营自然语言需求（一句话或多句）
2. 品牌 VI 基础变量（主色、辅助色、字体倾向，可缺省用中性方案）
3. 门店/活动基础信息（地址、经纬度、营业时间、电话、活动规则）

## 输出（outputs）
1. 页面模块清单（模块 / 功能 / 交互逻辑三列）
2. 真实可运行的落地页 HTML 文件（自包含，可本地双击打开）
3. 关键组件代码片段（预约表单校验+定位、组队分享、三方地图导航）
4. 数据埋点方案（事件名 / 触发时机 / 关键字段）
5. 部署命令级流程（CloudStudio 沙箱 + EdgeOne 生产）

## workflow（5 步）
1. **需求解构**：解析自然语言需求，拆出页面模块清单（Hero 主视觉 / 核心转化 / 社交裂变 / 导航到店 / 信息展示 / 数据回流 / 分享传播）。每个模块给出功能点与交互逻辑。
2. **品牌变量化**：将品牌 VI 沉淀为 CSS Variables（主色/深色底/圆角/间距），并按 375 / 768 / 1024 三断点写响应式。
3. **关键组件编码**：生成预约表单（手机号正则实时校验 + 数字键盘 + 定位距离 Haversine）、组队分享（URL ?inviter= 上下文感知 + Web Share API 降级剪贴板）、三方地图导航（微信 wx.openLocation / 高德 / 百度 URI Scheme + 网页降级）。
4. **数据埋点**：设计 10-15 个关键事件（page_view / cta_click / 表单聚焦提交 / 组队 / 导航 / 拨号 / 滚动深度 / 离开），用 navigator.sendBeacon 保证 beforeunload 不丢包，手机号 sha256 脱敏上报。
5. **部署上线**：给出 CloudStudio 沙箱一键部署（生成公网可访问域名）与 EdgeOne 生产部署命令（打包 / 上传 / 缓存策略 / A-B 灰度 / 校验）。

## 关键规则 / 提示
- 落地页必须是单文件自包含 HTML（内联 CSS/JS），保证本地双击即可预览，不依赖外部服务。
- 手机号等隐私字段禁止明文上报，客户端 sha256 后再发。
- 分享与地图必须做降级：Web Share API → 剪贴板；App URI Scheme → 网页版链接。
- 埋点事件命名统一 snake_case，payload 含 ts / sid / uid。
