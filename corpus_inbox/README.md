# 语料投递包（放文件就行，不用写说明）

这是给平台导入「公司真实制度 / SOP / 产品手册」的收件箱。
**你只需要做一件事：把文件拖进下面对应的文件夹，然后跟我说一声「语料放好了」。**
转换、去重、导入、验收都由我来做，你不用碰命令行。

---

## 三步

1. 打开 `raw/`（原始文件）里对应的部门文件夹，把文件**直接拖进去**（可以整个文件夹拖）。
2. 在对话里说一句：**「语料放好了」**，如果只想先试一部分，就说「先只导财务部」。
3. 我会先跑一遍 `--dry-run` 把「将要导入多少篇、哪几篇可能有问题」列给你确认，你点头后再正式导入并跑隔离/召回验收。

---

## 文件夹怎么分

| 文件夹 | 放什么 | 谁能看到 |
|---|---|---|
| `raw/global/` | 全公司通用：员工手册、考勤制度、报销总则、公司简介 | 所有部门 |
| `raw/dept_finance/` | 财务制度、预算口径、科目说明 | 财务部 |
| `raw/dept_sales/` | 销售政策、报价规则、客户分级 | 销售部 |
| `raw/dept_hr/` | 招聘流程、绩效办法、薪酬等级 | 人事部 |

需要加部门（比如「法务部」）？跟我说部门名，我建好文件夹并同步权限映射。
文件夹名字用英文只是为了避免中文路径在某些工具里乱码，**里面放中文文件完全没问题**。

`converted/` 是我转换出来的纯文本，**不用管，也不要手动改**。

---

## 能直接放的格式

| 格式 | 能不能 | 说明 |
|---|---|---|
| `.docx` Word | ✅ | 正文段落 + 表格都会抽出来 |
| `.xlsx` Excel | ✅ | 每个工作表转成一段文字，保留表头 |
| `.pdf` | ✅ | 只抽文字层；**扫描件/图片 PDF 抽不出字**，需要 OCR（另行安排） |
| `.txt` / `.md` / `.csv` / `.html` | ✅ | 原生支持，不用转 |
| `.doc`（老 Word） | ❌ | 请用 Word 打开另存为 `.docx` |
| `.xls`（老 Excel） | ❌ | 请另存为 `.xlsx` |
| 图片 / 扫描件 / 压缩包 | ❌ | 先别放，需要的话告诉我，我单独处理 |

---

## 请不要放这些

- 员工身份证号、银行卡号、手机号清单、薪资明细等**个人信息**
- 客户合同原件、报价底价、未公开的财务数据（除非明确要进知识库并已确认可见范围）
- 带密码的加密文件（打不开，会被记为失败）
- 任何标注「绝密 / 禁止外传」的材料

拿不准某份文件能不能放，**先单独问我一句**，不要整批拖进来。

---

## 安全说明（重要）

- `raw/` 和 `converted/` 已经写进项目 `.gitignore`，**不会被提交到 GitHub、不会进任何备份包**。
- 导入后的语料按部门/角色过滤（平台第 18 章单一过滤点），跨部门不会被检索到。
- 每次导入都会留审计日志（谁、什么时候、导了哪些文件）。
- 导入前我会把清单给你确认；任何时候说「撤销这批」，可以整批删除。

## 我这边会跑什么（给你看个底）

```
# 1) 原始文件 → 纯文本（保留部门目录结构）
scripts/convert_corpus.py --src ../corpus_inbox/raw --out ../corpus_inbox/converted

# 2) 先干跑，不写库，给你看清单
scripts/ingest_corpus.py --dir ../corpus_inbox/converted/global --scope global --dry-run

# 3) 你确认后正式导入（按部门分别跑）
scripts/ingest_corpus.py --dir ../corpus_inbox/converted/global --scope global --role platform_admin
scripts/ingest_corpus.py --dir ../corpus_inbox/converted/dept_finance --dept d_finance

# 4) 双部门隔离 + 召回验收
scripts/pilot_second_dept.py
```

这几条**不用你执行**，是我收到「语料放好了」之后做的事。
