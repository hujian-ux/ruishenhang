## 一、为什么判定「不是智谱」

| 判据 | 智谱真 key | 这串 key |
|---|---|---|
| 形态 | `{api_key_id}.{api_key_secret}`，**点号分隔** | `sk-` + 48 位，**无点号** |
| 前缀 | 无 `sk-` | 有 `sk-` |
| 长度 | 约 65（32 + 1 + 32） | 51 |

智谱官方端点探活：

```
glm-4.6      -> 401 {"error":{"code":"401","message":"令牌已过期或验证不正确"}}
glm-4-plus   -> 401 同上
glm-4-flash  -> 401 同上
```

三个端点（`open.bigmodel.cn/v4`、`/v3`、`api.zhipuai.cn`）× 三个模型全部 401，
排除「模型名不对」「参数不对」，是**认证层**拒绝。

## 三、要跑真跑分，二选一

1. **给硅基流动充值**（推荐，最快）：控制台充值最低 10 元即可。本次验收两个技能包
   约消耗 1 万 tokens 量级，成本在 0.1 元以内，够跑几十轮。
   充完直接执行：

   ```bash
   cd backend
   .venv/Scripts/python.exe scripts/accept_real_llm.py \
     --vendor siliconflow --model zai-org/GLM-5.3 --key <你的key>
   ```

2. **换真正的智谱 key**：到 bigmodel.cn 控制台 → API Keys 生成，形如
   `xxxxxxxxxxxxxxxx.yyyyyyyyyyyyyyyy`（**带点号、不带 `sk-`**）。

   ```bash
   .venv/Scripts/python.exe scripts/accept_real_llm.py \
     --vendor zhipu --model glm-4.6 --key <智谱key>
   ```

两条路径代码都支持，无需改任何业务代码。

## 四、这轮顺手修掉的产品问题

拿到 key 之后就该一路跑通，不该在排障上耗时间。补齐三处：

| 问题 | 修法 |
|---|---|
| 只有「HTTP 402」原文，看不出是 key 错还是没钱 | `model_gateway.diagnose()` 把 401/402/403/404/429/5xx 翻成可执行结论，探活接口新增 `hint` 字段 |
| 401 原文只说 "Invalid Authentication"，不说「你打错门了」 | `scripts/check_key.py` 六家并测，直接给归属与可用性，退出码可进 CI |
| 硅基流动这类聚合通道要手写 base_url | `PROVIDER_PRESETS` 增加 `siliconflow` 预设，一个 key 可跑 GLM / DeepSeek / Qwen 做横向比效果 |
