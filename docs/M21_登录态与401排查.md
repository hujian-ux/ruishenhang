# M21 · 技能库加载失败（登录态三处漏点）

> 现象：技能库整页报「加载失败：unauthorized: missing caller context」，
> 右上角「模型未连接」，包数显示 0。三个症状，一个根因族。

## 1. 真正的原因有三层，叠在一起

### ① 前端 token 存在模块级变量里，热更新即丢

`client.ts` 里 `let token = ""`，只在 `main.tsx` 启动时 `setToken()` 一次。
Vite 热更新重新执行 `client.ts` 时这个变量被清空，而 `main.tsx` 不会跟着
重跑 —— 此后**每个请求都不带 Authorization**，后端只能回 401。

这也解释了为什么「改完代码就这样了」：不是改坏了功能，是登录态被热更新冲掉了。

### ② dev token 只有 2 小时

`create_dev_token` 写死 `exp = now + 7200`。演示从下午做到傍晚就全线 401，
而页面上看不出是过期，只看到一屏「加载失败」。

### ③ 401 只有一句话，分不清原因

`deps.py` 无论「没带 token」还是「token 过期/验签失败」都报
`unauthorized: missing caller context`。排障时没法判断该重新登录还是查请求头。

## 2. 修法

| 位置 | 改动 |
|---|---|
| `web/src/api/client.ts` | 每次请求惰性取 token：内存没有就从 `localStorage` 的会话里兜；401 时广播 `wb-unauthorized` |
| `web/src/Root.tsx` | 启动时判 `sessionExpired()`，过期直接进登录页并说明原因；监听 401 事件清会话回登录页 |
| `web/src/auth/session.ts` | 新增 `sessionExpired()`，同时解 dev token 与标准 JWT 的 `exp` |
| `web/src/pages/Login.tsx` | 支持 `notice`，把「登录已过期」写在登录按钮下方，而不是静默回登录页 |
| `backend/app/core/config.py` | 新增 `DEV_TOKEN_TTL_S`，默认 **12 小时**（环境变量可改） |
| `backend/app/deps.py` | 401 分两种文案：`missing token (未携带 Authorization)` / `invalid or expired token` |

关键取舍：**登录态不能只存在内存里**。前端任何模块级可变状态在热更新、
代码分割重载后都会归零，而它恰好是发请求的必要条件。存储是真源，内存只是缓存。

## 3. 验证

| 场景 | 期望 | 实际 |
|---|---|---|
| 新登录进技能库 | 115 个包 / 11 个岗位 / 模型已连接 | 通过 |
| 过期 token 打开任意页 | 登录页 + 「登录已过期（演示账号有效期 12 小时）」 | 通过 |
| 不带 Authorization | `missing token (未携带 Authorization)` | 通过 |
| 带过期/伪造 token | `invalid or expired token` | 通过 |
| 后端登录接口 | `expires_in = 43200` | 通过 |

后端测试 163 → **167 passed**；前端 tsc + build 通过。截图：`docs/验收/M21_登录态/`。

## 4. 一个必须说清的边界

**后端目前是内存模式**（无 PG），重启即清空，115 个包要靠
`scripts/seed_live_demo.py` 重新灌。本次排查中重启了两次服务，所以数据要
重灌一次才回来。

真上客户必须接 PG + Qdrant：`knowledge_scope=global` 的包落库后重启不丢，
现在的"重启就空、登录就 401"这类问题在正式环境不会出现。

## 5. 踩坑记录

- 在 `render` 里调 `clearSession()`：React StrictMode 会二次挂载，第二次
  渲染读不到 session，`notice` 当场变空，用户只看到普通登录页。已改为不清。
- `--dump-dom` 只输出顶层文档，**iframe 内的文本读不到**。用这种方式验证
  嵌入页面会误判成"提示没显示"，必须让页面脚本自己把结果打印出来。
