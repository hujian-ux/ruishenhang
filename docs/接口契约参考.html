POST/auth/sso/callbackauth

接收企业 IM 网页授权 code，换取员工身份与部门，并做设备绑定。
请求参数（路径 / 头）
字段类型必填说明
X-Caller-Contextheader否由网关从 Bearer Token 解析并注入，前端不可伪造。 格式：userId,deptId,role 经服务端签名，例 u_1024|d_sales|employee
请求体（application/json）
字段类型必填说明
providerenum(wecom, dingtalk, feishu)是
codestring是IM 回调授权码（一次性）
device_idstring是设备指纹，用于绑定与换机二次验证
statestring否防 CSRF
响应示例（200）
{
  "code": 0,
  "data": {
    "token": "<jwt>",
    "expires_in": 7200,
    "user": {
      "userId": "u_1024",
      "name": "张三",
      "deptId": "d_sales",
      "role": "employee"
    },
    "device_bound": true,
    "need_stepup": false
  }
}

POST/rag/retrieverag

与 PC 同一召回服务。网关注入调用者身份后，在召回阶段按 scope / owner / dept 过滤，仅返回授权片段。filtered_out 仅返回被过滤的越权片段计数（不返回内容）。
请求参数（路径 / 头）
字段类型必填说明
X-Caller-Contextheader否由网关从 Bearer Token 解析并注入，前端不可伪造。 格式：userId,deptId,role 经服务端签名，例 u_1024|d_sales|employee
请求体（application/json）
字段类型必填说明
querystring是用户自然语言问题（经脱敏后入参）
kb_scopeenum(all, department, personal)否仍受调用者身份约束
top_kinteger否
tenant_idstring是企业租户隔离
响应示例（200）
{
  "code": 0,
  "data": {
    "query": "五一活动话术",
    "hits": [
      {
        "doc_id": "doc_8831",
        "title": "五一营销活动方案 v3",
        "snippet": "建议分三档：① 到店礼 ② 满减 ③ 老带新",
        "scope": "department",
        "kb_tier": "department",
        "score": 0.91,
        "source": "产品手册 v3",
        "can_access": true
      }
    ],
    "filtered_out": 3,
    "trace_id": "trace_2026abc"
  }
}

POST/agent/invokeagent

调用者上下文随任务下发，Agent 调用的工具（如 rag_retrieve）同样走带权召回。 默认 SSE 流式返回，末帧为结构化结果。
请求参数（路径 / 头）
字段类型必填说明
X-Caller-Contextheader否由网关从 Bearer Token 解析并注入，前端不可伪造。 格式：userId,deptId,role 经服务端签名，例 u_1024|d_sales|employee
请求体（application/json）
字段类型必填说明
agent_idstring是
inputstring是用户输入（语音经 ASR 转写后传入）
streamboolean否
响应示例（200）
{
  "code": 0,
  "data": {
    "answer": "建议分三档执行五一活动：到店礼、满减、老带新……",
    "citations": [
      {
        "doc_id": "doc_8831",
        "title": "五一营销活动方案 v3",
        "scope": "department"
      }
    ],
    "tool_calls": [
      {
        "tool": "rag_retrieve",
        "authorized": true
      }
    ]
  }
}

POST/agentsagent

新建智能体。adapter_type 来自模型选型向导结论（第 35 章）；knowledge_scope 受 RBAC 与 单一过滤点约束（本人 / 负责人 / 部门 / 集团）。服务端以 caller 为准强制回填 owner_id / dept_id， 前端传入仅作展示，越权写被过滤点拦截。注册后进入待发布评审（第 35 章红线：缺选型不可发布）。
请求参数（路径 / 头）
字段类型必填说明
X-Caller-Contextheader否由网关从 Bearer Token 解析并注入，前端不可伪造。 格式：userId,deptId,role 经服务端签名，例 u_1024|d_sales|employee
请求体（application/json）
字段类型必填说明
agent_idstring否业务侧使用的智能体标识（路由键），缺省由 name 生成
namestring是智能体名称
adapter_typeenum(rule, ml_serving, llm, llm_retrieval, ml_llm_retrieval)是来自第 35 章选型向导结论。rule=规则引擎/传统ML；ml_serving=传统ML服务； llm=大模型；llm_retrieval=RAG（检索增强）；ml_llm_retrieval=数据分析+RAG 混合
descriptionstring是选型说明（为何选该 adapter）
knowledge_scopeenum(personal, owner, department, global)是多人知识库可见范围；服务端强制等于 caller 权限，越权写被过滤点拦截
model_idstring否选用的已注册模型（见 /models），可空由平台默认
selection_rationaleobject否选型向导上下文（仅记录，便于审计/评审）
响应示例（200）
{
  "code": 0,
  "data": {
    "agent_id": "contract_review",
    "status": "pending_review",
    "adapter_type": "llm_retrieval",
    "registered_by": "u_1024"
  }
}

POST/approval/{approval_id}/decideapproval

仅平台管理员 / 部门管理员 / 授权人可审批；操作人由网关解析，记录审计。
请求参数（路径 / 头）
字段类型必填说明
X-Caller-Contextheader否由网关从 Bearer Token 解析并注入，前端不可伪造。 格式：userId,deptId,role 经服务端签名，例 u_1024|d_sales|employee
approval_idpath是审批单 ID
请求体（application/json）
字段类型必填说明
decisionenum(approve, reject)是
commentstring否
响应示例（200）
{
  "code": 0,
  "data": {
    "approval_id": "ap_5502",
    "status": "approved",
    "decided_by": "u_admin_01",
    "decided_at": "2026-05-01T09:12:00Z",
    "audit_id": "audit_77"
  }
}

POST/kb/documentskb

受 RBAC 与 scope 约束。服务端强制以 caller 为准回填 owner_id / dept_id / scope， 前端传入仅作展示，防止越权写库（scope=department 时 dept_id 须等于 caller.deptId）。
请求参数（路径 / 头）
字段类型必填说明
X-Caller-Contextheader否由网关从 Bearer Token 解析并注入，前端不可伪造。 格式：userId,deptId,role 经服务端签名，例 u_1024|d_sales|employee
请求体（application/json）
字段类型必填说明
titlestring是
contentstring是正文（入库自动向量化）
scopeenum(personal, department, global)是global 仅平台管理员
dept_idstring否scope=department 时必填，强制等于 caller.deptId
响应示例（200）
{
  "code": 0,
  "data": {
    "doc_id": "doc_9001",
    "scope": "department",
    "owner_id": "u_1024",
    "dept_id": "d_sales",
    "indexed": true
  }
}

POST/modelsmodels

由平台管理员登记新模型。仅登记元数据与适配器标识，业务调用方通过 model_id 透明路由， 不感知底层厂商差异。参数仅平台管理员可写。
请求参数（路径 / 头）
字段类型必填说明
X-Caller-Contextheader否由网关从 Bearer Token 解析并注入，前端不可伪造。 格式：userId,deptId,role 经服务端签名，例 u_1024|d_sales|employee
请求体（application/json）
字段类型必填说明
model_idstring是
vendorstring是
adapterstring是
capabilitiesarray<string>是
context_windowinteger是
price_per_1k_promptnumber否
price_per_1k_completionnumber否
default_quotainteger否默认部门/智能体月度配额（token）
响应示例（200）
{
  "code": 0,
  "data": {
    "model_id": "claude-sonnet",
    "status": "active",
    "registered_by": "u_admin_01"
  }
}

GET/usageusage

返回指定维度的 token 用量与成本。维度支持 tenant / dept / user / agent / session。 用量数据受 scope 约束：部门只能查本部门，跨部门汇总仅平台管理员可见（cost 属敏感指标）。
请求参数（路径 / 头）
字段类型必填说明
X-Caller-Contextheader否由网关从 Bearer Token 解析并注入，前端不可伪造。 格式：userId,deptId,role 经服务端签名，例 u_1024|d_sales|employee
dimensionquery否
startquery否统计起始日（含）
endquery否统计结束日（含）

{
  "code": 0,

        "cost": 312.5,
        "quota": 1000,
        "quota_used_pct": 31.3
      },
      {
        "key": "d_design",
        "prompt_tokens": 640000,
        "completion_tokens": 410000,
        "cost": 188.0,
