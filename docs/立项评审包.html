★建议立项评审顺序

  1. 通读主蓝图：确认平台 + 模型双闭环的章节结构（第 1–44 章）。
  2. 看 AI 工程评审缺陷分析：理解为什么要补模型工程十章（P0×3 / P1×4 / P2×3）。
  3. 走接口契约 Swagger UI：确认后端契约，重点新增的 POST /agents 与各召回接口的单一过滤点。
  4. 走查高保真原型：从「选型」向导得出推荐 → 一键新建智能体 → 看知识库可见性实时预览 → 导出选型结论 JSON。
  5. 导入 Sprint 任务卡：把 P0 三章任务卡导入 Jira / 飞书多维表，进入第一迭代。
  6. 按需查阅附册：模型工程 / 生产化 / 平台扩展 / 移动端权限等细化文档。
提示：本页最佳通过本地服务器打开（已起 http://127.0.0.1:8000/立项评审包.html）；直接双击打开亦可，CSV 与 PDF 以文件形式下载/查看。
