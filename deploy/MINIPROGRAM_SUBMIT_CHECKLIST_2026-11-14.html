1. 代码与配置改动

  1. ☐ miniprogram/project.config.json："appid" 由 touristappid 改为真实 AppID 【必填】。
  2. ☐ miniprogram/utils/api.js：API_BASE 由 https://ai.your-domain.com 改为已 ICP 备案的 HTTPS 后端域名 【必填】。
  3. ☐ 微信公众平台 → 开发管理 → 开发设置 → 服务器域名：request 合法域名加入该 HTTPS 域名（仅 https，需备案）。如用 wx.login 换码，无需 socket/upload/download 额外配置。
  4. ☐ libVersion（当前 3.0.0）保持与基础库兼容即可，无需改。
  5. ☐ 本地联调：开发者工具勾选「不校验合法域名」→ 真机预览先用游客/测试。

2. 后端配套（小程序登录可用）

  1. ☐ 后端 .env 设 WX_MINI_LOGIN_ENABLED=1 + WX_MINI_APP_ID + WX_MINI_APP_SECRET（与小程序 AppID/AppSecret 一致）。
  2. ☐ 验证 POST /auth/wx/login 用真实 code 返回 token（参考 tests/test_m_auth_wx_login.py）。
  3. ☐ 若同时做身份收口，按 deploy/CASDOOR_CLOSURE_ENV_PATCH.md 启用 OIDC 并验证 SSO。

3. 功能自检

  1. ☐ 微信登录全链路：小程序 wx.login() → 后端换码 → 存 token → 跳聊天页。
  2. ☐ 会话：建会话、发消息、看回复；outputs 页能拿到 xlsx/docx/pptx/pdf 下载链接。
  3. ☐ enforce 分支：在 /auth/settings 返回 enforce_oidc=true 时，登录页自动走微信登录、隐藏演示入口。
  4. ☐ 不同机型 / 弱网 / 登录态持久化（重开小程序 token 仍在）。

4. 合规与隐私（审核重点）

  1. ☐ 隐私协议：上传《隐私保护指引》并配置隐私协议入口（登录前弹窗授权）。
  2. ☐ 用户授权：wx.login 属获取 openid，须在隐私协议与授权弹窗中明示。
  3. ☐ 内容安全：AI 生成文本/图片接入微信内容安全（msgSecCheck/imgSecCheck）或自有审核，避免违规下架。
  4. ☐ 不得诱导分享、不得强制关注、类目与功能一致。

5. 提审与发布流程

  1. ☐ 开发者工具导入 miniprogram/ → 上传代码版本（填版本号 + 备注）。
  2. ☐ 公众平台设为「体验版」，内部体验账号先走通。
  3. ☐ 提交审核：填写功能页面路径、测试账号（如有登录态）、类目资质。
  4. ☐ 过审后发布（建议先灰度 10% → 全量）。

6. 验收

  • 真机预览：iOS / Android 主流机型各一遍。
  • 崩溃监控：接入小程序自有异常上报或微信后台「运维中心」。
  • 回归：登录 → 建会话 → 产出物下载 全链路。
